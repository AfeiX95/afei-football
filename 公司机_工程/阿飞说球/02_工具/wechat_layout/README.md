# 公众号排版风格池（4套轮换）

> 用途: 阿飞·赛博聊球公众号深度版(MD)发布前的视觉排版。**骨架轮换管内容结构, 排版池管视觉呈现, 两个维度互相独立**。
> 规则: 相邻两篇公众号文章排版风格不重复(与骨架轮换同规则); 头条 Word 版不套此池(Word 排版由 docx 模板控制)。

## 使用流程

1. afei_generator 生成 `公众号_深度版.md`
2. 按当前轮换序号选一套风格(见各文件头部的"轮换记录"注释)
3. 用墨滴(markdown.com.cn)或壹伴导入 md, 粘贴对应 CSS 到自定义样式区
4. 发布后在本风格文件头部追加一行轮换记录

## 风格一览

| 风格 | 文件名 | 主色 | 气质 | 适合场次 |
|---|---|---|---|---|
| A 数据蓝 | style_A_data_blue.css | #1B4B8C 深蓝 | 理性/专业/可信 | 模型偏差大、数据卖点强(欧超杯/决赛) |
| B 对决红 | style_B_derby_red.css | #C0392B 红 + #1A1A1A 黑 | 对抗/悬念/热血 | 恩怨局、德比、淘汰赛生死战 |
| C 暖橙 | style_C_warm_orange.css | #E67E22 橙 + #FDF2E9 米白 | 叙事/温度/故事感 | 黑马故事、情怀局、首回合遭遇战 |
| D 墨绿 | style_D_pine_green.css | #1E6B52 墨绿 + #F7F9F7 灰白 | 沉稳/复盘/深度 | 赛后复盘、赛季总结、深度长文 |

## 轮换规则

- 每篇深度版记录一个 style(在 md 头部加 `<!-- style: B -->` 注释)
- check 相邻 2 篇: 骨架和排版风格都不得重复(骨架查 3 篇, 排版查 2 篇即可)
- 赛事类型优先: 决赛/强模型偏差→A; 恩怨/德比→B; 故事/黑马→C; 复盘/总结→D。类型冲突时以上一篇为准轮换

## CSS 兼容性

- 选择器按墨滴(markdown.com.cn)默认结构编写: `#content h2` / `#content table` 等
- 若用壹伴/秀米: 将 `#content` 前缀改为 `.rich_media_content` 或编辑器自己的容器类
- 微信正文不支持 `<style>` 标签, 必须通过第三方编辑器(墨滴/壹伴)的自定义 CSS 功能注入
- 所有颜色用 HEX, 字号用 px, 移动端 375px 宽度实测过(2026-08-11)

## 通用排版基线(所有风格共用)

- 正文 16px / 行距 1.75 / 字距 0.5px / 段距 18px
- 段落首行不缩进, 段间空一行
- 图片 100% 宽度圆角 8px, 图注 12px 灰色居中
- 表格 13px, 表头加粗, 斑马纹
- 强调用 `**加粗**` + 高亮色(每风格自定), 不用下划线(移动端难看)
- 链接: 深色带下划线, 勿用蓝色默认
