## ① 周日002 町田泽维 vs 柏太阳神 (让球 -1)

**我的 λ: 主 1.98 / 客 1.33 / 总 3.31** (市场总进球 2.82)

| | 我的 | 市场 | 差 |
|---|---|---|---|
| 主胜 | **52.5%** | 41.6% | +10.9pp |
| 平 | 21.8% | 27.5% | −5.7pp |
| 客胜 | 25.6% | 31.0% | −5.4pp |
| 让胜(町田赢2+) | **30.5%** | 18.8% | +11.7pp |
| 走水(町田恰好赢1) | **22.0%** | 23.6% | −1.6pp |
| 让负(町田不胜) | **47.4%** | 57.5% | −10.1pp |

**我的比分排序**: 1:1 **9.6%** / 2:1 **9.5%** / 1:0 7.3% / 2:0 7.2% / 1:2 6.4% / 2:2 6.3%

**走向判读**: **1:1 与 2:1 几乎并列第一**, 说明"平局"与"一球小胜"在同一个量级。
町田赢 52.5%, 但其中 **22.0pp 是只赢一球**, 赢两球以上 30.5%。
→ **盘面上的落点是"走水"最扎实**(我的 22.0% vs 市场 23.6% vs 历史基准 23.7%, 三方一致)。
→ **我倾向 1:0 或 2:1, 其次 1:1**; 2:0 有意思但不是首选。

⚠️ **这一场我的把握度较低**, 两个原因:
1. 我的总进球 3.31 高于市场上已验证无偏的 2.82 → 我可能整体算高了;
2. 町田主场攻击(3 场 6 球)收缩到赛季值 2.71 后变成 2.41, 而 2.71 本身是被**两场客场大胜**(0:4 千叶、1:5 东京FC)抬起来的 —— 用客场数据抬高主场估计, 逻辑上不干净。
   **若按纯主场 2.00 算, λ_主 降到约 1.79, 主胜降到约 47%, 让胜降到约 25%** —— 那就会更接近市场。
→ **所以我对 002 的实际倾向偏保守: 1:0 / 1:1 优于 2:1 / 2:0。**

## ② 周日003 大阪钢巴 vs 神户胜利 (让球 +1)

**我的 λ: 主 1.01 / 客 1.57 / 总 2.58** (市场总进球 2.69) —— **几乎重合**

| | 我的 | 市场 | 差 |
|---|---|---|---|
| 主胜 | 24.3% | 27.0% | −2.7pp |
| 平 | 25.3% | 26.4% | −1.1pp |
| 客胜 | **50.4%** | 46.6% | +3.8pp |
| 让胜(大阪不败) | **49.6%** | 52.4% | −2.8pp |
| 走水(神户恰好赢1) | **24.2%** | 25.7% | −1.5pp |
| 让负(神户赢2+) | **26.2%** | 21.9% | +4.3pp |

**我的比分排序**: 1:1 **12.0%** / 0:1 **11.9%** / 1:2 9.4% / 0:2 9.4% / 1:0 7.7% / 0:0 7.6%

**走向判读**: **1:1 与 0:1 并列第一**, 都是低比分; 前三里两个是神户赢、一个是平。
总进球 2.58, 0-1 球占 27.2%、2-3 球占 46.9%。
→ **我倾向 0:1 或 1:1, 其次 1:2**; **看好这场是"神户一球小胜或平"的闷战**。
→ 让球 +1 上, "大阪不败"49.6% 与"神户赢两球以上"26.2% —— 我比市场略高看神户, 但差距在 4pp 内, **不构成反向**。

✅ **这一场我的把握度较高**: 我的 λ 总量、三项胜平负、三项让球落点, **全部落在市场值的 4pp 以内**。
说明去掉模型的 form 加成与防守惩罚二次计入之后, 剩下的分歧可以忽略。
→ **这场我更愿意相信"低比分小胜"这个剧本, 而不是任何一边的大胜。**

| | 002 | 003 |
|---|---|---|

| 与市场差 | **+0.49 偏高** | −0.11 吻合 |
| 最可能比分 | 1:1 / 2:1 | 1:1 / 0:1 |
| 我倾向的比分 | **1:0、2:1** | **0:1、1:1** |

**这正是我在文章里写进去的那句话 —— 两场唯一没有分歧的位置。**

**如果只让我挑一个比分**: **003 的 0:1**。理由是这场我的数字与市场高度一致, 且神户客场三战
(神户视角: 2:0 胜东京绿茵、0:1 负横滨水手、1:0 胜福冈黄蜂)**的总进球都没超过两个**,
"客场一球小胜"是它本赛季客场最稳定的形态。

**如果让我挑一个最不确定的**: **002 的町田能否赢两球**。我的 30.5% vs 市场 18.8%,
差距 11.7pp 全部来自"客场上限被当成主场上限"这一个口径问题 —— 这一点我自己都没说服自己。
