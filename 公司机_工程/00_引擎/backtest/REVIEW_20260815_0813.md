## 一、核心结论(倒金字塔)

1. **平局潮第三期,且是"比分平局"大爆发**: 30场里11场平局(36.7%), 且大量是**高比分平局**——3:3(兰斯/帕福斯)、2:2(伍尔弗/瓦尔韦克/基尔)这种对攻型平局, 不是上周的1:1闷平。大小球偏大。
2. **深热让球盘继续翻车**: 里斯本(-2)只赢1球、赫拉克勒(-1)3:2、新未来(-1)2:1、克拉约瓦(-1)2:1、雷克维京(-1)3:2——**让1球以上全部输盘**。唯一赢盘的是圣埃蒂安(-1)3:1、埃夫斯堡(-1)3:0、达曼协定(-1)4:2。
3. **市场最高方向命中率回升**: 主队深热大量兑现(里斯本3:2、圣埃蒂安3:1、埃夫斯堡3:0), 但**让球盘(-1)仍是重灾区**——赢球≠赢盘, 深热赢1球是常态。
4. **两场出稿文章验证: 模型"高估预警"继续有效**——流浪者vs比亚韦市场1.54主胜未兑现(实际1:1), 帕福斯vs萨尔茨堡3:3平。

## 二、出稿文章验证(2场本地config对照)

### 1. 流浪者vs比亚韦(欧联资格赛3次回合) — ✅ 文章核心判断命中

| 项 | 值 |
|---|---|
| 实际比分 | 1:1(半场1:0), 总比分2-2进加时 |
| 模型 | 主27.3% 平24.3% 客48.4%(最高客胜) |
| 市场 | 主57.6%(1.54) 平22.7% 客19.7% |
| 文章首选比分 | **1-1(11.4%)→ 精确命中** |
| 文章核心论点 | "1.54主胜被高估30.3个点" → **完全正确,流浪者没赢** |
| 让球盘(-1) | 实际1:1,让球后平局,让球主胜未打出 |

**教训/验证**: 模型+文章对"市场高估流浪者主场翻盘"的判断经受住了考验。市场1.54隐含57.6%主胜, 实际流浪者连90分钟胜利都没拿到——**"高估预警"类标题(模型低主胜 vs 市场高主胜)是可信的**。

### 2. 帕福斯vs萨尔茨堡(欧联资格赛3次回合) — ⚠️ 半对半错

| 项 | 值 |
|---|---|
| 实际比分 | 3:3(半场帕福斯2:0领先!), 萨尔茨堡总比分4:3晋级 |
| 模型 | 主20.6% 平21.4% 客57.9%(最高客胜) |
| 市场 | 主29.1% 平25.7% 客45.2%(最高客胜) |
| 文章论点 | "萨尔茨堡客场比市场定价更稳" → **客胜未兑现,3:3平** |
| 大2.5球 | 模型60.2% → 实际6球 ✅ 命中 |
| 帕福斯翻盘威胁 | 半场2:0领先, 一度触及"净胜2+直接晋级"剧本 → 文章的翻盘路径分析是对的 |

**教训**: 模型看客胜方向没错(萨尔茨堡确实晋级), 但"3:3平局"暴露了萨尔茨堡客场的防守软肋——帕福斯半场2-0就是证据。**"客队稳"的结论在欧战客场要打折, 保平即可的球队心态≠防守稳健**。

## 五、对写稿的落地建议

1. **"高估预警"标题继续用**: 流浪者vs比亚韦验证了"模型低主胜 vs 市场高主胜"= 高估预警可信。这类场次标题写"市场高估XX点"安全且命中率高
2. **"客队稳"结论要打折**: 帕福斯vs萨尔茨堡教训——欧战客场"保平即可"的球队, 防守未必稳(半场0-2落后)。写"客队稳"前先看客队客场防守数据
3. **深热让球盘(-1)三期全翻车**: 写盘路分析时, 深热(-1)场次默认"赢球不赢盘"剧本——比分演算倾向写"小胜1球/平局"
4. **平局剧本结构变了**: 上周写闷平(1:1/0-0), 这周要写对攻平(2:2/3:3)——大2.5球平局是当前主流, 大小球叙事别只写小球
