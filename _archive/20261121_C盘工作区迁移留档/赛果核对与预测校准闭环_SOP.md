# 赛果核对与预测校准闭环 SOP（自动化反哺版 v1.0）

> 定位：把原工作流 S5「复盘反哺」从**描述性复盘**升级为**可自动执行的量化校准闭环**。
> 一句话：**赛果自动核对 → 偏差自动纠正 → 变差自动归因 → 参数自动反哺下一期分析预测**。
> 配套资产：`预测校准台账.xlsx`（数据载体）、`.足球预测共识分析框架.ref/reconcile.py`（执行引擎）、`26167期_内部分析报告.html` 第 8 章（接口）、`赛果核对与预测校准闭环_总览.html`（速查）。
> 版本：v1.0 ｜ 首个挂载期：第 26167 期 ｜ 生成 2026-11-21

---

## 0. 为什么需要这一层

原 S5 只做「奖期概览 → 逐场冷热归类 → 奖金成因 → 跨期预警」，产出的是**文字结论**，无法回答三个问题：

1. 上一期到底**准不准**，准到什么程度？
2. 哪些环节正在**变差**（不是哪场输赢，而是预测能力衰减）？
3. 变差之后，**下一期该改哪个参数**？

本闭环把这三点全部量化、可计算、可定时执行，并把结果写回 S1 的权重参数与 S3 的结构校验，形成真正的自我纠偏。

**「变差」的定义（关键）**：指**预测校准度衰减**，不是单场结果不利，也不是某期没中奖。判定依据是滚动窗口内的统计指标越过阈值，且必须可归因、可验证。

## 1. 数据流与三种触发入口

```
赛前预测基线（S1–S3 产出，冻结）
        ↓  登记到 01_赛果核对台账 A–K / U / V 列
开奖 / 赛果公布
        ↓  录入 L（3/1/0）、M（实际比分）两列
reconcile.py 自动核对
        ↓
指标计算 → 变差信号判定 → 纠偏建议 → 变差总结
        ↓  --write-back（需人工确认参数版本）
06_反哺参数出口 → 下一期 S1 权重 / S2 阈值 / S3 结构
```

| 入口 | 触发条件 | 执行方式 |
| --- | --- | --- |
| A · 赛果开奖单期页 | 用户打开赛果页或说「核对赛果」 | 手工录入 L/M 列后运行 reconcile.py |
| B · 定时任务 | 每期开奖后固定时点 | 定时任务调用 reconcile.py，输出变差总结与参数建议 |
| C · 手工补录 | 历史期次批量回填 | `--input results.json` 批量导入 |

## 2. 第一层：赛果核对

### 2.1 冻结原则

赛前预测基线一经登记即**冻结**。开奖后只允许填写 L、M 两列，**严禁反向修改 A–K 的预测方向、概率、把握层次与信号**。否则校准就变成事后诸葛亮。

### 2.2 字段字典（`01_赛果核对台账`）

| 列 | 字段 | 性质 | 说明 |
| --- | --- | --- | --- |
| A–D | 期号 / 场次 / 联赛 / 对阵 | 基线 | 与 S0 锁定清单一致 |
| E | 预测方向 | 基线 | `3` 主胜 / `1` 平 / `0` 客胜，取去水后隐含概率最大项 |
| F–H | 预测主/平/客概率 | 基线 | 欧赔比例法去水 `qᵢ=(1/oᵢ)/Σ(1/o)` |
| I | 把握层次 | 基线 | 最敢碰 / 赢面在但卡壳 / 最值得防平博冷 / 最不敢碰 |
| J | 共振信号 | 基线 | 共振 / 背离 / 数据不足 |
| K | 预测比分区间 | 基线 | S3 比分方案给出的比分串，未给则留空 |
| **L** | **实际赛果** | **录入** | `3/1/0`，延期或腰斩填 `*` |
| **M** | **实际比分** | **录入** | 如 `2-1` |
| N | 方向命中 | 计算 | `E=L` 记 1，否则 0 |
| O | Brier | 计算 | 三项 `(qᵢ−yᵢ)²` 之和，越小越好 |
| P | LogLoss | 计算 | `−ln(q_实际项 + 1e-6)` |
| Q | 实际项概率 | 计算 | 赛前赋给真实结果那一档的概率 |
| R | 信心偏差 | 计算 | `qmax − q_实际项`，衡量「错得多自信」 |
| S | 比分命中 | 计算 | 实际比分是否落在 K 的比分串内 |
| T | qmax | 计算 | 该场最高隐含概率，用于高置信分层 |
| U | 任九状态 | 基线 | 单选 / 双选 / 剔除 |
| V | 备注 | 基线 | 采集时点、数据源、特殊说明 |

### 2.3 三层核对

1. **方向层**：预测方向 vs 实际 1X2，得命中率；按联赛、把握层次、共振信号、任九状态分组拆解。
2. **概率层**：Brier（校准度）、LogLoss（对错误的惩罚）、实际项概率、信心偏差；做概率分箱校准（把 q 分成 0–0.3 / 0.3–0.5 / 0.5–0.7 / 0.7–1.0 四档，比对每档预测均值与实测命中频率）。
3. **方案层**：比分命中率、任九单选/双选/剔除三组的命中率、方案覆盖注数与实际回报结构。

### 2.4 汇总指标（`03_期次汇总`）

期号级共 24 项：有效场数、方向命中数与命中率、平均 Brier、平均 LogLoss、平均实际项概率、平均信心偏差、比分命中率、实际 3/1/0 占比、平均预测平局概率、四组分层命中率（最敢碰 / 共振 / 背离 / 数据不足 / 剔除 / 单选）、高置信场数与未命中率，以及三个**倒挂差值**（见 3.2）。

## 3. 第二层：自动纠正

### 3.1 四类纠偏动作

| 动作 | 输入 | 规则 | 约束 |
| --- | --- | --- | --- |
| **A · 来源权重纠偏** | 各来源滚动命中率 | `系数 = clamp(命中率 / 基准命中率, 0.60, 1.50)`，`建议权重 = 基线权重 × 系数` | 最小样本 30 场；单期调整 ≤ 20%；缺席来源不降权 |
| **B · 判定阈值纠偏** | 实测价值/回避标签兑现率 | 价值阈值 `+5%`、回避阈值 `−5%` 按实测回撤微调；完整度阈值 `60%` 按「低完整度场实际命中率」复核 | 单次调整 ≤ 1 个百分点；需连续 2 期同向才生效 |
| **C · 结果偏置纠偏** | 预测 3/1/0 频率 vs 实测频率 | 指数平滑 `bias ← 0.7×bias + 0.3×(实测−预测)`，下期加到共识概率 | 单期幅度 ≤ 0.03；偏置绝对值上限 0.08；只用于内部量化层 |
| **D · 剔除规则纠偏** | 剔除场 vs 单选场命中率倒挂 | 若剔除组反而更准，下期减少剔除场数或重排剔除优先级（优先剔除「数据不足且命中率最低」） | 需 ≥ 3 期样本；不得单期翻转整套 S3 结构 |

### 3.2 三个「倒挂差值」（本闭环最有价值的信号）

- `W = 剔除场命中率 − 单选场命中率`：正常应为负。**转正说明剔除规则正在变差**，把该剔除的留着、把该留的剔了。
- `X = 最敢碰命中率 − 数据不足命中率`：正常应为正。**收窄或转负说明把握层次排序失效**，「该赢 vs 真赢得」的拆解没拉开层次。
  > 口径：`最敢碰` 按把握层次字段**精确等于**「最敢碰」计（26167 期为 2 / 6 / 9 / 13 四场）；11 号「最敢碰（但赔率已低）」单独分层，不计入本组，避免与报告第 3 章口径打架。
- `Y = 实际平局占比 − 平均预测平局概率`：持续为正说明**系统性低估平局**，需给平局偏置。

### 3.3 防过拟合硬规则

1. 单期结果**不得**触发大幅参数变更；所有权重调整需滚动窗口 ≥ 30 场。
2. 缺席来源（本期未取到）不参与评分、不降权，只标「无样本」。
3. 延期/腰斩（`*`）场次不进入任何指标计算，单独登记。
4. 纠偏只写「建议值」，参数版本由人工确认后才生效；默认 dry-run。
5. 严禁用赛果反向修改已发布预测或已交付报告。

### 4.1 判定口径

`04_变差监控` 共 11 条信号，统一格式：`当前值 → 与基线 ± 容差比较 → 变差 / 正常 / 数据未齐`。

| --- | --- | --- | --- | --- | --- |
| 1 | 方向命中率衰减 | 汇总 D | 0.45 | 低 | 0.08 |
| 2 | Brier 上升 | 汇总 E | 0.60 | 高 | 0.05 |
| 3 | LogLoss 上升 | 汇总 F | 1.00 | 高 | 0.15 |
| 4 | 实际项概率下降 | 汇总 G | 0.45 | 低 | 0.05 |
| 5 | 信心偏差扩大 | 汇总 H | 0.20 | 高 | 0.05 |
| 6 | 比分命中率衰减 | 汇总 I | 0.20 | 低 | 0.08 |
| 7 | 高置信倒灶率上升 | 汇总 V | 0.15 | 高 | 0.10 |
| 8 | 共振兑现率下降 | 汇总 O | 0.55 | 低 | 0.10 |
| 9 | **剔除规则倒挂** | 汇总 W | 0 | 高 | 0.05 |

> 基线为首版参考值，跑满 5 期后用「近 5 期滚动均值」替换，替换动作写入参数版本记录。

### 4.2 六类变差归因

| 归因 | 典型表现 | 纠正方向 |
| --- | --- | --- |
| 数据缺口型 | 数据不足场命中率异常、来源覆盖数低 | 补来源，不调权重；扩 S1 必查清单 |
| 来源失效型 | 某来源滚动命中率持续低于基准 | 按动作 A 降权，观察 2 期 |
| 盘型漂移型 | 均势/次级联赛期与基线差异集中 | 按盘型分组建独立基线 |
| 赛季阶段型 | 国际比赛日后、冬歇前后集中变差 | 加时间衰减因子，不永久改权重 |
| 临场信息型 | 高置信倒灶集中在首发/天气未复核场 | 停售前 22:00 强制二次定盘与临场名单复核 |
| 过拟合型 | 参数频繁调整但指标不改善 | 冻结参数 3 期，回退到上一稳定版本 |

（逐项列出 24 项汇总指标中的关键 8 项）

## 二、触发的变差信号
（逐条：信号名、当前值、阈值、越界幅度）

## 三、归因
（六类归因中命中哪几类，附证据：哪几场、哪组分层导致的）

## 7. 全程硬规则

1. **不追溯**：赛果只用于下一期纠偏，绝不反向修改已发布预测与已交付报告。
2. **不编造**：赛果未录入、来源未取到时一律留空，标「数据未齐」，不估算、不填充。
3. **最小样本**：权重类调整需 ≥ 30 场滚动样本；结构类调整需 ≥ 3 期。
4. **幅度上限**：单期权重 ≤ 20%、偏置 ≤ 0.03、阈值 ≤ 1 个百分点。
5. **默认 dry-run**：`--write-back` 必须显式指定，且需人工确认参数版本。
6. **缺席不罚**：未取到的来源不降权、不计入命中率分母。
7. **内外双轨不变**：纠偏只在内部量化层生效，对外合规口径不受影响。
8. **预算硬约束不参与纠偏**：50 元上限与单注 2 元恒定。
9. **免责**：全部输出仅作数据观察与思路参考，控制仓位与过关风险。
