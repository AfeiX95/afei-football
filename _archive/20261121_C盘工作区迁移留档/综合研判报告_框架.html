0. 分析链路

1. 来源分级与默认权重

权重是起点，不是结论。建议积累历史样本后用命中率 / Brier 分数回测校准；单个来源连续失效时应临时降权并在报告中披露。

来源层级默认权重口径处理主要风险

分层合计：模型 50% ｜ 预测市场 25% ｜ 媒体 25%。外盘欧赔均值单独作为市场基准，不参与共识加权。

2. 计算口径

归一化p'ᵢ = pᵢ / (p_H + p_D + p_A)强制三项合计为 1，消除来源口径差异；只有三项齐全才计为有效来源。
欧赔去水（比例法）overround = Σ(1/均赔)
qᵢ = (1/均赔ᵢ) / overround均赔取多家公司算术平均；主胜赔率极差用于观察公司间分歧。
共识概率Pᶜᵒⁿ = Σ(wⱼ·p'ⱼ) / Σwⱼwⱼ 仅对有效来源求和，缺席自动剔除，等价于按参与来源重新归一。
偏离（edge）Δᵢ = Pᶜᵒⁿᵢ − qᵢ取绝对值最大的一项为主偏离；保留符号区分「价值」与「回避」。
分歧度σᵢ = √(Σw·p'²/Σw − (Pᶜᵒⁿᵢ)²)三项加权标准差取平均。越大说明各来源越分裂，共识可信度越低。
数据完整度C = Σw有效 / Σw全部低于最低完整度时不做价值判定，只标「数据不足」，避免小样本假信号。
优先级分30·C + 30·(1 − σ/σ_max) + 40·(|Δ|/0.15)0–100 截断；≥70 记 A，45–69 记 B，其余 C。仅用于排序，不是投注建议。
媒体倾向量化主胜倾向 55/27/18
平局倾向 30/40/30
客胜倾向 18/27/55仅在来源无数值概率时使用，必须在备注标注「媒体量化」，权重保持低位。

3. 判定规则

标签触发条件报告中的处理
高共识完整度 ≥ 60% 且 分歧度 ≤ 6%进入「高共识场次」章节，重点看与市场是否一致
高分歧完整度 ≥ 60% 且 分歧度 ≥ 12%进入「高分歧场次」章节，必须拆解分歧来自哪一层（模型 / 市场 / 媒体）
价值带符号最大偏离 ≥ +5% 且 完整度 ≥ 60%进入「价值场次」，须同时披露赔率时点与水位
回避带符号最大偏离 ≤ −5% 且 完整度 ≥ 60%列为市场比共识更乐观的场次，提示不要跟随模型
数据不足完整度 < 60%只做事实陈述，不给方向性结论

阈值均可在 Excel「04_权重参数」中修改；报告须注明本次采用的阈值版本。价值判定不等于可投注结论：还需复核赔率时效、公司水位、赛前伤停与首发。

4. 报告正文骨架

0报告信息
  • 数据截止：YYYY-MM-DD HH:mm　覆盖场次：N 场　口径版本：v1.0 / 自定义阈值
  • 赔率来源公司：公司名列表　采集时点：时点
1市场基准概览
  • 逐场列出欧赔均值、水位合计、去水后 1X2 隐含概率，标注水位异常（过高/过低）的场次。
  • 说明公司间主胜赔率极差：极差大 → 市场本身定价不稳，后续偏离要打折看待。
2共识总览表
  • 表格列：编号 / 对阵 / 有效来源数 / 完整度 / 市场 H-D-A / 共识 H-D-A / 主偏离 / 分歧度 / 共识标签 / 价值标签 / 优先级。
  • 数据直接来自 Excel「05_共识汇总」A–U 列，不重新手工计算。
3高共识场次
  • 逐场说明：共识方向、与市场一致 or 相反、支撑该共识的是哪一层来源。
  • 若高共识但与市场偏离小 → 属「市场已充分定价」，明确写出来，避免包装成机会。
4高分歧场次与分歧拆解
  • 定位分歧来源：模型层 vs 预测市场 vs 媒体层，列出具体来源的三项概率。
  • 说明可能的成因（伤停信息差、合约流动性、模型未更新、杯赛轮换），并标注为推断而非事实。
5价值 / 回避场次
  • 逐场给出：带符号偏离、对应赔率、凯利参考值 f* = (b·p − q)/b、数据完整度。
  • 必须列出反向风险：赔率是否已变动、共识是否被少数高权重来源主导、是否存在缺席来源。
  • 本框架不自动给出仓位建议；凯利值仅作参考，需自行决定是否采用分数凯利。
6数据缺口与风险披露（必填，不可省略）
  • 缺席来源清单及原因；被「媒体量化」处理的来源清单；预测市场合约的换算方式与价格时点。
  • 赔率与预测的采集时点是否一致；赛前信息（伤停、首发、天气、赛程密度）是否已反映。
  • 任何未验证的公开来源、无法抓取的页面，一律标注「未取到」，严禁用估计值填充。
7结论与优先级
  • 按优先级 A → C 排序，给出每场一句话结论；区分「高共识且有价值」「高共识但已定价」「高分歧需观察」「数据不足」四类。
  • 结尾声明：本报告为公开信息的结构化汇总与统计分析，不构成任何投注建议。

6. 使用方式

① 在 Excel 中按「01 比赛清单 → 02 外盘欧赔 → 03 来源预测」填入真实数据，按需在「04 权重参数」调整权重与阈值。

② 「05 共识汇总」自动出结果；核对状态看板中的已填场次、来源组数、高共识与价值场次是否合理。

③ 把填好的工作簿（或汇总表结果）交给我，按本骨架逐章生成正式研判报告，并补齐第 6 章的数据缺口披露。

当前模板预留 5 场比赛 × 10 个来源。若实际场次更多，告诉我场次数，我会按实际规模重新生成并把公式扩展到全部行。
