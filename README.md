# 阿飞说球

头条号「阿飞·赛博聊球」+ 公众号「AfeiX聊球」的足球赛事分析与内容创作项目。

## 项目结构

| 目录 | 用途 | 文件数 |
|:-----|:-----|:------:|
| `📚知识库/` | 写作指南、模型脚本、技能包、比赛分析、球队档案 | 289 |
| `📝文章/` | 按日期组织的已产出文章（分析报告+头条版+公众号版） | 45 |
| `database/` | Python数据分析脚本 | 44 |
| `⚙️工具/` | 辅助脚本（HTML生成、修复等） | 5 |
| `assets/` | 配图资产 | — |

## 核心能力

- **14维评分卡模型**：4大模块×14维度评分，修正泊松λ值，输出概率矩阵
- **八层写作铁律**：头条号合规+反AI检测+降AI+肉质化包装
- **全维度分析报告**：9节结构（赛事信息→评分卡→模型推演→剧本推演）
- **公众号矩阵方案**：主号+子号冷启动7篇选题框架
