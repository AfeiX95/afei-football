- 🚨 **坑#67 复现（第 3 次）**：模型 `P_model(让球盘)` 行仍是废数（印 让胜 7.0 / 让平 9.3 / 让负 83.7）→ **一律用 λ 自算 Poisson**。
- 自算脚本: `.uv-cache/score_synth_1009_002.py`（由 `score_synth_1009.py` 改 λ 与比分赔率而来）
  - 模型三格 **16.0 / 15.4 / 67.3**（让球方赢够 / 让平 / 受让方守住）
  - 模型大 2.5 球 **78.0%**（市场约 41%）→ 按**坑#36** 进球量**只用于比分排序**，不用于总量。
  - 模型最可能比分前六: **1:2 7.53% / 2:2 7.11% / 1:1 6.42% / 2:1 6.07% / 1:3 5.88% / 2:3 5.56%**
  - 净胜球分布(柏): +3 4.4% / +2 9.3% / **+1 15.4%(让平)** / **0 19.6%(受让方中)** / −1 19.1% / −2 14.3% / −3 8.5%
- **模型与市场的关系**：在“受让方守住”上**同侧**（67.3 vs 59.0，模型更极端）；**分歧**在让平（模型 15.4 vs 市场 23.3）与主胜（模型 31.6 vs 市场 40.4）。
- 结论口径：两边同侧 → 方向照给；分歧只影响比分档排序，**不印任何模型数字**。
