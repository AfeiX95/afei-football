### 日常纪律(每台机器, 三步)
```

```

## 五、注意事项(踩过的坑, 别再踩)

1. **换行符**: 本仓已设 `core.autocrlf=false` + `core.eol=lf` + `.gitattributes`; **新机器 clone 后不要改这两项**(改回 CRLF 会触发坑#53: 读 TSV 时行被静默跳过)。
2. **编码**: 批量改文件**禁用** `Get-Content -Raw`(PS 5.1 会把无 BOM UTF-8 当 GBK → 中文全毁, 坑#46); 一律 `[System.IO.File]::ReadAllText/WriteAllText(..., UTF8)`。
3. **`.venv` 不共享**: 每台机器用 `python -m venv .venv` + 基础解释器 pip 装 A 档依赖(见 `AGENTS.md` §0)。
4. **台账只追加、不重建**(坑#57 的教训): 冲突时**不要删别人的行**, 保留双方行并在备注里标注来源机器/时点。
5. **不要把令牌写进任何文件**: push 时输入一次即可(Windows 凭据管理器会记住)。仓库里**永远不要**出现密码/令牌。
6. **冲突怎么办**: `git pull` 报冲突时, 优先保 **"规则类文件"以最新日期那份为准**(`workflow.md` / `AGENTS.md` / `自改进总结`), 而**台账/日志类两边都留**(追加不覆盖)。拿不准就把冲突文件发我。
