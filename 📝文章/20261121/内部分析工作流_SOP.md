# 足球赛事内部分析报告工作流（整合优化版 v2.1）

> 定位：先做**内部分析报告**（决策用、全量化），再写**头条文章**（对外、合规口径）。
> 本版把原有 17 个报告模块、两份参考工作流（《足球情报与盘面预测》《传统足彩全流程工作流》）与已有工具资产串成一条可执行流水线。
> 核心增量：**模块路由、内外双轨口径分离、出稿交接过滤、复盘反哺**。
> v2.1 增量：S5 由描述性复盘升级为**自动化赛果核对 → 偏差纠正 → 变差总结 → 反哺预测**的量化校准闭环，详见 `赛果核对与预测校准闭环_SOP.md`。

## 2. S0 锁定输入

1. 核对当前网页可见内容：赛事编号 / 期号、停售与开赛时间、主客队排名、让球结构、14 场完整对阵（序号、联赛、主队 VS 客队、开赛日期）。
2. 确认四项输入：玩法（单场比分 / 14 场胜负彩 / 任选 9 场）、**预算上限 50 元**、出稿目标（是否要头条）、数据截止时点。
3. 登记「缺失位」：官方显示 `--` 或未开售的场次（常见于德乙、法乙、荷乙、挪超等次级或早场），标记为**必须搜索补齐外盘欧赔**，不得跳过。
4. 盘型归类（决定后续冷门权重）：
   - 纯五大联赛周末期：强弱分明，重点查强队轮换与德比冷门。
   - 周五/周一混杂及次级联赛期：均势局多、平局与冷门高发。
   - 周中欧战 / 洲际杯赛 / 国内杯赛期：重点排查战意、轮换与主场爆冷。
   - 国家队比赛日期：正路火锅与豪门翻车两极分化。

## 3. S1 客观数据层（先客观，后主观）

### 3.1 情报收集与正反面分栏

每场必须覆盖以下事实，且**有利情报与不利情报分两栏并置，每场至少保留一条核心反证**：

| 维度 | 必查内容 | 输出字段 |
| --- | --- | --- |
| 伤停 / 停赛 | 前场支点、做墙球员、中后卫防线缺阵；以官方最新公布为准 | 有利 / 不利情报 |
| 近期状态 | 主客场反差；**创造机会能力**与**射门转化效率**分开看 | 近期状态 |
| 赛程体能 | 近 7 天赛程、国际比赛日后加赛、双线三线作战、轮换深度 | 体能消耗 |
| 交锋心理 | 历史交锋记录、风格克制、排名悬殊下的反常记录 | 交锋心理 |
| 天气 | 雨雪、大风、高温对节奏与传控的影响 | 天气 |
| 积分形势 / 战意 | 争冠、欧战席位、保级、无欲无求、杯赛轮换 | 积分形势、战意 |

> 开赛前临场名单变动会改变体能与对位判断，须标注采集时间并按需重取。

### 3.2 盘面量化（内部报告专用）

- **百家欧赔对比**：多家公司 H/D/A 赔率、均值、公司间极差。
- **盘口变化**：只记录时间、方向、幅度三项事实；**禁止解读为机构主观态度或操盘意图**。
- **凯利指数**：记录数值与异常项，作为风险提示而非方向依据。
- 缺失场次：用搜索补齐主流外盘欧赔参考。
- 输出填入 `足球预测共识分析框架.xlsx` → `02_外盘欧赔`，自动完成去水（比例法）与隐含概率计算。

### 3.3 外部预测汇总

- 全球主流媒体：Goal、FootballWhispers、SportsGambler、Futbol24。
- 预测市场：Polymarket、Kalshi（登记合约标的、价格与三项概率换算方式）。
- AI / 数学模型：Google 数据模型、Forebet、Wincomparator、BetBuilders xG、OddAlerts。
- 输出填入 Excel → `03_来源预测`：三项概率齐全才算有效来源；**缺席整行留空，绝不填 0、绝不猜测**；媒体文字预测按倾向量化规则赋分并标注「媒体量化」。

### 3.4 多维共振总表（S1 强制产出）

统一表格，14 场（或当批全部场次）逐行列出：

`场次 | 联赛 | 对阵 | 官方/外盘欧赔 | 情报正反面 | 媒体与预测市场观点 | AI 与数学模型概率 | 共识概率/分歧度/完整度 | 综合定性`

必须标记三类信号：

- **多维共振**：赔率、情报、媒体、模型方向高度一致 → 稳胆 / 核心主选候选。
- **背离与冲突**：赔率与算法反向、多模型互打、情报与 AI 严重冲突 → 陷阱标注、任九剔除候选。
- **数据不足**：有效来源完整度低于阈值 → 只做事实陈述，不给方向结论。

## 4. S2 交叉验证与落差拆解

### 4.1 量化结论（取自 Excel `05_共识汇总`）

市场隐含概率、共识概率、带符号偏离、分歧度、数据完整度、价值 / 回避标签、优先级分。
硬规则：**外盘欧赔只作市场基准，不进入共识加权**（避免循环论证）；完整度 < 60% 的场次不做价值判定。

### 4.2 「该赢」与「真赢得」的落差

1. 对比账面实力优势与实际赢球条件是否齐备（体能消耗、伤停结构、交锋心理、战术执行条件）。
2. 按把握层次排序，必须明确点出：
   - **最敢碰**的场次；
   - **最值得防平或博冷**的场次；
   - **赢面在但过程容易卡壳**的场次；
   - **最不敢碰**的场次。
3. 禁止写出三个平行且同构的结论；多场同向时也必须拉开层次。

### 4.3 叙事字段（每场独立成文）

核心矛盾、胜负手、看点、综合分析（含核心反证）。
套用 `综合研判报告_框架.html` 的 0–7 章骨架，**第 6 章「数据缺口与风险披露」必填**：缺席来源、媒体量化项、预测市场换算方式、赔率与预测时点一致性、赛前信息是否已反映。

## 5. S3 50 元内投注比分方案

1. **纠偏与剔除说明**：列出因「赔率与模型背离」「多模型互打」「大热陷阱」被剔除或防冷的场次及理由。
2. **比分区间**：按小胜 / 平局 / 防冷比分给出合理区间，分「稳健」与「博弈」两套方向；每场附核心反证。
3. **玩法分支**：
   - 单场 / 少量场次比分方案：直接按比分区间组合。
   - 传足玩法：任选 9 场小额精选单（16–32 元）与 14 场复式思路两套；果断剔除 5 场最混乱场次、共振稳胆单选、双选名额投向「强队伤停/体能隐患局」与「次级联赛平局回补局」。
4. **精确核算（硬约束）**：单注 2 元，总注数 ≤ 25，**总金额 ≤ 50 元**。逐项列出注数拆解与合计，不得只写「约」。
5. **结构校验**：检查方案整体 `3/1/0` 配比是否符合本期盘型特征与近期回归节奏；核对注数、金额、场次覆盖，输出校验表。

## 6. S4 出稿交接：内部报告 → 头条文章

### 6.1 内外双轨口径分离（本版核心红线）

| 内容项 | 内部分析报告 | 头条正文 |
| --- | --- | --- |
| 具体赔率、盘口数字、支持率百分比 | 保留，集中在「量化校准区」 | **不写** |
| 凯利指数、隐含概率、模型概率数值 | 保留 | 不写，改为定性表述 |
| 机构态度 / 操盘意图 / 诱导解读 | **两者都不写**（只记盘口变化事实） | 不写 |
| 伤停、体能、交锋、战意、天气、积分形势 | 保留（事实表述） | 保留（事实表述） |
| 核心矛盾、胜负手、看点 | 完整 | 保留，但去结构化、去模板化 |
| 投注方向与比分 | 完整方案 + 金额核算 | 仅作思路参考，不承诺、不诱导、不写金额明细 |
| 数据缺口与免责 | 必填 | 保留精简版免责 |

> 交接单必须列出「采纳项」「因合规红线不采纳项」，以及**不得外发的内容清单**。

### 6.2 反工整与去 AI 味

- 避免连续多组严格平行排比句、避免完全相同的结尾模板。
- 用口语化、有层次的收尾点出最敢碰、最不敢碰或宁可博平的场次。
- 改稿优先压缩冗余修饰，保留事实依据与核心反证。

### 6.3 标点与篇幅节奏

- 控制破折号数量与长句长度；压缩冗余修饰。
- 错字校验：如「一球没进」而非「一分没进」；球队名、比分、伤停人名逐一核对。

### 6.4 终态校验清单（出稿前逐项打勾）

- [ ] 正文无赔率数字、盘口数字、支持率百分比
- [ ] 正文无机构态度 / 操盘意图解读
- [ ] 每场都有至少一条反证，多场结论不同构
- [ ] 字数、破折号数、最长句长度在约定范围
- [ ] 风险扫描：承诺性表述、诱导性表述、绝对化结论 = 0
- [ ] 采纳项 / 不采纳项清单已列
- [ ] 免责声明：投注方向与比分仅作数据观察与思路参考，注意控制仓位与过关风险

## 7. S5 复盘与历史校准（反哺下一期）

### 7.1 历史开奖宏观统计（历史列表页触发）

1. `3` / `1` / `0` / `*`（延期腰斩）的总场次、占比、场均个数，对比近 30 期与近 100 期趋势。
2. 奖金五档统计：头奖滚存（0 注）、500 万封顶、100–500 万、5–100 万、5 万以下火锅奖的期数与占比。
3. 实战规律：单期 ≥ 6 场平局与滚存/500 万的对应关系；超小火锅奖与主胜 ≥ 8 场的对应关系；结合最近 3–5 期判断处于「火锅连发后的反弹窗口」还是「大奖后的回调期」。

### 7.2 赛后单期复盘（赛果页触发）

统一模板：奖期概览（期号、开奖日期、联赛结构、胜/平/负分布、一二等奖注数与单注奖金）→ 逐场冷热归类表（绝对稳胆 / 预期内平局 / 心理小冷 / 核心大冷）→ 奖金成因 2–3 条核心逻辑 → 跨期联动与重合球队预警。

### 7.3 S5-C 自动化校准闭环（v2.1 新增，替代原「7.3 回写」）

由 `预测校准台账.xlsx` + `reconcile.py` 执行，规则全文见 `赛果核对与预测校准闭环_SOP.md`。四层：

1. **赛果核对**：赛前预测基线冻结登记；开奖后只录 L（3/1/0）、M（实际比分）两列，自动算方向命中、Brier、LogLoss、实际项概率、信心偏差、比分命中、qmax。
2. **自动纠正**：四类动作——A 来源权重纠偏（滚动命中率 × 系数，上下限 0.60–1.50、最小样本 30 场）、B 判定阈值纠偏、C 结果偏置纠偏（指数平滑，单期 ≤ 0.03）、D 剔除规则纠偏。
3. **变差总结**：11 条信号自动判「变差 / 正常 / 数据未齐」，六类归因（数据缺口 / 来源失效 / 盘型漂移 / 赛季阶段 / 临场信息 / 过拟合），输出变差总结与下期验证点。
4. **反哺预测**：参数建议写入 `06_反哺参数出口`，人工确认版本后回写 S1 权重、S2 阈值、把握层次排序、S3 剔除结构。

**三个倒挂差值**是核心观察量：`W = 剔除场命中率 − 单选场命中率`（应 < 0）、`X = 最敢碰命中率 − 数据不足命中率`（应 > 0.10）、`Y = 实际平局占比 − 平均预测平局概率`（应 ≈ 0）。

执行：`python3 _工具/reconcile.py --issue <期号>`；`--demo` 演示；`--write-back` 才回写 05/06 表。默认 dry-run，赛果未录入时只报「等待赛果录入」，不生成结论、不编造赛果。

### 7.4 回写

把复盘与校准结论回写到下一期：更新来源权重与共振阈值、修正盘型判断、校准 S3 的 `3/1/0` 结构校验参数、按 W 信号调整任九剔除场数。历史统计必须严格按页面实际展示赛果逐期核算；**纠偏只用于下一期，不追溯修改已发布预测与已交付报告**。

> 第 26167 期已在本闭环挂载：`26167期_内部分析报告.html` 第 8 章登记了 7 条可证伪断言与三个倒挂差值，作为开奖后的自动核验基线。

## 8. 全程硬规则

1. **信息准确优先**：缺失赔率与外部模型数据必须搜索补齐，不得估算凑数；伤停与首发以官方最新公布为准。
2. **先客观后主观**：S1 的多维对照未呈现前，不得输出综合结论与选场方案。
3. **严禁脑补未加载页面**：期号/清单未加载时先提醒补充。
4. **内外口径分离**：量化数据留在内部报告，头条正文走合规口径。
5. **每场必有反证**，多场同向必须拉开把握层次。
6. **预算硬上限 50 元**、单注 2 元，注数与金额精确核算。
7. **零机构态度解读**：盘口只记变化事实，不归因主观意图。
8. **免责**：全部输出仅作数据观察与思路参考，控制仓位与过关风险。
9. **不追溯**：赛果只用于下一期纠偏，不反向修改已发布预测与已交付报告；校准台账 A–K 基线列冻结。
10. **校准防过拟合**：权重调整需 ≥ 30 场滚动样本、结构类调整需 ≥ 3 期；单期权重 ≤ 20%、偏置 ≤ 0.03；缺席来源不降权、不计入分母。
11. **默认 dry-run**：参数建议需人工确认版本后才生效；`--write-back` 必须显式指定。纠偏只在内部量化层生效，不改变 S4 对外合规口径。
