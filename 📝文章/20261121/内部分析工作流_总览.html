6. 合规红线与硬规则

零赔率 / 零机构解读正文不写赔率、盘口数字、支持率；不把让球定价解读为机构主观态度。内部量化区例外，但同样禁止主观归因。
区分概率与可信度多场同向也要按体能、伤停、交锋、战术执行拉开把握层次。明确最敢碰 / 防平博冷 / 赢面在但卡壳 / 最不敢碰。
反工整去 AI 味避免连续平行排比与相同结尾模板，口语化收尾。改稿优先压缩冗余修饰，保留事实与核心反证。
标点篇幅与错字控制破折号与长句，核对「一球没进」类错字。球队名、比分、伤停人名逐一核对。
信息准确优先缺失赔率与模型数据必须搜索补齐，不得估算凑数。伤停与首发以官方最新公布为准，临场变动须重取。
预算硬约束单注 2 元、总注数 ≤ 25、总金额 ≤ 50 元。逐项列出注数拆解与合计，并校验 3/1/0 配比。

7. 出稿终态校验清单

  • 正文无赔率数字、盘口数字、支持率百分比
  • 正文无机构态度 / 操盘意图解读
  • 每场至少一条反证，多场结论不同构
  • 字数、破折号数、最长句长度在约定范围
  • 风险扫描：承诺性、诱导性、绝对化表述 = 0
  • 采纳项 / 不采纳项 / 不得外发清单已列
  • 免责声明：仅作数据观察与思路参考，控制仓位与过关风险
  • 复盘结论已回写：来源权重、共振阈值、盘型判断、3/1/0 结构参数
