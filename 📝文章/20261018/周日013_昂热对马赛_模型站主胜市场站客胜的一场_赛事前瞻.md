# 一场两边完全相反的球：昂热对马赛

周日的分歧榜上，有一场形态最特别：模型和市场站在对立面，而且这是三方里唯一的反向场次。

模型给主胜 47.4%，市场只给 30.4%；反过来，模型给客胜 26.8%，市场给到 43.9%。17.1 个点的差距，主胜与客胜两格完全对调。

## 三方各吃的是什么

三方是什么：后台模型、市场公开定价折算、外部媒体与接口算法。前两者是同一份赛果数据的不同算法，第三者是完全独立的另一套数据源。当三方里两方站一边、一方站另一边，纪律上只记不改。不是因为改不了，是因为没有依据改。

昂热的读数为什么和两边都不一样？看主客分离就明白。昂热近十场场均进 1.3 球、失 1.4 球，看着平平无奇；把主场样本单独拎出来，主场三场进 5 球、丢 2 球，两胜一平，主场效率明显高于整体。模型吃的是主客分离后的主场均值，市场吃的是「昂热是中下游球队」的整体印象，两边的输入根本不同。

马赛那边正相反。近十场场均进 2.1 球、失 1.3 球，整体数据优于昂热，但客场三场只进 2 球、丢 4 球，一胜两负。客场效率被整体数据盖住了，模型的读数低于市场，原因就在这儿。

外媒预报给马赛客胜，依据是阵容厚度与近期状态的对比；市场给客胜 43.9%，依据是同一层认知加上资金分布；模型给昂热 47.4%，依据是主客分离后的效率均值。三边吃的不是同一层数据，所以分歧不代表哪一方错了。

⚔️ 战意上，昂热要拿分脱离下半区，马赛要为欧冠席位稳住轮换，两边的目标都不允许放松。

💰 信号在小球与平局：大 2.5 球只有 47%，比分前两格 1-1 的 12.3%、1-0 的 11.5%，全在两球以内。两边都认为这会是一场低分对局。

战意这一层还能再拆。昂热目前在下半区，主场三场两胜一平是它最近的抢分窗口，这一场的三分价值比马赛高；马赛要为欧冠席位轮换，四天前的欧战消耗摆在那儿，客场的阵容厚度打折。模型的效率读数没吃轮换这一层，市场也没吃——两边都只看了联赛样本。这也是为什么这一场不能简单判定谁错：真正决定结果的可能是一个双方都没输入的变量。

三个比分全部在两球以内，大 2.5 球只有 47%。这种分布在低分对局里意味着：方向分歧的参考价值下降，球量共识的参考价值上升。真正能定这场的是谁先丢球，而这件事任何一方都没算。

## 值得看到开赛前

纪律上对这种形态有一条硬规矩：模型单独反向时只记不改。原因是主客分离的样本如果在五场上下，效率均值的置信区间很宽，一个主场 3 比 0 就能把主胜概率抬十个百分点。这种场次的值钱之处不在方向，在于它逼着去看样本量。

临场变化才是判断的依据：主胜那一格开始回抬，说明有没被读到的信息在修正市场的印象定价；市场继续往客胜压，说明叙事还在加码，模型这一侧暂时没有支撑。两种情况结论相反，所以这场值得看到开赛前。

再看一遍昂热的主场样本，就知道模型的 47.4% 有多依赖这三场。三胜一负之外的七场里，昂热的场均进球只有 1.1 个，主场的高效是小样本里的高光。模型的处理是按主客分离后的均值给，这是它一贯的做法，但在三场样本上，这个均值的置信区间宽到几乎不能用来反驳市场。市场给昂热 30.4% 的主胜，也不是精确计算，是印象定价。两个都不精确的数，差 17.1 个点很正常，难的是怎么用。
