# 一个主场火力全开，一个客场颗粒无收

周日分歧榜往后数，有两场的读法几乎一样：模型比市场更敢给一边，而且两边的依据都是同一类数据，主客分离。

一场是里昂对尼斯，模型站主队多 12.0 个点；一场是勒沃库森对弗赖堡，模型站客队多 16.0 个点。方向不同，逻辑同源：市场按整体印象定价，模型按分场景效率定价。

## 里昂这一场

模型给主胜 66.0%，市场只给 54.0%，差 12.0 个点。客胜一格模型 14.6%、市场 22.4%，方向一致指向主队。

读数的来源在主队主场：里昂近两个主场进 7 球、失 2 球，3 比 2 胜水晶宫、4 比 0 胜雷恩。模型的主队进攻期望被拉到 2.2，是全周日第二高的单一球队期望。法甲主场打出这个量级，市场只给五成四，说明市场把水晶宫那场的对手强度打了折，模型没有。

反过来看尼斯。这支球队近两个客场进 0 球、失 4 球，两场比赛一个球都没进。模型的客队进攻期望因此压到 0.9，是全场最低。一个主场场均三球半的队，碰一个客场两场零进球的队，模型把概率往主胜堆，市场还留着 22.4% 给客胜。

⚔️ 战意上，里昂要抢前二，尼斯要为欧战席位守客场，两边的目标都不允许放松。

💰 信号在大球与双方进球：大 2.5 球 76.5%，双方进球 69.1%，比分前三格 2-0 的 10.9%、1-0 的 10.1%、2-1 的 9.9%，三种比分两种是主队零封。
## 勒沃库森这一场

模型给主胜 44.2%，市场给 59.0%，差 14.8 个点全落在主胜；客胜模型 35.6%、市场 19.7%，差 16.0 个点。方向反过来了，模型站客队。

依据同样在主客分离。勒沃库森近两个主场进 4 球、失 0 球，2 比 0 胜莱比锡、2 比 0 胜采列，主场数据极干净；弗赖堡近十场场均进 3.3 球，是全周日场均进球最高的球队，客场 2 比 2 平法兰克福。模型看到的是弗赖堡的客场进攻仍在 3.3 的量级上，市场看到的是勒沃库森的主场零失球。

两边的输入不同，结论自然相反。模型把客队进攻期望给到 1.9，主队 2.2，两边几乎持平；市场反推法给客队只有 0.8，这就是 16 个点的来源。

⚔️ 战意上，勒沃库森要守住前四，弗赖堡要为欧战席位抢分，两队都是进攻型踢法。

💰 信号在大球：大 2.5 球 78.4%，双方进球 76.4%，比分前三格 2-1 的 7.4%、2-2 的 7.3%、1-1 的 6.7%，最可能的三个比分里两个是双方进球。

## 两场对照

| 场次 | 模型主/平/客 | 市场主/平/客 | 最大差距 | 方向 |
|:--|:--|:--|:--|:--|
| 里昂对尼斯 | 66.0 / 19.4 / 14.6 | 54.0 / 23.6 / 22.4 | 12.0 主胜 | 主胜 |
| 勒沃库森对弗赖堡 | 44.2 / 20.2 / 35.6 | 59.0 / 21.3 / 19.7 | 16.0 客胜 | 客胜 |

勒沃库森那一场挂着置信度减半的标记：客队胜率 35.6% 低于四成，同时分歧超过 8 个点，属于叙事驱动的高风险区。这类场次的处理方式是把方向当观察项，不当结论项。

两场的比分分布几乎没有重合：一场的榜首是主队零封，一场的榜首是双方进球。同样是十分点以上的分歧，落到比分上一个是小球，一个是开放局。分歧的方向能看出谁被低估，比分能看出低估到什么程度。

## 看结构

两场的共同点是主场数据都好看，差别在模型愿意为这种好看付多少。里昂的主场是联赛两连胜加一个欧战胜，模型给到 66%；勒沃库森的主场是两场零封，市场给到 59%，模型只给 44%。模型对前者的信任高于市场，对后者的信任低于市场。

差别的根源在对手。尼斯客场两场零进球是事实，弗赖堡十场 33 球也是事实。模型只认这两组数，市场还要掺进队名。掺队名的定价不会错得很离谱，但在十个百分点这个量级上，它不够细。

风险提示：勒沃库森那一场的客队客场样本只有一场（2 比 2 平法兰克福），单场样本撑不起 3.3 的场均进球。模型的客队期望有偏高可能，这一场的置信度减半不是客套。
