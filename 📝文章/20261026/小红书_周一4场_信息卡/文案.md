# 四场夜球：两场有话说，两场只摊账本

四张卡，四场球，都在后半夜。

圣克拉拉主场两场进四个、一个没丢，六成场次能零封对手；本菲卡客场三场进七个，四成场次没让对面破门。一边门关得死，一边门开得大。历史上五次交锋场均不到三球，平局两成，低比分四成——这场更像比谁先犯错。

布洛涅主场一胜六平三负，平局是它的拿手戏；兰斯客场四胜五平一负，正经联赛客场只输过一次。两队最近五场都是两胜两平一负上下，谁都不吃亏，可主场那支把比赛拖成平局的本事更大。

塞维利亚主场两场丢六个，奥萨苏纳客场两场丢九个，两边后防都在漏；可历史五次交锋四场总进球不到三个、平局四成。数据一边指向对攻，一边指向闷战，卡上把两面都摆出来了。

弗拉门戈主场六胜四平零负，主场两场只进一个球、零失球，赢法都是 1 比 0 和 0 比 0；米竞技客场两场丢四个。一支靠防守赢球的队，撞上一支客场漏得厉害的队，画面不难想。

卡上只放已经发生的事：近五场的进失与零封、同主客的赢平负、交锋的场均与小比分占比、半场的进球时段。谁强谁弱自己看，我不替你下结论。
