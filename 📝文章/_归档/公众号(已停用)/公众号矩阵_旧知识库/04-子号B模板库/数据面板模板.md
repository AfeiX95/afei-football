# 子号B数据面板模板

> 用于「足球数据实验室」子号B的数据可视化文章

---

## 标题公式

```
{联赛}{轮次}·{主队}vs{客队}·数据面板
```

**示例：**
- 挪超第15轮·罗森博格vs腓特烈·数据面板
- 瑞超第12轮·四场数据速查

## 设计规范

- **字体**：思源黑体 / 苹方
- **配色**：深色背景(#1a1a2e) + 白色文字 + 蓝色强调(#4fc3f7)
- **图表**：使用Python matplotlib或在线图表工具生成
- **尺寸**：900×1200px（手机阅读友好）
- **格式**：PNG图片，文件名格式：{日期}_{联赛}_{主队}vs{客队}.png
