# 阿飞文章风格库 — 防审美疲劳轮换方案

> 原则：4套差异化视觉模板 + 3种开头钩子 + 3种结尾风格
> 排列组合=4×3×3=36种变体，同一读者不会连续看到相同的排版

---

## 模板A — 红黑经典（当前主力）

```css
/* 表头: 深红 #8b1a1a */
/* 左框线: 红色 */
/* 底色: 白底 */
/* 风格: 沉稳专业 */
```
**适用：** 强强对话、焦点战
**使用频率：** 每4篇用1次

## 开头钩子 — 3种轮换

### 类型1 — 反差钩子
> "首尔联赛第一，主场胜率50%。金泉15场平了8场，主场0胜。这两个数据放在一起，排名突然就没那么有说服力了。"

### 类型2 — 数据锚钩子
> "卡尔马10场赢3场。厄格里特近8场联赛没赢过。两个数据加在一起，就是今晚20点这场瑞超的全部。"

### 类型3 — 故事性钩子
> "1998年，英格兰在阿兹特克输给阿根廷。28年后，他们又回来了——同一个球场，同一轮淘汰赛。"

---

## 结构方式 — 3种轮换

### A型 — 分场拆解（当前主力）
```
[总览表] → [场次1] → [场次2] → [场次3] → [一句话总结]
```

### B型 — 主题串联
```
[全篇一个核心矛盾] → [场次1是它的表现] → [场次2是它的变体] → [场次3是它的反例]
```
**适用：** 多场比赛有共同主题时

### C型 — 倒金字塔
```
[核心结论先出] → [为什么是这个结论] → [逐场数据支撑] → [不同之处]
```
**适用：** 单场深拆

---

## 结尾风格 — 3种轮换

### 类型1 — 硬立场（当前主力）
> "模型跑出来索尔纳45.1%，哥德堡31.9%。数据链条最干净的一场，直接就是答案。"

### 类型2 — 留白开放式
> "三场球每个方向都有自己的道理。90分钟之后，数据会给出最终答案。"

### 类型3 — 数据复盘式
> "今晚三场，模型概率加起来——埃夫斯堡50% / 索尔纳45% / 大2.5球64%。命中率？明早回来再看。"
