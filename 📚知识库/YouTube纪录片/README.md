## §1 细分市场与主题选择

**选赛道的三条硬线**（缺一条就换）

1. **搜索需求存在**：YouTube 搜索框输入主题词，自动补全出现 ≥3 个长尾变体（说明有人搜）。
2. **供给不饱和**：搜索结果前 10 条里，播放量中位数 < 50 万，且有 2–3 条是 1 年内发布 → 老片没垄断。
3. **无面孔可讲**：内容靠资料、档案、地图、数据、示意图就能撑住，不需要出镜。

**高留存的四类常青母题**

| 母题 | 为什么留人 | 例子方向 |
|---|---|---|
| 消失/失踪 | 天然悬念，结局可验证 | 失踪的航班、被抹去的城市 |
| 灾难复盘 | 因果链清楚，情绪重 | 工程事故、海难、空难 |
| 犯罪与骗局 | 好奇心缺口强 | 艺术造假、金融骗局 |
| 系统与规则 | 解释型满足感 | 一个行业怎么运转、一条法律的来历 |

**趋势主题**（可做但要快）：新事件发生后 48–72 小时内出复盘，超过一周流量断崖。

**竞争分析表**（每个候选赛道填一行）

| 频道 | 订阅 | 近 10 条均播 | 更新频率 | 平均时长 | 我们的切入差 |
|---|---|---|---|---|---|

**观众心理**：前 30 秒只回答两个问题——「这事和我有关吗」「接下来会发生什么」。好奇心缺口必须在 15 秒内打开，且**不能立刻关上**。

**验收**：每个选题必须能写出「一句话悬念」（≤25 字）+「一句话答案」（≤40 字）。写不出来，选题不过关。

## §2 研究系统

**收集工作流（每期 6–10 小时）**

1. 建资料夹：`research/<slug>/`，下设 `sources/`、`timeline.md`、`facts.md`、`quotes.md`。
2. 三个以上独立来源交叉：官方报告 / 主流媒体 / 学术或档案。
3. 每条事实在 `facts.md` 标注：结论、来源链接、可信度（A 官方 / B 主流 / C 单一来源）。
4. 时间线先于叙事：把事件按时间排好，再决定从哪一天切入（不按时间顺序讲是留人技巧）。

**事实核查红线**

- 只有 C 级来源的数字，正文不写具体数值，只说趋势。
- 涉及在世个人的指控，必须两家 A/B 级来源，否则不写。
- AI 生成内容（图像/声音）按平台要求标注。

**故事角度开发（同一素材的三种切法）**

- **因果型**：为什么会发生 → 适合灾难、事故。
- **人物型**：谁在中间做了决定 → 适合骗局、犯罪。
- **系统型**：这件事暴露了什么规则漏洞 → 适合行业、制度。

**研究提示库（可直接用）**

- 找出「官方说法」与「现场证词」不一致的地方（最强钩子）。
- 找出被反复引用但没人核过的数字（做核实就是差异点）。
- 找出时间线里「空白的 48 小时」（悬念素材）。

**验收**：能画出 12–18 个节点的故事大纲，其中至少 3 个节点是「反预期」。

## §3 脚本框架

**钩子（0:00–0:15）**
三种结构，任选其一，不要混：

1. **结果前置**：先给最反常的结果，再回到起点。
2. **缺失前置**：先给「少了什么」，再解释为什么重要。
3. **矛盾前置**：两个不可能同时成立的事实并列。

**叙事弧（纪录片四幕）**

| 幕 | 时长占比 | 任务 |
|---|---|---|
| 钩子 | 0–3% | 打开缺口 |
| 铺陈 | 3–25% | 建立人物/地点/规则，埋 2 个伏笔 |
| 升级 | 25–70% | 三次反转，每次抬高代价 |
| 收束 | 70–100% | 回答缺口 + 一个更大的余味 |

**紧张感节奏**：每 60–90 秒一个小悬念，每 4–6 分钟一次结构反转。悬念必须**在本集内回收**，不能靠「下集揭晓」硬拖（完播率会掉）。

**保留技巧**
- 章节点（chapter）用问题命名，不用名词。
- 每个段落结尾留半句（悬置），下一段开头接上。
- 数字只留三个：最大、最小、最反常。

**AI 脚本提示（模板）**

```
你是纪录片编剧。素材：<facts.md 摘要>。
要求：1) 15 秒钩子，用结果前置；2) 四幕结构，标出每幕时间码；
3) 每一幕结尾留一个未解问题；4) 全文只允许 3 个数字；
5) 不写旁白以外的内容（无镜头说明）。
```

## §4 视觉叙事

**素材来源与许可**

| 来源 | 许可 | 用途 |
|---|---|---|
| Archive.org / 各国国家档案馆 | 多为公有领域 | 历史影像、报纸、地图 |
| Wikimedia Commons | CC / PD，逐条看 | 照片、地图 |
| Pexels / Pixabay / Mixkit | 免费商用 | 空镜、氛围 |
| Storyblocks / Artgrid | 付费订阅 | 高质量空镜 |
| AI 生成图像/视频 | 平台要求标注 | 示意图、复原图 |

**红线**：新闻片段、影视片段、他人频道画面不做主力素材；必要引用控制在短片段 + 评论性使用，并保留来源。

**素材库工作流**：`assets/<slug>/{broll,stills,maps,ai}/`，文件名带来源与许可：`archive_1953_flood_publicdomain.mp4`。

**场景构图三规则**
1. 一镜一个信息点，不做信息堆叠。
2. 关键数字用满屏字幕卡（0.8–1.2 秒），不用角标小字。
3. 地图类镜头必须有「当前位置」标记，否则观众迷路。

## §5 旁白与叙述

**声音选择**：纪录片用中低音、语速 130–150 字/分钟，句尾下沉；不用上扬的「短视频腔」。

**节奏控制**：每 3–4 句留一次 0.4–0.6 秒停顿；反转句前留 0.8 秒。

**脚本到声音对齐**：先按「气口」切句，再逐句生成/录制；每段生成后立刻对时间码，避免整段重做。

**音频处理链**：降噪 → 高通 80Hz → 压缩（3:1）→ 轻 EQ（-2dB @ 300Hz）→ 限幅 -1dBTP；音乐床 -18 至 -22 LUFS，旁白 -16 LUFS。

## §6 编辑与打包

**节奏基线**
- 平均镜头长度 4–6 秒；信息密集段 2–3 秒。
- 每 40 秒一次「视觉换气」（全屏字幕卡 / 地图推近 / 色块转场）。
- 片头不超 8 秒，且必须包含钩子的第一句话。

**结构模板**：钩子 → 章节卡（问题式）→ 三段主体（每段含一次反转）→ 收束 → 结尾 15 秒（下一个问题的引子）。

**文字与动效**：统一两套字体（标题粗、正文常规）；数字卡统一底色与停留时长；转场只用三种（切、推、闪白）。

**调色**：档案素材做旧（降饱和 + 轻噪点），现代空镜保持中性；全片 LUT 一致，不做逐镜风格跳跃。

## §7 缩略图与标题

**缩略图三要素**：一个主体物（占画面 40%+）+ 一个方向性视觉（箭头/对比/裂痕）+ ≤4 个词的大字。人脸不是必需，**情绪靠构图**（暗角、对比、留白）。

**标题公式**（≤60 字符，前 40 字符承载信息）
- 结果式：`X 在 Y 分钟内消失，直到 Z 被发现`
- 疑问式：`为什么 X 从来没有 Y？`
- 反差式：`全世界最 A 的地方，却 B`

**A/B 测试**：同一视频准备 3 张缩略图，48 小时看 CTR；低于频道均值 20% 立刻换图。

## §8 增长引擎

**SEO**：标题含主关键词；描述前 2 行写清楚「这期讲什么 + 会看到什么」；章节时间码齐全；标签 8–12 个（主词 + 长尾）。

**上传节奏**：固定周更（同一天同一时间），系列化命名（`第 01 集`），播单按主题聚合。

**关键指标（周看）**

| 指标 | 及格线 | 说明 |
|---|---|---|
| CTR | ≥5% | 缩略图/标题质量 |
| 前 30 秒留存 | ≥70% | 钩子质量 |
| 平均观看时长占比 | ≥35% | 叙事与节奏 |
| 完播率 | ≥25%（10 分钟以上） | 收束质量 |

## §9 变现

1. **AdSense**：纪录片类 RPM 差异大（历史/犯罪偏高，泛科普偏低）；单条 10 分钟以上可放中插。
2. **数字产品**：素材包、研究模板、脚本模板（与频道主题强相关才卖得动）。
3. **联盟**：剪辑软件、素材库、AI 工具（只推自己真在用的）。
4. **会员/社区**：提供「未采用的档案」「加长版」。
5. **多频道扩展**：同一套 SOP 复制到相邻母题，不复制内容。

## §10 自动化与系统

**内容管道（看板六列）**：选题 → 研究 → 脚本 → 配音 → 剪辑 → 发布。

**SOP 要点**
- 每个环节有「交付物 + 验收标准」，不达标不流转。
- 提示词统一放 `prompts/`，按环节编号（`03_script_hook.md`）。
- 外包只外包「可验收」的部分（配音、剪辑、缩略图），研究与脚本不外放。

**扩展多频道的三个前提**：单频道稳定周更 8 周以上、CTR/留存达标、SOP 文档能交给新人照做。
