## 一、平台硬指标（先记死）

| 项 | 限制 | 备注 |
|:--|:--|:--|
| 简介 | **50 字以内（含标点）** | 超了会被 `…` 截断；App 输入框有实时计数，以它为最终准 |
| 昵称 | **2–24 字符**，**7 天只能改一次** | 想好了再改 |
| 改简介频率 | **≥1 周一次** | 频繁改会被判「账号不稳定」，影响曝光 |
| 联系方式 | **禁止** | 微信 / QQ / 手机号 / 邮箱 / 淘宝 / 拼多多等第三方引导 = 违规引流，实测有限流 7 天的案例 |
| 极限词 | **禁止** | 「最、第一、绝对、稳赚」这类 |

## 二、三条红线（本项目特有，比平台规则更严）

按 `📚知识库/公司工程/平台风控与自查.md` 的结论，简介里**永远不出现**：

1. **投注引导形状**：方向 + 比分的清单化承诺、命中率 / 稳赢 / 跟单 / 带单 / 上车 / 红单、任何「跟我走」暗示；
2. **任何联系方式与站外跳转**：不留微信 / 群 / 公众号 / 邮箱，也不写「私信领资料」（`私信` 本身就在软禁词表里）；
3. **博彩语义词**：彩票 / 竞彩 / 赔率 / 盘口 / 下注 / 投注 / 串关 / 水位 / 让球盘。

**正确姿势**（也就是我们被封后给平台的说法）：**「公开赛事数据的整理与呈现，不含投注引导」**——简介照这个口径写，就不会自己往「荐彩服务」上靠。

## 三、五版可直接抄的简介（都 ≤50 字）

**A 版 · 定版（推荐，40 字）**

```
只做公开赛事数据整理：近期战绩、主客场、交锋与六维对比。不做购买引导，理性看球。
```

**B 版 · 突出「看图」（42 字）**

```
用数据和图表拆比赛：三向概率、近期战绩、六维雷达。每场一张图，数据来自官方公开平台。
```

**C 版 · 突出复盘（36 字）**

```
赛事数据整理与复盘：赛前看数据，赛后对答案。只做公开数据整理，不做推荐。
```

**D 版 · 突出内容清单（40 字）**

```
欧冠/五大联赛数据卡｜核心矛盾·近期战绩·六维雷达·赛后复盘。数据来自公开平台。
```

**E 版 · 极简（26 字）**

```
公开赛事数据整理，用图表看比赛。不做推荐，理性看球。
```

| 版本 | 字数 | 适合 |
|:--|:--|:--|
| **A（推荐）** | 40 | 通用定版：把「数据整理 + 不做购买引导」写死，最安全 |
| B | 42 | 想突出「每场一张数据卡」这个内容形态 |
| C | 36 | 以后要重点做「赛前看数据 / 赛后对答案」的复盘流 |
| D | 40 | 想把联赛范围与栏目名写清，搜索关键词更全 |
| E | 26 | 只想要干净一句话 |

> ⚠️ 连「不含**投注**引导」这种否定句也别写进简介：平台的风险识别不看语义，见到那个词就记一笔。**对外写「不做购买引导」，对平台申诉时才用「不含投注引导」的完整口径。**
> 换行用 `·` 或 `｜` 分隔，不要用 emoji 堆砌（简介里 emoji 会被算字数，也不显专业）。

## 四、昵称 / 头像 / 背景

- **昵称**：`阿飞·赛博聊球`（沿用量、辨识度最高）。⚠️ 但要知情：跨平台同名同人设，理论上会被按「关联账号」看待（微信规则 3.13.1 关联账号可一并处置）。**要不要同名，见下面的二选一。**
- **头像**：用同一套视觉（米白底 + 墨黑字 + 赭石强调，和卡片一致），一眼看出是「数据卡」账号；别用真人模糊自拍。
- **背景图**：可以用一张卡片风格的数据图（例如六维雷达 + 一行小字「数据来自中国体育官方公开数据平台」），**背景图里同样不能放联系方式**。
- **简介里的自称**：统一 `阿飞`，别一会儿「小编」一会儿「我」。

**同名 or 隔离——你拍一个：**

| 方案 | 做法 | 好处 | 代价 |
|:--|:--|:--|:--|
| **① 同名（我建议）** | 昵称、头像、视觉全沿用 `阿飞·赛博聊球` | 品牌复用、涨粉快、卡片水印一致 | 跨平台关联、同主体同品类，属「关联账号」监管面 |
| ② 隔离 | 小红书另起名字与头像，简介不提头条号 / 公众号，不交叉引流 | 与现有产线解耦，单点被限不牵连 | 粉丝与品牌从零攒 |

> 无论选哪个：**都不要在小红书简介或笔记里写其他平台的名字**（跨平台引流是小红书明确的违规项，也是微信 3.29.2 判定的加重情节）。

## 五、怎么改（App 操作，1 分钟）

1. 打开小红书 → 右下「我」→ 头像下方「编辑资料」；
2. 「简介」里粘上面 A 版（先数一下字数，≤50）；
3. 昵称若也要改：**注意 7 天只能改一次**，确定再动；
4. 保存 → 回到主页刷新确认没被截断（末尾别丢「理性看球」这半句）。

## 六、改完之后（别做的事）

- **别一天改三次**：定版后至少放一周再看数据；
- **别在简介里加任何联系方式**，也别用谐音、拼音、图形暗示（「+V」「威信」这类同样会被识别）；
- **别把简介当免责声明堆满**：一段就够，长免责留给笔记末尾；
- 观察一个指标就够：**关注率 = 新增关注 / 主页浏览量**，低于 5% 再回头调价值点，一周最多调一次。
