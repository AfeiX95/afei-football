# 写作管线清单

> 发文前逐项检查，漏一项不发。

## 标题
- [ ] 日期+队名VS队名：钩子（≤30字）
- [ ] 多场合集：所有队名必须出现在标题里
- [ ] 没有"第一天""首战"等时间锚点——用"1/16决赛"等赛事轮次替代

## 正文
- [ ] 无"赔率""盘口""庄家"等博彩术语
- [ ] 无"蒙特卡洛""泊松"等具体模型名 → 统一"后台模型"
- [ ] 无"竞彩网"出现在数据来源
- [ ] 无EV/Edge/仓位/凯利术语
- [ ] 无具体赔率数字（@1.xx格式）
- [ ] "个人猜测比分方向"软化词存在
- [ ] 每场末尾"难说。真说不好。"（多场则每场各一句）
- [ ] 数据用表格呈现（概率表+进球区间表）
- [ ] 互动提问（结尾评论区引导）
- [ ] 所有事实已联网核实（积分/赛果/伤停）

## 结尾
- [ ] 两行免责声明（⚠️ 免责声明 + 仅供参考）
- [ ] 数据来源：懂球帝、ESPN、各队官网（无竞彩网）

## 输出格式
- [ ] 头条号 → .html（浏览器打开→全选复制→粘贴）
- [ ] 公众号 → 纯文本

## 发文前检查
- [ ] 字数合理（单场800-1200字，三场2000-3000字）
- [ ] 无AI味：去掉过度连接词、四字成语连用
