## 0. 最后出什么 / 一次几张

- **一次 4 张**：1 张封面 + 每场 1 张单卡（3 场 = 3 张）。
- **单卡装 8 块**：对阵与开球时间 → 我的判断（立场）→ 核心矛盾 → 三向概率（我 / 机构）→ 高概率比分 → 近期战绩对比 → 六维雷达 → 本次看点 → 战意 / 信号 → 页脚。
- **尺寸**：画布 1080×1440（小红书竖图 3:4），导出 2 倍 = 2160×2880。

## 1. 挑比赛 —— 🖐️ 你说要哪几场

**先看今天在售什么**（只读，不改任何文件）：

```bash
python scripts/sporttery_fetch.py slate
```

输出每天的期号、场次号、联赛、开球时间、胜平负与让球固定奖金。

**挑场三原则**（样例就是这么挑的）：

1. **我这一侧和机构有明显分歧**才值得做：三向差 ≥5 个百分点，或让球档差 ≥5 个百分点；
2. **要有基本面支撑**：近期战绩 / 主客场 / 交锋，至少两条能对得上；
3. **只做挂了「胜平负」的场次**：像周二008 维京 vs 拜仁只有让球 +3、没挂胜平负 → 直接跳过。

**🖐️ 你只要说一句**，例如「周二005、007、009」或「你挑三场有分歧的」。样例里挑出来的是：

| 场次 | 对阵 | 机构胜平负 | 机构让球 | 一句话看点 |
|:--|:--|:--|:--|:--|
| 周二005 | 国际米兰 vs 布鲁日 | 1.18 / 5.60 / 9.75 | 主让 2：2.75 / 4.20 / 1.90 | 我算主胜 81.1%，机构 75.1%，分歧在球差 |
| 周二007 | 比利亚雷 vs 那不勒斯 | 2.04 / 3.40 / 2.90 | 主让 1：4.05 / 3.95 / 1.59 | 我这边只差 1.9 个百分点 → 不挑边 |
| 周二009 | 莱红牛 vs 埃因霍温 | 1.60 / 4.25 / 3.73 | 主让 1：2.61 / 3.95 / 2.03 | 我算 60.5%，机构 55.4%，主场数据撑得住 |

## 2. 抓数据（agent 干，你只需知道数字从哪来）

```bash
python scripts/sporttery_fetch.py match 2041954 2041956 2041958
```

- 抓 **10 个端点**（head / feature / result / history / injury / player / future / tables / score / event），落到 `state/_match_<sportteryMatchId>/`。
- 卡片真正只用到三个文件：
  - `feature.json` → 主客场 10 场胜平负、**同主客** 10 场胜平负、场均进球 / 失球
  - `result.json` → 最近 5 场逐场比分
  - `history.json` → 交锋（**很多场是空的**，005 就是 0 条）
- 抓下来的东西**只看不动**：那是原始凭证，图上每个数字都能回溯到它。

（真实样例的水位：005 交锋 0 条；007 有 5 次交锋但最近一次是 2022 年；009 交锋 1 条；008 没挂胜平负。）

## 3. 算概率（agent 干）

- 常规做法：`scripts/model.py`（λ → 泊松矩阵 → 三向 / 让球 / 比分 → 溢价）。
- **这一批的特殊情况**：`model.py` 的 λ 要用联赛主客场场均进球（官方积分榜），而欧冠的 `tables` 端点是空的 → 改用**市场锚定**：
  1. 机构欧赔折去水（`scripts/odds_snapshot.py` 的 devig）→ 机构三向；
  2. 用**同主客**胜率算一个主场加成：`tilt = clamp((同主客差)/100 × 0.30, ±0.12)`；
  3. 「我」这一侧 = 机构三向 × 加成（定版权重 0.60）后重归一。
- **诚实的缺口**：六维里的「中场控制力」本地缓存没有控球率 / 传球数据，是用「场均净胜球 + 不败率 + 同主客」折出来的**代理指标**，文案与文档都标了「代理」。

| 场次 | 我 胜/平/负 | 机构 胜/平/负 | 让球档 | 我 / 机构 | 首选比分 |
|:--|:--|:--|:--|:--|:--|
| 周二005 | 81.1 / 12.7 / 6.2 | 75.1 / 15.8 / 9.1 | 主让 2 球 | 我「打穿」60.5% vs 机构 53.3% | 2-0 |
| 周二007 | 45.3 / 25.8 / 28.9 | 43.4 / 26.0 / 30.5 | 主让 1 球 | 55% vs 56% | 1-1 |
| 周二009 | 60.5 / 19.6 / 19.8 | 55.4 / 20.9 / 23.8 | 主让 1 球 | 我 38.4% vs 机构 33.9% | 2-1 |

## 4. 写卡的文案（agent 起草，🖐️ 你看措辞）

四段话，每段都有硬上限（超了会把页脚挤掉，出图脚本会打 `⚠️`）：

| 字段 | 位置 | 上限 | 写法 |
|:--|:--|:--|:--|
| `contradiction` | 核心矛盾 | ≤60 字 | 一句话把「机构怎么看 / 我为什么不同意」说清 |
| `focus[0]` `focus[1]` | 本次看点 | 各 ≤60 字 | 写「看什么」，不写结论 |
| `will` | 战意 | ≤60 字 | 动机与形势（荣誉 / 出线 / 保级 / 赛程） |
| `signal` | 信号 | ≤60 字 | 数字分歧（我 vs 机构差几个百分点） |

**口径纪律（踩过坑）**：写数据一定要说清是「最近 5 场」「同主客 10 场」还是「客场 10 场」，同一个词别混两个口径——卡片上雷达的「主客战力」用的是**同主客**。

> 官方 `feature.json` 里其实有**两套**主客数据：`eachHomeAway`（主/客场近 10 场，卡片战绩行印的就是它）与 `eachSameHomeAway`（同主客 10 场，雷达「主客战力」用它）。
> 一批里会出现「主场 5胜0平5负」与「同主客十场 8胜2平0负」同时出现——**两边都是官方口径**，文案里必须把标签写全，否则读者会以为数字打架。

🖐️ **你要做的**：看一遍措辞有没有过头。禁用词由脚本硬拦：赔率 / 盘口 / 庄家 / 泊松 / MC / EV 这类命中 `📚知识库/模型脚本/check_article.py` 词表就**拒绝出图**（exit 2）。

## 5. 填 `cards.json`（agent 干）

位置：`📝文章/<日期>/小红书/cards.json`（样例：`📝文章/20261014/小红书_第二批/cards.json`）

```json
{
  "title": "国米、比利亚雷、莱红牛：两场站主场，一场不挑边",
  "xhs_title": "三场里两场站主场，一场我不挑边",
  "subtitle": "国米和莱红牛的主场数据跟机构差着几个点；比利亚雷那场我不硬凑",
  "cover_kicker": "欧冠图文｜10/14 三场（第二组）",
  "cover_items": ["国际米兰 vs 布鲁日：站国米赢两个球以上", "……"],
  "matches": [{
    "no": "周二005", "league": "欧冠", "kick": "10/14 03:00",
    "home": "国际米兰", "away": "布鲁日", "sporttery_match_id": 2041954,
    "stance": "站国米赢两个球以上",
    "contradiction": "机构给国米 75.1% 的主胜，我这一侧算 81.1%……",
    "focus": ["……", "……"],
    "probs_mine": [81.1, 12.7, 6.2], "probs_mkt": [75.1, 15.8, 9.1],
    "score": ["2-0", "3-0", "2-1"], "will": "……", "signal": "……"
  }]
}
```

- **只有 `sporttery_match_id` 填对，雷达和近期战绩才会自动算**：出图时 `xhs_data.build_one()` 去 `state/_match_<id>/` 取数（取不到只打 `⚠️`，不阻断），也可以先手动跑 `python scripts/xhs_data.py --input <cards.json>` 看它算出来的六维值。
- 封面文案的坑：`title` 太长会把页脚挤掉（第一次 45 字时脚本报「底部仅 13px@2x」）→ 压到 24 字左右最稳。

## 6. 出图 —— 🖐️ 双击一下就行

**傻瓜路径**：

1. 双击仓库根目录的 **`小红书出图.cmd`**；
2. 菜单列出所有批次 → 输入序号（回车 = 最新一批）；
3. 再输 `1`（按定版杂志风出正式图）→ 回车；
4. 成品就写在那一批 `cards.json` 所在的 `📝文章/<日期>/小红书/`。

**等价命令行**（agent 用的就是这条）：

```bash
python scripts/xhs_html.py --input "📝文章\20261014\小红书_第二批\cards.json" --style editorial
```

- `--style swiss` 换瑞士风；`--kind full` 退回「每场三张（判断 / 战绩 / 深读）」；`--limit 1` 只出首场试版；`--engine playwright` 换更快引擎；`--html-out <目录>` 留中间 HTML 供排版诊断。
- 产出：`01_封面.png` + 每场一张 + `文案.md`。**出图时脚本自检底部留白，不够就打印 `⚠️`，让你回去精简文案。**

## 7. 目测门禁（🖐️ 你看 3 秒）

- 页脚有没有被裁 / 雷达两条线分不分得清 /「我 · 机构」的数字和 `signal` 里说的是不是同一个数。
- 不满意就直接说「第 3 张的看点太长」「雷达换对比更明显的」——改文案到重渲一次约 4 秒。

## 常见问题

- **要多久？** 抓数约 10 秒/场，算数与写文案是 agent 的活，渲染 4 张约 4 秒。**你这边总共 3 分钟。**
- **换联赛 / 换日期？** 只改 `slate` / `match` 的场次号，以及 `cards.json` 里的 `no / league / kick`。
- **没有交锋数据？** 雷达第 5 轴自动退成「主客战力」，卡片右上也只在有交锋时才写字（010 就是这样：`近 2 次交锋 0胜1平1负（样本太少，雷达第 5 维用主客战力）`）。
- **想加 / 减卡片上的块？** 改 `scripts/xhs_html.py` 的 `all_card_html()` 与 `ALL_CSS`，再用 `python scripts/xhs_measure.py <目录>` 看有没有超 1440px。
- **想偷懒不想交互？** 直接跑第 6 节那条命令行，效果与双击菜单 `1 → 1` 完全一样。
