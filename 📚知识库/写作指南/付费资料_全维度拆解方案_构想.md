## 一句话

不是把卡片装订成册，而是**一批比赛的全维度数据拆解**：每个场次给出胜平负／让球／总进球与大小球／双方进球／比分分布／半全场分布（将来还有角球），每项都写清口径、数据来源、怎么读、什么情况下会失效——做成可卖的分析资料。

## 风控红线（比内容更先决）

- 这些维度打包起来（大小球 + 角球 + 比分 + 半全场 + 分布 + 推荐），形态上**极像博彩方案**；公众号 2026-09-24 就是按「体育荐彩类主体资质」**永久封禁**（见 `📚知识库/公司工程/平台风控与自查.md`），小红书首篇也因「方向 + 让球球数 + 具体比分 + 场次号」四件套被判博彩 28 条。
- 所以付费资料只能做成**「数据观察 + 概率分布解读」**：写分布、写口径、写适用与失效条件，**不出现**下注动作、「推荐投注」「稳胆」「串关」「跟单」这类词；比分/角球/半全场一律以**分布与历史同口径对照**呈现，不给「买这个比分」的暗示。
- 交付渠道也过平台规则：公众号（已封）／小红书（最严）都不适合挂售卖链接；优先考虑**不依赖平台内销售的渠道**，且售卖页面本身的措辞按上面同一套红线审。

## 分阶段（2026-10-17 起 P0 已启动）

**成品**（当天全部场次口径，用户 2026-10-17 选定「整批＝当天全部场次」）：

- `📝文章/20261016/付费资料_全维度拆解_样册_v0.1.html` ← **主交付**（单文件、样式内嵌，浏览器直接打开；屏幕下每节一张白页，Ctrl+P 可直接存 PDF）
- `📝文章/20261016/付费资料_全维度拆解_样册_v0.1.pdf` ← 顺手出的打印版（A4，11 页，文字可搜可复制）

**结构（11 页）**：封面（场次清单 + 8 场／6 类分布／5 维修正／90′ 口径）→ 「这册怎么读」（六维读法卡：怎么读／失效条件）→「这些数字是怎么来的」（λ → 分布 → 六块 → 对市场四步）→ 每场一页（基本面 + 六维雷达、λ 双方法、胜平负、让球、总进球 8 格柱图 + 大小球 + 双方进球、比分 Top8 带定价与溢价）→ 尾页（逐场《数据提示》+ 口径与不做什么）。

**生成**：`python scripts/doc_pack.py`
- `--model state/_model_<日期>_<星期>.txt`（model.py --all 的落盘输出，真源，不重算）
- `--cards "📝文章/<日期>/小红书_<批>/cards.json"`（可选，取近期战绩/六维雷达；缺了就只出分布）
- `--out <目标.pdf>`（同时写同名 `.html`）；`--html-only` 只出 HTML 调版式
- 实现：解析模型文本 → 渲染 A4 打印 CSS → Chrome `--print-to-pdf`（中文路径不稳，故先写 ASCII 临时目录再 copy）→ 用 `pdfcraft-cli text` 验文字层

**已知取舍**：`state/_match_<id>/` 缓存会随清理消失，模型文本一旦没留档就只能重拉数据重跑；所以样册的输入是**已落盘的模型文本**，不是实时重算。角球仍未覆盖（见 P2）。
