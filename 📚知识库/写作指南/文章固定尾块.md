# 文章固定尾块（话题标签 / 数据来源 / 免责声明）

> 所有头条前瞻、内部分析报告、赛事复盘、小红书之外的图文稿，**正文最后一段之后固定接这三块**，顺序不能换。
> 机器可校验：`check_article.py` 第 5 项认「数据来源」「免责」；话题标签行会被 `wordcount.py` 计入正文，写稿时留 20–30 字余量。

## 一、标准尾块（复制即用）

```
话题标签：#联赛1 #联赛2 #队名1 #队名2 #赛事前瞻 #足球分析

数据来源：公开赛事数据 · 官方赛程 · 联赛积分与主客场进失球（数据截至发布时；90 分钟口径，加时与点球不计）。

免责声明：本文为个人观察与公开数据整理，仅供交流参考，不构成任何购买或投资建议；赛事结果存在不确定性，请理性看待比赛，量力而行。
```

## 二、话题标签怎么配

规则：**2 个联赛标签 + 1–3 个队名标签 + 2 个固定标签**，总数 5–7 个，多了会被判堆砌。

| 场景 | 标签示例 |
|---|---|
| 日职 + 韩职 多场 | `#日职 #韩职 #赛事前瞻 #足球分析 #早场` |
| 英超 / 意甲 / 西甲 单场 | `#意甲 #那不勒斯 #罗马 #赛事前瞻 #足球分析` |
| 德甲 / 法甲 多场 | `#德甲 #法甲 #赛事前瞻 #足球分析 #五大联赛` |
| 世界杯 / 欧洲杯 | `#世界杯 #赛事前瞻 #足球分析 #国家队` |
| 复盘 / 校验类 | `#复盘 #赛事校验 #足球分析 #数据回看` |

固定标签只用 `#赛事前瞻` `#足球分析` 两枚，其余按联赛与队名替换。**不写** `#推荐` `#必看` `#稳单` 这类诱导词，也不写与正文无关的蹭热搜标签。

## 三、数据来源行

- 固定主干：`公开赛事数据 · 官方赛程 · 联赛积分与主客场进失球`
- 必须补一句**时效与口径**：`（数据截至发布时；90 分钟口径，加时与点球不计）`
- 若本场另用了外媒/伤停名单，加一段：`伤停与轮换信息来自公开报道，可能滞后`
- 不写「独家情报」「内部消息」「内部数据」，也不写具体数据商名。

## 四、免责声明行

固定句式，不要自创：

`本文为个人观察与公开数据整理，仅供交流参考，不构成任何购买或投资建议；赛事结果存在不确定性，请理性看待比赛，量力而行。`

**禁词**：投注、下注、串关、跟单、稳赚、包中、保证、必胜（`check_article.py` 第 2/3 项会标红）。

## 五、加尾块的命令

```bash
# 自动补 / 规范化（幂等，重复跑不会叠两块）
python -X utf8 scripts/tail_block.py "📝文章/YYYYMMDD/xxx.md" --tags "#日职,#韩职,#赛事前瞻,#足球分析,#早场"

# 只看会改成什么，不写盘
python -X utf8 scripts/tail_block.py "📝文章/YYYYMMDD/xxx.md" --tags "#意甲,#赛事前瞻" --dry-run
```

不带 `--tags` 时按文件名/正文里的联赛关键词猜标签（日职、韩职、英超、意甲、德甲、西甲、法甲、葡超、荷甲、英冠、德乙、瑞超、澳超、欧冠、中超、世界杯），猜不到就只给 `#赛事前瞻 #足球分析`，并在输出里说明。
