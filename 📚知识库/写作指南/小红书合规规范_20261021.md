## 〇、一页纸（只想看结论的话，看这一节）

1. **这次不是"写错了一个词"，是"整套卡片的形态"被判成了购彩内容。** 文字正文其实很干净，问题全在**图**和**标签**：封面写着"竞彩""让球盘口"，内页写着"让球盘客队一侧读到 62.4%""主胜一格 67.1%"，每页左上角是体彩独有的"周一001"式编号，正文末尾挂了 `#竞彩`。
2. **小红书的审核比头条、公众号都严，且是"图片优先"。** 它会用 OCR 读图里的字，所以"图里写的东西"和"正文写的东西"是同等证据，甚至图更重。
3. **两次处置，两种触发。** 第一篇（10/19 八场）发布两天后才被判，那两天它爆了（曝光 22,591，其他篇 1,200–7,900）→ 是**爆款后进人工池**；第二篇（10/21 十场）发布 07:07、处置 14:26，**7 小时内**、流量还没起来 → 是**账号被标记后的抽查**。两条合起来：**形态要干净，而不是等它不火。**
4. **整改原则：把"彩票语言"换成"体育数据语言"。** 不是不说数据，而是数据的主语从"市场/盘口/庄家"换成"赛程/战绩/模型"。判据只有一句：**这句话如果被截图给一个不买彩票的人看，他会不会认为这是在教人下注？**
5. **账号虽然解封了，但当天下午又倒了一篇。** 10-21 上午解封，07:07 发的那篇 14:26 就被判；同时账号头上还挂着「一年内注销重注册受限」。所以：**解封不等于清零，解封后 7 天是危险期。**
6. **最重的一条结论：改词救不了版式。** “八场/十场数据一览”这种多场汇总清单，配上场次编号，就是购彩指南的版式。第二例证明它不需要写任何赔率也能被定性。**要改的是“一篇讲几场”，不是“换个词”。**

## 二、平台到底判了什么（两份判词不是一回事）

### 2.1 笔记级：8 条「涉赌」，全部指向形态

原文 8 条：赌场/赌博渠道、赌博器具或技巧、宣传或组织线上线下赌球、赌博账号买卖或跨国提现、线上彩票交易服务、非官方渠道购彩、批量展示中奖信息引人效仿、其他。

**这 8 条是"涉赌类"标准话术模板，不会逐条对应我们的具体句子。** 它命中我们的是三类可验证的形态：

1. **术语层**：让球盘、受让、胜平负、主胜一格、市场把 X% 给了谁、被定成 X%。
2. **编号层**：`周一001`–`008`、封面 `001~008` —— 这是体彩竞彩独有的编码，审核员看到编号不需要看内容就能定性。
3. **标签层**：正文末尾 `#竞彩`。带这个 tag 的笔记一旦起量，会被分流到涉赌队列重点看。

### 2.1.1 第二例（10/21 十场）说明了什么

第二篇《10/21 周三赛事前瞻：十场数据一览》发布 07:07、处置 14:26，**7 小时内**、判词完全相同。这提示两件事：

1. **账号在解封后仍处于观察期**，新发内容抽查率极高。解封 ≠ 恢复。
2. **“十场数据一览”这个形态自带风险**：标题里的「十场」「数据一览」，加上内页的场次编号与开赛时段，构成“批量赛事清单”，正是第 7 条「批量展示…引人效仿」的形状。**即使一个赔率数字都没有，形态本身就可以被定性。**

**待核验**：这篇的卡片本地没有归档，无法逐图比对。**在拿到素材之前，“到底是哪个词”不能下定论**；但“系列这种形态不能再发”这个结论不依赖素材。

### 2.1.2 素材已到：10/21 十场逐图归因（11 张图，10-21 晚用户提供）

素材到手后，不用猜了。这套卡不是“数据分析卡”，是**十场预测卡**。逐元素对表：

| 5 | 「比分率 2:1 9.9% / 2:0 8.8%」逐比分概率 | 每张卡 | 具体比分预测 | **致命** |

**我漏掉的一项（认账）**：之前的图卡规范只禁了“热力图红框标剧本落点”，没禁“整张比分概率矩阵”。 4×4 矩阵本身就是比分预测，红框只是加重。现已补进 §6.1.1。

### 2.2 账号级：4 条「安全风险」，与足球内容不同源

原文：①通过非平台工具引导他人交易 ②无合规资质发布风险招聘信息 ③以交友为名实则引导他人进行风险交易 ④其他影响账号安全的风险内容。

这四条属于**财产/安全类**判词（卖料号、带单号、撸货号的典型画像），跟"涉赌"是两个不同的规则模块。这次申诉就是只打这四条、一个字不碰内容，结果是解封 —— **说明账号级四条确实缺乏事实基础**，这是本次最值钱的一条经验：**两个模块要分开打，混在一起打必输。**

## 三、红线清单（分三级，按"能不能写"排）

### 3.0 形态禁令（优先级最高，高于一切词表）

词可以改，形态改不了。以下四种形态**直接不用**，不管里面写了什么词：

| 禁止的形态 | 为什么 | 替代 |
|---|---|---|
| **多场汇总清单**（八场/十场/九场数据一览） | 批量场次 + 编号 + 时段 = “购彩指南”的版式，命中第 7 条“批量展示，引人效仿” | 单篇 **1 场**，最多 2 场；写深不写多 |
| **体彩三维编号**（`周一001`） | 体彩专属编码，看到就知道是竞彩 | 只写联赛 + 双方 |
| **三项概率并列**（胜/平/负 各一个百分比） | 三项概率就是盘口形状，换主语也不变 | 只用战绩计数 |
| **比分 + 剧本**（`2:1` 主推、热力图红框） | 这是“预测结果”，是赌博内容的核心，不是周边 | 不给比分、不给热力图 |

**一句话**：**一篇只讲一场，讲发生了什么，不讲接下来会怎样。**

### 3.1 一级：绝对禁用（命中即改，不讨论语境）

| 类别 | 具体词 |
|---|---|
| 平台/玩法名 | 竞彩、体彩、足彩、北单、彩票、购彩、官方开奖、中奖 |
| 盘口语 | 赔率、盘口、让球、受让、让一球、大小球、水位、初盘、即时盘、升盘、降盘、走水 |
| 主体词 | 庄家、机构、主任、市场（指赔率市场时）、开盘 |
| 下注动作 | 串关、二串一、单关、重注、上车、跟单、红单、收米、搏冷、稳胆 |
| 格式 | `周一001` 式三维编号、三项赔率并列（如 `2.15 / 3.40 / 3.10`）、带金额/奖金 |
| 引流 | 私聊、加我、进群、联系方式、站外链接、二维码 |

### 3.2 二级：语境灰区（自己在每句上过一遍"截图给不买彩票的人看"）

| 词 | 什么时候算红线 | 合规写法 |
|---|---|---|
| 概率 / 百分比 | 与"一格/最重/市场给到/让球盘"同句出现 | 只与"战绩/模型/历史"同句 |
| 主胜 / 平局 / 客胜 | 作为三格玩法并列出现 | 写"赢球/拿分/不败" |
| 分歧 | 紧跟指数、赔率数值 | 写"数据分歧/战绩分歧" |
| 看好 / 方向 / 推演 | 指向具体结果（谁赢、几比几） | 只写结构（账面/近况/反差），不写结果 |
| 最重 / 一格 / 被定成 | 任何时候 | 删，或写"概率最高的一项是…" |

### 3.3 三级：允许（这些可以说，而且是我们的差异化）

联赛名、球队名、开球时间、主客场、近 5/10 场战绩（胜平负场次）、进球数/失球数、场均进失、积分与排名、共同对手对照、伤停与名单、教练更迭、赛程密度、xG 类公开数据、六维雷达（积分率/净胜球/场均进失/主客场胜率）。

**一句话判据**：**描述"发生过什么"是安全的；描述"接下来会怎样、值多少"是危险的。**

## 五、账号安全类红线（账号级的四条判词专用）

这几条与足球无关，但会让整个号一次性消失，必须单独立规：

1. **任何位置都不留联系方式**：笔记、评论、主页简介、背景图、私信自动回复 —— 不留微信、QQ、邮箱、手机号、群号、"看主页"。
2. **不接商单、不做招聘、不写招募**：不出现"招募/兼职/代理/合作/投稿返佣"。
3. **不以交友话术建立联系**："加个好友""私我""进群聊"一律不做。
4. **评论区别做引流**：有人问"怎么买/在哪买/求带"，**不回复具体渠道**，只回"这里只做数据整理"；出现导流话术要主动删评。
5. **私信不开招商**：陌生私信谈合作，一律不回。

## 六、图卡模板规范（这一节是本次的核心）

| **比分概率矩阵**（4×4 主客进球网格，格内百分比） | 这本身就是比分预测，红框不红框都一样致命 |

## 九、事后处置流程（被处置了怎么办）

顺序很重要，别乱：

1. **先分清两层**：笔记级（内容）与账号级（画像）。**分开处理，不要混在一份申诉里。**
2. **笔记级**：过期内容**不修改重发、不二次发布**。要么放着不动，要么隐藏/删除。修改重发等于把同一份证据再送审一次。
3. **账号级**：可以申诉。原则见 `申诉定稿_小红书账号_20261021.md`：
   - 只争"判词与账号实际内容不符"，**一个字不为内容辩护**；
   - 申诉文本里禁出现：赌、竞彩、比分、预测、前瞻、推荐、看好、方向、盘口、赔率、概率；
   - 要求平台**指明具体内容指向**（哪篇、哪句、哪个行为），答不上来就要求撤销；
   - **客服要求人脸/实名验证时停下不做** —— 账号已带"注销后重注册限制"，验证会把这条钉死。
4. **结果**：本次按此策略申诉，当晚解封。**但解封不等于清零**，账号历史记录仍在，后续按新规执行。
5. **别做的事**：不要连发同类内容"测试还能不能发"；不要改标题重发同一套图。
6. **解封之后的 7 天是危险期**（本次实证）：10-21 上午解封，当天 14:26 新发的那篇就被判。**解封当天不要发任何新内容；之后 7 天内只发“单场 + 纯战绩”的内容，不发任何汇总清单。**
7. **累计违规是阶梯的**：同一账号已有 2 条内容违规（10/19 八场、10/21 十场）。平台原话「多次违规将加重处罚」。**第 3 次很可能是账号级、且不再是一次申诉能解决的那种。**
