# 写作素材库 — 模块化沉淀（R25）

> 用途：日常按四类分门别类沉淀素材，写作时像拼积木组合（afei-writing-standards R25）。
> 规则：每类按日期追加，标注来源场次/实测数据；同类型不连续两篇用同一条。

## 一、爆款标题句式（带 CTR 实测）

## 使用规则

1. 写作前从四类中各取可用素材，像拼积木组合（标题句式 + 反常识案例 + 数据结论 + 金句）
2. 同类型不连续两篇用同一条素材（轮换防审美疲劳）
3. 新素材随每篇产出追加（标注日期+场次），随 git 提交
