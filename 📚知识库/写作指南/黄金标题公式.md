# 黄金标题公式 v1.0

> 来源：外部参考模板 + 头条号SEO实践
> 优先级：与八层写作铁律第三层互补
> 适用范围：今日头条文章标题

---

## 一、标题核心公式

```
[强强对话/核心矛盾] + [数据反差/悬念] + [搜索关键词]
```

### 公式拆解

| 元素 | 作用 | 示例 |
|:-----|:-----|:-----|
| 强强对话 | 制造冲突感 | 蔚山HD vs FC安养 |
| 核心矛盾 | 引发好奇 | 主场伪强队 vs 客场真黑马 |
| 数据反差 | 提供谈资 | 40%胜率 vs 90%赢指率 |
| 悬念设问 | 激发点击 | 这次还能撑住吗？ |
| 搜索关键词 | SEO吃流量 | 韩K联、足球前瞻、数据分析 |

---

## 二、标题模板库

### 模板A：数据反差型（推荐用于冷门场次）
```
[球队A][数据反差]，[球队B][数据反差]，[悬念]
```
范例：`蔚山HD主场40%胜率告急，FC安养90%赢指率客场来袭，谁是伪强队？`

### 模板B：球星对决型（推荐用于焦点战）
```
[球星A]遇[球星B]，[核心矛盾]，[悬念]
```
范例：`哈兰德遭遇最强铁闸，曼城主场迎阿森纳，谁能笑到最后？`

### 模板C：复仇/恩怨型（推荐用于德比战）
```
[复仇/恩怨标签]：[对阵]，[数据悬念]
```
范例：`复仇之战！全北主场迎首尔，80%客场胜率能否延续？`

### 模板D：模型偏差型（推荐用于有明显模型信号的场次）
```
[赛事]预警：[模型发现]，[悬念]
```
范例：`韩K联预警：市场高估主胜21个百分点，今晚防冷有奇效！`

---

## 三、标题硬约束

1. 字数：25-30字（含标点空格）
2. 必含：球队全称（吃搜索流量）
3. 必含：至少1个数据点或悬念
4. 禁用：绝对化表述（必胜、稳赢、包中）
5. 禁用：博彩黑话（盘口、水位、红单）
6. 竞彩代码：可选，但有助于SEO

---

## 四、与八层铁律第七层的关系

八层铁律第七层规定：
> 标题铁律：25-30字，核心公式"数据+悬念，不要数据+答案"

本公式在其基础上增加了：
- 「强强对话/核心矛盾」元素（制造冲突感）
- 「球星对决/复仇恩怨」变体（拓展适用场景）
- 「模板库」（降低每次创作的思考成本）

两者不冲突，本公式是第七层的增强版。
