## 四、赛事速览卡

用一个紧凑表格让读者30秒看清比赛背景：

```markdown
| 项目 | 内容 |
|:-----|:-----|
| 赛事 | 韩K联 第21轮 |
| 对阵 | 蔚山HD(主) vs FC安养(客) |
| 时间 | 2026-08-02 18:30 |
| 场地 | 蔚山文殊球场 |
| 天气 | 天晴 31°C |
| 重要指数 | ⭐⭐⭐⭐（卡位战：第4 vs 第5，仅差1分） |
```

### 重要指数定义

| 星级 | 含义 | 示例 |
|:----:|:-----|:-----|
| ⭐ | 普通联赛 | 中游球队无欲无求 |
| ⭐⭐ | 有看点 | 保级战/德比 |
| ⭐⭐⭐ | 重要比赛 | 争冠/保级关键战 |
| ⭐⭐⭐⭐ | 焦点战 | 榜首大战/强强对话 |
| ⭐⭐⭐⭐⭐ | 天王山 | 决赛/国家德比/生死战 |

## 五、核心结论（倒金字塔前置）

在文章最前面直接给出结论，不要让读者等到最后。

```markdown
后台模型跑完这场[联赛名]，发现一个惊人信号：
[核心发现1]。
[核心发现2]。
[一句话总结核心矛盾]。
```

示例：
> 后台模型跑完这场韩K联卡位战，发现一个惊人信号：市场严重高估蔚山HD主胜21个百分点。市场给蔚山1.86（隐含53.8%），模型只给32.8%。蔚山主场胜率仅40%，场均失球1.70，中卫+中锋双核缺阵。这不是强队打弱队，这是伪强队遇上真黑马。

## 六、模块一：近况与历史交锋

### 6.1 近期战绩（5场）

要点：
- 不要只列比分，要提炼趋势（连胜/连败/起伏）
- 标注关键转折点（如杯赛被淘汰）
- 对比双方状态温差

### 6.2 H2H历史交锋

要点：
- 近5-10次交手的胜负比例
- 是否存在「血脉压制」（某队克制另一队）
- 主客场分离分析
- 上一次交手的关键事件
