## 四、写作工作流

### 4.1 标准流程
`
选题（6场选2场话题最高）
-> 用户贴竞彩网官方数据
-> 核对数据（排名/积分/近况/交锋）
-> 14维评分卡分析
-> 模型推演（泊松+MC）
-> 出全维度深度分析报告
-> 写文章（倒金字塔:结论前置）
-> 应用三源融合模块
-> 头条号SEO优化（标题30字内+标签）
-> 降AI处理
-> 生成Word文档（含图表）
`

### 4.2 关键教训
| 问题 | 教训 | 解决方案 |
|:-----|:-----|:---------|
| 数据错误 | 不能凭印象写数据 | 每次分析前先让用户贴竞彩网数据 |
| 赛制规则错误 | 欧足联已取消客场进球规则 | 删除所有客场进球相关内容 |
| 模块标记残留 | 【热梗】等不能出现在正文 | 去掉所有模块标记,自然融入 |
| 结构倒置 | 表格堆前面结论在后面 | 改为倒金字塔:结论前置 |
| 战意冷门缺失 | 每场必须分析 | 强制包含战意+冷门因素 |
| 图表缺失 | 用户要求多做图表 | matplotlib六维图/柱状图/饼图嵌入Word |
