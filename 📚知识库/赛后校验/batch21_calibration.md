## 二、欧冠附加赛两场模型复盘（本批核心价值）

### 2.1 费内巴切 1:1 里昂（周二004）—— 方向错，但比分"留意"档预警

**预测回顾**（20260819_周二004_费内巴切vs里昂_全维度分析.md）：
- 模型：主胜 **55.8%** / 平 23.9% / 客胜 20.2%
- 市场：主胜 **47.8%**（竞彩去水）/ 平 26.5% / 客胜 25.7% → **模型主胜 +8pp（模型比市场更激进）**
- 大2.5：模型 49.1% vs 市场 2.75盘略偏大
- 比分Top：1-0(12.3%) → 1-1(**11.4%**) → 2-0(10.4%) → 2-1(9.7%)
- 推荐：首选 1-0 → 次选 2-1 → **留意 1-1**（冷门 0-1）
- 剧本B（闷平/小比分）32% + 剧本C（客队偷袭）26% = 非主胜 58%
- 卢卡库大概率替补（名单反转）→ 攻坚力下降 → 慢节奏小比分（分析已预判）

**实际**：**1:1**（半场 0:1，里昂先进球）

**复盘**：
| 维度 | 判定 | 说明 |
|:-----|:----:|:-----|
| 方向 | ❌ | 模型主胜55.8% vs 实际平；但剧本B+C合计58%已覆盖非主胜区间，主胜第一判断错误 |
| 比分 | ⚠️ 命中留意档 | **1-1 正是比分"留意"档（11.4%第三高）**——比分预警机制有效 |
| 让球 | ❌ | 竞彩让-1：1:1 → 让球负（0:1），C09/C12 再添一例 |
| 亚盘 | ❌ | 6家升盘至半球，1:1 → 主队让半球输盘——**升盘信号失败** |
| 大小球 | ❌ | 1:1=2球小球；模型49.1%与市场2.75盘均略偏大 → **附加赛首回合客队保守压低进球**（分析风险提示点中） |
| 半场 | ⚠️ | 0:1 客队先进球 = 剧本C（客队偷袭）形态，剧本C 26%兑现 |

**核心教训**：
1. **模型 vs 市场激进分歧时，本场市场更接近**——模型主胜55.8% vs 市场47.8%，实际平局。与 Batch #17 奥胡斯场（模型压主胜被打脸）相反，本场模型"敢给主胜"反而错。欧冠附加赛首回合主队热门定价需更保守；
2. **比分留意档的价值再次验证**——1-1 在第三档（11.4%），半场0:1形态与剧本C吻合，预警链条完整；
3. **升盘≠必赢**：6家集体升半球+澳门半/一，主队仍 1:1 被逼平——升盘资金方向本批失败；
4. **卢卡库替补剧本兑现**：攻坚力不足→慢节奏→小球小比分（1:1）——战意/阵容逻辑链成立，问题出在"仍给主胜55.8%"。

### 2.2 萨格勒布迪纳摩 2:2 维京（周二003）—— 方向错，但大球命中（C27 验证）

**预测回顾**（20260819_周二003_萨格勒布vs维京_全维度分析.md）：
- 模型：主胜 **64.8%** / 平 21.0% / 客胜 14.2%
- 市场参考：克媒"轻微热门"→55-60%档
- 大2.5：模型 **63.2%**（含C27+12pp）vs **MatchPulse 62%** → 两方共识
- 比分Top：1-0(12.9%) → 2-0(12.3%) → 1-1(9.9%) → 2-1(9.7%)
- 推荐：首选 1-0 → 次选 2-0 → 留意 1-1（冷门 0-1）
- 关键冷门信号（分析已点名未量化）：裁判 Gözübüyük 执法迪纳摩**全败**；维京定位球威胁；维京拒绝2000万欧报价阵容稳定；克甲强度低

**实际**：**2:2**（半场 2:2！上半场即对攻）

**复盘**：
| 维度 | 判定 | 说明 |
|:-----|:----:|:-----|
| 方向 | ❌ | 模型主胜64.8% vs 实际平——两小联赛互搏"主队全面占优"被证伪 |
| **大球** | **✅ 命中** | 2:2=4球大球；**模型63.2%（C27+12pp）与 MatchPulse 62% 双双命中**——C27 再添正面验证 |
| 比分 | ❌ | 1-0/2-0/1-1 全未命中（2:2 在模型概率表中仅约3%档） |
| 让球 | ❌ | 竞彩让-1：2:2 → 让球负（1:2），C09/C12 再添一例 |
| **裁判信号** | ✅ 应验 | Gözübüyük 执法迪纳摩全败 → 2:2 被逼平——**分析点名但未折算进概率** |
| 维京定位球 | ✅ 应验 | 克媒点名的最大威胁兑现 |
| 客队保守假设 | ❌ 证伪 | 分析假设"首回合客队保守" → 维京直接对攻（半场2:2）——**实力接近的对攻比摆大巴更常见** |

**核心教训**：
1. **裁判信号必须量化**：Gözübüyük 执法迪纳摩全败是本场最明确冷门信号，分析只作定性提示未折算进概率。若按"裁判全败历史"给迪纳摩主胜-10pp，64.8%→55%，平/客胜上浮——方向未必翻但置信度会降档；
2. **两小联赛互搏 ≠ 主队全面占优**：14维合计+7（全面占优）→ 模型64.8%，但克甲 vs 挪超（卫冕冠军）强度差被高估——维京是2025挪超冠军不是中游（分析自己已纠正"非中游"，模型仍只给客胜14.2%）；
3. **C27 大球规则在欧冠附加赛也成立**：克甲新赛季+挪超赛季中，两队场均进球合计4.3球，大2.5双源共识（63.2% vs 62%）命中——**大球判断是本批唯一的高置信命中**；
4. **"首回合客队保守"是错误默认**：维京上半场2:2对攻——当客队实力接近且战意强（队史首欧冠）时，对攻概率高，平局+大球组合需提前给权重。
