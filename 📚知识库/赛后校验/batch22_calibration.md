## 二、两场模型预测复盘（本批核心价值）

### 2.1 奈梅亨 1:3 博德闪耀（周三007）—— "伪五五开"完全验证 🔴🔴

**预测回顾**（20260820_周三007_奈梅亨vs博德闪耀_全维度分析.md）：
- 模型：客胜 **37-42%**（λ主1.20/客1.40，状态碾压主导）；大2.5 **52-55%**
- 市场：主 **37.7%** / 平 25.3% / 客 **37.0%**（**表面五五开**，差0.7pp）
- "伪五五开"信号：**半全场负负 4.10 第二热**（博德闪耀半场领先+全场赢）+ **让-1客队+1约62%** + **总进球3球最低**
- 推荐比分：1-2 → 1-1 → 0-2

**实际**：**1:3**（半场 0:2 → 全场 1:3）

**复盘**：
| 维度 | 判定 | 说明 |
|:-----|:----:|:-----|
| 方向 | ✅ | 模型客胜 37-42%（>市场37.0%），实际客队 3-1 大胜 |
| **半全场** | ✅ | **负负（客队半场领先+全场赢）完全命中**——模型点名的"第二热信号"兑现 |
| 大球 | ✅ | 4球大球，模型 52-55% 看大正确 |
| 让球 | ✅ | 奈梅亨(-1) → 1:3 让球负（客+1赢），C09/C12 验证 |
| 比分 | ⚠️ | 推荐 1-2/1-1/0-2，实际 1-3——方向对、净胜幅度略低估 |

**核心教训**：
1. **"伪五五开"是本批最漂亮的验证**：胜平负表面均衡（37.7vs37.0），但**半全场/让球/总进球三个独立玩法全部指向客队**——市场真实态度藏在细节里，不是胜平负主盘；
2. **模型识破假象**：基于"状态碾压（80%胜率vs30%）+伤停4人+半全场负负第二热"给客胜更高权重，方向正确；
3. **C32 候选规则**：当胜平负表面均衡（|主-客|<3pp）但半全场/让球/总进球三玩法细节全指向一侧 → 跟随细节方向（该侧+10-15pp）——这是 R22"拆穿假象"的量化版。

### 2.2 马竞 2:0 马拉加（周三002）—— 首选比分命中 + C15a 反例

**预测回顾**（20260820_周三002_马竞vs马拉加_全维度分析.md）：
- 模型：主胜 **62-66%**（λ主1.90/客0.56，C05升班马修正）；让-1打穿 **~40%**
- 市场：主 **73.8%** / 平 17.4% / 客 8.9%（**深热**）
- C15a 触发（1.20<1.50+让-1）→ 主胜下调 -8~12pp；但缓冲：马拉加6人伤停+马竞主场+H2H
- 推荐比分：**2-0 → 1-0 → 1-1**

**实际**：**2:0**（半场 0:0 → 下半场2球）

**复盘**：
| 维度 | 判定 | 说明 |
|:-----|:----:|:-----|
| 方向 | ✅ | 模型主胜 62-66% 正确 |
| **比分** | ✅✅ | **2-0 首选比分命中！**（模型比分Top1） |
| 让球 | ✅ | 马竞(-1) 2:0 → 让球胜（净胜2球打穿） |
| **C15a** | ⚠️ 反例 | 马竞 1.20 让-1 **未翻车**——累计 6/10 → 6/11=54.5% |

**核心教训**：
1. **模型对深热主胜打折（-8~12pp）方向正确但幅度不足**：实际 2:0 主胜，模型给 62-66% vs 市场 73.8%，市场仍偏乐观但方向对；
2. **C15a 反例（马竞 1.20 未翻车）**：与 Batch#20 巴西国际1.41翻车形成对照——**缓冲条件决定成败**：马拉加6人伤停（2锋2中2后）+马竞主场+H2H 7胜2平1负 = 实力差真实存在；
3. **C15a 修订候选**：当让-1方为豪门/强队 + 对手伤停≥5人 + 主场 → C15a 下调减半（-10~12pp 而非 -20~25pp）；
4. **比分模型再次验证**：2-0 首选命中（Batch#18 仁川次选1-1、Batch#20 拉科留意1-1、Batch#21 费内巴切留意1-1、本批马竞首选2-0）——比分预警体系持续有效。

- **C27 修订候选**：降级为参考信号，仅"新赛季前2轮"或"双方场均进球合计≥4.5"时触发，不再默认全联赛+10-15pp。
