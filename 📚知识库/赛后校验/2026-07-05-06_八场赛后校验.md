## 六、模型偏差诊断

### 偏差A：品牌溢价模型失效（巴西案例）

**根因：** 淘汰赛的品牌溢价被简单套用，未考虑「强队攻坚效率」随比赛阶段下降。

| 版本 | 参数 | 巴西vs挪威结果 |
|:----|:----|:------------:|
| 旧 | brand_premium = min(20, rank_diff/10×2 + log(value_ratio)×3) | 巴西66.3%(Edge+9.2pp) → 实际1-2输 |
| **新** | **brand_premium × 0.80（淘汰赛折扣）** | 巴西~61% → 偏差收窄~10pp |

**修正公式：**
```
淘汰赛品牌溢价 = 基础品牌溢价 × 0.80
```

### 偏差B：弱队高Edge的虚假信号（墨西哥案例）

**根因：** 胜率<40%的球队出现Edge>+8pp时，往往是模型被叙事驱动而非数据驱动。

| 版本 | 规则 | 墨西哥vs英格兰 |
|:----|:----|:------------:|
| 旧 | 无特殊标记 | 墨西哥37.9%(Edge+10.2pp) → 实际输 |
| **新** | **Edge>+8pp且胜率<40% → 标记🔴叙事驱动风险** | 自动标记 → 降低仓位 |

**新规则：**
```
if model_pct < 40 and edge > 8:
    confidence_discount = 0.5  # 置信度减半
```

### 偏差C：超低赔率过热未预警（蔚山@1.36）

**根因：** 赔率<1.40时爆冷概率显著增加，模型未做特殊处理。

**新规则：**
```
if 赔率 < 1.40:
    🔴 标记「过热预警」
    # 自动调低热门1-2pp给平局
    热门胜率 -= 2pp
    平局胜率 += 1.5pp
    客队胜率 += 0.5pp
```

### 偏差D：淘汰赛强队攻坚效率

巴西半场0-0→1-2输，说明淘汰赛的防守强度限制了强队攻坚。

**修正：** 淘汰赛强队进攻λ × 0.90（叠加在原有淘汰赛修正之上）

## 七、参数修正方案

### 1. 品牌溢价模块更新

```
# 品牌溢价 v2.2
def brand_premium(rank_diff, value_ratio, match_phase):
    base = min(20, rank_diff/10 * 2 + math.log10(value_ratio) * 3)
    if match_phase == "淘汰赛":
        base *= 0.80  # 淘汰赛折扣
    return base
```

### 2. 置信度评分系统新增

```
# 置信度调整 v2.2
def confidence_check(match_type, model_pct, edge, odds_h, odds_a):
    warnings = []
    
    # 规则1: 弱队高Edge
    if model_pct < 40 and edge > 8:
        warnings.append("🔴 叙事驱动风险")
    
    # 规则2: 超低赔率过热
    if odds_h < 1.40 or odds_a < 1.40:
        warnings.append("🔴 过热预警")
    
    # 规则3: 淘汰赛强队攻坚
    if match_type == "世界杯淘汰赛":
        warnings.append("⚡ 淘汰赛攻坚折扣")
    
    return warnings
```
