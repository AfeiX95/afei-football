## 二、核心发现 & 参数修正

### 🟢 修正1：新增「三四名决赛/已出局球队」λ上调规则

**发现：** 法国vs英格兰4-6（10球）是季军争夺战。两队都已出局（无缘冠军），完全无压力，全开放进攻。半场0-4说明上半场就已是开放局面。

**根因：** 当前模型有「已出线球队λ×0.85」的修正规则，但没有「已出局球队λ上调」的对称规则。三四名决赛和小组赛末轮已出局球队是两种不同的心理状态：
- 已出线球队 → 保守/轮换 → λ×0.85
- 小组赛已出局球队 → 荣誉之战 → λ×1.10~1.15
- 三四名决赛 → 完全无压力表演赛 → λ×1.20~1.30

**修正：**
```python
# 新增 λ 修正规则
if match_type == "三四名决赛":
    λ_home *= 1.25  # 双方无压力，进攻开放
    λ_away *= 1.25
elif match_type == "小组赛末轮_已出局":
    λ_home *= 1.10
    λ_away *= 1.10
```

**证据等级：** 单场（法国4-6英格兰）→ 🟡 中等，有待后续验证
**影响范围：** 世界杯季军赛、杯赛已出局球队末轮

### 🟢 修正2：新增「决赛极端防守」叠加修正

**发现：** 西班牙vs阿根廷决赛0-0，90分钟互交白卷。这是高压下的典型低比分决赛。

**根因：** 当前淘汰赛修正（进攻×0.9）适用于一般淘汰赛，但决赛的心理压力是非线性的——球员在面对"一生一次"的机会时，决策趋于保守。

**修正：**
```python
if match_type == "决赛":
    # 叠加在淘汰赛修正之上
    λ_home *= 0.90  # 额外压缩
    λ_away *= 0.90
    # 决赛修正 = 淘汰赛修正(×0.9) + 决赛额外修正(×0.9) = 总计×0.81
```

**证据等级：** 🟡 多场世界杯决赛历史数据支持
**影响范围：** 世界杯决赛、欧冠决赛等单场定冠军的终极对决

---

### 🟡 修正3：K联赛过热阈值收紧（rank_gap<6时）

**发现：** 安养FC(#6) @1.49 vs 光州FC(#12垫底) → 1-1平局。rank_gap=6 < 8，所以原规则使用1.40阈值，1.49>1.40未触发过热警告，但实际爆冷。

**根因：** K联赛主场胜率低（6个主队本轮仅2胜），安养主场胜率仅28%，1.49的定价在K联赛语境下已经偏热。

**修正：**
```python
# K联赛特殊规则收紧
if league == "K联赛":
    if rank_gap < 6:
        overheat_threshold = 1.30  # 从1.40收紧至1.30
    elif rank_gap < 10:
        overheat_threshold = 1.40
    else:
        overheat_threshold = 1.50
```

**证据等级：** 🟡 多场K联赛验证支持（仁川+12.3pp翻车、安养1.49平局）
**影响范围：** K联赛分析

### 🟡 修正4：rank_gap≥12时的超低赔例外规则

**发现：** 哈马比(#2) @1.13 vs 代格福什(#14) → 4-0大胜穿指。rank_gap=12 ≥ 12，@1.13远低于1.50阈值，但合理低赔成立。

**根因：** 当排名差极大（12位以上）时，强队对弱队的统治力足以支撑超低赔率。模型需要区分"合理低赔"和"过热陷阱"。

**修正：**
```python
# 超低赔例外规则（强化已有逻辑）
if rank_gap >= 12 and odds <= 1.20:
    # 不触发过热预警
    overheat_alert = False
    notes.append("🔵 rank_gap≥12的超低赔属于合理定价")
```

**证据等级：** 🟢 验证案例：哈马比1.13→4-0、维京1.15→2-1（均穿指或赢球）
**影响范围：** 跨联赛适用
