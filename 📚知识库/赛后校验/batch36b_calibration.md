### 2.3 🔴 本场最大教训：半场 2:0 → 全场 2:2

- **让球盘的判定在半场就已经"看起来完成了"**：罗马 37' 打进第二球后净胜 2，罗马-1 已在打穿线上；46' 与 79' 连丢两球，最终**输盘**。
- 这是 **C37（主让-1 打穿率系统性下调）的又一个正例**，且是**极端路径样本**：不是"从没打穿"，是"打穿了 45 分钟然后掉出来"。
- **可操作含义**：C37 的下修不应只看赛前实力差。本场有两个条件同时在场——**罗马两名后防主力伤缺** + **对手火力联赛第一（13 球）**；此时 -1 的"打穿"是**高波动**的，而不是"定价低位就安全"。文章赛前就抓到了这两条（第 6 行主张），方向判断是对的；但如果只拿"机构只给 16.6%"当理由，**理由是不充分的**。

### 2.4 ✅ 旁证：对称定价 → 平局

- 赛前 **不让球胜平负 36.6 / 26.8 / 36.6**，主客完全同价（意甲主队通常有 4-6pp 主场溢价，本场被抹平）；**半全场两侧同样对称**（胜胜 19.8% / 平平 15.1% / 负负 19.8%）。
- 实际：**平局**，且市场给的 **平局 26.8% 是三项最低**；半全场打出 **"胜平"**（市场列出的三档里没有这一项，属冷门复合）。
- **可积累信号**：「胜平负主客同价 + 半全场两侧对称」这一组合，**平局与"一方半场领先、全场被追平"是同一枚硬币的两面**——本场正落在"半场主胜 → 全场平"这条缝上。样本 +1，与 **C16（强强对话平局上浮）** 同源，记在 C16 下的「对称定价」子样本。

### 2.5 ❌ C39 首验复盘（本场最重要的一条规则修正）

**C39 原文**（v1.6 立项）：*德比/强强对话的大球共识降级为"不碰"——反向理由已明确列出时该方向必须降级为不碰，而非保留温和倾向*。首验样本即本场，当时把 **H2H 近十次大 2.5 仅 40%** 当作反向证据。

**实际 4 球**：市场 60.0% / 模型 57.7% 的**共识方向是对的**，被拿来否它的 H2H 反向证据 **错了**。

**机制修正建议**：反向证据至少要分两类——
- **结构型**：伤停 / 阵容缺口 / 锋线状态 / 战术对位 → 权重高
- **历史型**：H2H 比分分布 / 过往大小球占比 → 权重低，且与结构型撞车时**让位**

本场支持大球的是**结构型**（双方合计 5 名后卫伤缺），反向证据是**历史型**，结构型胜。→ **C39 应改为「反向证据为历史型时才降级为不碰；反向证据为结构型时保留共识方向」**。C39 样本 **0/1**，置信度下调为**低·观察项**（原"中-高"）。
