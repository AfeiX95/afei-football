**判定：方向/门槛/晋级三线全错，大球与半场命中。** 模型把「0:3 心理阴影（-1）+ 实力（-1）」压过「战意差（+1）」，实战中**落后方主场搏命 vs 领先方心态松懈**的战意差主导了比赛——这是模型上线以来第三次「Edge>+10pp 大翻转失败」。

### 2.3 两场合并教训（写入候选规则）🔴

1. **模型翻转需要「实力差真实」支撑，纯心理/面子翻转不可靠**：
   - 成功样本：马拉加场（模型翻转市场 = 盘面背离 + 实力真实 + 平局三印证）✅
   - 失败样本：LASK场（0:3 心理阴影 + 主场面子价翻转）= batch11 贝西克+16pp / 博塔弗戈+15pp 同款教训第三次重演 💀
   - **规则建议**：Edge>+10pp 的翻转信号，若依据含「心理/战意」类修正且缺实力差支撑，风险等级上调；翻转幅度应打折看待。
2. **「领先方守成」是双刃剑，C33 1球主义需收紧**：
   - 博德闪耀（强队领先主场）→ 没守成，3:0 打穿；凯尔特人（已近晋级）→ 松懈被 4:1。
   - **C33 仅适用于「领先方无动力/大轮换/已出线无欲无求」**；排除「领先方强队主场继续进攻」与「领先方基本晋级但对手搏命」两类场景。
3. **「落后方必须压上 + 领先方有火力/反击」→ 次回合大球是强信号（2/2 兑现）**：
   - 博德闪耀 73%（双共识）→ 3球；LASK 模型 71.7% > 市场 64% → 5球（模型激进方向正确）。
   - **建议升级为欧冠附加赛/杯赛次回合专属信号**：领先方已确立优势 + 落后方需净胜2+球 → 大球概率上调 5-8pp。
4. **落后方主场搏命反弹被系统性低估**：LASK 4:1（模型主胜仅 36.4%、λ修正仅 +0.1）。0:3 落后 + 主场 + 对手松懈场景，战意修正应上调（λ+0.15~0.2 或战意差 ≥+2 分）。
