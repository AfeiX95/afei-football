**根因定性（原文）**：3.29.2 是**主体资质条款**, 不是内容词表条款。
- 3.29.2 的主语是"**主体**"——「**个人主体不得从事**此类服务」。它管的是"你**在做什么业务**", 不是"你这篇**用了哪些词**"。
- "体育彩票**分析**、**预测推荐**"这两件事本身, 就在被管控的服务清单里。**把赔率、让球线、方向、比分全部删掉, 也改变不了"账号在做竞彩分析"这个定性。**
- 旁证: 被判文章**恰恰是合规做得最干净的一篇**——无赔率、无让球线、无受让/走水、无方向结论、无比分形态、全文无"竞彩"二字, 四个闸门（risk_scan / check_md_release / zhuque / risk_audit）**全绿**。它仍然被判。
- 因此 **09-15 之后那整套"形态级"对策（去赔率化 + 双平台分流 + 四道闸门）在这条条款面前结构性无效**——能降低单篇被判的概率, 但无法阻止账号被归类为"体育荐彩服务"。
- 平台判定在**升级**（09-15 屏蔽=内容层 → 09-24 永封=主体层）, 不是在挑词。

### 单平台化的具体约束

- **还能发**：头条号 —— 唯一主阵地。赔率、让球线、方向、比分盘最热一档可写（**不带奖金**）。09-15 分流表对头条的口径：赔率/固定奖金数字"保留(带"竞彩官方"来源)"；让球线/受让/走水/低赔方/盘口"保留"；胜负"方向"结论"保留但改描述句("市场更重的一侧")"；具体比分"单篇 ≤1 处, 且不带奖金"；免责声明"保留"；内容形态"单场/双场深度"；多场扫描"低频, 谨慎"。
- **不能发**：公众号全部 —— 该渠道 2026-09-24 起关闭, 本项目不再产出公众号稿；微信侧新注册的号只做非体育内容、与本产线解耦（不复用名称/描述、不交叉引流）。
- **头条不是安全区**（原文）：其对"荐股荐彩"的口径含「推荐…吸引他人跟进购买」（**非官方条文, 待/需自行核实**）；**改规则 ≠ 降风险** —— 公众号永封依据 3.29.2 主体资质（判"体育彩票分析、预测"这件事本身）, 我们放开比分是知情选择, 平台判定口径不因此改变。
- **过闸门 ≠ 可发布**：闸门只证「形态合规」, 不证「业务合规」（坑#55）。
- **公众号时期的旧分流硬规则（渠道已关, 仅作口径留档）**：公众号一律不写赔率/固定奖金数字、让球线/受让/走水/低赔方/盘口、胜负"方向"结论、具体比分、"竞彩"二字；"多场扫描"不做；免责声明改写为不含赌注语境的版本；内容形态限"足球数据前瞻"（积分/近况/交锋/赛程体能/伤停(有源)/战术）。
- **公众号内容白名单（留档）**：可写 = 联赛积分与排名、近 10 场战绩与场均进失球、历史交锋、赛程密度与体能、伤停(须有署名来源)、战术与阵型描述、裁判/场地/天气等客观条件；不可写 = 任何赔率与奖金数字、让球线、水位、方向结论、具体比分、"热门/冷门/低赔方"、投注相关动词、诱导性互动（"你会挑哪场"可以, "跟哪一手"不行）。一句话：**公众号只发"这场比赛是什么样", 不发"这场比赛该怎么看"**；分析结论与盘口结构只留头条。
- 竞彩内容的平台风险从"双平台"收敛为"单平台 + 结构整改"；微信侧的合规知识（3.27/3.28/3.29.2/4.4.2/9.1）保留备查, **新渠道上线前先问"这个主体有没有资格做这件事"**。

## 整改要求（逐条可执行）

来源：`头条产线整改方案_20260924.md`（背景：公众号 09-24 被永久封禁（3.29.2 体育荐彩类, 主体资质）→ 决策: 头条为主阵地; 微信新号只做非体育内容）。原文定性：**不是词表补丁, 是产线结构调整。**

### 风险面（三条叠加才是真风险）

| 风险 | 依据 | 我们的暴露点 |
|---|---|---|
| ① 荐彩形状 | 平台对"荐股荐彩"的判定口径（用户经验贴引述头条客服: **推荐购买指定的…博彩…吸引他人跟进购买**。⚠️ 非官方条文, 需自行核实） | 头条稿含**方向 + 比分 + 让球判读** —— 形状上最接近"推荐"。目前未判, 靠的是**无购买引导 / 无引流 / 无收费 / 无战绩宣传** |
| ② 模板化 / 低质 | 微信 3.28 套路化模板写作; 头条有同质的"低质内容/同质化"治理与信用分扣分 | 每篇同构: 标题格式 + tags + 信息卡 5 行 + 两张表 + 我的看法 + 门槛追问; 一天可发多篇同形态 |
| ③ AI 生成 | 微信 3.27 非真人自动化创作 + 4.24.2 生成式内容标识; 头条亦有对应治理 | 产线是模型生成 + 人工润色, 人工占比低 |

原文判断：单独任一条都未必致命；**"AI 生成 + 模板化 + 高频 + 荐彩形状"四条凑齐, 就是平台治理最典型的目标账号。**

### P0 — 立刻（不改就会持续暴露）

1. **收敛"推荐"形状**（⚠️ **2026-09-29 用户改规则: 恢复收口比分**）
   - **现行（09-29 起）**：「我的看法」**主体仍为市场结构陈述**（不让全文变成推荐口吻）, 但**结尾允许一句话收口 = 方向 + 比分预测**, 每篇**最多一处**、**不带奖金**、**不得出现"推荐/建议购买/稳"等语境**。
   - **写法四条**：①先标**盘口**（让球盘 / 胜平负）——让球盘的"守住"≠胜平负的"平或客胜"（坑#50）；②方向**跟市场更重一侧**, 不另起炉灶；③比分给 **2–3 档**, 不给单一比分；④紧跟一句限定（"这是我读到的结构"）。
   - 依据：头条口径本就允许比分（`risk_audit.py` 对头条"比分形态 N 处(允许, 但不许带奖金)", 只记录不拦）。原 P0.1 的"取消比分"属**自我加严**, 09-29 用户决定放开。
   - ⚠️ **风险留档（改文档不会消掉它）**：公众号永封依据是 **3.29.2 主体资质**——判的是"体育彩票分析、预测"**这件事本身**, 不是用词；**我们改自己的文档, 不改变平台的判定口径**。头条是否安全仍**未核实**（见 P2.8）。
   - 决策沿革：**2026-09-28 定案 = P0.1 全面执行**（「我的看法」收口为**市场结构陈述** + **取消比分**），首篇执行稿 `04_赛事文章/2026-09/周一选场_0928/周一001+002_头条版.md`（四道闸门全绿）；**09-29 用户改规则恢复收口比分**（即上文现行写法）。
2. **每篇必带一条增量信息**：伤停 / 首发 / 场地 / 天气 / 教练表态 / 历史纪录, 至少 1 条**三源交叉**。这是对"缺乏增量信息价值"最直接的对策, 也是当前产线**最薄**的一块（现在几乎全是竞彩官方数据）。
3. **不同形态连发**：同一天最多 1 篇串烧 + 1 篇单场, 两篇骨架不同, 发布间隔 **≥ 3 小时**（避开"批量、连续发布"的形态）。

### P1 — 一周内

## 人工特征检查清单

来源：`人工特征检查清单.md`（文件 frontmatter: `name: human-writing-checklist`；`description: AI降率核心检查清单——14个人工写作特征，写稿时逐条对照`）。
用途：写完初稿后逐条对照, 缺哪条补哪条；目标——读起来像人在赶稿时写的, 不是机器生成的。
参考拆解文章：SportsMole 热刺vs利兹联赛前预览（Ben Knapton, 2026-05-09）；Standard 托特纳姆热刺 vs 利兹联赛前讨论帖（2026-05-11）。

**1. 跨领域联想** —— 不要只在足球圈里找比喻, 拉一个圈外的人/事进来制造"意外感"。反例："热刺保级形势严峻"；正例："如果托特纳姆热刺队打电话来，保级专家肖恩·戴奇和萨姆·阿勒代斯或许会接听电话"；跑题联想："我其实挺同情西汉姆联的"。**操作方法**：写到抽象概念时问自己"这事像生活中的什么？"然后把那个东西写进去。

**2. 换称呼** —— 同一支球队/球员在文章里至少用 2-3 种叫法, 不要连续三次写"那不勒斯"。例：球队 那不勒斯 → 迭戈·马拉多纳球场的主人 → 联赛第二 → 主队；球员 赫伊隆 → 19号 → 队内射手王；对手 博洛尼亚 → 白衣军团 → 客队 → 来访者。为什么有效：AI 倾向于用同一个词从头写到尾, 人脑不会精确重复。

**3. 口语判断词穿插** —— 叙述中加入带情绪的判断词, 不是每句都客观陈述。词库："悄悄地说"（制造私密感）、"竟然"（表达意外）、"说实话"（拉近距离）、"有点邪门"（口语化判断）、"说实在的"（强调真实感）、"倒不是说"（先退一步）、"换句话说"（换个角度解释）、"精彩绝伦"（翻译腔式夸张, 适用于翻译素材）。**操作方法**：每 300 字至少放一个, 不堆砌, 自然嵌入。

**4. 原话不润色** —— 引用教练/球员/专家发言时保留口语的毛边, 不要替他们"优化"。反例："德泽尔比确认维卡里奥仍将缺阵，球员感到遗憾但目前无法上场"；正例："我不知道接下来的计划是什么。他很痛苦，因为他很想帮助球队和队友。但是，他现在还不能上场。"；重复不删："我们需要可靠的人和可靠的球员，而帕利尼亚就是其中最优秀的人之一"。为什么有效：AI 会自动精简引语删掉重复/啰嗦/情绪化部分, 而**原话就是这么说的**——重复和啰嗦本身就是人的特征。

**5. 括号即兴补充** —— 伤病信息、数据来源、补充说明用括号塞进去, 不整合进句子结构。反例："索兰克因腿筋伤势缺阵" → 正例："多米尼克·索兰克（腿筋）这场比赛来得太早了"；反例："奥卡福过去7场英超参与7球" → 正例："包括他自己的六粒进球——平均每68分钟一球"。为什么有效：括号是人类"写到一半想起来要补充"的痕迹, AI 通常会把信息整合进主句。

**6. 板块粗暴拼接** —— 不在板块之间加承上启下的过渡句, 直接拼。反例："接下来我们看看两队的历史交锋。在过去的10次交锋中……" → 正例：直接从伤病名单跳到历史交锋, 中间没有过渡；反例："分析完数据后，让我们来看看专家们的预测。" → 正例："比赛事实"板块直接接"专家预测"板块, 像论坛帖一样堆上去。为什么有效：人类编辑赶稿时不会精心设计过渡, 这种**不流畅**恰恰是真实感。

**7. 数据嵌叙事 + 双向数据** —— 不要单独开一个"数据板块", 把数字穿插在叙述里；进一步——**同时给两个方向的数据**。反例（独立数据对比块）："那不勒斯主场：12胜4平1负，进30球失15球 / 博洛尼亚客场：8胜4平5负，进26球失21球"；正例（嵌叙事）："那不勒斯这个赛季主场17场，12胜4平1负。71%的胜率，全联赛排第二。主场进了30个球，丢了15个。平均每场净进将近1个。"；正例（双向数据）："1997年至2001年间，利兹联在客场对阵热刺的四场联赛中赢了三场（1平），但最近六次客场挑战热刺均告负。"**操作方法**：每个数据点前后加一句判断或情绪；有正向数据时顺手找一个反向数据放旁边——制造"先给希望再打脸"的效果。

**8. 多声部 / 允许自相矛盾** —— 引用多方观点时让每个人保持自己的说话风格, 允许他们观点冲突。反例："专家普遍看好热刺获胜"；正例（三个专家三种人格）：希勒稳重肯定"我认为他们现在或许有足够的实力保级"、默森先夸后反转"热刺确实取得了进步……但我实在看不上他们的胜算"、萨顿理性引用数据"与10月份在埃兰路球场获胜时相同的比分"；正例（自相矛盾）：默森先说热刺进步大, 又说他们赢不了, 还跑题去同情西汉姆联。为什么有效：人的观点本来就会前后矛盾, 保留这种不自洽比强行统一观点更真实。

**9. 情绪词 / 小标题带情绪** —— 小标题或关键句不要纯信息, 带一点判断。反例："那不勒斯主场数据""博洛尼亚客场数据"；正例："那不勒斯的主场，不好惹""博洛尼亚的客场，其实没那么差"；正例（SportsMole）："那种奇怪的感觉"。**操作方法**：写完小标题后问——"这个标题有没有态度？"没有就加一个形容词或判断。

**10. 留余地的预测** —— 预测不要说太绝对, 用"想象""倾向""大概率"软化。反例："那不勒斯将获胜，比分2-0"；正例："个人倾向：那不勒斯2比0或者2比1""我们可以想象，热刺队再添三分，离保级更近一步""那不勒斯大概率不会放过"；正例（给理由+留余地）："凭借他们前几天展现出的活力，我认为他们也有足够的实力在主场击败利兹联"。**操作方法**：预测前加理由（"因为主场胜率71%"）, 预测后加限制（"大概率""倾向""个人看法"）。

**11. 松弛的标点使用** —— 不要每句都用句号；适当用分号（；）连接有关联的两个半句、破折号（——）做即兴补充或强调、逗号串联长句不拆成短句。反例："那不勒斯主场战绩出色。他们进了30个球。失球只有15个。" → 正例："那不勒斯主场进了30个球，丢了15个。平均每场净进将近1个。"为什么有效：AI 倾向短句+句号的"安全写法", 人类赶稿时会自然地用分号和破折号把句子串起来。

**12. 跨时间对比** —— 不要只说"本赛季", 拉历史数据做参照。反例："热刺本赛季主场战绩很差" → 正例："连续第二个赛季主场输掉10场比赛。只有在1991-92赛季，他们单赛季主场联赛输球场次更多（11场）"；反例："利兹联近期状态出色" → 正例："自12月初以来，只有6支球队在英超联赛中获得的积分比利兹联队（32分）更多"。**操作方法**：写到一个数据时问自己"历史上什么时候更差/更好？"然后把那个时间点拉进来做对比。

**13. 圈外信息和上下文** —— 不要只写本场比赛的两支队伍, 拉相关上下文进来：其他球队的比赛结果如何影响这场（"布伦特福德帮了他们一个忙"）、联赛格局（"如果西汉姆联周日爆冷战胜阿森纳"）、球员个人背景（"德布劳内虽然只来了半个赛季"）、历史渊源（"2022年底一场激动人心的4-3主场胜利"）、教练评价其他球队（"利兹联……战胜了曼联，在伯恩茅斯表现出色地战平对手"）。为什么有效：AI 只知道给定的数据, 人类记者会自然联想到相关背景信息。

**14. 不完美的语言痕迹** —— 允许文章中出现"不标准"的表达：翻译腔、语法小瑕疵、不完美的措辞。例：翻译腔"对此我们非常尊重他们"（直译英文 "We respect them a lot for this"）、不完美的锚文本"在 [伯恩茅斯] 表现出色地战平对手"（链接插在句中）、重复用词"可靠的人和可靠的球员"。为什么有效：AI 生成的中文很"标准"很"流畅", 真人写的有毛边；这些"不完美"在检测工具眼里反而是**人类信号**。

### 快速对照表（原文, 逐条打钩）
