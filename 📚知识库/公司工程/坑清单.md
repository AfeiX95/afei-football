## 自改进总结里尚未进坑清单的教训

### 自改进总结_20260921.md

- 任何"按符号分角色"的统计，必须与已知基准对表后才允许下结论（+1线首版算出 47.2/23.6/29.2，按角色翻转后 29.2/23.6/47.2 才与基准 32/23/45 对上）。
- 本批两条线同时偏主队（主队覆盖 17/29=58.6% vs 库基准 34.6%），但 n 太小全部不显著 → 只记录、不改判据。
- 出稿对账必须补上"工具当时怎么说"这一列：上一版只对照"我们写的 vs 实际"，漏掉了工具输出。
- 同日出稿"是否给方向"标准不统一（待定硬规则）：默认回抄深度稿判读列；编辑若要选边，必须在稿内标明与结构判读相反。
- 环境：Python 3.14.3 可用、A 档依赖 cp314 轮子齐、缺 faiss/sentence-transformers → KB 优雅降级；venv 内无 pip，须用基础解释器 `pip --python <venv解释器>`（`--python` 必须在子命令之前）。
- config 的 `odds` / `hhad` 键必须是大写 H/D/A，否则 `run_model` 抛 `KeyError: 'H'`。
- 官方"近10场"数据在 `value.matchList`；判主客用 `homeTeamAbbName/awayTeamAbbName` 精确匹配（不能用 `uniformHomeTeamId` 比 `gmTeamId`，也不能用全称子串匹配）。
- 青年队/赛会制球队的"近10场"必须先看日期跨度（韩国亚运男足近10场横跨 2023-09→2026-09，2026 年内仅 1 场；模型据此算的 4.66 球、大2.5球 81.3% 两数都不可用）。
- 第四道闸门 `risk_audit.py` 转正：比分形态（历史比分也算）/公众号硬禁词/免责声明语境/未开售处是否印数/头条术语密度；**`方向` 在公众号是硬禁词，在头条只是普通词**。
- 工具待办：`afei_generator.run_model` 在"胜平负未开售"时抛 `AttributeError: 'NoneType' object has no attribute 'items'`；比分盘反推的 1X2 偏高（本次反推主胜 85.0%），只能定性、须在 config `_口径说明` 标注"反推、非官方"。
- 标题口径：头条上限 36 字（30 只是提示线），加"15:00"会到 39 字放不下 → 时间只留信息卡；公众号上限 60。
- 检查器判据要看源码：`check_md_release` 的"λ±10% 区间表"判据 = 全文含 `λ` 且（含 `±10%` 或 `场景`）；公众号"纯数据句占比 ≥30%"是真硬线。
