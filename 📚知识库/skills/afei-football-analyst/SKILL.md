## 二、数据层：AFEI引擎六段式

### L0.5 战略目标判断（最关键一步，不可跳过）

```
比赛阶段判断 → 战略目标分析 → xG修正系数

淘汰赛首轮：
  强势方目标="90分钟解决" → xG×0.9
  弱势方目标="不输（拖入加时）" → xG×0.5~0.6

实力接近淘汰赛：
  双方目标="全力争胜" → 弱势方×0.85 / 强势方×0.95

小组赛末轮（已出线双方）：
  目标="控分/轮换" → 双方×0.7~0.8
```

### L1 xG计算

```
xG_for ≈ 场均进球 × 0.92
xG_against ≈ 场均失球 × 1.08

λ_home = (主队xG_for + 客队xG_against) / 2 + 状态修正
λ_away = (客队xG_for + 主队xG_against) / 2 + 状态修正

状态修正：近5场 W+0.08 / D+0.02 / L-0.05（±0.25封顶）
身价修正：身价比>3→+0.10 / >2→+0.05
伤停修正：核心球员出局 → λ直接下调5~15%
### λ修正规则 R11-R16（Batch #12校准 · 2026-07-26）

详见 match-model-pipeline skill 中的「自生长λ修正规则」章节。

速查表：

| 规则 | 场景 | 修正 |
|:----|:-----|:-----|
| R11 | 五五开赛事（赔率2.0-3.0） | 平局概率+5-8pp |
| R12 | 欧战资格赛 | 主队λ-10%，客队λ+5% |
| R13 | 韩职全北/蔚山受让 | 豪门λ+8-10% |
| R14 | 巴甲 | 平局概率+5pp |
| R15 | 韩职 | λ系数0.95→0.85 |
| R16 | 强队低赔主胜(≤1.50)非碾压态 | 主胜-3-5pp |
```

### L1 泊松→MC模拟

```python
# 泊松概率
P(k) = (λ^k × e^(-λ)) / k!

# MC模拟（正确写法）
t = 0.0
while True:
    t += -math.log(1 - random()) / lam
    if t >= 1.0: break
    goals += 1
# ⚠️ t从0开始累加指数间隔，不是t=1开始
```

### L2 市场隐含概率

```
P_raw = 1/odds
P_market = P_raw / Σ(P_raw)    # 去水处理
```

### L3 Edge检测

```
Edge = P_model - P_market

Edge > +6% → 强价值 ⭐（必出单）
+3~+6%  → 中价值 🟡（可出单）
0~+3%   → 弱价值 ⚪（观察）
< 0%    → 无价值（放弃）
```

**品牌溢价修正：**
- 传统强队（西班牙/德国/英格兰/巴西/法国）→ 市场溢价 +3~8%
- 非传统强队（瑞士/克罗地亚/日本等）→ 市场折价 -3~6%
- ⚠️ 淘汰赛弱势方（目标="不输"）→ 品牌折价被抵消

### L4 Kelly仓位

```
b = odds - 1
p = 模型概率
q = 1 - p
f* = (b × p - q) / b
最终仓位 = f* × 保守系数(0.5) × 冷门修正(0.6~0.8)
```

### L4 比分EV

```
EV = 模型概率 × 赔率 - 1
EV > 0   → 正期望
EV > 0.5 → 高价值 💎
```

## 三、叙事层：战术级拆解（六段式）

在数据层完成后，用以下结构产出叙事层分析。详见知识库 `📚写作指南\战术级拆解模板.md`

```
1️⃣ 比赛本质定义
   "[控球极限体系] vs [高强度破坏型反击体系]"
   → 决定比赛的不是谁更强，而是"强队什么时候破局"

2️⃣ 战术结构拆解
   强队：核心结构 / 进攻模型 / 问题点
   弱队：战术结构 / 进攻来源 / 优势点 / 致命问题

3️⃣ 节奏模型（时间轴三段）
   ⏱ 0-30分钟 → 试探+消耗
   ⏱ 30-60分钟 → 关键窗口（破门概率最高）
   ⏱ 60分钟+ → 分剧本（先进球/0-0）

4️⃣ 关键胜负点
   ① 首球时间
   ② 弱队定位球质量
   ③ 强队边路宽度

5️⃣ 冷门路径
   强队久攻不下→弱队反击/定位球领先→反控节奏

6️⃣ 最终结论
   🎯 主预测比分
   🔁 次选比分
   🧠 本质一句话
```

## 五、输出层：文章生产

### 标题铁律
```
公式：日期+队名VS队名：钩子（≤30字）
多场合集：所有队名必须出现在标题
```

### 必备元素（每篇必含）
```
- 话题标签 × ≤3
- 赛事信息头（时间·场馆·轮次）
- 数据表格（概率表+进球区间表，可加市场隐含对比列）
- "后台模型"统一称呼（禁用"泊松/蒙特卡洛"）
- "个人猜测比分方向" + "难说。真说不好。"
- 互动提问
- ⚠️ 免责声明 + 数据来源
```

### 禁用词（零容忍）
```
赔率 / 盘口 / 庄家 / 蒙特卡洛 / 泊松 / EV / Edge / 仓位 / 凯利 / 竞彩网（数据来源中不可出现）
✅ 替换为："后台模型"、"数据"、"市场"
```

### 降AI两步流水线
```
Step A → humanizer-zh：去过度连接词/四字成语连用/模板句式
Step B → 人工注入：脏话1处+跑题比喻1处+不完整句1处+视角滑动1处
         ⚠️ 不均匀分布——只3-5个点位各插1句，非均匀注入
```

### 写作池轮换
```
风格骨架(7种) → 写作模块(8种选≥2) → 呈现手法(8种选≥3) → 叙事素材包(6种选1-2)
每篇排列组合，确保没有两篇雷同
```
