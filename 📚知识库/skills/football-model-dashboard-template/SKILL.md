# 单场模型数据HTML仪表盘模板

## When to Use

模型（match-model-pipeline）跑完一场比赛后，需要生成一份可直接浏览器打开的深色主题可视化分析页面。

## 前置条件

已通过 `match-model-pipeline`（或手动）获得以下数据：

| 数据 | 来源 |
|------|------|
| 市场赔率（1.23 / 4.75 / 9.40） | 竞彩网API |
| 模型概率（59.0% / 24.6% / 16.4%） | MC 10万次模拟 |
| λ值（1.621 / 0.718） | 双方法λ估算 |
| 大2.5球%、双方进球% | MC结果 |
| 最可能比分Top 10 | MC比分分布 |
| 品牌溢价pp、Edge值 | 品牌溢价计算 |
| 球队数据（排名/身价/小组赛） | 竞彩网特征页/懂球帝 |
| 关键变量（伤停/内讧/裁判） | 雷速SWOT/竞彩网 |
| 总进球分布 | MC进球数汇总 |

## 流程

### Step 1: 加载模板参考文件

```text
skill_view(name="football-model-dashboard-template", file_path="references/single-match-template.html")
```

然后打开该 HTML 文件，直接用实际数据替换模板中的占位符。

### Step 2: 数据替换映射表

| 模板占位符 | 替换为 |
|:-----------|:-------|
| `竞彩编号` | 如 `周四083` |
| `主队` / `客队` | 如 `西班牙` / `奥地利` |
| `赛事时间` | 如 `07-03 03:00` |
| `主队排名` / `客队排名` | FIFA排名 + 小组名次 |
| `主队λ值` / `客队λ值` | 如 1.621 / 0.718 |
| `大2.5%` | 如 41.5% |
| `双方进球%` | 如 41.2% |
| `主队胜率%` / `平局%` / `客队胜率%` | 如 59.0 / 24.6 / 16.4 |
| `市场主胜%` / `市场平%` / `市场客%` | 如 72.0 / 18.6 / 9.4 |
| `Edge值pp` | 如 -13.0 |
| `品牌溢价pp` | 如 +6.0 |
| `主队色` / `客队色` | CSS颜色（主队红/蓝，客队红/橙） |
| 比分表行 | Top 10比分 |
| 总进球分布行 | 0-6球分布 |
| 敏感性行 | λ±0.2 → 胜率波动 |
| 关键变量列表 | 伤停/内讧/裁判等 |
| 方案A/B/C | 稳健/进取/激进 |

### Step 3: 配色调整

默认配色方案：

| 元素 | 默认颜色 | 适用场景 |
|:----|:--------:|:---------|
| 主队色 | `#4fc3f7` 浅蓝 | 通用 |
| 主队色（替代） | `#c9252b` 红 | 西班牙/曼联/阿森纳等红衣球队 |
| 客队色 | `#ff8a65` 橙红 | 通用 |
| 客队色（替代） | `#e0001b` 红 | 奥地利等红衣球队 |
| 平局色 | `#ffb74d` 橙 | 固定 |
| 极端信号边框 | `#ef5350` 红 | Edge>10pp的场次 |

参考 `references/single-match-template.html` 中的完整CSS变量定义。

### Step 4: 文件命名

```text
I:\阿飞说球\{YYYYMMDD}\{主队}VS{客队}_模型分析_{MMDD}.html
```

示例：`I:\阿飞说球\20260702\西班牙VS奥地利_模型分析_0703.html`

### Step 5: 验证

打开HTML文件后检查：
- [ ] 所有数据无 `占位符` 残留
- [ ] 三方向概率加起来 ≈ 100%
- [ ] 表格行数与数据一致
- [ ] 页脚信息完整
- [ ] 移动端正常显示（meta viewport已设）
