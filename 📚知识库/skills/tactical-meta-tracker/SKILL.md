# Tactical Meta Tracker 主帅战术演变追踪器

> 定位：追踪教练战术变化，自动更新球队档案
> 核心价值：教练不是机器人，战术会变。这个Skill确保模型跟上变化
> 搭配使用：football-tactical-analyst + 球队档案

---

## 一、追踪维度

### 1.1 阵型变化追踪

| 追踪项 | 数据来源 | 更新频率 |
|:-------|:---------|:---------|
| 首发阵型 | 比赛数据/懂球帝 | 每场 |
| 比赛中阵型切换 | 比赛数据 | 赛中/赛后 |
| 训练中阵型试验 | 记者推特/训练照片 | 赛前 |

### 1.2 打法风格追踪

| 追踪项 | 数据来源 | 识别方法 |
|:-------|:---------|:---------|
| 控球倾向 | 控球率数据 | >55%=传控, <45%=防反 |
| 逼抢强度 | PPDA数据 | <8=高位逼抢, >12=低位 |
| 进攻方向 | 传球热图 | 左路/中路/右路偏好 |
| 定位球战术 | 角球/任意球进球占比 | >25%=定位球依赖 |

### 1.3 赛后发言追踪

| 追踪项 | 数据来源 | 关键词 |
|:-------|:---------|:-------|
| 战术意图 | 赛后发布会 | 阵型/战术/调整 |
| 球员使用 | 采访 | 位置/角色/变化 |
| 对手评价 | 赛前/赛后 | 战术针对/部署 |

## 二、核心脚本

### 2.1 球队战术档案

脚本位置：`database/scripts/tactical_profile.py`

功能：
- 从近5场比赛数据中提取战术特征
- 生成/更新球队战术档案JSON
- 标注战术变化趋势

```bash
python database/scripts/tactical_profile.py --team "Ulsan HD" --matches 5
```

### 2.2 战术变化检测

脚本位置：`database/scripts/tactical_drift.py`

功能：
- 对比最近3场 vs 之前5场的战术数据
- 检测显著变化（控球率变化>10%、阵型变化等）
- 输出变化报告

```bash
python database/scripts/tactical_drift.py --team "Ulsan HD"
```

## 四、战术变化检测规则

### 4.1 变化信号

| 信号 | 阈值 | 置信度 |
|:-----|:----:|:------:|
| 阵型变化 | 连续2场不同阵型 | 高 |
| 控球率变化 | ±10% vs 近5场均值 | 高 |
| 射门方向变化 | 左/中/右占比变化>15% | 中 |
| 逼抢线变化 | PPDA变化>3 | 中 |
| 定位球战术变化 | 角球进球率变化>10pp | 低 |

### 4.2 变化原因推断

| 变化类型 | 可能原因 | 验证方法 |
|:---------|:---------|:---------|
| 阵型切换 | 针对特定对手 | 赛后发布会确认 |
| 控球率下降 | 对手逼抢加强 | 比赛数据对比 |
| 防守收缩 | 领先后保守 | 比赛时间线分析 |
| 进攻加速 | 落后后搏命 | 比赛时间线分析 |

## 六、注意事项

1. **不要过度解读单场变化**：教练可能只是轮换或实验，需要连续2-3场确认
2. **对手因素**：某些战术变化是针对特定对手的，不代表长期趋势
3. **伤病影响**：阵型变化可能是因为球员缺阵被迫调整，不是主动选择
4. **数据滞后**：战术数据通常赛后才完整，赛前分析只能用上一场的数据
