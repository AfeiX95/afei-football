# 头条号HTML排版生成 + SVG图表生成

## 触发条件

用户写完头条版MD文章后，要求"出头条版HTML"、"生成排版"、"文章插入图表"时触发。

## 输入

- `[比赛]_头条版.md` — 已完稿的MD文章（含模型概率、赔率、分析文本）
- 模型数据：概率分布、市场定价、高概率比分
- H2H/基础数据表格

## 输出

- `[比赛]_头条版.html` — 可直接粘贴到头条号编辑器的深色主题HTML（含3个SVG图表）

---

## 第一步：SVG图表生成

使用Python脚本（`scripts/gen_charts.py`）从模型数据生成3个SVG图表。

### 数据准备

从MD文章提取以下数据：

```python
# 六维雷达图数据（归一化0-100）
radar_dims = ["近期状态","进攻火力","防守稳固","交锋历史","市场支持","模型预测"]
hacken = [50, 78, 28, 60, 55, 57]  # 主队
guest = [67, 52, 57, 20, 25, 23]  # 客队

# 柱状图数据：模型概率 vs 市场隐含概率
model_probs = [56.9, 19.7, 23.4]  # [主胜, 平局, 客胜]
market_odds = [1.83, 3.95, 3.60]  # [主胜均价, 平局均价, 客胜均价]
# 市场隐含概率 = 返还率/赔率

# 饼图数据
pie_data = [("主队胜", 56.9, "#4fc3f7"), ("平局", 19.7, "#ffd93d"), ("客队胜", 23.4, "#ff6b6b")]
top_scores = [("2-1", 9.0), ("1-1", 7.8), ("3-1", 6.9), ("其他", 76.3)]
```

### 六维雷达图生成规则

- 6个维度等角分布（每60度一个轴）
- 网格环5圈（30/60/90/120/150半径）
- 主队多边形填充 `#4fc3f7`（透明度0.15），描边2px
- 客队多边形填充 `#ff6b6b`（透明度0.15），描边2px
- 尺寸600×460，背景 `#1a1a2e`
- 每个数据点画圆点（r=3）

### 柱状图生成规则

- 3个分组：主胜/平局/客胜，每组2根柱（模型蓝/市场黄）
- 蓝色柱 `#4fc3f7`，黄色柱 `#ffd93d`
- 柱宽度55px，组间距160px
- x轴在y=372
- 柱顶标注百分比，柱间标注Edge差异（+绿色/-红色）
- 底部写分组名
- 尺寸600×420，背景 `#1a1a2e`

### 饼图生成规则

- 左饼（主）：模型概率分布（3块），半径110px
- 右饼（次）：高概率比分分布，半径75px
- 引线+标签标注百分比
- 尺寸600×420，背景 `#1a1a2e`
- 颜色按主队蓝、平局黄、客队红

## 第二步：深色主题HTML模板

### 基础样式

```html
<div style="background:#0f0f1a;color:#e0e0e0;font-family:-apple-system,
  BlinkMacSystemFont,Segoe UI,Roboto,sans-serif;line-height:1.8;
  padding:20px;max-width:720px;margin:0 auto;">
```

### 文字样式
- 正文：`#e0e0e0`，行高1.8
- 小字标签：`#888`，字号0.9em
- 表格表头：背景 `#1e3a5f`，白色字
- 表格行交替：`#16213e` / `#1a1a2e`
- 正数/主队数据：`#4fc3f7`
- 平局数据：`#ffd93d`
- 负数/客队数据：`#ff6b6b`
- 绿色状态：`#4caf50`

### 表格结构
- 宽度100%，折叠边框
- `text-align:center`
- 表头行深蓝底 `#1e3a5f`，单元格padding 8px

### SVG图表嵌入位置

| 图表 | 插入位置 |
|:----|:---------|
| 六维雷达图 | 基础数据对比表格之后，🛡️关键对位之前 |
| 柱状图 | 模型推演表格之后，高概率比分之前 |
| 饼图 | 大小球结论之后，🌍百家定价对比之前 |

每个图表下方加一行居中灰色说明文字：
```html
<p style="text-align:center;color:#888;font-size:0.85em;">⬆ 说明文字</p>
```

### 禁用词列表（HTML版也要检查）
- ❌ 赔 → 定价
- ❌ 盘口/赢盘率 → 赢指率
- ❌ 庄家 → 机构
- ❌ 泊松/蒙特卡洛 → 后台模型
- ❌ EV → 溢价
- ❌ 凯利
- ❌ 防范 → 留意

## 第三步：数据核验（嵌入前必做）

HTML生成前必须逐项核验以下数据：

1. **排名/积分** — 对照源数据表 ✅
2. **近6场战绩** — 胜平负计数是否一致
3. **场均进球/失球** — 总分/场次计算
4. **赢指率** — 亚盘赢/输场次计算
5. **大球率** — 总进球≥3场次/总场次
6. **H2H记录** — 逐场计数，注意检查"主场交锋总进球≥3"断言
7. **伤停球员** — 姓名/位置是否匹配源数据
8. **赔率数据** — 每家机构数值逐一比对
9. **百家均值** — 与官方即时平均值对比
10. **模型概率** — 三方和是否为100%
