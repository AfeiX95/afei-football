# 阿飞说球 · 内部分析报告与双层出稿技能（v3.2）

> **真源**：流程详规见 `docs/INTERNAL-REPORT-WORKFLOW.md`；生成脚本为 `scripts/build_internal_report.py`；自洽验收为 `scripts/check_report_consistency.py`。  
> **红线**：A 层（内部分析报告，含赔率/凯利/EV/50 元方案）**永不上平台**；B 层（头条公开稿，文件名带 `赛事前瞻`）严守 R41/R55/R56/R60/R61/R62/R63。

## 一、触发场景与双模式路由

| 场景 | 切入模式 | 执行动作 |
|:--|:--|:--|
| 赛前竞彩分析 + 写头条文章（**默认**） | **竞彩双层模式** | 采数补全 → A 层 17 维内部分析报告（含 ≤50 元方案）→ `check_report_consistency` 0 ERROR → B 层头条公开稿 → `preflight` + `check_dup` + `check_pub_safety` 全绿 |
| 审核/改写已有头条稿件 | **审核改稿模式** | 事实核验 + R41/R55/R56/R60/R61/R63 合规过滤 + 反工整去 AI 味 + 交付附「采纳项 / 合规不采纳项 / 终态校验指标」 |
| 传足 14 场胜负彩 / 任选 9 场 | **传足全流程模式** | 模块一（14 场盘型归类 + `--` 缺赔外盘补齐）→ 模块二（全网情报 + 媒体/AI 多维共振总表）→ 模块五（任九 ≤32~50 元精选单 + 14 场复式 + 3/1/0 校验） |
| 浏览传足历史开奖列表 / 单期赛果页 | **传足复盘校准模式** | 模块三（近 30/100 期 3/1/0 分布与五档奖金成色节奏）或 模块四（单期冷热归类 + 奖金成因 + 跨期重合球队预警） |

## 二、A 层内部分析报告执行管线（采→补→算→报→验）

```bash
python -X utf8 scripts/prematch_intel.py --date YYYYMMDD --leagues --media  # 1. 竞彩五套盘+积分榜+比赛时刻天气+外媒
python -X utf8 scripts/books_500.py --date YYYYMMDD                         # 2. 500 百家亚盘/欧赔/大小（初盘→即时）
python -X utf8 scripts/market_from_intel.py YYYYMMDD                        # 3. 聚合市场结构
python -X utf8 scripts/audit_data.py YYYYMMDD                               # 4. 入模前数据质检（阻断错位/污染）
python -X utf8 scripts/model_v3.py YYYYMMDD                                 # 5. 跑 v3.1 模型（λ/MC/五状态EV/台账）
python -X utf8 scripts/build_internal_report.py YYYYMMDD 周N<k>场           # 6. 生成 v3.2 内部分析报告
python -X utf8 scripts/check_report_consistency.py YYYYMMDD                 # 7. C1-C7 硬验收（必须 0 ERROR）
```

### 必查四项硬核情报（落入 `state/intel/<date>/_ext_<date>.json`）
1. **关键伤停与停赛**：前场支点、做墙中场、主力中卫防线（只采可核实源，无源明标不编）。
2. **近期状态与主客反差**：全季 vs 同主客 vs 近 5 场（先去重再算），区分「创造机会能力」与「临门一脚转化率」。
3. **赛程密度与体能消耗**：周中欧战/亚冠、国际比赛日后加赛、长途飞行、轮换深度。
4. **历史交锋心理与风格克制**：识别排名悬殊背后的反常交锋记录。
5. **缺失赔率补齐**：竞彩显示 `--` 或 500 被拦时，走 `scripts/_x500.py gate` 或联网补主流外盘欧赔，**不得跳过或凭记忆估算**。

## 三、A 层报告标准结构（每场 7 块覆盖 17 维 + 末尾 2 块）

> **顺序铁律**：逐场拆解在前，全批汇总与 50 元方案在末尾（严禁把总结提到开头）。

1. **一、情报收集与利弊拆解（含天气）**：赛事背景、比赛时刻天气（自动读 `_leagues_`）、伤停停赛、体能赛程、主客有利/不利情报、情报冲突与伤停预警。
2. **二、百家欧赔、盘口变化与凯利指数**：百家亚盘/欧赔/大小初盘→即时表、去水三向、位移轨迹、**凯利指数（均值/返还率/主平客凯利方差×100/超标警报）**、跨盘自洽。
3. **三、积分形势、近期状态与战意**：积分榜形势（合并 `_data_` + `_leagues_`）、真实战意、同主客与近 5 场重算进失、逐场战绩、历史交锋。
4. **四、全球主流媒体及 AI 预测分析**：海外/国内媒体观点（Goal / SportsMole / 懂球帝 / 7M 等）、预测市场（Polymarket 等）与第三方算法（API-Football / Forebet 等）对照。
5. **五、数学模型模拟分析预测（v3.1）**：λ_A / λ_B / λ_C、Edge(A−B)、Gamma 参数区间、亚盘/大小五状态 EV（含 C50 拦截）、10 万次 MC 与进球分布、敏感性、比分前六。
6. **六、核心矛盾、胜负手与看点（「该赢」vs「真赢得」）**：拆解账面优势与实际赢球条件的落差 + **R63 单场关键变量（胜负手）** + 看点 + 技术面研判。
7. **七、单场综合分析与打破条件**：**把握分级**（`S 最敢碰 / A 顺势可跟 / B 赢面在但易卡壳 / C 防平弱倾向 / D 证据不足跳过`）+ 共振定性 + 方向站位 + 剧本比分三档（首选/次选/防范）+ 打破条件 + 足彩。
8. **八、全批多维共振总表与把握分层排序**：一表总览全批共振/背离与凯利方差，按 S→A→B→C→D 排序，附溢价清单与基线自检。
9. **九、50 元以内投注与比分方案（A 层内部参考）**：按单注 2 元核算，**方案 A（稳健方向过关）＋ 方案 B（剧本比分博弈）合计强制 ≤ 50 元**，明列 D 级剔除清单与临场首发熔断提示（支持 `_plan_<date>.json` 人工覆盖）。

## 四、A 层 → B 层（头条公开稿）脱敏与出稿红线

1. **彻底剥离 A 层专属内容**：零具体赔率小数、零让球行话（受让/平手盘/球半/上盘/走盘）、零机构态度/资金流向编造、零凯利/EV/模型内部术语（泊松/蒙特卡洛/权重/样本量）、零金额注数与押注黑话（押/下注/稳胆/投注）。
2. **区分赢球概率与赢球可信度**：多场同向时必须按把握层次拉开表达，严禁平行排比与同构结尾；先定单场独立判断再定标题与开场（R61）。
3. **证据强度与关键变量（R60/R63）**：数据权重 <0.25 只写弱倾向/观察；分歧 <5pp 不用强词；每场落清一个真正能让纸面数字失效的 R63 关键变量。
4. **硬门禁（全绿才交付）**：
   - `python -X utf8 scripts/writing_engine.py --pick --matches N`（R62 风格×结构轮换）
   - `python -X utf8 scripts/preflight.py <文章.md>`（800–1500 字 + 8 项合规 + R55 视角 + 破折号 ≤3 + 句长 sd）
   - `python -X utf8 scripts/check_dup.py YYYYMMDD`（0 命中）
   - `python -X utf8 scripts/check_pub_safety.py YYYYMMDD`（A/B 隔离安全闸 0 违规）

## 五、传统足彩（14 场 / 任九）专项速查

- **盘型归类**：纯五大联赛周末期 / 次级混杂大奖滚存期 / 周中欧战杯赛期 / 国家队比赛日期。
- **任九策略**：果断剔除 5 场盘模背离/多模型互打/最混乱场 → 锚定多维共振稳胆 → 双选投向强队体能伤停隐患局与次级联赛平局回补局 → 核算 `3/1/0` 配比与精确金额（2 元/注，不超预算）。
- **严禁脑补未加载页面**：历史开奖与单期赛果复盘必须严格按实际展示赛果逐期核算；页面未切换时直接提醒用户切页。
