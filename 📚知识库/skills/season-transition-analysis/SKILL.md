# 赛季过渡期分析管线（Season Transition Analysis）

## 何时使用

当以下任一条件成立时加载此技能：

1. **比赛在联赛休赛期或赛季初进行**（7-8月）
2. **一方已完赛季，另一方赛季进行中**
3. **双方都已休赛≥6周但备战节奏不同**
4. **特征分析页同时缺失H2H、积分榜、射手数据**（欧冠资格赛典型）
5. **跨联赛/跨大陆俱乐部比赛**（欧战资格赛、友谊赛性质的杯赛）

## 核心原则

> 赛季状态差异是λ估算中最容易被忽略的隐藏变量。
> 模型偏差>10pp的案例中，超过一半源于未量化的赛季状态差异。

## 场景一：一方休赛 vs 一方赛季中

### 触发条件
一方联赛已休赛≥6周，另一方联赛赛季进行中。

### 修正方法
```
休赛队：λ×0.90（进攻端受影响更大）
赛季中队：λ×1.02（比赛节奏保持）
```

### 案例（2026-07-15 杰尔2-2雷克维京💥）
杰尔(匈甲休赛2个月·仅2场热身赛)HT 2-1领先→下半场体能崩盘→2-2被逼平
Model原给杰尔73.3%/Edge+14.2pp，未修正状态差导致方向失误。

## 场景二：双方都休赛但备战深度不同

### 何时触发
双方都已休赛≥6周（如欧洲二级联赛5月结束→7月欧冠资格赛），但备战节奏差异显著。

### 判断流程
```
① 查双方最后一场正式比赛日期
② 查双方友谊赛场次(数量+对手强度)
③ 查是否有已踢正式比赛(超级杯/杯赛)
④ 按修正表调整λ
```

### λ修正表

| 备战组合 | λ修正 | 2026-07-22实战案例 |
|:---------|:-----|:------------------|
| A：3-4友谊赛 vs B：4-6友谊赛+1正式比赛 | A×0.90~0.93, B×1.03~1.05 | AGF(3友谊赛·休赛9周) vs 波兹南(4友谊赛+波超杯) |
| A：0-2友谊赛 vs B：5-7友谊赛 | A×0.90, B×1.00 | — |
| 双方友谊赛场次接近（±2场） | ±0.02或不修 | 格风暴(6场) vs 哈茨(4场) |
| 一方含惨败（净负≥4） | 该方进攻-2%，防守-3% | 格风暴2-6 LNZ Cherkasy |
| **双方休赛≥9周(无正式比赛)** | **双方各×0.93（强度×0.90）** | AGF 5月18日末轮→7月22日首战 |

### 关键判断标准
**最后一场正式比赛日期**（不是友谊赛）。如果一方在开赛前1-2周内已有一场正式比赛（超级杯/国内杯赛），而另一方仅有友谊赛，则正式比赛的实战状态增益不可忽视。

## 场景三：零H2H+零积分榜+零射手数据

### 问题描述
欧冠资格赛的特征分析页中，"历史交锋"、"(联赛)积分榜"、"射手信息"三个模块全部显示"暂无数据"。这在常规联赛分析中不出现。

### 应对策略

当三模块同时为"暂无数据"时：

1. **跳过H2H修正**（H2Hλ修正自动不触发）
2. **联赛实力改用替代指标**：
   - FIFA排名（国家队≠俱乐部但反映联赛整体水平）
   - UEFA俱乐部系数
   - Transfermarkt总身价对比
   - 搜索：`"teamA vs teamB champions league" form`
3. **教练背景成为关键情报源**：
   - 搜索教练履历（同国/同联赛教练带队有战术优势）
   - 搜索：`"{coach name} former teams"`
4. **以市场法为主，数据法为辅**：
   - 资格赛数据基础薄弱，双向λ偏差通常>0.5
   - 偏差>0.5时，方法1(数据法)不可靠，偏向方法2(市场法)
   - 但需保留休赛期修正（市场通常定价不足）

## 场景四：同国/同联赛教练带队"倒戈"

### 定义
教练并非对手前主帅，但与对手同国/同联赛出身，对对手体系有深度了解。

### 实战案例
2026-07-22 波兹南主帅Niels Frederiksen（丹麦人）——此前执教布隆德比(丹超冠军)、丹麦U21、埃斯比约，对AGF(丹麦冠军)了如指掌。

### 搜索线索
```text
查教练履历→
  若执教过对手所在联赛/国家队→ 标记为"同联赛倒戈"
  若执教过对手本身→ 标记为"旧帅倒戈"（λ修正幅度更大）"
```

### λ修正
- 教练情报优势方：进攻λ×1.02, 防守λ×1.02（战术针对性）
- 对手被熟悉方：进攻λ×0.98（战术被看透）
- 净λ差值：约3-5%（较小但不可忽略）

## 综合使用流程

欧冠资格赛分析时三个场景常同时出现：

```
Step 1: 检查特征分析页数据完整性
   → 缺H2H/积分榜/射手？→ 使用场景三策略
Step 2: 检查双方休赛状态
   → 最后正式比赛日期
   → 友谊赛场次+质量
   → 是否已有正式比赛
   → 使用场景一/场景二修正
Step 3: 搜索教练背景
   → 同国/同联赛？→ 使用场景四修正
Step 4: 组合修正 → 跑双方法λ
Step 5: MC模拟 → 资格赛Edge 7-8折
```

## 常见陷阱

1. **忽视友谊赛质量**：只看数量不看对手。胜巴列卡诺(西甲)≠胜利文斯顿(苏冠)
2. **默认双方状态相同**：双方都休赛≠备战深度相同。谁先踢了正式比赛是关键分界线
3. **忽略教练变量**：同国教练带队回国比赛是小变量，但在0 H2H+0积分榜时成为不可忽略的情报源
4. **直接按联赛级别判断**：丹超(欧战系数#12) vs 波甲(欧战系数#15)差距很小，不足以支撑明显λ差异
5. **非五大联赛主场高估（2026-07-20校准）**：非五大联赛的欧冠资格赛球队，主场优势系数应从0.15降至0.10。阿塞超、奥甲、丹超等联赛球队的主场数据受联赛水平限制，参考价值低于五大联赛。格风暴(奥甲)主场λ被高估案例。
