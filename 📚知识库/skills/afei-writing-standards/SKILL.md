# 阿飞说球写作偏好覆盖层

## 用途
此技能记录`football-match-preview-article`中未被覆盖或需要覆盖的用户写作偏好。加载写作skill后、写文章前，加载本skill应用修正。

## 修正记录

### R1. 比分表述方式（2026-07-22）
❌ 原格式：`个人猜测比分方向：X-X或X-X`
✅ 修正格式：`概率最高的比分是X-X（XX%），其次是X-X（XX%）`
- 只用概率描述，不用推荐语气
- 带上具体百分比数值
- 多场表格表头从"推荐比分"改为"高概率比分"

### R2. 多场合集重复项规则（2026-07-22）
- `难说。真说不好。` 在全文中**仅出现1次**（放在最后一场段落末尾）
- `数据来源：懂球帝、ESPN、各队官网` 在全文中**仅出现1次**（放在文末免责处）
- 前几场不重复出现这两句

### R3. 标题规则（2026-07-22）
多场合集标题中，表头列名：
- ❌ `推荐比分` → ✅ `高概率比分`

### R4. 标签命名（2026-07-22）
- ❌ `💰 资本信号` → ✅ `💰 信号`
- 精简，去冗余

### R5. 强制分析维度（2026-07-22）
每场分析必须包含以下两个独立段落（嵌入数据表前后）：

**⚔️ 战意** — 分析双方比赛动机：
- 谁更需要赢/更想赢
- 历史背景（首次参赛、夺冠后首秀、告别战等）
- 心理状态（复仇动力、压力、松弛等）
- 赛事阶段对战意的影响（资格赛首回合、末轮等）

**💰 信号** — 分析市场信号：
- 市场定价与模型概率的偏差幅度
- 偏差来源（数据泡沫/信息不对称/过热/低估）
- 资金流向观察（临场价格移动方向意味着什么）
- 价值信号判断

### R6. SCA开篇公式（2026-07-24 新增）

每场比赛开头使用SCA三段式开篇（S场景→C冲突→A答案），替代直给式开头。

**模板：**
```
很多人【S场景】，以为【固有认知】。但【C冲突】。后台模型跑完后的结论是【A答案】。
```

**三种变体按比赛类型选：**
| 类型 | 适用场景 | 示例 |
|:----|:---------|:-----|
| 常识vs真相 | 强弱分明场次 | 看到榜首打中游以为稳赢→拆开主场数据发现只有50%胜率 |
| 预期vs现实 | 表面均衡实际悬殊 | 以为五五开→拆开主客场+伤停+H2H发现差距极大 |
| 热度vs价值 | 过热/价值信号场次 | 市场低赔看似稳→模型跑完发现溢价/过热 |

**正文完整结构（单场）:**
```
SCA开篇（1段，钩子）
⚔️ 战意（1段，事实描述）
📊 数据表 + 比分表
🌍 外媒对比（1段，2-4家）
💰 信号（1段，偏差分析）
```

更多示例见 `📚知识库/写作指南/SCA开篇公式.md`

### R9. 4场以上（8-10队名）标题处理（2026-07-23 新增）
当凌晨场达到4-5场时，将所有队名塞进30字内**不可行**（10队名+日期≈44字已超限）。

| 场次数 | 标题策略 |
|:------|:---------|
| 1场（2队） | 单场：`日期+主队VS客队：钩子` |
| 2场（4队） | 四队名空格分隔 |
| 3场（6队） | 六队名无VS直连 |
| **4-5场（8-10队）** | **仅列5支主队+"五场"+赛事名**，客队名放标签行 |

**实战已验证格式（29字 ✅）：**
`7月24日凌晨五场欧联：哈马比本菲卡贝西克塔斯特温特海杜克`

补漏法则：所有客队名在正文标签行出现（如 `#哈马比VS安德莱赫特 #本菲卡`），弥补标题中的搜索漏失。

### R10. 降AI写法的具体示例（2026-07-22 新增）
每篇选3-5处，不均匀分布。以下为实战验证可用的写法：

| 要素 | 具体写法 | 放置位置 |
|:----|:---------|:---------|
| 脏话/粗口 | 「说白了」「说句不好听的」「确实够烂」 | 数据段落后，切入口语 |
| 跑题比喻 | 「就像三国里那些看起来兵多将广的，真打起来不一定赢」 | 信号段落末尾 |
| 不完整句/断句 | 「金泉这个队吧，你说他强也不强，说弱也不弱，就是平。一直平。」 | 平局大师/状态描述后 |
| 视角滑动 | 突然从分析师切到球迷：「不过说句不好听的」 | 战意/分析段落间 |
| 反问/自问自答 | 「真要指望他们客场稳赢？」 | 客队能力存疑时 |

五要素不必全用，至少覆盖3种。几处人工痕迹不均匀分布。

### R11. 叙事池使用（2026-07-22 ｜ 2026-08-20 更新：选型记录强制落盘）

写作前加载 `📚知识库/写作指南/叙事池.md`，从10个维度中选2-3个嵌入正文：
- ⚔️ 战意（必选，至少1个角度）
- 💰 信号（必选，至少1个角度）
- 外媒对比（固定维度）
- 再从其余维度选1-2个
- 同维度不连续两篇用同一种角度

**选型记录强制落盘（2026-08-20 恢复机制）：**
1. 写完文章后，把本篇使用的「维度+角度」追加到 `📚知识库/写作指南/叙事池.md` 文末「选型记录」章节，编号递增（#N）；
2. 下一篇动笔前**先查最新选型记录**，从不同维度或不同角度取材，避免连续两篇同款；
3. 选型记录随 git 提交，防止丢失（历史教训：早期选型记录未落盘全部丢失，轮换机制失效）。

### R12. 外媒对比段落规范（2026-07-24 新增）

每场分析**有源才写**🌍 外媒对比段落，位置放在比分表之后、💰 信号之前。

> 🔴 **R12 修订（2026-10-06，用户定）**：检索不到可用外媒源时，**直接不写这一段**——不要写"待补 / 查不到 / 不编造 / 暂无外媒覆盖"之类的占位说明，那对读者是废话。门禁第 5 项已同步把外媒从硬性必备降为可选（`check_article.py` v1.1），缺了只提示、不判 FAIL。

**格式：** 叙述式，不列整齐表格。有分歧就呈现分歧。
**来源：** 2-4家外媒（Sports Mole / Forebet / WinComparator / FootballPredictions / Sportskeeda / SoccerVital）

**实战示例：**
```html
<p><strong>🌍 外媒对比：</strong>WinComparator给博塔弗戈74%胜率，比模型还高3个点。但FootballPredictions的AI模型却预测2-2平局——理由是两队防守都有问题。说白了，外媒在"博塔能不能零封"上有分歧，但在"博塔不败"上基本一致。</p>
```

**降AI技巧：** 外媒对比段落是植入"说白了"等口语化表达的最佳位置。

### R13. 赔率时间序列在信号段的应用（2026-07-24 新增）

当竞彩固定奖金页有赔率时间序列数据时，在💰 信号段落中引用资金流向：

**格式：**
```text
竞彩主胜从开盘1.93一路降到1.75（降9.3%），客胜从3.20升到3.80（升18.8%）。
资金持续涌入{方向}方向，与模型方向一致/矛盾。
```

**信号解读规则：**
- 主胜持续下降 → 资金涌入主队 → 与模型一致则Edge被市场"追认"
- 客胜持续上升 → 市场卖出客队 → 客队价值信号
- 平赔稳定 → 平局非资金主方向

### R15. 标题优化策略（2026-07-24 后台CTR数据驱动）

用户头条号后台数据分析显示，标题类型对CTR影响巨大：

| 标题类型 | CTR | 案例 |
|:---------|:----:|:-----|
| **悬念/冲突型** | **>10%** | "9连败的魔咒遇上15场0胜的尴尬" |
| 特定看点型 | ~9% | "最稳、最猛、最被低估" |
| **球队名堆砌型** | **3.6%** | "哈马比安德莱贝西克中日德兰斯海杜克帕福斯" |

**原则：**
1. 只放1-2个最热门队名，其余正文展开
2. 用悬念/冲突/数字制造停留理由
3. ≤30字硬限制
4. **禁止球队名堆砌** — 信息过载导致读者跳过

**优化示例：**
```
❌ 旧: 7月24日哈马比安德莱贝西克中日德兰斯海杜克帕福斯：欧联
✅ 新: 芬超倒数第2vs倒数第3：70%克星胜率今晚失灵？

❌ 旧: 7月25日瓦斯特拉斯奥尔格里特：主场虫遇上历史克星
✅ 新: 瑞超最诡异的主场虫：客场赢马尔默回家就输
```

### R17. 互动钩子模板库（2026-07-24 评论率优化）

每篇文章末尾必须有1个互动钩子，从以下模板选：

**钩子A — 数据争议提问：**
```
你们觉得[数据矛盾点]是[原因A]还是[原因B]？评论区聊聊。
```

**钩子B — 立场引导：**
```
[判断]你信不信？反正我是信了。你们呢？评论区聊聊。
```

**钩子C — 比分竞猜：**
```
你们觉得这场能打破[X场X胜]的魔咒吗？评论区留个比分，赛后回来验证。
```

**钩子D — 多场选择题：**
```
这三场[赛事]你们觉得哪场最有看点？[悬念A]？[悬念B]？评论区聊聊。
```

### R20. 自媒体合规话术替换总表（2026-08-19 新增 — 系统化合并 R7/八层铁律/用户方法论）

面向头条/百家号/抖音等「荐彩/导流」审核严平台时使用。原则：**形式上做严谨赛事推演与数据科普，逻辑上精准满足彩民决策需求**。与 R14（竞彩数字表述）并存：数字可写，但必须配定性词汇解释。

| 平台违规高危词 | 安全学术词 | 实际传达的实战信息 |
|:--------------|:----------|:-----------------|
| 竞彩胜平负、主胜、买客队 | 胜负走势倾向、看好主队拿分/全取三分 | 胜平负方向 |
| 让球、让胜、受让 | 门槛要求、净胜球预期、指数阻力 | 让球胜平负判断 |
| 盘口、水位、初盘、变盘 | 机构初始态度、数据阻诱模型、市场热度 | 指数变动与市场意图 |
| 推荐、必发、稳胆、红单 | 赛事前瞻结论、核心推演、概率偏向 | 明确观点支持 |
| 2串1、过关、投注建议 | 数据组合参考、风险对冲推演 | 串关或防守策略 |
| 庄家 | 市场 / 机构 | — |
| 打穿 | 大胜 / 赢球 | — |
| 赔率不值 | 定价不值 / 溢价 | — |
| 境外平台名（bet365/皇冠/威廉希尔等） | **一律不出现**（一票否决） | — |

**细节要点：**
1. 杜绝外部引流：不出现「公号」「看更多私信」「进群」「带红」等字眼
2. 金额与赔付数字尽量定性化：「低位防范」「合理支撑区间」；确需写数字时配合解释（R14 格式）
3. 文末免责声明（肉质化包装，现有模板）
4. 落脚话术三件套：方向倾向（保平争胜/净胜1球以上）+ 节奏进球预期（沉闷缠斗1-2球/大开大合3球+）+ 比分推演

### R21. 实战落脚多重化（2026-08-19 新增 — 覆盖 R16 单一比分落脚）

彩民最买账的是「多重落脚点」：**不只给胜负，还给出让球方向与进球数互补防守方案**。每场结尾固定四重落脚（替代只写推荐比分）：

```
🎯 方向倾向：主队保平争胜（主胜概率更高）/ 客队不败
🧱 门槛方向：主队让-1难打穿，受让方+1有支撑（指数阻力大）
⚽ 进球区间：倾向胶着小比分 1-2 球（沉闷缠斗）
🔢 比分参考：1-0、2-0、1-1（首选/次选/防范，各带一句逻辑）
```

- 四重落脚必须**逻辑自洽**：战术→节奏→进球数→比分一条链推下来，禁止方向与大小球自相矛盾
- 「互补防守方案」示例：看好主胜但疑虑客队反击 → 方向主胜 + 进球看小 + 受让方不败对冲

### R22. 条件式场景推演 + 战术转化表（2026-08-19 新增）

**（1）条件式推演（if-then 剧本，替代静态剧本A/B/C概率）**
不要只写「主队会赢」，写清楚局面分支：
```
客队若早早落后将被迫压上，主队反击空间更大；
若前60分钟胶着，比赛大概率走向小比分；
若主队迟迟打不开，替补席上的[X]是破局点。
```
每场至少给 2 个条件分支，分支必须由「战术对决+伤停」推出，而非空想。

**（2）战术→进球数推导（战术分析的最大价值是判断节奏快慢）**

| 技战术分析点 | 场面逻辑 | 实战结论（合规表述） |
|:------------|:---------|:-------------------|
| 高位逼抢 vs 后场出球 | 压迫强度大→逼迫后场失误直接射门 | 倾向主队破局，防线稳定性决定胜负 |
| 阵地攻坚 vs 低位铁桶 | 缺肋部渗透/破密集手段→边路传中效率低 | 进球转化率低，倾向沉闷小比分（1-2球） |
| 后防回追慢 vs 边路/反击快马 | 攻守转换被打身后→频繁战术犯规吃牌 | 节奏大开大合，进球预期偏高 |
| 关键位置伤停（后腰/出球中卫） | 中场拦截硬度骤降→后场出球受阻 | 弱势方防守崩盘风险大，门槛难以支撑 |

把「攻防克制」写清楚，大小球推导就顺理成章——**每个战术点后必须挂一个进球数/节奏结论**。

**（3）战术排除法（用战术短板排除冷门）**
```
「客队双后腰全部缺阵，客场完全无法组织有效反击，爆冷几率极低」
```
战术短板直接排除选项，让结论更硬，避免「两头堵」——彩民最烦模棱两可。

**（4）拆穿假象（读者最买账的反常识细节）**
- 看似连胜但对手极弱 → 翻对手近5场强度
- 看似连败但 xG 预期进球极高 → 运气差≠实力差
- 首轮大胜题材 vs 历史交锋克星 → 题材热度≠真实战力

### R20b. 数字与动词合规细化（2026-08-21 新增 — 用户精修版实战验证）

头条机器审核对**具体小数数字**（1.39/1.37/2.41）敏感——易被识别为涉彩数据。规则：

| 场景 | ❌ 原写法 | ✅ 精修写法 |
|:-----|:---------|:-----------|
| 引用主胜定价 | 主胜1.39、机构开1.37 | **机构给主队开出近65%的理论胜率**（换算成百分比） |
| 让步数字 | 让一球2.41 | **让步数据让胜/让负几乎持平（36.8% vs 35.7%）** |
| 强引导动词 | 综合推荐、押、重仓 | **综合研判、终极推演、我更倾向、个人预判** |

**降权词清单（2026-08-21 用户精修版补充）：** 深盘→深位/深位让步/深位门槛；赢盘率/赢盘→删除或改"净胜X球概率"；我先押/押→我更倾向/个人预判；打穿→跨越/大胜/突破；过关→赢下/全取3分。**「让步」合规可保留**（机构让步=门槛含义）。

**原则**：小数价格尽量转成「百分比胜率」或「机构胜率支撑」表述；结论动词用研判/倾向，不用推荐/押/重仓。已实战验证（日职两场精修版 + 阿森纳重构版，头条合规通过）。

### R23. 写作骨架法则（2026-08-21 新增 — 用户方法论落地）

**（1）金字塔原理开篇**：结论先行，前两段交代核心观点/最吸引人的冲突点，铺垫不超过3句话。示例（日职精修版）：
```
周五两场日职，牌面都是主队大热：机构开出近65%的理论胜率，清一色"稳稳拿下"。
可后台模型跑完，两场都暗藏杀机。
**结论先行**：柏太阳神场无便宜可占、命门在净胜两球；东京FC场纸面胜率虚高、对面是3个月前3-0的苦主。
```

**（2）单点打透法则**：一篇文章只解决一个核心问题。罗列5个浅显观点不如把1个核心观点用「论点+案例/数据+反常识推论」讲透。两场/多场合集里，每场也只抓1个核心矛盾（如东京FC场=克星+状态差，柏太阳神场=主场50%胜率）。

**（3）小标题带结论**：小标题不用模糊词（"原因分析/数据对比"），改用带结论的动作短语：
- ❌ `数据对比` → ✅ `撕开主场伪强队面具`
- ❌ `历史交锋` → ✅ `3个月前的0-3血洗不是旧账`
- ❌ `市场分析` → ✅ `模型与市场严重背离（-13.6pp强预警）`

### R24. 语言去水三表（2026-08-21 新增）

| 常见毛病 | 优化方向 | 修改示例 |
|:---------|:---------|:---------|
| 滥用抽象形容词 | 用具体动作/场景/数字替代 | ❌ 防守非常糟糕 → ✅ 后腰连续3次失位，被对手在禁区前沿打出无对抗远射 |
| 长句从句堆砌 | 拆成短句，控制一口气读完 | ❌ 在经历了一系列伤病导致的阵容不整后主队终于复苏 → ✅ 伤员归队，主力重聚，主队止住颓势 |
| 被动语态+AI套话 | 强化主动动词，删"不可否认/总而言之" | ❌ 这被很多人认为是不可多得的机会 → ✅ 多数人盯紧了这个风口 |

**修改三遍法（定稿前必做）：**
1. 第一遍：删去全文前 15% 的废话导语
2. 第二遍：大声朗读，把所有卡顿、拗口的长句砍断
3. 第三遍：检查各段首句——读者只看段首就能了解全貌

### R27. 核心推演矩阵（2026-08-21 新增 — 多场合集去结构重复）

多场/两场文章的结论区**不要重复堆叠**（四重落脚×N + 速览表 + 综合推荐 + 结尾总结 = 四次结论冗余）。合并为一张**核心推演矩阵**表格，落脚点和比分直接放进表格：

```

|:-----|:--------:|:--------:|:--------:|:---------|:---------|
| 001 柏太阳神vs长崎 | 63.7% | 63.3% | 0（定价精准） | 主队小胜/2-3球 | 1-0/2-1（防1-1） |
| 002 东京FCvs千叶 | 64.6% | 51.0% | 🔴 -13.6pp | 谨防冷门/1-2球 | 1-1/1-0（防0-1） |
```

表格后只留 1 个互动钩子收尾，不再重复结论。已实战验证（日职两场精修版）。

### R30. 每场必须给三个比分（2026-09-13 新增；2026-10-19 按 R30-A 改写表达）

> 🔴 **R30-A（2026-10-19 用户 m08051 定，覆盖本条的表达方式）**：比分不再按「首选/次选/防范」三个**方向**摆，改成**按剧本摆**——主剧本给两格，其他剧本给一格。
> 用户原话：「比如综合下来主胜的概率大一点，那么主胜剧本的高概率比分为 2-1，2-0，冷门或其他剧本为 1-2；要是为主不败的剧本则为 2-1、1-1，这样才不会影响阅读。」
> 原因：旧写法会出现「首选主胜 51%、次选客胜 28%、防范客胜 28%」这种两档同向的话，读者一眼觉得逻辑不通。
>
> **新格式**：`**高概率比分：主胜剧本 2-1、2-0；冷门剧本 1-2。**`（独立成行，「高概率比分」五个字必须留，门禁第 5 项认它）
>
> | 主剧本情形 | 比分怎么取 | 例 |
> |:--|:--|:--|
> | 单一赛果（差距 ≥10pp） | 该赛果内概率最高的两格；第二格刻意取**总进球更少**的那格，避免两格都是大比分 | 主胜 → 2-1、2-0 |
> | 某队不败（首选与次选差 <10pp 且是「赢＋平」） | 赢的最高一格 + 平的最高一格 | 主不败 → 2-1、1-1 |
> | 其他剧本（冷门/反向） | 剩余方向里概率最高的那一路，**只给一格** | 主胜主剧本 → 其他剧本 1-2 |
>
> 实现：`scripts/paid_cyber.py` 的 `scenario_view()`，`verdict["scenario"]` 直出，报告见 `scripts/intel_full.py` 第六节「收敛」。

- **任何场次（单场/合集）都必须给比分**：主剧本两格 + 其他剧本一格，缺一不可
- 格式：`**高概率比分：主胜剧本 2-1、2-0；冷门剧本 1-2。**`（独立成行）
- 多场合集：每场各自给；合集末尾的矩阵表也须含"高概率比分"列
- **理由**：读者按剧本选择，单给一个比分没有容错空间；用户多次明确要求。而按方向给三档会让「次选=防范」自相矛盾，所以改成按剧本。

### R31. 结构轮换（2026-09-13 新增）
- **连续文章不得使用同款结构**，同一批次内必须换写法。可用结构库：
  | 结构 | 形态 | 适用 |
  |:-----|:-----|:-----|
  | 逐场分节 | 一、A场 → 二、B场（镜像） | 两场强弱/看点对称时 |
  | **按判据横切** | 判据一/二/三，每节横切多场对比 | 多场同类型、需讲规则时（如客热分档） |
  | 悬念三连问 | 一问 → 二问 → 三问递进 | 单场，存在多重反常数据时 |
  | 双面矛盾 | 交锋优势 vs 当前状态等两幅面孔对撞 | 单场，历史与现实冲突时 |
  | 速览式 | 多场各 200-300 字 + 比分矩阵 | 5 场以上大合集 |
- **写法同样要换**：逐场通报 vs 对比分析 vs 判定前置（开头先给判定总表）
- **理由**：同款结构连发会被算法判定内容同质，也降低读者新鲜感；用户明确要求"轮换写作结构""换结构和写法"

### R33. 阅读排版规范（2026-09-19 新增 — 手机端优先）

### R35. 爆款四件套：位移表 / 基准线 / 金句缝 / 敢不挑边（2026-10-06 新增）

**起因**：用户提供本号历史最高阅读篇（**1.7 万**），要求学习其写法。

**样本**：`9月30日 周三002 乌兹别亚vs日本亚：34比2的账，让不动一球`（2026-09-30 13:01 发布，开球 18:30）
完整拆解见 `📚知识库/写作指南/爆款拆解_20260930_乌兹别亚vs日本亚_1.7万阅读.md`。

🔴 **重要前提：该篇按今天的 `check_article.py` v1.1 复跑是 FAIL 的（4 项未过：标题 34 字超长 / 硬禁用词「盘口」×2+「北京时间」×1 / 缺战意+信号+高概率比分+互动钩子 / 正文 1804 字超 R32 单场区间 40%）。**
**结论：结构可以学，字面必须换。照抄原文会直接卡门禁。**

#### 四件套（按复制价值排序）

**① 分时位移表 —— 把"钱的移动"做成叙事主干** ⭐ 最高价值

| 更新时间 | 主 | 平 | 客 | 门槛（+1）胜/平/负 |
|:---|:---|:---|:---|:---|
| 09-29 09:55 | 29.1% | 29.9% | 60.6% | 51.3% / 30.3% / 31.3% |
| …4 行… | | | | |

- **静态概率讲不出故事，位移能。** 四个时间点并排，读者自己看得出"一天里一路往哪压"
- 触发条件：同一场次抓到 **≥3 个时间点**的竞彩价格（用户可从投注页分时截图提供）
- 全部换算成**百分比**入表（门禁第 6 项；且见下方"表格豁免漏洞"）
- 正文必须点出方向与幅度：`受让方守住那侧从 X% 压到 Y%，净胜两球那侧从 A% 抬到 B%`

**② 基准线对照 —— 写"偏离"，不写"数值"** ⭐ 第二价值

> 对照 {N} 场基准：受让方守住 45%、让平 23%、净胜两球以上 32%。**受让侧低了 6.8 个百分点，净胜两球那侧只高了 3.4 个点。**

- 孤立的"38.2%"没有信息量，"比基准低 6.8 个点"才有
- 🔴 **基准必须自算**：样本取自 `📚知识库/赛后校验/batchNN_market_review.md` 或 `state/model-state.json` 的累计池，**必须写清样本量**
- 🔴 **禁止沿用来源不明的数字**：原爆款写的「469 场基准」在本库全库搜不到（累计池是 379 场，market_review 里也无此三向基准）→ 未经重算不得复用

**③ 金句缝 —— 同一主体 + 两个动词，人为造一道缝**

> **市场信日本赢，不信日本赢够**：赢球和赢够中间那一截，就是这场球最大的分歧。

- 句式：`同一主语 + 肯定A + 否定A的升级版`，缝就在中间
- **一篇只造一句，首尾各回收一次**（中段点出"那一截是最大分歧"，收口回收"那道缝市场一直没补上"）
- 禁止为金句牺牲事实：缝必须真的存在（这里两侧只差 2.8 个点，缝是真的）

**④ 敢说"不挑边" —— 两档差值过小时公开声明不做落点**

> 两边只差 2.8 个点。**这场只写门槛，不挑边。** …**这是我读到的结构，不是我的落点。**

- 触发阈值：两侧规范化概率差 **< 5 个百分点**时，优先走"只写门槛不挑边"
- 同期所有号都在给推荐，公开说不选反而更可信
- 收尾必须带 `这是我读到的结构，不是我的落点。`——把**分析**与**推荐**切开，观感专业、合规更稳

#### 另外三个可复用部件（结构层）

- **标题公式**：`日期 + 竞彩编号 + 对阵 + 极端数字的账 + 结构悬念动词短语`——**全文一个字不说看好谁**。数字从正文挑最极端的一组（进34失2）。⚠️ 总长压到 **≤30 字**（原篇 34 字不合规）
- **【】数据卡开篇**：`【对阵】【赛事】【阵容】【伤停】` 四行给完硬信息，替代 emoji 标签行（已登记为 R34 ④ 的新档位）
- **对仗数据 + 矛盾前置**：两句对仗数据 + 一句矛盾，第三句就进正题，零寒暄零铺垫（已登记为 R34 ⑤ 的新档位）
- **分歧型外媒引用**：不找"外媒也看好X"印证自己，而是**专门呈现不一致**（中文媒体给 0:1/1:2 vs 越媒给 1:1，各自理由都摆出来）。比印证型高一个层次，且天然规避外媒源造假风险

### R38c. 头条标题定版格式（2026-10-17 新增 — 用户给定，覆盖 R38 的钩子写法）

**格式**：`{M月D日}赛事前瞻:{主队}VS{客队},{一句话钩子}`

**实例（2026-10-17 用户原话）**：`10月17日赛事前瞻:斯特拉斯VS巴黎,法甲独苗，两边看法几乎一样`

**三步各做什么**

- 让球 **-1**：不让球主胜 ≈ 让球主胜（赢 2 球+）+ 让球平（正好赢 1 球）；不让球「客胜 + 平」≈ 让球客胜

- 实测差 **≤2.5pp 算自洽**；超过说明两套盘不是同一时间报的，**两套盘不要当同一件事读，取更保守的那一侧**

**五条取用纪律**

1. 盘口读数只作**背后研判依据**，公开稿按 **R41** 换成非盘口语（赔率→定价、盘口→设置/门槛、让球→一球的差距）

### R48-B. 站位怎么定（2026-10-19 定 · 机械判定，不许凭手感）

上一版只在「分歧够大」时喊停，把**同向分歧**（模型与定价 argmax 一致、只是幅度差）也当成「方向被打脸」，结果差点改坏两篇本来就对的稿。现在的顺序是**先看分歧落在哪个轴上**，再裁决。

| 站法 | 触发条件 | 说明 |
|---|---|---|
| 跟模型方向 | 同向、分歧 <15pp、稳定率 ≥80% | 正常情况，最干净的一种 |
| 跟方向不跟幅度 | 同向但分歧 ≥15pp | 两边都说同一队赢，只是赢多少差很远 |
| 跟定价方向 | 反向，且外媒/AI 至少两家站定价侧 | 反向时让第三方裁决 |
| 站模型方向（反向） | 反向，但外媒/AI 多家站模型侧 | 分歧来自定价时反过来用 |
| 让球观察（±1 盘才成立） | 定价胜平负给得高、让一球那格却明显低；或给了客胜却让受让主队最高 | 读的是**定价自己承认或自相矛盾**的那一格，不是站方向 |
| 方向不站，只谈总进球 | 稳定率 <50%，或两边读数打平到没有差价 | 不站方向≠这场没话说，总进球与比分剧本照给 |

**四条硬约束**

1. **稳定率来自蒙特卡洛**（λ 在 ±12% 上扰动 200 组 × 2000 次）：低于 50% 意味着「参数动一动最高那一路就换人」，这种方向不能站。2026-10-20 实测周二006 巴黎-巴萨稳定率 **0%**——模型给客胜 57.8%，但 200 组扰动没一次站住，Opta 同期给 39.7 / 37.7 五五开，佐证 57.8% 是参数假象。
2. **深盘不套让球观察**：让球 ±2 讲的是「差几个球」，跟胜平负的「谁赢」不是同一件事，硬套会把「客队让两球」误读成「主队受让不败」。
3. **同一个批次内，同向同分歧的场次要给同一个判法**。2026-10-20 周二001 与 010 是同一形态（定价主胜 59.0 / 61.9，让一球只 35.5 / 39.4），两篇稿却一个写「跟方向、让球不碰」一个写「站受让一侧」——统一后的判法是**方向跟主胜 + 让球那一档不站、只当读数**（让球格按第 5 行定性为观察，不构成站法）。
4. **已发布的稿子不回改**（2026-10-20 用户定「不改和不补了」）：发布之后才发现的站位与内部判定对不上、外媒该写没写、口径混批——**只在新稿里纠正，旧稿按发布时状态留档**，并在 HANDOFF 记明「留档不追」。例：周二004 与 009 的公开站位与内部报告不一致、两篇公开稿都没写外媒（`state/records/_ext_ai_20261020.json` 有 20 条读数），均不补。唯一例外是用户明确要求改。

**实现**：`scripts/intel_full.py` 的「站位建议（机械判定）」节，报告每场收敛后统一出表；公开稿按这张表站，不按模型 argmax 站。


### R49. 多场合并的「单一命题」骨架（2026-10-19 用户 m07317 在公司手写的成品为范本 —— 结构与内容判断）

> 触发：`10月19日 周一精选5场前瞻:热刺VS考文垂,垫底的那支还在被看好`（同日 15:37 已发布）。用户明确「我说的是内容和结构」。

**为什么值得立规则**：这条稿比同日的两篇（001+002+003 按时间线串联、004–008 按对照组）更强，强在**它是按论点组织的，不是按比赛组织的**。五场不是并列的五段，是同一个论点的五份证据。这解决了多场合并最容易犯的病——写成流水账。

**八段骨架（顺序不许换）**

| 段 | 装什么 | 范本原句 |
|---|---|---|
| ① 标题 | 日期 + 形态标称 + 焦点一场 + **一句反差钩子** | `10月19日 周一精选5场前瞻:热刺VS考文垂,垫底的那支还在被看好` |
| ② 标签行 | 按 R47 四层 | 12 个，球队全名 + 通用 |
| ③ **开篇总纲** | 一句话给全篇立命题，三个动作：否定 → 转移焦点 → 立论点 | 「没有一场能单独出手。最值得看的不是谁能赢，是市场凭什么这么定价：五场摆在一起形状一致，球队的名字比这两个月踢出来的样子更管用。」 |
| ④ 逐场（×N） | 见下面「单场四件套」 | — |
| ⑤ **综合段** | 把命题再收一次，回扣最典型的两三支 + 一组数据 | 「市场拿名字定价，近十场拿状态说话。」 |
| ⑥ **3 条看点** | 每条＝一句事实 + 一句该看什么，**必须赛后能验证** | 「一看热刺能不能止血。对手考文垂刚在主场 4:1 赢过纽卡。」 |
| ⑦ 一句总结 | 收口金句，可独立当摘句 | 「名气撑得住定价，撑不住九十分钟。」 |
| ⑧ 钩子 + 来源 + 免责 | 钩子指向赛后对账 | 「后半夜这几场，你最想验证哪一个？评论区留一句，赛后我们对账。」 |

**单场四件套（每场顺序固定）**

1. **小标题＝场次 + 时间 + 一句反差陈述**，反差的两端必须是「状态事实」与「市场读数」。范本五条的句式全不一样：
   `英超还没开张的那支，被定成 67%` / `五连败换过帅，被定成 60%` / `这一场市场自己也分不出来` / `四个共同对手，一边全败` / `同积 8 分，主场还没输过`
2. **第一段先摆状态事实**（近十场胜负 + 进失 + 主客分离），**第二段才给读数**。顺序不许倒——先给读者一个自己能算的基线，再抛读数，反差点才成立。
3. **对照系**：每场换一种，五场里不许出现两次同款。范本用了四种：共同对手（热刺/考文垂打同一批）、同分对照（布拉加/吉维森特同积 11）、让球三格（布拉加三格只差 0.6 个点）、单项纪录（赫塔费主场没输过）。
4. **收尾一句固定格式**：`推演跟重侧：结论。主胜剧本的高概率比分是 A、B；冷门剧本 C。`（比分按 **R30-A** 的剧本口径，见 §R30）。位置固定、写法统一，读者知道去哪找结论。

**三条硬纪律**

1. **单一命题**：开篇那句命题必须能统摄每一场，写完回头验一遍——若某一场和命题无关，这场就该踢出去或换命题，**不许各写各的**。
2. **场次口径必须标出来**：「全部十场 / 主场十场 / 近五个主场 / 含杯赛」要说清是哪一批。范本里赫塔费「主场 3 胜 2 平 0 负，主场还没输过」是近五个主场，本季主场十场其实是 6 胜 2 平 2 负——数字没错但读者会按本季理解，属口径没标清。
3. **⚔️战意 / 💰信号 这两块由「状态事实 vs 市场读数」的反差承担**（范本全文没用这两个图标，读起来反而更顺）。这是 R1-R41 硬性标记之外的一种合规替代，**只在多场合并形态里允许**；单场前瞻仍按原标记要求。

**与「时间线串联 / 对照组」的分工**：时间线（按开球顺序）适合场次跨越一整个下午到凌晨、读者会按时间追；对照组（按球队类型分组）适合两场之间有明显同构。**两者都是按外部维度组织；单一命题是按论点组织，多场合并时优先用它**——除非命题找不到。

### R50. 标题可检索性：队名进前 12 字，禁数字黑话（2026-10-21 新增，依据 10 篇后台实测）
