# 文章优化规则 v3.0（2026-07-24 数据诊断后制定）

## 一、推荐比分三档格式（2026-07-24新增）

每场比赛必须输出三档推荐比分，格式固定：

```
推荐比分：
| 维度 | 比分 | 概率 |
|:----|:---:|:----:|
| 首选 | X-X | XX% |
| 次选 | X-X | XX% |
| 防范 | X-X | XX% |
```

**选择逻辑：**
- **首选**：概率最高的比分（通常是1-0/0-1/1-1）
- **次选**：第二高概率比分（考虑不同走势）
- **防范**：冷门入口比分（概率不高但一旦命中回报大）

**注意：** 正文中仍用"概率最高的比分是X-X"描述，三档格式用于全景表和总结段落。

## 二、互动钩子模板（2026-07-24新增 — 三种风格轮换）

每篇文章必须在文末植入一个互动钩子，从以下三种风格中选择：

### 风格A — 数据型
```
你们觉得[球队名]这场能打破[X场不胜]的魔咒吗？评论区留个比分，赛后回来验证。
```

### 风格B — 争议型
```
[球队名]主场[XX]%胜率你信不信？反正我是信了。你们呢？评论区聊聊。
```

### 风格C — 投票型
```
这场你站哪边？A.主队稳赢 B.客队爆冷 C.闷平收场
```

### 首发评论（发布后立即自己评论）
```
我先来——我押X-X，理由是XX。欢迎打脸。
```

**轮换规则：** 连续两篇文章使用不同风格的互动钩子。

## 三、标题优化公式（2026-07-24数据诊断后强化）

### 核心公式
```
联赛名 + 核心矛盾（数字/反差/悬念）+ 问号或感叹号
```

### 高CTR案例（>10%）
- "芬超倒数第2vs倒数第3：70%克星胜率今晚失灵？"
- "瑞超最诡异的主场虫：客场赢马尔默回家就输"
- "9连败的魔咒遇上15场0胜的尴尬——谁先破局？"

### 低CTR案例（<4%）
- "7月24日哈马比安德莱贝西克中日德兰斯海杜克帕福斯：欧联"
- "7月21日瑞超两场"

### 关键数据
| 赛道 | 平均CTR | 标题策略 |
|:----|:-------:|:---------|
| 韩职 | 11-12% | 悬念+数据 |
| 挪超/芬超 | 10%+ | 反差+冲突 |
| 瑞超 | 3-4% | 需强化悬念 |
| 欧联资格赛 | 2-3% | 需找到核心看点 |

## 四、发布时间规则（2026-07-24数据诊断后细化）

### 按赛事类型细分

| 比赛时间 | 最佳发文窗口 | 原因 |
|:--------|:-----------|:-----|
| 韩职18:30 | 11:00-12:00 或 16:00-17:00 | 午休+赛前2h |
| 欧联01:00-03:00 | 18:00-20:00 | 晚间黄金档 |
| 巴甲06:30 | 22:00-23:00 | 睡前档 |
| 瑞超/芬超00:00-01:00 | 17:00-19:00 | 晚饭后档 |

### 核心原则
- 发文时间 = 比赛时间 - 6~12小时
- 凌晨赛事提前一天发
- 避开 0:00-8:00 和 14:00-16:00 的低活跃时段

## 五、14维深度分析模板（2026-07-24新增）

当用户要求"多模块分析"或"深度分析"时，使用以下14维结构：

```markdown
# [标题]

**比赛时间：** YYYY-MM-DD HH:MM | [场馆]
**联赛排名：** [主队#X] vs [客队#Y]

## 一、百家欧赔 & 凯利指数
[赔率表 + 凯利信号解读]
```

## 六、SCA开篇公式（2026-07-24新增）

详见 `📚知识库/写作指南/SCA开篇公式.md`

**足球分析应用：**
```
S场景：很多球迷看比赛习惯性看排名——榜首打中游，主队应该稳赢吧？
C冲突：但拆开主客场数据一看，首尔主场胜率只有50%，浦项客场排名第2。
A答案：后台模型跑完后，这场最合理的走势是低比分胶着，浦项不败才是更大概率方向。
```

**四种变体：**
1. 标准SCA（公众号长文）
2. CSA忧虑式（短视频钩子，先抛痛点）
3. ASC结论先行（职场汇报）
4. 完整SCQA（深度文章）
