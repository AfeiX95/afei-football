# 叙事池 — 写作轮换素材库

每篇从以下维度选2-3个嵌入正文，不单独成章。同维度不连续两篇用同一种写法和同个角度。

## 使用方式
写文章前，加载叙事池选2-3个维度，嵌入对应段落。下一篇换不同的角度。

## 10个叙事维度

### 1. 恩怨情仇（两队历史纠葛）
| 角度 | 写法示例 | 适合场景 |
|------|---------|---------|
| A旧将反戈 | "XX曾在A队踢了X年，转头去了B队" | 有转会/青训关联 |
| B复仇叙事 | "上次交手A队X-X惨败" | 首回合大比分 |
| C魔咒纪录 | "A队主场对B队X年不败/连败" | 有极端H2H数据 |
| D打断连胜 | "B队带X连胜来，A队最擅长终结连胜" | 一方近期连胜 |
| E江湖恩怨 | 教练/球员之间的旧怨口水战 | 有公开冲突史 |

### 2. 教练博弈
| 角度 | 写法示例 | 适合场景 |
|------|---------|---------|
| A战术风格对撞 | "A教练控球vs B教练防反" | 风格鲜明对立 |
| B换帅前后对比 | "自从XX接手，A队场均从X分涨到X分" | 中途换帅球队 |
| C师徒对决 | "XX曾是XX的助教/弟子" | 有师承关系 |
| D告别/里程碑 | "这很可能是XX在这支球队的最后一场" | 教练离任/合同到期 |
| E临场应变对比 | "XX以临场调整闻名，XX偏好一套阵容打到底" | 风格稳定可预测 |

### 3. 战术要素

| C攻防命门 | "A队左后卫是突破口" | 有明显短板 |
| D定位球战术 | "A队角球进球X个联赛最多" | 有相关数据 |
| E高位逼抢vs蹲坑 | "A队场均抢回球权X次" | 风格反差大 |

## 每篇必选组合
1. ⚔️ **战意**（维度4）— 至少1个角度
2. 💰 **信号**（维度5）— 至少1个角度
3. 🌍 **外媒对比** — 固定维度，放在客队近况之后
4. 从其余维度**再选1-2个**嵌入 → 共3-4个叙事角度
