# SCA开篇公式（SCQA精简版）

源自《金字塔原理》SCQA，去掉中间提问Q，简化为SCA开篇。

## 定义
**S（场景）→ C（冲突）→ A（答案）**

1. **S场景**：描述读者熟悉、认同的现状，快速建立共鸣
2. **C冲突**：现状里的矛盾、痛点、认知误区（钩子核心）
3. **A答案**：抛出本文核心观点、解决方案

## 足球分析SCA应用

### 类型1：常识vs真相（适合强弱分明场次）
```
S：很多球迷看比赛习惯性看排名——榜首打中游，主队应该稳赢吧？
C：但首尔主场胜率只有50%，浦项客场排名第2——主场虫遇上客场龙。
A：后台模型跑完10万次后，这场最合理的走势是低比分胶着，浦项不败才是更大概率的方向。
```

### 类型2：预期vs现实（适合表面均衡实际悬殊场次）
```
S：同积25分、排名紧挨着，看起来是一场五五开的卡位战。
C：但拆开主客场数据一看悬殊太大了——博塔主场大球率100%，维多利亚客场0胜8伤缺。
A：模型跑完给出的结论很清晰：博塔弗戈71%胜率，Edge+15pp，是今晚巴甲最强的价值信号。
```

### 类型3：热度vs价值（适合信号场次）
```
S：看到主胜1.35，很多人第一反应是——稳了。
C：但主场胜率只有44.4%，场均只进1球，核心中场还停赛了。
A：后台模型跑下来胜率六成，方向对但定价压太低了，存在过热风险。
```

### 类型4：名气vs数据（适合欧战资格赛）
```
S：安德莱赫特是比甲传统豪门，这个名头够响吧？
C：但比甲8月才开赛，最后正式比赛是5月底。上赛季同阶段就被瑞典球队淘汰。
A：后台模型跑完，哈马比67%胜率，赛季中状态大好的主队才是更合理的方向。
```

## 三种变体
| 类型 | 顺序 | 适用场景 |
|:----|:----|:---------|
| 标准SCA | S→C→A | 长文分析 |
| CSA忧虑式 | C→S→A | 先抛痛点 |
| ASC结论先行 | A→S→C | 简短快评 |

## 写作小技巧
- S不要太宏大，写读者亲身经历的小事
- C一定要制造落差：期待vs现实、常识vs真相
- 前3行就要进入冲突，不要长篇铺垫
- SCA开篇后紧跟⚔️ 战意段落，不要重复同一批数据
