# 赛前情报搜索清单

## 为什么这个步骤是强制的

2026-07-18 法国vs英格兰季军赛证明：不主动搜索就会漏掉决定性的变量——
- 法国全替补（姆巴佩除外）→ 核心81%进球缺席
- 全队士气崩塌（内部直言"恶心"）→ 战意归零
- 迈阿密体感42.6°C → 高温体能消耗翻倍
- 这些变量让法国胜率从36%修正到25%

**用户反馈：** "你什么不自己联网查找动态呢"

## 🚨 休赛期伤病数据陷阱（重要）

**休赛期后首场比赛的伤病数据可能是休赛期前的旧数据，不可直接当临场用。**

蒙特利尔vs多伦多案例（2026-07-17）：
- 雷速显示多伦多**8人伤病**（看起来像送分题）
- 但7周长间歇后，核心球员可能已康复
- 赔率趋势才是真实信号：主胜1.82→1.87(上调)说明市场已反映伤愈变量
- **正确做法：**先看赔率趋势（市场反映的信息），再看伤病列表（可能滞后），最终以赛前1小时首发名单为确认依据

## 竞彩赔率获取

- 优先用浏览器打开竞彩固定奖金页面获取官方数据
- API数据仅作补充，比分赔率以竞彩页面最新时间为准
- 页面被拦截时用web_search搜索"竞彩 队名1 队名2 固定奖金"
- **必须获取≥3个时间点（早期/中期/临场）**
