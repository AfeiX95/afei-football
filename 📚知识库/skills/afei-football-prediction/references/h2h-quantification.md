# H2H量化修正方法论与案例

## 核心公式

```
h2h_matches = 近N场(通常7-10场)
h2h_win_rate = 主队胜场 / h2h_matches

若 h2h_win_rate < 0.25: λ × 0.88  # 被严重克制
若 h2h_win_rate < 0.40: λ × 0.93  # 明显劣势
若 h2h_win_rate > 0.60: λ × 1.07  # 克制对手
否则: 无修正(×1.00)

对手λ反向修正: La修正 = La / 修正系数
```

## 限制条件
- 近3年无交手→权重减半
- 双方阵容变动>5人时权重减半
- H2H分主客场查看（整体H2H和主场H2H可能差异巨大）
- 必须综合看近5场和近10场两个窗口

## 案例1：法国vs西班牙（2026世界杯半决赛）

| 数据 | 值 |
|:-----|:----|
| H2H | 近7场法国1胜1平5负 |
| 胜率 | 14%（被碾压） |
| 修正系数 | λ×0.88 |
| 修正前模型 | 法国48% |
| 修正后模型 | 法国44.2% |
| 市场隐含 | 法国43.6% |
| 修正后Edge | +0.6pp → 不推荐方向 |
| 实际结果 | **西班牙2-0法国 ✅** |
| 教训 | 赔率趋势(法国2.26→2.03)显示资金买入，但H2H修正后Edge归零。状态vs克星完全对冲 |

## 案例2：西雅图vs波特兰（Cascadia德比）

| 数据 | 值 |
|:-----|:----|
| H2H | 近10场西雅图2胜4平4负 |
| 胜率 | 20%（明显劣势） |
| 修正系数 | λ×0.88 |
| 修正前模型 | 西雅图74.7% |
| 修正后模型 | 西雅图63.1% |
| 市场隐含 | 西雅图63.2% |
| 修正后Edge | -0.1pp → 不推荐方向 |
| 外媒验证 | 波特兰+1.5盘口对西雅图15连胜 |
| 教训 | H2H克星再次验证。德比战中客场球队常超常发挥 |

## 操作流程

```
1. 从竞彩特征分析页获取历史交锋数据
2. 分主客场统计H2H
3. 计算近10场整体胜率 + 近5场主客场胜率
4. 根据胜率查表得修正系数
5. 纳入λ计算
6. 修正后Edge<3pp时不推荐方向
```
