### 11维精简分析结构（编号一→十一必须连续）

**已删除一(百家欧赔)和二(赔率时间趋势)——用户明确要求从分析报告中移除。** 每场完整分析按以下11节输出。编号必须从一连续到十一。

| 节 | 内容 | 说明 |
|:---|:-----|:------|
| 一 | 基础数据 & 身价对比 | 排名/积分/主客场场均进失 |
| 二 | 近期状态对比 | 近10场+特殊趋势（主场龙/平局大师） |
| 三 | 战术对位分析 | 阵型/战术克制 |
| 四 | 关键对位分析 | 胜负手区域 |
| 五 | 关键球员对位 | 射手+核心依赖度+进攻集中度 |
| 六 | 天气 & 裁判 | 温度/场地/裁判风格 |
| 七 | 更衣室情况 | 主帅采访/士气/内部动态 |
| 八 | 数学模型 | λ+MC+比分概率Top5 |
| 九 | 比赛剧本推演（三章节） | 正常70%/胶着20%/冷门10%·含上半场/下半场/冷门路径 |
| 十 | 外媒 & 全球预测对比 | 8-10家来源+一致性评分 |
| 十一 | 伤停 & 赛程 | 逐人伤病+下轮对手影响 |

**⚠️ 必须保留的维度：**
1. **编号完整性：一→十一必须连续** — 不允许跳过
2. **比赛剧本三章节** — 正常70%/胶着20%/冷门10%，每场必须包含
3. **全球AI预测对比（第10节）** — 至少5家来源+方向一致度评分
4. **可信度/信心评分** — 每场结束时输出综合信心评分(⭐⭐⭐⭐/⭐⭐⭐/⭐⭐)

**曾使用但已删除的维度：** 百家欧赔(已删除)·赔率时间趋势(已删除)·身价对比(无稳定数据源)·天气裁判(无公开数据时跳过)·更衣室(无欧洲媒体覆盖时跳过)

## 关键判断规则（基于69场校准·v3.1.1更新）

### H2H权重应高于短期异常数据（规则新增）

**案例：** 哥德堡2026赛季主场0胜(0胜2平3负)→推荐布鲁马波不败。结果哥德堡第10个主场2-1逆转，H2H 6胜2平2负(60%)被完全忽略。

**规则：**
1. "主场0胜"是短期极端数据——连续N场不胜≠第N+1场也不会赢
2. **H2H长期权重应高于短期异常数据**（H2H反映两队长期实力对比，比10场内异常波动更有预测力）
3. 主场0胜队在第8-12个主场附近回归均值的概率显著上升——统计回归现象
4. 赔率从1.78→1.93(市场降温)不一定是"看衰"，可能是市场过度反应创造主客价值

**判断优先顺序：**
```
H2H长期(7-10场) > 排名实力差 > 短期状态(近5-10场) > 主场/客场单个数据 > 赔率趋势 > 品牌溢价/负面叙事
```

### 过热规则——联动排名差（v3.1.1代码更新）

**代码改动（adapter_v1.py parse_market）：**
```python
# 当主队排名高于客队≥8位时，阈值从1.40放宽至1.50
rank_gap = away_rank - home_rank
overheat_threshold = 1.50 if rank_gap >= 8 else 1.40
```

**规则说明：** #2打#14的低赔是合理定价—不触发过热。

**feature_extractor.py改动（主场联动对手排名）：**
```python
def _home_advantage(tb):
    gap = away_rank - home_rank
    base = 0.08
    if gap >= 8: base += 0.08    # 主场对弱队加成
    elif gap >= 4: base += 0.04
    return round(base + max(0, gap) * 0.005, 4)
```

## 架构总览（7层完整贯通）

```
Layer 0  Match Context —— 比赛上下文识别 + 赛前情报搜索
    ↓
Layer 1  Data Collector —— 数据采集 + 竞彩赔率（3时间点）
    ↓
Layer 2  Analysis Engine —— 11维分析 + 基础数据拆解
    ↓
Layer 3  Model Engine —— λ(乘法因子) + Poisson + MC10万次
    ↓
Layer 4  Prediction Fusion —— 多源评分融合 + 置信度 + 风险标记
    ↓
Layer 5  Content Generator —— 最终预测报告 + 全球AI对比
    ↓
Layer 6  Feedback Learning —— 20场短周期 + 100场长周期校准
```

**核心原则：** 单向数据流·层间JSON契约·每层独立迭代

### Layer 3：数学模型

#### λ生成器（乘法因子公式）

```
λ_home = base(1.4) × (1 + strength_gap×0.35 + point_gap×0.15 + home_adv×0.20 + form_gap×0.20 + injury_away×(-0.30))
λ_away = base(1.4) × (1 - strength_gap×0.35 - point_gap×0.15 - home_adv×0.12 + form_away×0.20 + injury_home×(-0.30))
```
