# 竞彩数据获取通用指南

> 适用场景：任何需要从竞彩网获取赔率/赛程/积分榜/特征分析数据的任务

## 一、竞彩网数据源总览

| 数据源 | URL/端点 | 可用性 | 返回内容 |

## 二、JSON API 详解

### 端点

```
GET https://webapi.sporttery.cn/gateway/uniform/football/getMatchCalculatorV1.qry?channel=c
```

### ⚠️ 关键局限（2026-07-20实战验证）

**API仅返回当前营业日的比赛。** 如果目标场次在明天或后天，API会返回空结果。

**验证记录（2026-07-20 周一）：**
- 当前日（周一）：返回3场（瑞典超）
- 次日（周二）：K联赛6场 — **未返回** ❌
- 第三日（周三）：无比赛 — 未返回

**应对方案：** 见下文「API不可用时的赔率估算」

### 字段映射

| API字段 | 含义 | 提取方式 |
|:--------|:------|:---------|
| `had.h` / `had.d` / `had.a` | 胜平负赔率 | `float()` |
| `hhad.h` / `hhad.d` / `hhad.a` | 让球胜平负 | `float()` |
| `crs.s{h}g{s}a` | 比分赔率 | `s{h}g{s}a` → 如`s02s01`=2-1 |
| `ttg.s0` ~ `ttg.s7` | 总进球 | `float()` |
| `hafu.hh` ~ `hafu.aa` | 半全场 | 两个字母=半场+全场 |
| `matchNumStr` | 竞彩编号 | 匹配用户输入（如"周二201"） |
| `matchStatus` | 销售状态 | `Selling`=在售 |

### 快速提取脚本

```python
import json
from urllib.request import urlopen, Request

TARGET_MATCH = '周二201'  # ← 改成目标场次
url = 'https://webapi.sporttery.cn/gateway/uniform/football/getMatchCalculatorV1.qry?channel=c'
req = Request(url, headers={'User-Agent': 'Mozilla/5.0'})
data = json.loads(urlopen(req, timeout=10).read())

found = False
for day in data.get('value',{}).get('matchInfoList',[]):
    for sub in day.get('subMatchList',[]):
        mid = sub.get('matchNumStr','')
        if TARGET_MATCH in mid:
            found = True
            had = sub.get('had',{})
            h,d,a = float(had.get('h',1)), float(had.get('d',1)), float(had.get('a',1))
            t = 1/h + 1/d + 1/a
            print(f"胜:{h} 平:{d} 负:{a}")
            print(f"市场隐含: {(1/h)/t*100:.1f}% / {(1/d)/t*100:.1f}% / {(1/a)/t*100:.1f}%")

if not found:
    print("⚠️ 目标场次未找到 — API可能没有未来日比赛数据")
    print("切换到赔率估算模式（见下文）")
```

## 三、API不可用时的赔率估算

### 触发条件

当以下任一成立时：
1. API不返回目标 `matchNumStr`（最常见：未来日比赛）
2. API空结果（`totalCount`=0或`matchInfoList`为空）
3. 网络请求失败

### 估算输入

需要从用户提供的特征分析页或积分榜获取：

| 输入 | 示例（济州SK vs 江原FC） |
|:----|:------------------------|
| 主队排名/积分 | 济州SK #8（23分） |
| 客队排名/积分 | 江原FC #2（31分） |
| 主队主场战绩 | 3-3-4 (30%胜率) |
| 客队客场战绩 | 4-3-2 (44%胜率) |
| 秩差 = abs(rank_h - rank_a) | 6 |
| 联赛典型返还率 | K联赛 89-91% |
| H2H历史（可选） | 济州0胜7平3负 |

### K联赛参考赔率模式

| 秩差 | 高位方赔率 | 低位方赔率 | 平局参考 |
|:---:|:---------:|:---------:|:--------:|
| 0-2 | 2.50-3.00 | 2.50-3.00 | 2.90-3.20 |
| 3-5 | 2.20-2.50 | 2.80-3.30 | 2.90-3.10 |
| 6-8 | 1.90-2.25 | 3.00-3.50 | 2.90-3.10 |
| >8 | 1.50-1.90 | 3.50-5.00+ | 3.00-3.50 |

**主客场修正：** K联赛主场优势弱(0.08-0.15)，主客场各±0.10-0.15赔率浮动。

### 估算流程

```python
# 1. 基于秩差和主客场确定估算赔率
rank_gap = abs(home_rank - away_rank)
if rank_gap >= 6:
    # 高位方客场 → 取偏保守
    away_est = 2.10 if away_away_win_rate > 0.40 else 2.30
    home_est = 3.10 if home_home_win_rate < 0.35 else 2.85
    draw_est = 3.00

# 2. 返还率验算
total = 1/home_est + 1/draw_est + 1/away_est
payout = 1/total * 100  # 应在89-91%
if payout < 87 or payout > 93:
    # 调整赔率使返还率落在合理区间
    ...

# 3. 市场隐含概率
fair_h = (1/home_est) / total
fair_d = (1/draw_est) / total
fair_a = (1/away_est) / total
```

### 完整实战案例（济州SK vs 江原FC, 2026-07-20）

**输入：**
- 济州SK #8 (23分) / 江原FC #2 (31分)
- 济州主场30%胜率 / 江原客场44%胜率
- H2H近10场：济州0胜7平3负
- 秩差：6

**估算：**
```python
# 秩差6 → 高位方江原约2.00-2.25
# 江原客场44%胜率 → 取2.25
# 济州主场30% + H2H0胜 → 取3.00
# H2H 70%平率 + K联赛高平率 → 平3.00
est_h, est_d, est_a = 3.00, 3.00, 2.25

# 返还率验算
total = 1/3.00 + 1/3.00 + 1/2.25  # 1.111 → 90.0% ✅

# 市场隐含
# 济州30.0% / 平30.0% / 江原40.0%
```

**结果：**
- 模型江原胜49.4% vs 估算市场40.0% → Edge+9.4pp ⭐
- 模型济州胜21.8% vs 估算市场30.0% → Edge-8.2pp ✗
- 方向判断：江原不败（模型+Edge均指向客队）

## 四、特征分析页数据提取

### 可用数据模块

| 模块 | 对模型的影响 | 提取难度 |
|:-----|:------------|:---------|
| 历史交锋（H2H） | 触发H2Hλ修正 | 低（表格结构规整） |
| 比赛近况（10场） | 形式修正输入 | 中（需筛选赛制列） |
| 射手信息 | 射手依赖度判断 | 中（需计算进球占比） |
| 伤停一览 | λ直接修正 | 低 |
| 积分榜（含主客场） | 主客场分离数据 | 低 |

### 关键读取规则

- **H2H数据务必区分"赛季总战绩"和"两队间交锋"**
- 比赛近况是「全部赛制」数据（含杯赛），需手动筛选联赛场次
- 伤停数据如为空（"暂无数据"），不应用修正
- 积分榜主客场分离数据优先于赛季总数据

## 六、百家欧赔数据获取（新球体育 titan007.com）

### 数据源
当用户提供新球体育（titan007.com）的百家欧赔页面时，可提取：

| 字段 | 说明 | 用途 |
|:-----|:------|:-----|
| 竞彩官方 | 主胜/平/客胜 | 市场基准价 |
| 365/威廉/立博等 | 各家赔率（170+家） | 市场定价分布 |
| 即时平均值 | 所有公司均值 | 市场共识 |
| 凯利指数 | 竞彩凯利 | 风险信号（<返还率=低风险） |
| 初盘→即时盘变化 | 赔率走势 | 资金流向 |

### 数据解读规则

1. **竞彩vs国际均赔差异>5%** → 竞彩有独立判断，需特别关注
2. **竞彩凯利<返还率** → 该方向市场风险低，可能打出
3. **竞彩凯利>返还率** → 该方向市场风险高，可能打不出
4. **初盘→即时盘主胜持续下降** → 资金涌入主队方向

## 七、赔率时间序列分析（竞彩固定奖金页）

### 数据提取
从竞彩固定奖金页提取赔率变化时间序列，分析资金流向：

```text
时间               主胜    平局    客胜
07-23 09:21       1.93    3.35    3.20   ← 开盘
07-23 15:44       1.90    3.39    3.24
07-23 17:26       1.85    3.39    3.40
07-23 18:20       1.80    3.40    3.57
07-23 18:53       1.75    3.40    3.80   ← 临场
```

### 信号解读

| 变化模式 | 含义 | 信号强度 |
|:---------|:-----|:--------:|
| 主胜持续下降（1.93→1.75） | 资金涌入主队 | 🔴强 |
| 客胜持续上升（3.20→3.80） | 市场卖出客队 | 🔴强 |
| 平赔稳定（3.35-3.40） | 平局非资金主方向 | ⚪弱 |
| 主胜先降后回升 | 早盘买入后修正 | 🟡中 |
| 客胜先升后降 | 早盘卖出后回补 | 🟡中 |

### 实战案例（2026-07-24 哈马比vs安德莱赫特）
- 主胜1.93→1.75（降9.3%）→ 资金单向涌入哈马比
- 客胜3.20→3.80（升18.8%）→ 市场对安德莱信心下降
- 模型67% vs 临场隐含51% → Edge+16pp，资金方向与模型一致

### 半全场赔率时间序列信号（2026-07-24 斯海杜克vs帕福斯案例）
- "胜胜"从2.80升到3.35 → 市场对上半场主队领先信心下降
- "平胜"从4.50降到4.05 → 半场平局后主队下半场发力概率上升
- **解读：耐心型主队——上半场可能不开花，下半场发力**
