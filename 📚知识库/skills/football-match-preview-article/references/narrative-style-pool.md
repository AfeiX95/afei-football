# 叙事池 — 写作轮换素材库

每篇从以下维度选2-3个嵌入正文，不单独成章。同维度不连续两篇用同一种写法和同个角度。

## 使用规则

1. 每篇选2-3个维度嵌入，不贪多。嵌入在对应段落里，不单独成节
2. 同维度不连续两篇用同一种角度
3. 外媒分析预测是固定维度，每篇必加
4. 叙事素材来源必须是联网搜索核实过的真实信息+用户提供的源数据
5. 预测首发/战术/转会等内容必须有据可查

## 轮换记录格式

篇末记录本场选用的维度和角度：

```markdown
**本篇叙事选型：**
- 恩怨情仇: C魔咒纪录
- 教练博弈: D告别/里程碑
- 战术要素: B关键对位
```
