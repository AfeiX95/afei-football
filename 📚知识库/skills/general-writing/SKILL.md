# 通用写作（General Writing）v1.0

> 把「人类写作核心能力」封装成可执行流程：不是文字堆砌，而是「想清楚 → 写清楚 → 改清楚」。

## When to Use

- 写任何需要结构化的文本：公众号/头条文章、职场公文、技术文档、随笔散文、小说故事、评论报告
- 改写/润色/压缩/扩写已有文本
- 需要建立写作流程、做写作复盘、给新手搭训练路径

## 核心心法：五层地基（底层认知能力）

1. **信息搜集与筛选**——调研素材、甄别信息真伪、取舍论据，从海量资料提取有效内容；
2. **主题与立意把控**——确定核心主旨，全文围绕中心不跑题；提炼观点，明确想传递什么；
3. **受众意识（读者思维）**——判断写给谁看：知识水平、情绪诉求、阅读目的 → 调整措辞深浅；
4. **逻辑架构能力**——搭大纲、分段落，安排因果/递进/总分/对比结构，理顺行文链条；
5. **思考提炼能力**——把零散感受、碎片想法浓缩成清晰观点，拒绝流水账。

## 工作流（8 步）

### Step 1 立意定题
- 用一句话说清「这篇要传递什么」（主旨句，全文任何段落都能回指它）；
- 提炼观点：不是罗列信息，而是有立场；
- 定文体与平台（公众号长文 / 职场汇报 / 技术文档 / 小说），文体决定结构。

### Step 2 受众画像
- 读者是谁：老粉还是新人？专业还是小白？阅读场景是刷信息流还是深度研读？
- 情绪诉求：想被说服 / 被感动 / 被逗乐 / 学到东西？
- 据此定：术语要不要解释、梗能不能用、深度到哪里、开头多快进正题。

### Step 3 素材调研
- 搜集事实、案例、数据、引用，**区分事实与观点**；
- 多源交叉甄别真伪，标注来源；
- 取舍：只保留支撑主旨的论据——克制取舍，敢于删掉「精彩但偏离主题」的内容。

### Step 4 搭大纲
- 总分 / 递进 / 对比 / 因果，选一种主结构，全文骨架统一；
- 每段一个任务、段首有中心句；
- 预估各部分占比，防止头重脚轻（开头别拖、结尾别泄）。

### Step 5 撰写（文本加工）
- **遣词造句**：选词精准、句式长短交替、口语/书面语区分、无病句歧义；
- **段落组织**：句与句衔接顺滑、过渡自然；
- 叙事 / 说理 / 描写 / 抒情按文体需要调用（见「专项能力速查」）；
- 初稿不求完美，先写完再改——写作时别当编辑。

### Step 6 润色
- 压缩冗余、扩写单薄；同义替换、调整语气风格；
- 检查节奏：长短句交替、段落密度、断句是否制造阅读疲劳；
- 视角滑动测试：能不能从读者视角顺畅读一遍。

### Step 7 校对
- 错别字、标点、语病；
- 核查事实与数字（人名、日期、引用是否准确）；
- 删减无效文字——每删一句都问「删了读者会损失什么」。

### Step 8 复盘迭代
- 写完复盘：哪里读者没看懂 / 没被打动 / 中途流失；
- 识别自己的短板（立意弱 / 结构散 / 词穷 / 校对糙），下一轮专项练；
- 把高频错误记入自己的写作清单。

## 文体专项速查

### 实用类
| 文体 | 要点 |
|:---|:---|
| 公文职场 | 通知/汇报/方案/邮件/纪要——简洁严谨、条理清晰、结论前置 |
| 技术写作 | 说明书/README/接口文档——客观准确、通俗易懂、步骤可复现 |
| 议论文 | 提出论点 → 多角度论证 → 反驳对立观点 |
| 说明文 | 解释事物原理，条理清晰讲清楚知识 |

### 内容创作类
| 文体 | 要点 |
|:---|:---|
| 自媒体文案 | 标题钩子、开篇反差/数据锚/故事（SCA）、节奏把控、适配平台阅读习惯 |
| 散文随笔 | 感受表达、意象营造、克制不煽情 |
| 小说故事 | 人物塑造、情节设计、伏笔、冲突、节奏控制 |
| 评论写作 | 观点输出、分析现象、有理有据 |

## 高阶能力（区分普通写手与高手）

1. **风格塑造**——建立个人文风（严谨/犀利/温暖/幽默/克制），全文调性统一；
2. **说服力与感染力**——说服他人、引发共鸣，兼顾理性逻辑与感性共情；
3. **视角切换**——换不同立场、人称来叙事表达；
4. **克制取舍**——知道什么不写，敢删「精彩但跑题」的句子；
5. **反思迭代**——写完复盘，识别短板，持续修改优化。

## 人类独有特质（与 AI 写作的分水岭——写作时主动注入）

- 真实私人体验、切身情绪记忆；
- 价值观、个人立场、人生阅历沉淀；
- 微妙的人情分寸、社交语境感知；
- 对社会复杂人性的洞察。

> **人机分工原则**：让 AI 做结构、语法、素材检索、批量润色；人类做体验、立场、分寸、洞察。AI 产出初稿后，人类必须过一遍「特质注入」：哪一段像 AI 写的（无体验、无立场、无细节），就替换成自己的真实经验。

## 发布前检查清单

- [ ] 主旨一句话能说清吗？（回指 Step 1 的主旨句）
- [ ] 受众是谁？术语有没有给新人解释？
- [ ] 大纲有没有头重脚轻？
- [ ] 每段有中心句、衔接顺滑吗？
- [ ] 有没有「精彩但跑题」的句子该删？
- [ ] 错别字 / 标点 / 语病 / 事实数字核查过了吗？
- [ ] 风格统一吗？人类特质（体验/立场/分寸/洞察）注入够吗？
- [ ] 平台适配了吗（公众号表格排版 / 标题字数 / 审核敏感词）？
