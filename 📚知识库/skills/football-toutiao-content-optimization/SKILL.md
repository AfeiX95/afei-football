# 头条号内容优化规则

## When to Use
- 写任何头条号文章时自动执行
- 用户要求优化标题/互动/发布时间时
- 赛后复盘文章也需要遵守

## 一、标题优化公式

### 核心公式（替代队名堆砌）
```
联赛名 + 核心矛盾（数字/反差/悬念）+ 问号或感叹号（≤30字）
```

### 正面案例（高CTR 10%+）
- "芬超倒数第2vs倒数第3：70%克星胜率今晚失灵？"
- "瑞超最诡异的主场虫：客场赢马尔默回家就输"
- "韩职第20轮：首尔10分领先打蔚山，浦项全北0-0概率最高！"

### 反面案例（低CTR 3-4%）
- "7月24日哈马比安德莱贝西克中日德兰斯海杜克帕福斯：欧联"
- 任何超过5个队名堆砌的标题

### CTR分联赛数据
| 类型 | 联赛 | CTR范围 |
|:-----|:-----|:--------:|
| 高CTR | 韩职、挪超、芬超 | 10-12% |
| 中CTR | 巴甲、欧冠正赛 | 7-9% |
| 低CTR | 瑞超、欧联资格赛、友谊赛 | 2-4% |

### 多场标题策略
- 1场焦点：标题放该场核心矛盾
- 2场：标题放两场核心矛盾
- 3场：标题只放最有话题的1-2场，其余正文展开

## 二、互动钩子三选一

每篇文章必须在结尾植入互动钩子，激活评论区。

### 风格A — 数据型
> 后台模型跑完，这场最可能的比分是X-X。你们觉得呢？评论区留个比分，赛后回来验证。

### 风格B — 争议型
> XX队主场XX%胜率你信不信？反正我是信了。你们呢？评论区聊聊。

### 风格C — 投票型
> 这场你站哪边？A.主队稳赢 B.客队爆冷 C.闷平收场

### 首发评论（发布后立即自己评论）
> 我先来——我押X-X，理由是XX。欢迎打脸。

## 三、推荐比分三档格式

| 维度 | 格式 | 说明 |
|:----|:-----|:-----|
| **首选** | X-X（XX%） | 模型概率最高的比分 |
| **次选** | X-X（XX%） | 第二高概率比分 |
| **防范** | X-X（XX%） | 最可能的冷门/意外比分 |

## 四、发布时间细分

| 比赛时间 | 最佳发文窗口 | 原因 |
|:--------|:-----------|:-----|
| 韩职18:30 | 11:00-12:00 或 16:00-17:00 | 午休+赛前2h |
| 欧联01:00-03:00 | 18:00-20:00 | 晚间黄金档 |
| 巴甲06:30 | 22:00-23:00 | 睡前档 |
| 瑞超/芬超00:00-01:00 | 17:00-19:00 | 晚饭后档 |

核心原则：发文时间 = 比赛时间 - 6~12h。凌晨赛事提前一天发。

## 五、MD-to-DOCX转换

```bash
PANDOC="/c/Users/wuyan/AppData/Local/Microsoft/WinGet/Packages/JohnMacFarlane.Pandoc_Microsoft.Winget.Source_8wekyb3d8bbwe/pandoc-3.10/pandoc.exe"
"$PANDOC" "input.md" -o "output.docx" --from markdown --to docx
```

- .docx最大15MB（正常文章约12-15KB）
- 转换后文件与md文件同目录
- 头条号支持.docx导入，内容还原优于HTML粘贴

## 七、封面优化

| 类型 | 效果 | 示例 |
|:----|:-----|:-----|
| 球星情绪特写 | ⭐⭐⭐⭐⭐ | 进球庆祝、怒吼 |
| 比分框对比 | ⭐⭐⭐⭐ | "1-0 vs 0-0" |
| 悬念文字叠加 | ⭐⭐⭐⭐ | "70%克星胜率今晚失灵？" |
| 普通球场图 | ⭐⭐ | 不推荐 |

## Pitfalls
1. **标题堆砌队名** → 用核心矛盾+数字替代
2. **无互动钩子** → 文末三选一必须植入
3. **发布时间错误** → 按联赛细分窗口
4. **忘记转DOCX** → 写完MD自动执行转换
5. **封面太平淡** → 用球星情绪或比分对比
