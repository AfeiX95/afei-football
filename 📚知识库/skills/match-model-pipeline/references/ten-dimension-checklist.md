## 教练稳定性（第11维）深度检查清单

| 检查项 | 问题 | 风险评级 |
|:------|:----|:--------:|
| 换帅时间 | 赛前多久换帅？<3个月→🔴, 3-6月→🟡, >6月→🟢 | 🔴🟡🟢 |
| 新教练经验 | 是否首次执教成年队？是→🔴, 有成年队经验→🟡, 老帅→🟢 | 🔴🟡🟢 |
| 前任成就 | 前任是否功勋教练（世界杯四强等）？是→对比压力巨大 | ⚠️ |
| 球员支持度 | 核心球员是否公开支持新帅？搜索确认 | ✅/⚠️ |
| 小组赛表现 | 新帅带队小组赛战绩如何？不败→🟢, 有波动→🟡, 差→🔴 | 🟢🟡🔴 |
| 国内压力 | 国内期望是否极高？(上届成绩越好→本届压力越大) | ⚠️ |

**实战案例（2026-07-04 摩洛哥）：**
- Regragui(2022四强功勋) 赛前3个月被替换 → 🔴
- 接任者Ouahbi从未执教过成年队(U20直升) → 🔴
- AFCON主场决赛失利→国内压力极大 → ⚠️
- 小组赛2胜1平表面正常，但R32点球险胜荷兰 → 🟡
- **综合风险：🔴 高 ↔ 若先丢球可能更衣室崩盘**
- **λ修正：进攻λ额外降3-5%**
