## 数据优先原则（2026-07-06新增 — 重要！）

**国内联赛分析时，竞彩网API通常不提供特征分析页数据（伤停/历史交锋/射手榜等）。此时严禁凭赔率推测球队状态。**

```
❌ 错误做法：赔率2.23 → "市场不信任赫根主场"（凭空推测）
✅ 正确做法：赔率2.23 → web_search实际数据 → 发现赫根10场不败但50%平率 → 真相大白

优先数据源(按成功率排序):
  ① ESPN球队赛果页 → https://www.espn.com/soccer/team/results/_/id/{teamId}/league/SWE.1
  ② 365Scores积分榜 → 含近5场走势、主客场分离、净胜球
  ③ FBref球队数据页 → 含完整赛季数据、主客场拆分
  ④ SoccerPunter H2H → 含两队历史交锋不败率
  ⑤ Transfermarkt积分榜 → 含排名、赛程密度
```

**核心原则：从赔率出发只能提出假设，不能得出结论。实际数据验证后才能形成判断。**

|:----|:------|:---------|:---------|

### K联赛特征总结
> 榜首≠主场强。K联赛的客队拿分率比五大联赛高15-20%。主客场分离计算是K联赛分析的必选项。

## Allsvenskan (瑞超)

| 变量 | 说明 | 修正幅度 | 实战验证 |
|:----|:------|:---------|:---------|
| **平局率高于五大** | 瑞超整体平局率偏高 | λ平局+5% | 埃夫斯堡11场6平(55%) |
| **主客场差异大** | 哈马比主场20球/客场4球 | 主客场必须分离 | 哈马比客场20%胜率被市场定价为1.72 |
| **夏季赛程开放** | 瑞典夏季比赛节奏快 | 大2.5球倾向+5% | 卡尔马vs厄格里特大球率64% |
| **历史交锋权重大** | 部分球队H2H模式稳固 | H2H权重=0.7×近期+0.3×H2H | 哈马比6胜2平2负占优 |
| **射手三叉戟模式** | 哈马比3人各5球(占全队63%) | 进攻点多→λ稳定性高 | 哈马比三叉戟拆解 |
| **主场不败≠胜利** | 不败率高≠胜率高 | 不败率与胜率分开计算 | 埃夫斯堡主场不败但5连平(胜率50%) |
| **平局大师陷阱** | 50%平率的队市场定价会压低主胜赔率 | 识别平率而非质疑实力 | 赫根5胜5平0负(50%平率)赔率2.23 → 不是市场不信任, 是平率太高 |
| **排名vs赔率偏差信号** | 排名#3主场赔率仅2.23(≈40%) vs #11 | 排名差被市场完全无视→放弃主队方向,关注客队不败或平局 | 赫根#3vs佐加顿斯#11: 2.23/3.38/2.60(2026-07-07) |

### ⚡ 实战案例：赫根 vs 佐加顿斯（2026-07-07）

**表面信号：** 赫根第3名主场打佐加顿斯第11名，赔率2.23（≈40%），反常的低。
**错误结论：** 市场不信任赫根主场。
**正确结论（数据验证后）：** 赫根10场联赛5胜5平0负——联赛唯一不败，但**50%平局率才是赔率2.23的根本原因**！佐加顿斯虽然第11名，但净胜球+6与赫根完全相同，客场3场2胜胜率67%比赫根主场胜率60%还高。

**核心教训：排名vs赔率偏差≠市场定价错误。很多时候，市场比你更了解球队的真实状态。**

### 瑞超特征总结
> 瑞超的"名头溢价"比K联赛更严重。哈马比客场20%胜率被市场定价为1.72——这是今天所有比赛中最严重的定价偏差。瑞超分析的核心不是"市场错在哪"，而是"市场为什么这么定价"。

### 验证案例

| 场次 | 要点 |
|:----|:------|
| 卡尔马vs厄格里特 | 厄格里特客场近6轮失14球,防线崩盘→大2.5球+7.9pp |
| 哥德堡vs索尔纳 | 哥德堡主场0胜vs索尔纳客场80%不败→索尔纳Edge+13.5pp |
| 埃夫斯堡vs哈马比 | 埃夫斯堡主场不败60%平率vs哈马比客场20%胜率→市场严重误判 |
| **赫根vs佐加顿斯** | **赫根10场不败(50%平率)vs佐加顿斯客场67%胜率→平局@3.38被低估** |
