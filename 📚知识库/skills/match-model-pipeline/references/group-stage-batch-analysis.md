# 小组赛末轮批量价值信号分析

## When to Use

世界杯/欧洲杯小组赛末轮，需要同时分析多场比赛时。不是逐场独立分析，而是跨场比较价值信号大小，排出投注优先级。

## 方法论

### Step 1: 数据采集

从竞彩网获取所有末轮比赛的：
- 胜平负赔率（初盘+最新）
- 让球盘
- 比分盘（至少Top 5比分）
- 小组积分榜（含第三名排名表）

### Step 2: 逐场运行v4.0七层漏斗

对每场比赛输出：
- 模型概率（10万次模拟）
- 市场隐含概率（反推自赔率）
- 价值信号 = 模型概率 - 市场隐含概率（单位：pp）
- 锦标赛战略定性（已出线轮换/背水一战/默契风险/荣誉战）

### Step 3: 价值信号排名

| 排名 | 场次 | 方向 | 价值信号(pp) | 仓位 |
|------|------|------|-------------|------|
| 1 | XXX | XXX胜 | +XX | X级 |
| 2 | ... | ... | ... | ... |

按价值信号大小排序。>10pp = 强信号，>20pp = 极强信号。

### Step 4: 第三名晋级分析

穷举所有第三名最终排名组合，确定：
- 安全线（几分的第三名大概率晋级）
- 各组第三名的命运如何被本轮结果影响

### Step 5: 输出联合策略

```
本轮全场比赛价值信号排名表
→ 推荐投注场次（按价值信号排序）
→ 4串比分过关组合（从高价值场次中选比分）
```

## 实战经验（2026世界杯第3轮验证）

| 场次 | 价值信号 | 实际结果 | 教训 |
|------|---------|---------|------|
| 法国vs挪威 | +29.8pp | — | 品牌溢价最大的场次往往最有价值 |
| 佛得角vs沙特 | +25.1pp | — | 小球队生死战 vs 已出局大球队 = 价值温床 |
| 埃及vs伊朗 | +15.7pp | — | 两队数据相同但市场因球星溢价定价失衡 |
| 塞内加尔vs伊拉克 | 无明显价值 | — | 双方已出局 = 变量太多，不碰 |

**核心规律：**
1. 已出线强队 vs 背水一战弱队 → 价值信号最大
2. 品牌溢价（球星效应）是价值信号的主要来源
3. 双方都已出局的"垃圾场次" → 无价值信号，放弃
4. 市场已充分修正的场次（赔率变动大）→ 剩余价值小
