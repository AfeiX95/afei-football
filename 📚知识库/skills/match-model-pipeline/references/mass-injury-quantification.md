# 大面积伤病量化修正指南（v1.0）

> 2026-07-07 瑞士vs哥伦比亚案例实战总结

---

## 问题

当球队突然爆发大面积伤病潮时（多名主力同时缺阵），现有的单一伤停修正系数表格不够用。需要整体量化修正方案。

---

## 量化公式

```
修正后λ = 原始λ × 进攻修正系数 × 防守修正系数
```

### 进攻修正公式

```
进攻修正系数 = 1 - (∑缺阵球员进球占比 × 0.85)
```

- 进球占比 = 该球员进球占全队总进球比例
- 0.85 = 效率修正（替补球员不如主力，但不会完全消失）

**瑞士案例：** 曼赞比33% + 巴尔加斯22% = 55%进球输出消失
→ 进攻修正系数 = 1 - (0.55 × 0.85) = 1 - 0.47 = **0.53**

### 防守修正公式

```
防守修正系数 = 1 + (缺阵后卫首发占比 × 0.15)
```

- 缺阵后卫首发占比 = 缺阵后卫首发场次 ÷ 总比赛场次
- 0.15 = 每场首发对防守体系的边际贡献

**瑞士案例：** 阿坎吉4场4首发 → 首发占比100%
→ 防守修正系数 = 1 + (1.0 × 0.15) = **1.15**
→ 再加上"8人健康危机"的额外系数，修正至 ×1.20

### 综合修正示例

**瑞士vs哥伦比亚临场修正（2026-07-07）：**

| 项目 | 原始值 | 修正系数 | 修正后 |
|:----|:------:|:--------:|:------:|
| 市场λ瑞士 | 1.254 | 进攻×0.60+防守×1.20 | 0.890 |
| 综合λ瑞士 | 1.030 | 进攻×0.60+防守×1.20 | 0.890 |
| 瑞士胜率 | 30.0% | — | 26.5% |
| 哥伦比亚胜率 | 41.7% | — | 44.5% |

---

## 使用原则

1. 进攻端：只计算有稳定出场时间的球员（>30%出场率）
2. 防守端：只计算首发级别的后卫（>60%首发率）
3. 如果进攻和防守同时受损 → 两个修正系数叠加相乘
4. 如果进攻端修正系数< 0.50 → 同时标记"🔴进攻瘫痪"警告
5. 大面积危机的"覆盖性影响"（如8人健康异样）额外加×0.95~0.98
