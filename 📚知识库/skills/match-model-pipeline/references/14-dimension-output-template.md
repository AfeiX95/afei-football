# 14维全维度分析输出模板

> 每场比赛分析完成后，按此14章结构输出到知识库。
> 所有分析文件统一保存在 `📚知识库\比赛分析\{赛事阶段}\{编号}_{主队}VS{客队}_全维度分析.md`

## 标准结构

| 章 | 维度 | 内容 | 数据来源 |
|:--:|:-----|:-----|:---------|
| 一 | **百家欧赔 & 凯莉指数** | 多家机构赔率去水对比+凯莉K值 | 竞彩网/国际赔率 |
| 二 | **赔率时间趋势** | 5-6时段时序+让球盘变化 | 竞彩固定奖金页 |
| 三 | **基础数据 & 身价对比** | FIFA排名/小组战绩/身价/核心射手 | SWOT/懂球帝 |
| 四 | **近期状态对比** | 近5场逐场赛果+场均进/失球 | 竞彩特征分析页 |
| 五 | **战术对比** | 阵型/风格/攻防方式/定位球 | 懂球帝/搜索 |
| 六 | **关键对位分析** | 3组决定比赛走势的对位(边路/中场/定位球等) | 自研 |
| 七 | **关键球员对位** | 9位置逐一对比表 | 懂球帝阵容 |
| 八 | **天气 & 裁判** | 温度/海拔/顶棚/雷暴+裁判风格 | 搜索+天气API |
| 九 | **更衣室情况** | 换帅史/内讧/士气/压力评级 | 外媒搜索 |
| 十 | **数学模型** | λ+MC 10万次+敏感性+凯莉 | AFEI引擎 |
| 十一 | **比赛剧本推演** | 上半场/下半场分段+冷门路径 | 自研 |
| 十二 | **外媒 & 全球预测对比** | 8-10家来源横向对比 | Google搜索 |
| 十三 | **伤停 & 赛程** | 球员状态+晋级路线 | 特征分析页 |
| 十四 | **综合预测 & 投资方案** | 比分预测+凯利仓位+三套方案 | 全部上文汇总 |

## 输出规则

### 头部
```
# {主队} vs {客队} — 全维度内部分析报告

> **比赛定位：** {一句话定性}
> **球队标签：** {🇨🇦 高节奏反击队（波动型）} | {🇲🇦 低失球+高纪律队（稳定型）}
>
> 内部参考 | {赛事阶段} | {时间} | {场地}
> 模型版本: AFEI v2.1（含{修正项}）
```

### 章节标题格式
```
## 一、百家欧赔 & 凯莉指数
## 二、赔率时间趋势
...
## 十四、综合预测 & 投资方案
```

### 文件信息结尾
```
---

## 文件信息

| 项目 | 内容 |
|:----|:------|
| 创建日期 | {日期} |
| 数据来源 | {来源清单} |
| 模型版本 | AFEI v2.1（含{修正项}） |
```

### 多场比赛同时分析

当分析同一天多个场次时，先逐个场次跑完14维分析分别保存，再汇总：

1. 每个场次各自保存到 `📚知识库\比赛分析\{赛事阶段}\{编号}_{主队}VS{客队}_全维度分析.md`
2. 所有场次跑完后，汇总价值排行写入 `📚知识库\比赛分析\{赛事阶段}\{日期}_价值排行汇总.md`
