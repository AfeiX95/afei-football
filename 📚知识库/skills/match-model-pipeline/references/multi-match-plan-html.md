# 多场联合投注方案 HTML 页面模板

> 2026-07-01 实战验证 | 三场（英格兰/比利时/美国）联合方案

---

## 适用场景

同一比赛日有2-4场淘汰赛同时进行，用户需要一份联合分析页面，包含：
- 每场的模型数据卡片（λ值、概率、比分分布）
- 市场 vs 模型对比（含Edge分歧条形图）
- 价值信号排序（按|Edge|降序）
- 三套方案：稳健/进取/激进

## HTML结构模板

### 整体布局
```
深色背景(#0f0f1a) + 卡片式(#1a1a2e) + 最大宽720px居中
```

### 核心组件

#### 1. 赛事卡片（match-card）
CSS: `background:#1a1a2e; border-radius:10px; padding:16px; margin:14px 0; border:1px solid #2a2a3e`

内容：
- 顶栏: 竞彩编号 + 时间
- 中间: 队名(VS) + FIFA排名
- 注释行: 关键变量（伤停/内讧/场地）

#### 2. KPI指标格（3列网格）
`grid-template-columns: 1fr 1fr 1fr; gap:6px`

三个指标：λ值 | 大2.5% | 双方进球%

颜色：大2.5>50% → `#4caf50`(绿), 40-50% → `#ff9800`(橙), <40% → `#b0b0b0`(灰)

#### 3. 概率条（prob-bar）
flex水平三段，颜色：主队`#4fc3f7`(蓝) / 平局`#ffb74d`(橙) / 客队`#ff8a65`(红)

宽度 = 概率百分比，展示模型的三方向概率。

#### 4. 市场vs模型对比（左右双栏）
左栏：市场概率（`72.0% / 18.6% / 9.4%`）
右栏：分歧值（`美国 -29.6pp` 红字标出）

极端信号卡片加`border:1px solid #ef5350`边框。

#### 5. 比分概率表
前6-12行，含排名、比分、模型概率、累计概率、参考赔率(可选)
首行高亮（`color:#4fc3f7; font-weight:600`）

#### 6. 价值信号排序（signal-card）
三档：极端信号(`border-left-color:#ef5350`) / 中度(`#ff9800`) / 有效(`#4caf50`)

#### 7. 三场总览表
`场次 | 时间 | 模型 | 市场 | Edge | 最可能`

#### 8. 投注方案卡片（3张）
- 🟢 方案A — 稳健（低风险）: `border-left:4px solid #4caf50`
- 🟡 方案B — 进取（中风险）: `border-left:4px solid #ff9800`
- 🔴 方案C — 激进（高赔率）: `border-left:4px solid #ef5350`

每张卡片含：方案名称 + 风险标签 + 核心逻辑 + 具体方向(ul列表)

#### 9. 核心结论区块
一句话拆解所有比赛，highlight出最大价值信号场次。

#### 10. 页脚
`数据来源：竞彩网 · 后台模型（10万次蒙特卡洛模拟）`
`纯数据分析参考，不构成任何投注建议。`

## 配色方案（暗色主题）
| 元素 | 颜色 | 用途 |
|:----|:----:|:------|
| 背景 | `#0f0f1a` | 页面底色 |
| 卡片 | `#1a1a2e` | 赛事/方案卡片 |
| 卡片边框 | `#2a2a3e` | 默认分割 |
| 极端信号 | `#ef5350` | 偏差>10pp的场次 |
| 主队色 | `#4fc3f7` | 概率条/队名 |
| 平局色 | `#ffb74d` | 概率条 |
| 客队色 | `#ff8a65` | 概率条 |
| 正EV | `#4caf50` | 大2.5/双方进球高值 |
| 负EV | `#ef5350` | Edge负值 |
| 正文 | `#e0e0e0` | 可读性 |
| 次要 | `#888`/`#999` | 标注/说明 |

## 文件命名
```
{YYYYMMDD}/三场模型投注方案_{MMDD}.html
```

## 流程
1. 使用竞彩网API获取所有场次实时赔率
2. 对每场运行匹配模型（双方法λ → MC 10万次 → 品牌溢价 → EV）
3. 按`abs(Edge)`排序，标记极端/中度/有效三档
4. 构建三套方案（稳健/进取/激进）
5. 生成HTML文件到项目目录
