## 三、规律提炼

### 品牌溢价极限

当以下条件叠加时，深盘冷门概率显著上升：

```
品牌溢价 > 15pp 且 盘口 ≥ -1.5
  → 深盘可能严重高估强队实际进攻效率
  → 特别是强队已确保出线/名次的情况下

品牌溢价 < 5pp 且 盘口 = -0.5
  → 市场定价合理
  → 无明显价值陷阱
```

### 冷门预警信号

```
🟢 安全（正常打）: 盘口≤-1 + 品牌溢价<10pp + 更衣室稳定
🟡 警惕（可能翻车）: 盘口≥-1.5 + 品牌溢价10-15pp
🔴 高危（强烈预警）: 盘口≥-2 + 品牌溢价>15pp + 强队更衣室任何负面信号
```

### 实操原则

1. **深盘(-2及以上)胜方向通常无价值** — 竞彩抽水+市场过度定价
2. **深盘下的受让方(+2)反而可能有价值** — 因为市场已把强队推到不可能的高度
3. **已出线球队的淘汰赛场次：λ修正系数可能需从×0.70~0.80下调至×0.50~0.60**
4. **品牌溢价不总是"高估"** — 西班牙vs奥地利：市场72%/模型59%(-13pp)，实际3-0胜。强队牌面也是实力的一部分。
