# 外部方案对比审计方法

> 用于"外部预测 vs 后台模型"的逐场对比分析流程
> 实战验证：2026-06-29 三场外部方案审计（巴西vs日本/德国vs巴拉圭/荷兰vs摩洛哥）

## 四步审计法

### Step 1: 事实核查（逐项核对外部方案的数据源）

| 核查项 | 常见错误 | 案例 |
|--------|---------|------|
| 小组战绩 | 数据来源过时（非最新积分榜） | 外部称巴西"6-0"，实际巴西7-1-1-1平摩洛哥 |
| 伤停信息 | 完全忽略 | 拉菲尼亚(巴西)、穆西亚拉(德国)均未出现在外部方案 |
| 进球数 | 基于不完整数据源 | 日本6GF→实际7GF（Yahoo vs 懂球帝差异） |
| 历史交锋 | 忽略关键近期交锋 | 日本2025年10月3-2巴西未被引用 |

⚠️ 三甲高频事实错误类型（2026-07-01 西班牙vs奥地利对比审计发现）：

| 错误类型 | 检查方法 | 案例 |
|---------|---------|------|
| 历史交锋编造 | 竞彩网特征页→历史交锋→查看近0/10/20场数据 | 外部称西班牙vs奥地利"近10次交手7胜2平1负"，实际两队新世纪0次正式比赛交锋 |
| 身价数据偏差 | 雷速体育SWOT页或懂球帝核实（最权威中文源） | 外部写西班牙10.2亿，实际12.2亿（差2亿，20%偏差） |
| 精密数据无来源 | 精确到小数点后两位的数字（114.05km、30.0%等）需有来源标注 | 外部"西班牙场均跑动114.05km""奥地利70分钟后体能下滑30%"——疑为AI编造 |

核查方式：每写到一个具体数字，问自己"这个我能找到来源吗？"答否就不写。

### Step 2: 概率和校验

外部方案最常见的系统性错误——**各比分概率之和远超100%**。

```python
# 校验方法
# 从外部方案的各比分概率，求和
sum_probs = sum(外部给出的每个比分的概率)
assert abs(sum_probs - 1.0) < 0.05, f"概率和={sum_probs}，超出5%误差"
```

**实战案例（2026-06-29 南非vs加拿大）：**
外部方案：0-0(30.3%) + 0-1(32.4%) + 0-2(17.3%) = **80%**
这恰好覆盖了80%的场景，而非100%——说明剩下20%的比分概率被截断或未给出。

**更严重的案例（荷兰vs摩洛哥）：**
外部方案：1-1(19.6%) + 2-2(13.4%) + 0-1(11.6%) = **44.6%**，但泊松理论值1-1≈12.3%、2-2≈5.0%、0-1≈8.0%，偏差极大。

### Step 3: 伤停追溯检查

外部方案如果未列出伤停，其概率估算**自动失去可信度**。

| 比赛 | 被忽略的伤停 | 对λ的影响 | 外部概率偏差 |
|------|------------|-----------|-------------|
| 巴西vs日本 | 拉菲尼亚OUT(巴西右路) | -8%进攻 | 巴西胜率被高估~15pp |
| 德国vs巴拉圭 | 穆西亚拉OUT(德国中场核心) | -10%创造 | 德国胜率被高估~18pp |
| 墨西哥vs厄瓜多尔 | 凯塞多OUT(厄瓜多尔中场核心) | -15%中场控制 | 厄瓜多尔胜率被高估~10pp |

### Step 4: EV真实性校验

如果外部方案给出多个+1以上的EV，则EV计算**几乎必定有误**——市场套利机制会抹平这类漏洞。

```python
# EV校验规则
for 每个比分的EV:
    if EV > +1.0:
        # 几乎不可能在成熟市场出现
        flag "EV异常高，检查概率和赔率数据"
    if EV > +0.5:
        # 罕见，仅在极低效市场出现
        flag "EV偏高，建议交叉验证"
    if 所有比分EV均为正:
        # 不可能——水钱(overround≈13%)会吃掉
        flag "所有EV为正=数据错误"
```

**实战发现：** 外部方案在南非vs加拿大中给出全部3个比分正EV(+3.55、+3.21、+3.50)，这意味着无论比赛结果如何都"稳赚"——这在13%水钱的固定赔率市场中数学上不可能。

### Step 5: λ值/比分对比（v1.7新增 — 识别系统性比分偏差）

外部方案最隐蔽的错误是λ值偏差导致的**比分系统性偏高或偏低**。

#### 对比方法

```python
# 比较λ值
λ偏差 = 外部λ - 模型λ
if |λ偏差| > 0.15:
    print(f"⚠️ 显著λ偏差: {λ偏差:+.3f}")
    if λ偏差 > 0:
        print("外部方案高估了进攻预期，比分分布可能偏高1球")
    else:
        print("外部方案低估了进攻预期，比分分布可能偏低")

# 比较首推比分
if 外部首推比分 != 模型首推比分:
    比分差 = 外部首推总进球 - 模型首推总进球
    print(f"首推比分差{比分差}球 → 符合/不符合强队比分偏高规律")
```

#### 实战验证（2026-07-01 西班牙vs奥地利）

| 对比项 | 外部方案 | 后台模型 | 偏差 |
|:-------|:--------:|:--------:|:----:|
| 西班牙λ | 1.81 | 1.62 | +0.19（外部高估11.7%） |
| 奥地利λ | 0.83 | 0.72 | +0.11（外部高估15.6%） |
| 首推比分 | 2-0 (11.7%) | 1-0 (15.5%) | 偏高1球 ✅ 符合规律 |

**核心规律：外部方案的λ值整体偏高，比分系统性偏高1球。** 这是"叙事驱动"（说西班牙强所以会大胜）vs "概率驱动"（模型说1-0最可能）的核心分歧点。

#### 判断标准

| λ偏差幅度 | 比分偏差 | 外部方案可信度 |
|:---------:|:--------:|:--------------:|
| < 0.10 | 基本一致 | 可信 |
| 0.10-0.20 | 偏高0.5~1球 | 有叙事驱动倾向 |
| > 0.20 | 偏高1~2球 | 强烈叙事驱动，数据质量可疑 |

## 审计输出格式

```markdown
## 📋 总结：模型差异核心

| 差异点 | 外部方案 | AFEI模型 | 谁更可信 |
|:-------|:--------|:---------|:--------|
| **伤停数据** | 未考虑拉菲尼亚/穆西亚拉/凯塞多 | 全部纳入 | **AFEI** ✅ |
| **概率和** | 多个比分概率和>50%且互斥 | 校准至≈100% | **AFEI** ✅ |
| **EV真实性** | 多个+1以上EV | Edge均<5pp | **AFEI** ✅ |
| **数据源** | Yahoo/ESPN(不完整) | 懂球帝+竞彩网API | **AFEI** ✅ |

### 一句话结论
外部方案的泊松概率计算偏高（概率和常超过100%），且忽略了关键伤停数据，导致多个比分出现不合理的正EV。相比之下，AFEI模型虽然保守，但全部概率和校准至≈100%、纳入了伤停信息，结果更贴近市场实际。
```

### 五段式审计摘要（v1.7 新增 — 按段输出）

对每篇外部文章的输出结构：

```
1. 胜率方向 ✅/⚠️/❌ 高度一致/轻度分歧/严重分歧
   外部XX% vs 模型XX% —— 差Xpp
   结论：XXXX

2. 比分分布 ⚠️ 系统性偏差/基本一致
   外部首推XX，模型首推XX —— 差X球
   符合/不符合"已出线球队比分偏高1球"规律

3. 大小球 ✅ 一致/分歧
   双方都倾向大/小X.5球

4. 事实错误 ❌❌❌（有则必列）
   ① 历史交锋编造：XXXX
   ② 身价错误：XXXX
   ③ 精密数据无来源：XXXX

5. 市场偏差共识 ✅/⚠️
   双方都认为市场高估/低估了热门方
```
