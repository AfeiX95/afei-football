# 外部分析优点吸收

> v1.0（2026-07-04） | 基于加拿大vs摩洛哥外部文章吸收实战

## 为什么做

用户提供的外部媒体分析不是噪音。它们往往包含模型缺乏的**叙事框架**：
- 实战型分析师提炼的"一句话比赛定位"（最值钱的部分）
- 媒体文章的"比赛剧本推演"（模型缺乏时间维度）
- 关键对位划分（与数据模型互补）

## 四步吸收流程

### ① 识别框架化元素

扫描外部分析中的以下结构，吸收到你的全维度分析对应位置：

| 外部结构 | 示例 | 吸收到分析的位置 |
|:--------|:----|:---------------|
| 一句话比赛定位 | "反击型东道主 vs 防守体系成熟的非洲强队" | 分析头部`> **比赛定位**`行 |
| 球队类型标签 | "高节奏反击队（波动型）" / "低失球+高纪律队（稳定型）" | 分析头部`> **球队标签**`行 |
| 关键对位分析 | 边路vs边后卫、中场控制权、定位球 | 独立章节"关键对位分析" |
| 比赛剧本推演 | 上半场0-15'抢开局 / 60-75'体能瓶颈 / 冷门路径 | 独立章节"比赛剧本推演" |
| 关键时间窗口 | "前30分钟加拿大能制造威胁，但很难持续压制" | 比赛剧本推演具体时间窗口 |
| λ/概率区间 | λ_can 0.9~1.2, λ_mor 1.1~1.5 | 交叉验证模型λ |

### ② 交叉验证模型结论

```text
外部分析结论 → 与AFEI模型结论对比

方向一致（偏差<5pp）：
  → 模型置信度提升 ✅
  → 可在结论中写："外媒xxx也给出了类似判断"

方向分歧（偏差>10pp）：
  → 找出分歧根源（数据来源？分析逻辑？视角差异？）
  → 分歧本身就是有价值的叙事素材
  → 可以在阿飞解码段落呈现两方逻辑
```

### ③ 标注来源

在知识库中标注吸收自哪个来源的什么结构。不隐匿外部来源——好的分析值得署名。

```markdown
> 以下结构吸收自：[来源名称/URL]
> - 比赛定位：回复型东道主 vs 防守体系成熟的非洲强队
> - 球队标签：高节奏反击队（波动型）
> - 三大对位结构
```

### ④ 更新到全维度分析

将吸收的结构整合进全维度分析的对应章节。

**注意：** 不要在头条号输出中保留结构标题（如"关键对位分析"）。它们是内部分析框架，融入自然语言段落呈现给公众读者。

## 实战案例（2026-07-04 加拿大vs摩洛哥）

### 来源内容
用户提供的外部文章包含：
- 比赛定位："反击型东道主 vs 防守体系成熟的非洲强队"
- 球队标签：加拿大"高节奏反击队（波动型）"，摩洛哥"低失球+高纪律队（稳定型）"
- 三大对位：边路vs边后卫、中场控制权、定位球
- 比赛剧本推演：上半场抢开局→下半场体能下降空间扩大
- λ区间：加拿大0.9~1.2，摩洛哥1.1~1.5

### 吸收操作

| 结构 | 吸收位置 | 结果 |
|:----|:--------|:----:|
| 比赛定位 | `全维度分析.md` 头部 `> **比赛定位：**` | ✅ 已加入 |
| 球队标签 | `全维度分析.md` 头部 `> **球队标签：**` | ✅ 已加入 |
| 三大对位 | 新增 **六、关键对位分析** 章节 | ✅ 已加入 |
| 比赛剧本推演 | 新增 **十一、比赛剧本推演** 章节 | ✅ 已加入 |
| λ区间交叉验证 | 模型λ(can 0.80, mor 1.50) vs 外部(can 0.9~1.2, mor 1.1~1.5) | ✅ 方向一致，模型更偏保守 |

### 校准效果

吸收外部框架后，全维度分析从11个章节扩展至14个章节，新增：
1. 比赛定位+球队标签（头部）
2. 关键对位分析（六）
3. 比赛剧本推演（十一）
