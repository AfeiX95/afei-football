# 赔率时间趋势信号强度 — 实战验证记录

## 核心原则

静态赔率告诉你市场价格。赔率时间趋势告诉你资金在哪里流动——后者更有价值。

## 信号强度排序（从强到弱）

| 信号 | 强度 | 说明 | 实战案例 |
|:-----|:----:|:------|:---------|
| **平赔持续下降3%+** | 🔴最强 | 机构集体加码防范平局，非单一机构行为 | 芝加哥vs温哥华 3.65→3.40(↓7%) |
| **主胜单调下降+客胜单调上升** | 🔴强 | 资金方向一致，无洗盘回弹 | 圣路易斯 1.34→1.32→1.30 |
| **让球赔率大幅度变动(>10%)** | 🟡中 | 市场对净胜球预期的重新定价 | 佐加顿斯让球-2 2.68→2.52(↓6%) |
| **晚盘3-6小时急变** | 🟡中 | 赛前信息驱动的聪明钱 | 挪威vs英格兰 英格兰1.83→1.69(↓8%) |
| **胜胜/平平半全场趋势** | 🟡中 | 与胜平负趋势一致时增强共识 | 圣路易斯胜胜 1.90→1.85 |
| **单一时间点** | ⚪弱 | 无法判断方向，仅作参考 | 仅开盘价的场次 |

## 五个必读信号

### 信号1：平赔持续下降（最强，已验证）

**规则：** 平局赔率在3+个时间点中持续下降，累计降幅≥3%。

**实战案例（2026-07-17 芝加哥vs温哥华）：**
```
3.65 → 3.55 → 3.45 → 3.40 (↓7%)
```
平赔是三项中降幅最大的，机构持续加强平局防范。加上温哥华门将红牌停赛+6人伤病+客场长途奔波，平局从"可能结果"升级为"首选结果"。

**解读流程：**
1. 确认平赔是否在3+时间点单调下降
2. 确认降幅是否≥3%
3. 确认基本面是否支持平局（伤停/客场/战意）
4. 三项都满足 → 平局为首选方向

### 信号2：主胜单调下降（常见于过热场景）

**规则：** 主胜赔率在3+时间点中持续下降，累计降幅≥3%。

**实战案例（2026-07-16 圣路易斯vs堪萨斯）：**
```
1.34 → 1.32 → 1.30 (↓3%)
```
主胜一路降但1.30已触发过热预警。三次下调均为单调方向→资金在持续加码买入过热方向→经典诱盘/过热陷阱信号。

**注意：** 过热方向(赔率<1.40)的单调下降不是共识信号，是过热信号。

### 信号3：主胜先降后升（洗盘/回吐）

**规则：** 主胜先下降后回升，形成V形或倒V形。

**实战案例（法国vs西班牙 2026世界杯半决赛）：**
```
2.26 → 2.10 → 2.03 → (临场回升)
```
早盘资金买入法国→晚盘资金回吐→H2H克星数据被市场重新定价。先降后升比单调下降更有信息量。

### 信号4：让球赔率与胜平负矛盾

**规则：** 胜平负看好某队，但让球盘不看好该队赢盘。

**实战案例（蒙特利尔vs多伦多）：**
```
胜平负: 主胜1.82→1.87(上调) → 市场降低对蒙特利尔的信心
让球-1: 主胜3.45→3.80(飙升10%) → 市场明确不看好蒙特利尔赢2球+
```
让球盘信号比胜平负更敏感。

### 信号5：胜胜(半全场)持续下降

**规则：** 胜胜赔率持续下降+胜平负主胜下降=半场领先+全场赢的共识增强。

## 解读原则

1. **变动的百分比比绝对值更有意义** — 1.34→1.30(-3%)比数字本身重要
2. **3个时间点是最低要求** — 少于3个时标注"趋势数据不足"
3. **晚盘(赛前3-6小时)比早盘(48-72小时)更可靠** — 信息披露更充分
4. **趋势分析不能替代EV计算** — 方向对≠有正EV
5. **平赔下降是最强信号** — 超过主胜和客胜的趋势
