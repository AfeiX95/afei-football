# 对比分析 · 观点校验方法论

## When to Use

当用户提供其他来源的分析文章，或你从 web_search 找到了多篇分析需要与之对比时。

## Comparison Grid

对每一项进行比对：

| 项目 | 我的模型 | 对方来源 | 偏差幅度 | 判断 |
|------|---------|---------|---------|------|
| 胜率 | 63.2% | 66.4%（市场赔率） | 3.2pp | ✅ 合理偏差 |
| 比分预测 | 1-0 / 2-0 | 3-0 / 4-0 | 核心分歧 | ⚡ 需模型数据裁决 |
| 大小球 | 52.3% | 未明确 | — | — |
| 场地 | ✅ 费城 | ✅ 费城 | 一致 | — |
| 伤病 | 遗漏 | 包含 | ❌ 我漏了 | 需补查 |

## Fact-Checking Protocol

### 1. 核验基本事实（必须先做）

```
- 场地：search "<team1> vs <team2> venue 2026 World Cup"
- 天气：search "<city> weather <date> thunderstorm"
- 伤病：search "<team> injury lineup 2026 World Cup"
- 比分/积分：search "Group X standings 2026 World Cup"
- H2H历史：search "<team1> <team2> head to head"
```

如果发现自己的文章有硬伤（写错场地、遗漏天气预警），必须承认并修正——这是信誉基础。

### 2. 核心分歧的分析框架

比分预测分歧时（对方说3-0，模型说1-0），用模型数据逐层拆解：

```
对方"3-0"的逻辑链：
身价悬殊 → 姆巴佩状态好 → 伊拉克防线被打穿过 → 大胜

模型数据反驳：
63.2%胜率中1-0(12.5%)最高，3-0仅8.2%
大2.5球仅52.3%（接近抛硬币）
雷暴天气利好防守方
德尚历史偏好领先即收
```

### 3. 信息来源标注

```
数据来源评级：
⭐⭐⭐⭐⭐ 官方/FIFA/竞彩网API
⭐⭐⭐⭐  主流外媒（ESPN/Sky/Sports Mole）
⭐⭐⭐   普通媒体/自媒体
⭐⭐     论坛/社交媒体
⭐      无来源/未核实
```

### 4. 输出格式

```
## 观点对比分析：[比赛名称]

### ① 事实核查
| 项目 | 我的文章 | 对方文章 | 结论 |

### ② 核心观点对比
| 维度 | 对方观点 | 我的观点 | 分析 |

### ③ 双方都遗漏的信息
| 信息 | 重要性 | 漏在哪方 |

### ④ 整体评价
```

## User Focus Adaptation

用户说"只关心X"时，砍掉所有非X内容。不要加"整体评价""遗漏信息"等分析框架。

**只关心比分和胜负概率** → 输出：
- λ值 + 胜/平/负百分比
- 最可能比分 Top 5 概率表
- 大小球概率
- 与对方文章的比分偏差表（1张表搞定）
- 一句话结论

**只关心胜负** → 输出胜率对比表 + 结论，不展开比分。

**要求全量分析** → 用下方完整四步框架。

## Common Pitfalls

1. 盲目信任外部比分预测：很多分析基于"名声"而非数据
2. 忽略天气变量：雷暴/大雨对控球型球队影响远大于防反型
3. 忽略伤病的连锁反应：一个球员缺阵可能改变整条线的战术角色
4. 被首轮比分误导：1-4 ≠ "防线被打穿"，要看比赛进程
5. 遗漏叙事钩子：梅西追平纪录、姆巴佩成队史射手王——流量入口

## 实战发现：外部文章系统性偏差（2026世界杯验证）

对比10+篇外部预测文章 vs 模型数据后发现的规律：

| 文章常见偏差 | 模型实际情况 | 发生频率 |
|-------------|------------|---------|
| 首选3-0/4-0大胜 | 实际最高概率通常是1-0或2-0 | 80%+ |
| "多球局""大2.5" | 大2.5球经常不到50% | 60%+ |
| 忽略平局 | 平局概率经常20-30% | 90%+ |
| "零封大胜" | 零封概率通常30-50% | 70%+ |
| 已出线球队大胜 | 轮换后攻击力大幅下降 | 100% |

**对比时重点关注这些偏差，作为分歧分析的切入点。**
6. **把73%写成"稳赢"**：四场里有一场意外，首轮被逼平就是活例子。数据越确定性措辞越要克制。
7. **忽略零封概率的量化**："极有希望零封"但模型说50.5%≈抛硬币——必须给出数字。
8. **品牌溢价陷阱**：身价差距大≠比赛结果确定。市场和媒体天然高估强队约Xpp。
