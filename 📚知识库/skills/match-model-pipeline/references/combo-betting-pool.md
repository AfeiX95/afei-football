# 组合投注池设计（2串1 / 3串1 三层结构）

> 版本：v1.0 | 实战验证：2026-07-02 三场淘汰赛
> 设计来源：阿飞·赛博聊球 用户原创结构

---

## 一、核心构建逻辑

组合投注池不是"全押正确比分"，而是 **"主路径 + 保险路径 + 冷门对冲路径"** 的三层结构：

```
🔵 稳定层（高概率比分/方向）— 控场压制型比赛
🟡 增益层（赔率更高但合理）— 允许波动的比赛
🔴 防冷层（结构对冲）— 冷门剧本保护
```

## 二、载体选择：让球盘/大小球 > 精确比分

精确比分2串1/3串1在竞彩市场**天然负EV**（每场抽水12-15%，串关后margin指数级放大）。

**正确做法：** 用三层结构选方向载体（胜平负/让球胜平负），而不是精确比分。

### 精算验证（2026-07-02 三场淘汰赛）

| 载体 | 组合 | 赔率 | EV | 说明 |
|:----|:----|:---:|:--:|:-----|
| ❌ 精确比分 | 西班牙2-0+瑞士1-0 | 30.60 | **-48%** | 抽水叠加不可接受 |
| ✅ 胜平负 | 葡萄牙平+瑞士胜 | 6.12 | **-0.6%** | 几乎保本，接近正期望 |
| ✅ 让球胜平负 | 葡萄牙-1让胜+瑞士胜 | 5.60 | **-1.7%** | 可接受的娱乐仓位 |

**结论：** 胜平负/让球胜平负串关的EV损失远小于精确比分串关。

## 三、三层结构转换表

将用户的原始三层逻辑翻译为可执行的市场投注：

### 🔵 稳定层（低风险主线）

| 原始逻辑 | 可执行投注 | 选择依据 |
|:--------|:----------|:---------|
| "控场压制" | 强队胜/让球胜 | Edge>+6pp 或 模型胜率>60% |
| "极低失球预期" | 小2.5球 | 期望总进球<2.3球，或高温修正已应用 |
| **实战：** 瑞士胜@1.80 | Edge+13.5pp⭐ | 全比赛日最高价值信号 |

### 🟡 增益层（收益提升，允许波动）

| 原始逻辑 | 可执行投注 | 选择依据 |
|:--------|:----------|:---------|
| "拉锯战锁风险" | 平局 @3~5倍 | 模型平局概率>20%且市场有效 |
| "进攻打开" | 让球胜(-1) @2~4倍 | 强队有≥1球的赢球能力 |
| **实战：** 葡萄牙平@3.40 | 模型25.9% vs 市场26.0% | 最接近的拉锯战 |

### 🔴 防冷层（结构对冲）

| 原始逻辑 | 可执行投注 | 选择依据 |
|:--------|:----------|:---------|
| "冷门剧本" | 弱队胜/受让球 | 弱队有真实爆冷路径时 |
| "反市场投注池" | 反向方向 | 市场一边倒时做对冲 |
| **实战：** 阿尔及利亚胜@4.06 | 佩特科维奇倒戈变量 | 旧帅倒戈是冷门最大X因素 |

## 四、仓位分配模型

```
┌──────────────────────────────────────┐
│  总投注池 = 100%                     │
│                                      │
│  🔵 稳定层: 50% → 总资金的3-5%       │
│     → 1-2场高确信方向串关             │
│                                      │
│  🟡 增益层: 25% → 总资金的2-3%       │
│     → 高赔率方向串关                  │
│                                      │
│  🔴 防冷层: 15% → 总资金的1%         │
│     → 冷门方向小注                    │
│                                      │
│  🔥 3串1核心: 10% → 总资金的1-2%    │
│     → 全穿1-2场的娱乐组合             │
└──────────────────────────────────────┘
```

### 实战参考仓位（2026-07-02）

| 层级 | 方向 | 赔率 | 仓位 |
|:----|:----|:---:|:----:|
| 🟢 稳健 | 瑞士胜(单关) | 1.80 | **8.0%** |
| 🟡 增益 | 葡萄牙平+瑞士胜(2串1) | 6.12 | 2-3% |
| 🔴 防冷 | 西班牙0-0(单关) | 13.00 | 2.4% |
| 🔥 3串1 | 西班牙胜+葡萄牙平+瑞士胜 | 7.53 | 1-2% |

**注意：** 瑞士胜单关是唯一Kelly正期望（8.0%），其他组合本质是娱乐小注。

## 五、关键决策点（临场盯盘）

### ① 首球时间
- ≤35分钟 → 稳定层方向更可靠
- >60分钟 → 防冷层概率上升

### ② 强队是否早进球
- 早进 → 穿指概率提升，增益层更可能命中
- 久攻不下 → 平局/冷门方向需调整

### ③ 弱队是否先得分
- 领先 → 冷门剧本启动
- 落后 → 稳定层覆盖

## 六、核心纪律

1. **单关>串关** — 有正期望的单关永远优于串关
2. **串关=娱乐** — 串关的本质是"正确叙事+小注博彩"，不是价值投资
3. **三层不是三个串** — 稳定层和增益层最多各选1个方向执行，不要同时下注5个组合
4. **保留现金** — 60-70%现金等待更好的入场机会（临场变盘/后续比赛日）
5. **竞彩是固定赔率市场** — 不分析资金流/Sharp Money/庄家意图，只分析可观测变量
