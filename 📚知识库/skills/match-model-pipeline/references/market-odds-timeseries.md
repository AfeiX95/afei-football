# 盘口时间序列分析方法论

## When to Use

用户提供竞彩网赔率时间序列数据（多时间点的胜平负/让球/比分/总进球赔率变化）时，用此方法解构市场意图。

## 分析框架

### 1. 胜平负轨迹解构

逐行列出每个时间点的赔率，标注趋势方向（↑↓→），重点识别：

| 信号 | 含义 | 示例 |
|------|------|------|
| 初盘→最新大幅变动 | 资金方向明确 | 法国1.52→1.45 = 法国被大量买入 |
| 先升后降（或反向） | 聪明钱逆流 | 挪威4.65→5.05→4.25 = 先被抛弃后被买入 |
| 平局赔率不变 | 市场共识 | 平局3.05→3.05 = 没有倾向 |
| 某方向赔率持续下降 | 该方向被大量买入 | 佛得角2.46→2.28→持续下降 |

### 2. 反推隐含概率

```
隐含概率 = (1/赔率) / (1/赔率A + 1/赔率B + 1/赔率C) × 100%
```

注意：三结果隐含概率之和 > 100%（庄家抽水），需归一化后才能与模型概率对比。

### 3. 比分盘信号提取

重点关注：
- 最低赔率比分 = 市场共识最可能比分
- 赔率大幅下降的比分 = 被大量买入
- 赔率大幅上升的比分 = 被抛弃
- 平局类比分（0-0/1-1/2-2）的变化方向 = 市场对默契/闷战的预期

### 4. 总进球盘信号

- 低进球（0-2球）赔率上升 = 市场预期高进球
- 高进球（4球+）赔率下降 = 高进球被买入
- 0球赔率变化幅度最大时 = 市场在赌极端结果

### 5. 让球盘解读

让球盘是1X2的"压缩版"：
- 让球平局 = 全场某特定比分（如+1平 = 主队输1球）
- 让球赔率变化方向与1X2一致 = 信号增强
- 让球赔率变化方向与1X2矛盾 = 注意分歧

## 输出模板

```
③ 🕒 盘口时间序列深度解构

* **1X2轨迹：** [逐时间点表格 + 趋势判断]
* **让球盘：** [变化方向 + 信号]
* **比分盘关键变化：** [5-8个关键比分的初盘→最新→变化%]
* **总进球盘：** [低/高进球方向信号]
* **核心信号：** [1-3句话总结市场意图]
```

## 常见陷阱

1. **赔率变化不等于概率变化** — 庄家会主动调赔平衡资金，不一定反映真实概率
2. **深夜场资金量小** — 03:00/05:00场次的赔率变化可能只是少量资金导致，不代表大趋势
3. **比分盘赔率基数小** — 从7.50降到6.00（-20%）不如从2.50降到2.00（-20%）有意义
4. **不要把赔率数字写入文章** — 合规红线，正文中禁止出现具体赔率数字
