## 1. 懂球帝详细指南

### URL模式
```
https://www.dongqiudi.com/team/{teamId}.html
```
- teamId 可通过 web_search("懂球帝 <队名>") 获得
- 示例：瑞士 teamId=1931，阿尔及利亚 teamId=13

### 提取的数据结构

每页包含以下信息，按位置分组：

**教练组：**
- 主教练姓名、国籍、年龄
- 助理教练/门将教练/体能教练

**球员（按位置）：**
- 位置（前锋/中场/后卫/门将）
- 姓名、俱乐部、年龄
- 出场数（国家队）、进球、助攻
- 身价（欧元）

**球队信息：**
- 英文名、城市、成立年份
- 主场名称、容量
- 总市值

### 注意事项
- web_extract 对此站可能返回空内容
- **推荐方式：browser_console + JS提取**（无需用户粘贴，直接提取结构化数据）
- 数据中的"出场/进球/助攻"为国家队生涯数据，非赛季数据
- 页面需要先点击"阵容"标签(browser_click @e4)才能显示球员列表

### Browser Console JS提取方法（2026-07-01实战验证）

当web_extract失败时，使用browser工具导航到该页面，然后：

```javascript
// 步骤1: 点击"阵容"标签
// browser_click ref=e4 (按钮"阵容")

// 步骤2: 提取所有球员
// 前锋+中场表（索引0,1，从教练表之后算起）
Array.from(document.querySelectorAll('table tr')).slice(1)
  .map(r => Array.from(r.querySelectorAll('td'))
  .map(td => td.textContent.trim()))
  .filter(cells => cells.length >= 7 && cells[1])

// 步骤3: 提取后卫表（索引3）
document.querySelectorAll('table')[3].textContent

// 步骤4: 提取门将表（索引4）
document.querySelectorAll('table')[4].textContent
```

**表索引规则（懂球帝阵容页）：**
| 索引 | 内容 | 提取方式 |
|:---:|:----|:--------|
| 0 | 教练组(6人) | textContent或行遍历 |
| 1 | 前锋(6人) | 行遍历 + 列解析 |
| 2 | 中场(8-9人) | 行遍历 + 列解析 |
| 3 | 后卫(8-9人) | textContent(快速) |
| 4 | 门将(3人) | textContent(快速) |

### 叙事角度挖掘（从阵容数据提取额外角度）

- **同俱乐部对位**：如马扎(阿尔及利亚·勒沃库森) vs 扎卡(瑞士·勒沃库森) → "药厂内战"叙事
- **身价集中度**：最高身价占全队比 > 15% → 被针对性锁死风险
- **年龄结构**：多名30+老将 → 体能存疑，尤其高温/加时赛场景
- **新星vs老将**：如曼赞比5000万(20岁) vs 马赫雷斯500万(35岁)

## 3. 多源数据采集工作流顺序（2026-07-01实战验证）

### 推荐采集顺序
```
Step 1: 竞彩网API → 赔率+市场隐含概率 (最快)
    ↓
Step 2: 竞彩网特征分析页 → 积分榜+近况+射手+伤停 (如用户提供)
    ↓
Step 3: 雷速SWOT → 定性情报+阵容名单+天气 (可选，需browser)
    ↓
Step 4: 雷速阵容页 → 基础球员名单 (可选，补充冷门队)
    ↓
Step 5: 懂球帝 → 详细阵容数据+身价 (推荐，数据最全)
    ↓
Step 6: Wikipedia → 小组赛比分+赛果 (验证积分/赛果)
    ↓
Run: 后台模型(λ+MC+MPS)
```

### 各来源耗时参考
| 来源 | 平均耗时 | 注意 |
|:----|:-------:|:-----|
| 竞彩网API | ~3s | curl即可，最快 |
| 竞彩网特征分析页 | 需用户粘贴 | 不可自动获取 |
| 雷速SWOT | ~10s | 需browser，可能有滑块 |
| 雷速阵容页 | ~8s | 需browser |
| 懂球帝 | ~12s | 需browser+点击标签 |
| Wikipedia | ~5s | web_extract |

## 5. 叙事角度提取框架

从阵容数据中提取以下维度用于文章：

### 5.1 身价碾压 vs 草根逆袭
- `总身价比` → 强弱叙事基调
- `最高身价球员` → 明星vs平民

### 5.2 联赛背景
- `英超/五大联赛球员数` → 大赛经验
- `同一联赛球员占比` → 默契程度

### 5.3 熟人网络（文章亮点）
- 前队友对位（如万-比萨卡 vs 拉什福德 — 曼联旧将）
- 同联赛交手记录
- **同俱乐部现役对决**（如马扎·勒沃库森 vs 扎卡·勒沃库森 → "药厂内战"）
- 教练过往交手

### 5.4 核心依赖度
- `头号射手进球占比 > 50%` → 被针对性防守风险高
- `助攻分布集中度` → 组织核心被锁死的风险

### 5.5 年龄结构
- `平均年龄 > 30` → 经验足但体能存疑（尤其高温/加时赛）
- `U23球员数` → 年轻活力但大赛经验不足
- `核心球员年龄 > 35` → "最后一舞"叙事（如C罗41岁、莫德里奇40岁）

### 5.6 门将对决
- 门将是常被忽略的叙事角度：身价差距、经验差距、扑点能力
- 如科贝尔4000万(多特) vs 齐达内100万(格拉纳达) → 门将档次差40倍
