# 市场效率分类 & Edge形态识别

> 基于2026-07-06 葡萄牙vs西班牙(市场高效) vs 美国vs比利时(市场低效) 两场对比分析总结。

## 一、市场效率的定义

**高效市场：** 赔率隐含概率、模型概率、外媒预测、盘口方向四源一致，且所有方向的Edge绝对值<3pp。
**低效市场：** 至少有一个方向的Edge绝对值≥3pp，且其他来源存在分歧。

## 二、判断流程

在完成MC模拟和EV计算后，按下述流程分类：

```
完成模型 → 计算Edge → 搜索外媒共识 → 分析赔率趋势 → 分类：

Step A: 计算每个方向的Edge = P_model - P_market
Step B: 搜索3-5家外媒，看共识方向是否与模型/市场一致
Step C: 分析赔率时间趋势：资金流向是否支持模型方向
Step D: 综合判断市场效率：

  若 |Edge| < 3pp 且 四源一致 → 高效率市场 → ⚪点缀场
  若 |Edge| ≥ 3pp 且 至少三源一致 → 有认知差 → 对应分层
  若 |Edge| ≥ 8pp 且 四源分歧 → 可能数据问题，需核查
```

## 三、四种Edge形态详解

### 形态1：健康Edge 🟢

| 特征 | 值 |
|:----|:---|
| 模型胜率 | 45-55%（接近均势） |
| Edge | +5~+10pp |
| 典型案例 | 🇺🇸美国48.5% +7.3pp vs比利时 |
| 赔率趋势 | 持续买入(赔率走低) |
| 外媒共识 | 与模型方向一致 |
| 置信度 | 🟢 可信，可考虑主攻场 |

**识别信号：** 胜率接近50%，Edge中等(5-10pp)，赔率资金持续流入。没有极端值。

### 形态2：品牌溢价Edge 🔴

| 特征 | 值 |
|:----|:---|
| 模型胜率 | >55%（热门方向） |
| Edge | +6~+15pp |
| 典型案例 | 🇧🇷巴西66.3% +9.2pp→1-2输挪威 |
| 赔率趋势 | 可能平稳或轻微上升 |
| 外媒共识 | 看好热门（受品牌影响） |
| 置信度 | 🔴 需检查3（淘汰赛攻坚折扣） |

**根因：** 市场/模型都被球队的FIFA排名、身价、历史成绩「说服」。淘汰赛阶段品牌溢价需要额外折扣（×0.80）。

### 形态3：叙事驱动Edge 🔴

| 特征 | 值 |
|:----|:---|
| 模型胜率 | <40%（弱队方向） |
| Edge | >+8pp |
| 典型案例 | 🇲🇽墨西哥37.9% +10.2pp→2-3输英格兰 |
| 赔率趋势 | 弱队赔率可能被压低 |
| 外媒共识 | 「有爆冷潜质」叙事 |
| 置信度 | 🔴 仓位减半，通过检查1 |

**根本原因：** 模型被小组赛某场亮眼表现或媒体「黑马叙事」说服。当弱队胜率<40%且Edge>+8pp时，这个Edge通常比实际偏高5-10pp。

### 形态4：零值Edge ⚪

| 特征 | 值 |
|:----|:---|
| 模型胜率 | 任意 |
| Edge | \|Edge\| < 3pp (三个方向均低于阈值) |
| 典型案例 | 🇪🇸西班牙50.6% +0.9pp vs葡萄牙 |
| 赔率趋势 | 充分博弈后收敛 |
| 外媒共识 | 四源一致 |
| 置信度 | ⚪ 市场价格有效，不碰方向 |

**市场意义：** 这是最「干净」的信号——市场已经充分消化所有信息。任何方向的仓位都会产生负EV（扣除抽水后）。此类场次最多小注正EV比分。

## 四、场次分类决策树

```
完成分析后的决策：

Edge > +6pp?
├─ 是 → 模型胜率范围？
│   ├─ > 55% 且 Edge +品牌溢价 → 🟢主攻场(需检查3:淘汰赛攻坚折扣)
│   ├─ 45-55% → 🟢主攻场(健康Edge，无需额外检查)
│   └─ < 40% 且 Edge > 8pp → 🟡利润核心(需检查1:仓位减半+叙事风险标记)
├─ 否 → Edge > +3pp?
│   ├─ 是 → 🟡弱价值，小注比分
│   └─ 否 → Edge > -3pp?
│       └─ 是 → ⚪点缀场(或跳过)
```
