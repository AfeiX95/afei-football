# 比赛日全流程作业管线

> 多联赛同日开球时的标准化作业流程
> 适用：韩职/瑞超/世界杯混合比赛日
> 版本：v1.0 (2026-07-05)

---

## 一、总流程

```
T-24h ──── 赛程确认 → 积分榜拉取 → 初步分层（哪些值得分析）
   ↓
T-6h ───── 竞彩赔率API拉取 → 赔率时序记录
   ↓
T-4h ───── SWOT/特征分析页数据提取 → 14维全维度分析
   ↓
T-2h ───── 6注结构分层（核心/放大/防守）→ 资金分配
   ↓
T-1h ───── 头条文章写作 → 降AI → 合规检查 → 发布
   ↓
T+0 开球 ── 比赛进行中（不操作）
   ↓
赛后次日 ── 赛果校验 → 模型校准 → 记忆更新
```

---

## 二、输入清单

| 阶段 | 需要什么 | 来源 | 优先级 |
|:----|:---------|:-----|:-------|
| 赛程确认 | 今日比赛列表+时间 | 竞彩网赛程页 | 🥇 |
| 积分榜 | 完整排名+主客场分离 | 竞彩网积分榜页 | 🥇 |
| 赔率 | SPF+让球+比分+总进球+半全场 | 竞彩API/固定奖金页 | 🥇 |
| 特征分析 | 伤停/射手/近况/交锋/排名 | 竞彩特征分析页 | 🥇 |
| SWOT | 有利/不利/天气/裁判 | 雷速SWOT(如有) | 🥈 |
| 射手榜 | 全联赛射手数据 | 懂球帝 | 🥈 |
| 外媒 | 预测/分析角度 | Google搜索 | 🥉 |

## 三、输出清单

| 输出物 | 格式 | 路径 | 标准 |
|:-------|:-----|:-----|:-----|
| 全维度分析(14维) | .md | `📚知识库\比赛分析\{联赛}\` | 每场必出 |
| 6注结构分层 | 终端输出/记忆 | — | 全天汇总 |
| 赛事前瞻(合集) | .html | `{日期}\{联赛}三场_赛事前瞻.html` | 三场合一优先生出 |
| 赛事前瞻(单场) | .html | `{日期}\{场次}_赛事前瞻.html` | 焦点战单独出 |
| 赛后校验 | 终端输出 | — | 赛后次日上午出 |
| 配图关键词 | 文末折叠块 | 追加到.html | 每篇必附 |

## 四、时间分配（按优先级）

| 优先级 | 任务 | 预估耗时 |
|:------|:-----|:---------|
| 🥇 | 14维全维度分析(每场) | 8-12分钟 |
| 🥇 | 6注结构分层 | 3-5分钟 |
| 🥇 | 三场合集文章 | 10-15分钟 |
| 🥈 | 单场焦点文章 | 8-10分钟 |
| 🥈 | 配图关键词 | 2-3分钟 |
| 🥉 | 赛后校验 | 5-8分钟 |

**实战案例（2026-07-05 韩职3场+瑞超3场）：**
- 14维分析×6场 = ~60分钟
- 6注分层 = 5分钟
- 韩职三场合集 = 12分钟
- 瑞超三场合集 = 12分钟
- 埃夫斯堡单场 = 10分钟
- 配图×4篇 = 8分钟
- **总耗时：~107分钟（约1小时47分）**

## 五、质量门

每个输出物过三道门才能交付：

| 门 | 检查项 | 通过标准 |
|:--|:-------|:---------|
| 🚪1 数据门 | 比分/排名/射手数据核实 | 至少2个独立源交叉验证 |
| 🚪2 逻辑门 | 分析链条完整(数据→判断→结论) | 每个数字都有来源或计算过程 |
| 🚪3 发布门 | 头条合规检查+排版轮换确认 | 禁用词0命中+与上一篇视觉不同 |
