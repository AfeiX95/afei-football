# 全链路HTML输出模板（双结构）

> 版本：v1.0 | 实战验证：2026-07-02 瑞士vs阿尔及利亚 / 葡萄牙vs克罗地亚
> 文件命名：`{日期}/{编号}_{队名}_{队名}_全链路分析.html`

---

## 一、页面结构顺序

```
1️⃣ L0.5 战略目标判断       ← 绿色标题卡片
2️⃣ L1 xG模型 → λ值         ← 数据表格+着色λ行
3️⃣ L2+L3 市场隐含+Edge     ← 概率条 + Edge三卡 + 品牌溢价说明
4️⃣ L4 比分EV + Kelly       ← EV表 + 策略卡片三档
5️⃣ 🔍 十维变量全检          ← 10行变量表（含旧帅倒戈/更衣室/裁判等）
6️⃣ 📉 盘口分析九维          ← 亚洲盘+大小球+百家+时变+凯莉+必发+晋级+球员+综合
7️⃣ 🔬 敏感性分析            ← λ±0.2波动表
8️⃣ 🌐 外媒分析              ← 3-5家外媒卡片+共识总结
9️⃣ 🎯 四源比分合成          ← 四源对比表 + 综合结论
🔟 🧠 叙事层战术拆解        ← 比赛本质+战术对撞+节奏模型+胜负点
🏁 最终综合预测             ← 四宫格+比分表+核心策略+综合加权+置信等级
```

## 二、最终综合预测 标准格式

放在页面最底部，固定在 `<!-- 最终综合预测 -->` 区块内。内容和顺序如下：

### 2.1 四宫格（2×2 grid）

| 格1 | 格2 |
|:---|:----|
| 主队胜率 + Kelly仓位 | 平局概率 + EV信号 |
| **格3** | **格4** |
| 客队胜率 + EV信号 | 大小球倾向 + 市场分歧 |

### 2.2 比分推荐表

| 优先级 | 比分 | 概率 | EV | 场景描述 |
|:-----|:----|:----:|:--:|:---------|
| 🥇 **最推荐** | 2-0 | 10.7% | - | 模型首推+外媒共识 |
| 🥈 | 2-1 | 10.0% | - | 最现实波动 |
| 🥉 | 1-0 | 10.8% | - | 低效率局 |
| ⭐ **EV最优** | 3-0 | 7.3% | +0.163 | 早进球+防线崩溃场景 |
| 🚨 **需防范** | 1-1 | 9.8% | - | 冷门入口+关键变量说明 |
| 🚨 **需防范** | 0-0 | 5.4% | - | 极端闷战场景 |

### 2.3 核心策略

```
🟢 主单：瑞士胜 @1.80 — Edge+13.5pp，四源一致，十维无矛盾
🟡 辅单：大2.5球 — 模型56.0% vs 市场小2.5分歧
🔴 防冷：重点关注1-1(佩特科维奇倒戈变量) 和 0-0(闷战拖加时)
```

### 2.4 综合加权 + 置信等级

```
📊 综合加权因素：
模型62.7% · 外媒52-55% · 盘口瑞士-0.5 · 凯莉正期望 · 十维全检8✅1⚠️1❌
主要风险：佩特科维奇倒戈 · 更衣室传闻 · 大小球分歧
置信等级：A级（四源一致 + 模型稳定 + 基本面支持）
```

**置信等级定义：**
- **A级**：四源一致 + 模型稳定(敏感性<3pp) + 十维无重大矛盾
- **B级**：市场有效(Edge<3pp) + 比分EV集中在冷门侧 + 不确定性高
- **C级**：四源分歧 + 模型波动(敏感性>5pp) + 重大未知变量
