# Football Tactical Analyst 战术复盘与对位大师

> 定位：阵型克制分析 + 核心球员对位评估
> 适用场景：深度分析阶段的战术拆解
> 搭配使用：14维评分卡（维度#5阵型克制 + 维度#6核心球员对位）

---

## 一、战术理论库

### 1.1 阵型分类

| 阵型 | 风格 | 优势区域 | 弱点区域 |
|:-----|:-----|:---------|:---------|
| 4-3-3 | 传控/高位逼抢 | 两翼宽度+中路渗透 | 中场防守空虚 |
| 4-2-3-1 | 攻守平衡 | 中场控制+前场创造力 | 边路防守薄弱 |
| 3-5-2 | 中场厚度+两翼齐飞 | 中场人数优势+边路攻防 | 两翼体能要求高 |
| 5-3-2 | 低位防守反击 | 防守密度+反击速度 | 控球率低+创造力不足 |
| 4-4-2 | 经典平衡 | 阵型紧凑+双前锋 | 中场容易被压制 |
| 3-4-3 | 激进进攻 | 进攻人数+宽度 | 防守空档大 |
| 4-1-4-1 | 防守反击 | 后腰屏障+边路速度 | 中锋孤立 |

### 1.2 风格克制矩阵

```
克制关系（行 → 克制列）：
传控 → 防反（控球消耗体力，防反等待机会）
高位逼抢 → 传控（压迫出球失误）
防反 → 高位逼抢（身后空间大）
低位防守 → 传控（密集防守难渗透）
两翼齐飞 → 三中卫（边路1v1优势）
三中卫 → 双前锋（中路人数优势）
```

## 二、核心脚本

### 2.1 阵型克制分析

脚本位置：`database/scripts/tactical_matchup.py`

功能：
- 输入两队常用阵型
- 输出克制关系评分（-2到+2）
- 分析空间优势区域

```bash
python database/scripts/tactical_matchup.py --home-formation "4-3-3" --away-formation "5-3-2"
```

### 2.2 球员对位分析

脚本位置：`database/scripts/player_matchup.py`

功能：
- 输入双方预测首发
- 识别关键对位（如：主队速度型边锋 vs 客队转身慢中卫）
- 输出对位优势评估

```bash
python database/scripts/player_matchup.py --home-lineup "lineup_home.json" --away-lineup "lineup_away.json"
```

## 三、阵型克制评分规则

### 3.1 评分标准

| 评分 | 含义 | 说明 |
|:----:|:-----|:-----|
| +2 | 高度克制 | 阵型完全压制，空间优势明显 |
| +1 | 轻微克制 | 阵型有一定优势 |
| 0 | 无明显克制 | 势均力敌 |
| -1 | 轻微被克 | 阵型有一定劣势 |
| -2 | 高度被克 | 阵型完全被压制 |

### 3.2 常见对阵克制关系

| 主队阵型 | 客队阵型 | 克制评分 | 分析 |
|:---------|:---------|:--------:|:-----|
| 4-3-3 | 5-3-2 | +1 | 两翼宽度 vs 三中卫，边路1v1有机会 |
| 4-3-3 | 4-4-2 | 0 | 势均力敌，中场4v3略被克 |
| 4-2-3-1 | 4-3-3 | -1 | 对方中场3人压制后腰2人 |
| 5-3-2 | 4-3-3 | +1 | 中路密集防守+反击身后空间 |
| 3-5-2 | 4-4-2 | +1 | 中场5人压制4人 |
| 4-4-2 | 3-5-2 | -1 | 中场被人数压制 |
| 4-1-4-1 | 4-3-3 | 0 | 后腰屏障 vs 中场渗透 |

## 四、核心球员对位分析框架

### 4.1 关键对位区域

| 对位区域 | 重要性 | 分析维度 |
|:---------|:------:|:---------|
| 中锋 vs 中卫 | ★★★★★ | 速度/力量/头球/跑位 |
| 边锋 vs 边后卫 | ★★★★☆ | 速度/1v1/传中/回追 |
| 前腰 vs 后腰 | ★★★★☆ | 组织/拦截/覆盖 |
| 边翼卫 vs 边前卫 | ★★★☆☆ | 攻防转换/体能 |

### 4.2 对位优势评估维度

| 维度 | 权重 | 数据来源 |
|:-----|:----:|:---------|
| 速度差 | 25% | 球员数据/评分 |
| 身体对抗 | 25% | 身高体重/评分 |
| 技术能力 | 20% | 过人/传球成功率 |
| 比赛经验 | 15% | 出场次数/年龄 |
| 近期状态 | 15% | 近5场评分 |

## 七、注意事项

1. **阵型非固定**：同一球队不同比赛可能换阵型，需确认本场实际阵型
2. **实时变化**：比赛中可能调整阵型（如落后后换3前锋），需关注赛前最终确认
3. **球员适配**：阵型克制是理论分析，实际效果取决于球员执行力
4. **数据局限**：对位分析依赖球员数据完整性，小联赛数据可能不足
