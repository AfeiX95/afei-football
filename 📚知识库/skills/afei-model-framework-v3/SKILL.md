## 二、五维升级路线图

### 🥇 优先级1：λ输入升级 — 真实xG替代xG代理

**当前问题：**
- λ估算中xG代理公式：`xG_for = GF × 0.92`（粗糙缩放）
- 无法区分"神仙球连胜"和"统治力连胜"
- 极端值（如6-0卡塔尔）需手动剔除

**目标方法：**
```python
# 当前（粗糙代理）
lambda_xg = (GF_avg × 0.92 + GA_opponent_avg × 1.08) / 2

# 目标（真实xG）
lambda_xg = (xG_for_per_game + xGA_opponent_per_game) / 2
```

**数据源：**
| 来源 | 可用性 | 覆盖范围 |
|------|--------|---------|
| FBref | ✅ 免费 | 世界杯+五大联赛xG/xGA/xPTS |
| Understat | ✅ 免费 | 五大联赛xG/xGA |
| Opta(Stats Perform) | 💰 付费 | 最全xG/xA/xGChain/xG Buildup |

**实施步骤：**
1. 接入FBref API/爬虫获取赛事xG数据
2. 将xG_for和xGA_against替换当前GF×0.92代理
3. 添加xPTS偏离度计算：`xPTS_deviation = actual_pts - xPTS`
4. 当|xPTS_deviation| > 3时标记为"不可持续状态"并触发λ警告

### 🥈 优先级2：进失球时间分布量化

**当前问题：**
- 剧本推演中的时间分段依赖定性判断
- "60-75分钟体能窗口"无数据支撑

**目标方法：**
```
每15分钟分段统计（0-15, 15-30, 30-45, 45-60, 60-75, 75-90）
  - 球队进球概率分布
  - 球队失球概率分布
  - 半场领先后的胜率
  - 先丢球后的逆转率
```

**数据源：** FBref比赛事件数据 / ESPN比赛报告

**输出示例：**
```
巴西进球分布: 0-15(12%) 15-30(25%) 30-45(18%) 45-60(15%) 60-75(20%) 75-90(10%)
→ 巴西习惯15-30分钟发力, 75分钟后懈怠
```

### 🥉 优先级3：必发/交易所资金面监控

**当前问题：**
- 仅用竞彩赔率时序判断资金方向
- 无法区分"正常市场消化"和"大单异动"
- 临场资金信号缺失

**目标方法：**
```
监控指标:
  1. 必发BF成交总量（流动性深度）
  2. 主/平/客资金分布比例（vs 赔率隐含比例）
  3. 大单追踪: 单笔>£1000的成交记录
  4. 临场(赛前2小时)资金流向突变检测

信号类型:
  - ⚠️ 大单异动: 临场大单集中涌入某一方向
  - ⚠️ 资金背离: 资金分布与赔率变动方向不一致
  - ✅ 正常消纳: 资金流入与赔率变动一致
```

**数据源：** Betfair Exchange API（需注册开发者账号）

---

### 优先级4：PPDA/高位压迫强度 & Field Tilt

**当前问题：**
- 战术对比中的"高压/控球"纯定性描述
- 无法量化压迫强度和真实场面控制力

**目标指标：**
```
PPDA (Passes Per Defensive Action):
  - <10 = 极端高压（利物浦式）
  - 10-13 = 高位压迫
  - 13-17 = 中等
  - >17 = 回收防守

Field Tilt (进攻三区控球率):
  - 衡量真正的场面统治力
  - 全场控球率低但Field Tilt高=反击效率高
```

**数据源：** Wyscout / Opta（均需付费）, 免费可用WhoScored统计

---

### 优先级5：替补xG输出率 & 后手质量

**当前问题：**
- 完全未考虑替补球员能力差异
- 假设所有教练临场调整能力相同

**目标方法：**
```
替补xG输出率 = 替补球员本赛季每90分钟xG之和 / 首发球员每90分钟xG之和
  > 1.0 = 板凳深度极佳（换人后进攻不降反升）
  < 0.5 = 首发依赖型（换人=进攻降级）

关键场景:
  - 强队领先60分钟后换上防守型替补→大球概率降低
  - 弱队落后换上3前锋搏命→防守空虚→对方反击机会
```

## 四、已知局限与注意事项

1. **xG数据源接入**：FBref免费但需爬虫维护，Understat覆盖不全（缺世界杯），Opta最全但付费
2. **必发数据**：英国IP更流畅，Betfair API需开发者账号
3. **世界杯vs联赛差异**：赛会制比赛（世界杯）的差旅/时差影响小于联赛，可降低优先级
4. **横财信号（俱乐部派系）**：世界杯基本不涉及，仅在联赛分析中需考虑
5. **数据时效性**：xG/PPDA数据通常延迟1-2天，赛前实时数据有限需注意
