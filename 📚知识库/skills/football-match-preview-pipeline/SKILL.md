# 阿飞·赛博聊球 — 赛事前瞻全流程管线 v3.0

## 定位

从竞彩网赛程数据到**发布就绪 docx** 的完整生产链。单场/两场/多场合集通吃。

**核心原则：**
- 分析层：14维评分卡 + 后台模型（λ/MC）+ 规则库 C01-C27 + 候选规则视角
- 写作层：骨架法则（R23）+ 语言去水（R24）+ 素材库（R25）+ 叙事池（R11）
- 合规层：R20/R20b 话术 + 禁用词 + 时间锚点 + 数字合规
- 交付层：**docx（R19，白底图）**，不再出 HTML/MD 头条版
- 闭环层：赛后校验（batch calibration）→ 更新修正规则/模型参数

---

## 依赖技能加载顺序（写作前必加载）

```text
1. match-model-pipeline          → 模型推演管线（λ/MC/Edge）
2. football-match-preview-article → 写作工作流
3. afei-writing-standards        → 写作偏好覆盖层 R1-R27（覆盖前者）
4. humanizer-zh                  → 降AI
5. 叙事池.md（R11）              → 选2-3维度+选型记录落盘
6. 写作素材库.md（R25）          → 四类素材拼积木
```

## 主流程（10 步，不可跳步）

### Step 1: 数据采集

**来源优先级（铁律）：** 竞彩网特征分析页 > 竞彩网固定奖金页 > 竞彩网API > web_search > 赔率反推

**必须采集（用户粘贴竞彩网HTML时，提取两个页面）：**

| 数据 | 来源 | 用途 |
|------|------|------|
| 胜平负/让球/比分/总进球/半全场固定奖金时间序列 | 固定奖金页 | 市场隐含概率 |
| 排名/积分（总/主/客分离） | 特征分析页·积分榜 | 主客场分离修正 |
| 近10场战况（总/同主客） | 特征分析页·比赛近况 | form修正 |
| 历史交锋（近10场/同主客） | 特征分析页·历史交锋 | H2H修正（注意时效！） |
| 射手信息（进球占比） | 特征分析页·射手信息 | 单点依赖评估 |
| 伤停一览 | 特征分析页·伤停一览 | λ修正 |
| 未来赛事 | 特征分析页·未来赛事 | 战意/留力评估 |

**⚠️ H2H 时效性教训（Batch#22）**：7年前的 H2H（2018-2019）不作数，不能触发 C24 克星信号；当季 H2H（3个月内）才是硬信号。

**API 拉取（辅助）：**
```bash
curl -s 'https://webapi.sporttery.cn/gateway/uniform/football/getMatchCalculatorV1.qry?channel=c'
```

### Step 2: 14维评分卡 + 模型推演

**执行 match-model-pipeline：**
1. **Step 0.5 战略目标判断**：双方目标是什么（抢分/留力/保级/杯赛轮换）
2. **14维评分卡**：基础硬实力（状态/主客/伤停/身价）+ 技战术（克制/对位/xG/H2H）+ 战略心理（战意/疲劳/更衣室/恩怨）+ 外部（天气/裁判）→ 合计Δλ
3. **λ双方法估算**：数据法 + 市场反推法，偏差>0.5时偏向数据法
4. **规则叠加**：C01-C27 修正规则 + 候选规则视角（C28-C32等）
5. **概率矩阵**：模型 vs 市场去水对比 → Edge = P_model - P_market
6. **比分Top** + 大2.5 概率

**输出落盘**：`📚知识库/比赛分析/{联赛}/{日期}_{编号}_{主队}vs{客队}_全维度分析.md`

### Step 3: 核心矛盾提炼（单点打透 R23）

每场只抓 **1 个核心矛盾**（单点打透法则）：
- 状态 vs 定价背离（东京FC 20%胜率却被深热）
- H2H 克星（当季克制）
- 伪五五开（表面均衡，细节全指一侧）
- C15a 陷阱（<1.50 让-1）
- 题材热度 vs 真实战力

小标题带结论（R23）：`撕开主场伪强队面具`、`3个月前的0-3血洗不是旧账`、`模型与市场严重背离（-13.6pp强预警）`——不用"数据对比""历史交锋"等模糊词。

### Step 4: 叙事池 + 素材库选型

- **叙事池（R11）**：加载 `📚知识库/写作指南/叙事池.md`，选 2-3 维度嵌入（战意/信号必选，外媒固定）——**查最新选型记录换角度**
- **素材库（R25）**：加载 `📚知识库/写作指南/写作素材库.md`，从四类取可用素材（标题句式/反常识案例/数据结论/金句）拼积木
- **写完文章后选型记录落盘**：追加到叙事池文末 #N（编号递增，随 git 提交）

### Step 5: 文章写作（R23 骨架）

**金字塔开篇（结论先行，铺垫≤3句）：**
```
[核心冲突一句话] + 可后台模型跑完，[结论]。 
**结论先行**：[每场1句话立场]。
```

**结构（单场/两场/多场通用）：**
```
标题（≤30字，冲突+数字+悬念）
话题标签
金句（素材库选/招牌句）
金字塔开篇（结论先行）
小标题带结论的正文段落（每场独立）
📊 数据速览（表格）
🧮 模型（概率矩阵，模型vs市场偏差）
🌍 外媒（2-4家，叙述式）
💰 信号（偏差分析，战术→进球数推导 R22）
🎬 剧本（条件式 if-then，R22）
🎯 核心推演矩阵（R27，替代重复的四重落脚+速览+总结）
互动钩子（R26 二选一）
数据来源（1处）
免责声明（新版）
配图关键词（中英双语，无水印近期赛照导向）
```

### Step 6: 合规体检（发布前必跑）

**用 Python 脚本扫描 md（不是手动）：**
```python
# 检查项：
# 1. 禁用词：赔率/盘口/庄家/泊松/蒙特卡洛/EV/凯利/让球盘/水位/投注/下注/串关/过关/稳胆/上车/跟单/重注/梭哈/打穿/穿盘/竞彩有风险
# 2. 时间锚点：今天/明天/昨天/刚刚/几个小时/北京时间
# 3. AI高频词：基本盘/成色/互相印证/真金白银/高度集中/完全吻合/完全一致/拉满/闭眼赢/表面看/说白了/实锤
# 4. 数字合规（R20b）：具体小数（1.39/2.41）→ 转百分比胜率或机构胜率支撑
# 5. 动词合规（R20b）：综合推荐/押/重仓 → 综合研判/我更倾向/个人预判
# 6. 破折号（——）≤3（金句除外）；箭头→ 0
# 7. 标题 ≤30字
# 8. 句长标准差（朱雀指纹）：标准差越大越像人写
```

**通过标准：禁用词0 / 锚点0 / 破折号≤3 / 标题≤30 / 数字已转百分比。**

### Step 7: 朱雀降AI（humanizer-zh）

**若上一步句长标准差偏小或检测到AI特征，执行 humanizer-zh 深度降AI：**
1. 打散对仗工整句（"热度是新的，压制是旧的"）
2. 替换 AI 高频词（基本盘→吃饭的家伙、成色→水平、互相印证→对上了）
3. 口语化：自嘲/承认不确定/短句碎句
4. 破折号压到 ≤3
5. 注入人味：视角滑动、废话文学自嘲、第一人称判断

**教训（朱雀100% AI）：** 对仗句、完美三刀结构、箭头符号、金句堆砌是四大AI指纹，必须全文级重写而非微调。

### Step 8: 白底图 + docx 生成（R19）

**图表（matplotlib，白底）：**
```python
PANEL = "#ffffff"; TXT = "#333333"; SUB = "#888888"
GRID = "#dddddd"; C_MODEL = "#4fc3f7"; C_MARKET = "#ffd93d"; C_AWAY = "#ff6b6b"
```
每场 3 张：雷达图（六维）/ 模型vs市场柱状图 / 比分Top5柱状图。输出 `database/charts_{日期}_{标签}/`。

**docx 生成**（脚本 `database/gen_docx_{日期}_{标签}.py`）：
- 读取 md 正文 → 构建 docx（微软雅黑，白底图嵌入）
- 输出 `📝文章/{日期}/{标题}_头条版.docx`（沙箱需 danger-full-access）
- 标题 emoji 小标题（⚔️/📊/🧮/🌍/💰/🎬/🎯）保留（R19）

### Step 9: 交付归档 + git

- md + docx 同目录归档 `📝文章/{日期}/`
- 分析报告归档 `📚知识库/比赛分析/{联赛}/`
- 叙事池选型记录、素材库新素材同步落盘
- git 提交（文章+分析+技能更新+记忆）

**发布窗口（SKILL v3.0.0）**：赛前 5-8 小时发布（晚间欧战中午11-13点/15点前，凌晨赛提前一天）；发文后首评置顶。

### Step 10: 赛后校验闭环（batch calibration）

**赛果出来后执行 football-calibration-batch 流程：**
1. 收集赛果（竞彩网赛果页/用户粘贴）→ 90分钟口径
2. 对比模型预测 vs 实际（方向/比分/让球/大小球）
3. 规则验证：C15a/C15b/C27/C09/C12/C24 等触发场次判定
4. 新增/加强修正规则（候选标记，样本达标后回写）
5. 报告落盘 `📚知识库/赛后校验/batch{N}_calibration.md`
6. 更新修正规则.md + model-parameters.json（样本达标时）+ 工作记忆

## 常见错误（防踩坑）

| 错误 | 后果 | 正确做法 |
|:-----|:-----|:---------|
| 输出 HTML/MD 头条版 | 违反 R19 | 一律 docx |
| 具体小数价格入文（1.39/2.41） | 头条机器审核判涉彩 | 转百分比胜率/机构胜率支撑 |
| 结论重复堆叠（四重落脚+速览+总结） | 结构冗余 | 合并为核心推演矩阵（R27） |
| 小标题用模糊词（"数据对比"） | 叙事无力 | 用带结论的动作短语（R23） |
| 对仗工整句/完美三刀/箭头符号 | 朱雀100% AI | 全文级降AI重写（humanizer-zh） |
| H2H 用7年前旧账 | 误判克星信号 | 只认当季（3个月内）H2H |
| 忽略候选规则（C28-C32等） | 错过价值信号 | 分析时按候选规则视角检查 |
| docx 写不进 📝文章 目录 | 沙箱拦截 | 用 danger-full-access 升级 |
| 赛后不校验 | 模型不迭代 | 每批赛果必跑 batch calibration |
