# Knowledge Base Layout

> 项目根目录 `I:\阿飞说球\`，知识库在 `📚知识库\`
> 每次写文章前，先查此处已有数据，勿凭记忆脑补

```
I:\阿飞说球\
├── 📚知识库/
│   ├── 索引.md                ← 目录入口
│   ├── 球队档案/               ← 每队一个md（阵容/身价/小组数据/λ参考）
│   ├── 比赛分析/2026世界杯R32/  ← 每场一个分析md（赔率/λ/MC/EV/方向）
│   ├── 写作指南/
│   │   ├── 梗库.md             ← 2026世界杯热梗（已纠正巴拉圭≠摩洛哥）
│   │   └── 写作管线清单.md      ← 发文前检查表
│   └── 数据源/
│       ├── API接口.md           ← 竞彩网/懂球帝/雷速API
│       └── 懂球帝队名ID映射.md
├── 📅赛事/{YYYYMMDD}/          ← 已发布文章/HTML/文档
├── 📋复盘与归档/               ← 历史文章
├── 📊模型脚本/                 ← model code
└── ⚙️工具/                    ← deploy scripts
```

## 使用原则
1. 球队小组数据（胜/平/负/进/失）**必须从Wikipedia或本地档案核实**，不凭印象
2. 本地 `📅赛事/{日期}/` 下如有已有模型分析HTML，直接复用数据
3. 用户提到的热梗先查 `梗库.md`，确认事实基底再写
4. 懂球帝"近期战报"含进行中比赛，不能当最终赛果
