### 1.5 🏆 锦标赛战略博弈推演层 (Tournament Strategy — 核心层)

> **⚠️ 本层是v4.0的核心升级。** 单场分析如果脱离锦标赛上下文，就是盲人摸象。必须在分析比赛本身之前，先把"这场比赛在锦标赛全局中的位置"搞清楚。

#### 1.5.1 小组出线形势穷举

**必须完成的工作：** 列出当前小组所有球队的积分、净胜球、进球数，然后**穷举本轮所有可能的赛果组合**，推演每种组合下的最终排名。

输出格式：

| 本轮赛果组合 | 主队最终排名 | 客队最终排名 | 主队出线? | 客队出线? |
|-------------|------------|------------|----------|----------|
| 主胜 + 另一场X | 第X | 第X | ✅/❌ | ✅/❌ |
| 平局 + 另一场X | 第X | 第X | ✅/❌ | ✅/❌ |
| 主负 + 另一场X | 第X | 第X | ✅/❌ | ✅/❌ |

**关键判断：**
- 哪些赛果组合对双方都有利？→ **默契球温床**
- 哪些赛果组合让一方必须拼命？→ **战意爆发点**
- 是否存在"双方平局都能出线"的情况？→ **极高默契概率**

#### 1.5.2 淘汰赛路径推演（下一阶段对手分析）

> **⚠️ 血的教训（2026-06-26）：** I组分析中，我凭"常理"推断I2打J1(阿根廷)，实际赛程是I2打2E(科特迪瓦)——阿根廷在完全不同的半区。**绝对不能靠"第1打第2"的常识推断淘汰赛对阵，必须查实际赛程表！** 参考 `references/wc2026-bracket.md`。

**核心问题：** 赢了这场比赛，下一轮打谁？输了打谁？平了打谁？
**⚠️ 铁律：必须从实际赛程表核实对阵关系，禁止凭经验推断。**

| 本场结果 | 对阵位置 | 潜在对手 | 对手实力评级 | 路径难度 |
|---------|---------|---------|------------|---------|
| 主队胜/小组第1 | [上/下半区] | [对手A] | [S/A/B/C] | [地狱/困难/中等/轻松] |
| 主队胜/小组第2 | [上/下半区] | [对手B] | [S/A/B/C] | [地狱/困难/中等/轻松] |
| 主队平 | [上/下半区] | [对手C] | [S/A/B/C] | [地狱/困难/中等/轻松] |
| 主队负 | [上/下半区] | [对手D] | [S/A/B/C] | [地狱/困难/中等/轻松] |

**路径价值计算：**
```
路径价值差 = 避开强敌的期望收益 - 主动输球的声誉/纪律成本
```
- 当路径价值差 > 0 且声誉成本低（小组赛末轮、已出线）→ **控分避战动机极强**
- 当路径价值差 < 0 或声誉成本高（淘汰赛、东道主）→ **控分动机弱**

#### 1.5.3 控分避战决策树

```
├─ 是否已确保出线？
│   ├─ 是 → 进入1.5.3A「已出线控分推演」
│   └─ 否 → 进入1.5.3B「生死战意评估」
│
├─ 【1.5.3A 已出线控分推演】
│   ├─ 小组第1 vs 第2的淘汰赛路径差异大吗？
│   │   ├─ 差异巨大（如第1打弱旅，第2打豪强）→ 第1名动机=100%，全力争胜
│   │   ├─ 差异不大 → 动机下降，可能轮换+保守
│   │   └─ 第2名路径反而更好（如避开某半区）→ **主动控分动机！**
│   ├─ 主力是否需要休息？（下一场淘汰赛间隔天数）
│   │   ├─ 间隔≤3天 → 轮换概率极高（80%+）
│   │   └─ 间隔≥4天 → 轮换概率中等（40%）
│   └─ 对手是否背水一战？
│       ├─ 是 → 即使己方轮换，对手战意S级，比赛强度≠友谊赛
│       └─ 否 → 可能演变为低强度默契战
│
├─ 【1.5.3B 生死战意评估】
│   ├─ 赢球=确定出线？→ 战意S级，全力争胜
│   ├─ 平局=确定出线？→ 战意A级，保守为主，不冒险
│   ├─ 需要赢X球以上？→ 战意S级但心态急躁，攻强守弱
│   └─ 即使赢球也大概率出局？→ 战意可能断崖（C级），但也可能"为荣誉而战"
```

#### 1.5.4 默契球/协议球概率评估

**五维判断矩阵：**

| 维度 | 高默契信号 (+1) | 低默契信号 (-1) | 本场评分 |
|------|----------------|----------------|---------|
| 双方利益一致性 | 平局双方都受益 | 一方必须赢 | [+1/0/-1] |
| 历史默契先例 | 同赛事有过默契球 | 无先例/死敌 | [+1/0/-1] |
| 球队文化 | 功利足球传统 | 进攻足球传统 | [+1/0/-1] |
| 舆论/监管压力 | 深夜场/关注度低 | 黄金时段/全球直播 | [+1/0/-1] |
| 教练风格 | 保守务实型教练 | 激进理想主义教练 | [+1/0/-1] |

**默契概率 = (总分+5) / 10 × 100%**

- ≥70% → **高默契风险**，大幅下调λ值，上调平局概率
- 40-69% → **中等默契可能**，适度调整
- <40% → **默契可能性低**，按正常模型运行

### 1.6 ⚠️ 数据源验证协议 (Data Source Verification — 血的教训)

> **2026-06-27连续犯错记录：** 把fifawatch.com HTML页面的静态"FT"数据显示当成真实赛果（未来比赛还没踢就当已结束），被纠正后又没检查同类问题。用HTML积分榜数据没交叉验证，导致5处比分错误（墨西哥3-0→2-0、德国2-0→7-1、墨西哥vs韩国胜负写反、比利时vs埃及、沙特vs乌拉圭）。

**铁律：**

1. **日期交叉验证（最高优先级）：** 当前日期之后的比赛**绝对不可能已结束**。看到"FT"标签必须先比对日期，违反此规则=直接犯错。
2. **数据源可信度层级：**
   - ✅ **Tier 1（可信）：** 竞彩网 sporttery.cn 实时页面、用户手动粘贴的比分、RSS文字描述
   - ⚠️ **Tier 2（需验证）：** fifawatch.com 积分榜HTML、第三方数据网站静态页面
   - ❌ **Tier 3（不可信）：** HTML页面中的预填"FT"比分、赛程表中的预设结果
3. **交叉验证规则：** 任何积分/赛果数据，必须用**至少两个独立来源**确认。RSS新闻文章的文字描述是最可靠的验证源。
4. **发现一处错误→立即检查所有同类数据：** 用户指出摩洛哥vs荷兰没踢→必须立刻检查南非vs加拿大、巴西vs日本是否也没踢。不要修一个漏一个。

### 2. 球队数据画像与防污染验证 (Data Portrait & Validation)

- **动态变量防污染：** 严格核查主力伤停、禁赛名单，剥离"市场传闻"。
- **⚠️ 主力轮换概率评估：**

  | 轮换因子 | 判断标准 | 对λ的影响 |
  |---------|---------|----------|
  | 已出线+末轮 | 几乎确定大轮换 | attack -10~20%, morale -15% |
  | 已出线+需争第1 | 部分轮换（保留核心） | attack -5%, morale -5% |
  | 3天内两场 | 体能轮换2-3人 | attack -5% |
  | 核心球员黄牌累积 | 避免停赛→可能替补 | 特定位置 -10% |
  | 淘汰赛加时风险 | 保留换人名额→首发不变 | 无直接影响 |

  **轮换阵容评估：**
  - 预测首发 vs 首轮首发的重合度（X/11人）
  - 替补球员的俱乐部水平差距（身价比）
  - 轮换后阵型是否变化（如4-3-3→4-5-1更保守）

- **极端进球与攻防效率（xG体系）：** 提取双方预期进球（xG）、预期失球（xGA）、射门转化率与防守质量，构建"优势-劣势"能力图谱。
  - **xG近似公式（无真实xG数据时的代理模型）：**
    ```
    xG_for ≈ 场均进球 × 0.92
    xG_against ≈ 场均失球 × 1.08
    ```
    说明：场均进球通常高估真实xG（运气成分），场均失球通常低估真实xGA（门将发挥）。0.92/1.08系数基于大赛统计回归。
- **状态修正量化（Form Index）：** 将近期战绩转化为λ修正值，避免只做定性描述。

  | 近5场结果 | 每场修正 | 累计范围 |
  |----------|---------|---------|
  | 胜 | +0.08 λ | |
  | 平 | +0.02 λ | |
  | 负 | -0.05 λ | |
  | **最大修正** | | **±0.25 λ** |

  示例：近5场3胜1平1负 → +0.24+0.02-0.05 = +0.21 λ修正
  ⚠️ 修正值叠加到λ估算中，与轮换折扣、战意修正并列。

### 3. 战术对位推演 (Tactical Matchup)

- 寻找核心矛盾碰撞，以己之长攻彼之短。量化三大对决场景：
  - **转换速度：** 反击速度 vs 防线身后空间（引入守转攻 xG 值与失位概率）。
  - **破密集路径：** 传中成功率 vs 远射补射 vs 中路渗透。
  - **定位球互爆：** 定位球得分占比 vs 定位球防守灾难指数。
- **⚠️ 轮换后战术变形：** 主力轮换不只是"人换了"，是战术体系可能降级。
  - 替补门将出击范围/扑救率差异
  - 替补中场控球率下降→被压着打概率上升
  - 替补前锋终结效率下降→λ直接下调

### 4. 隐性变量修正 (Hidden Variables)

- **魔鬼赛程与体能：** 评估未来3场密集度，量化75分钟后的跑动下降与失误率。
- **扰动因子：** 裁判（红牌/点球倾向）、天气（风速/降雨）、场地对技战术的压制/促进。
- **⚠️ 锦标赛心理博弈：**
  - "已经出线"的心理松懈效应（即使不轮换也有-5%战意）
  - "背水一战"的心理爆发效应（+10-15%战意，但可能急躁→红牌风险↑）
  - "默契球预期"对投注市场的扭曲（大众不信任默契→冷门投注偏移）

### 5. 资本盘口与资金解构 (Market & Money Flow)

- **盘口结构：** 记录初始欧赔、亚盘让球指数及总进球数边界，分析初盘深浅合理性。
- **资金流与凯利偏移：** 计算市场集中度（HHI），追踪大众投注方向与临场资金逆流。
- **庄家做局解构：** 精准识别四大陷阱（诱上盘、诱下盘、温和诱导控赔、阻平/阻大恐吓）。
- **⚠️ 锦标赛战略因素对盘口的扭曲：**
  - 已出线球队的市场溢价往往未被充分折价→**模型价值空间**
  - 默契球预期让平局赔率被高估→**平局价值信号**
  - "为荣誉而战"叙事让市场高估弱队战意→**反向价值信号**

## 三、 🧮 第二阶段：指数收敛与数理模拟层（控制层）
> **⚠️ 核心逻辑：** 拒绝拍脑袋决策，将上述解剖层压缩为三大核心指数，进行统一收敛计算。

- **🔵 CSI（基本面强度指数）：** $CSI = \text{实力差} + \text{xG体系} + \text{战意去泡沫} + \text{轮换折扣}$
  - 轮换折扣作为CSI的独立子项，权重不低于战意
- **🟡 MPI（市场压力指数）：** $MPI = \text{盘口结构} + \text{资金流向} + \text{凯利偏移} + \text{庄家做局} + \text{品牌溢价}$
  - 品牌溢价纳入MPI，锦标赛战略溢价单独计算
- **🔴 RDI（随机扰动指数）：** $RDI = \text{天气变量} + \text{裁判因子} + \text{信息噪声} + \text{默契概率修正}$
  - 默契概率作为RDI的独立子项

### 🧠 MPS 决策引擎
$$MPS = CSI - MPI \pm RDI$$
- **判定规则：**
  - $MPS > 0.8 \rightarrow$ 主强 / 正路稳健
  - $-0.8 \le MPS \le 0.8 \rightarrow$ 势均力敌 / 盘面均衡
  - $MPS < -0.8 \rightarrow$ 客强 / 极端冷门

### 🎲 泊松与蒙特卡洛双模型模拟（情景概率化）
- **泊松分布：** 基于 xG 分解模型，分别计算主客队预期进球值（$\lambda_1, \lambda_2$）。
  - ⚠️ **λ值必须经过轮换折扣和战意修正后才进入泊松模型，禁止用原始静态λ**
- **蒙特卡洛模拟：** 注入变量矩阵，进行 10,000+ 次比赛结果对撞模拟，输出三条互斥的比赛路径及精确比分概率。
- **⚠️ 锦标赛情景蒙特卡洛：** 在标准模拟之外，额外跑一组"控分/默契情景"模拟：
  - 情景A：双方全力争胜（正常λ）
  - 情景B：一方保守/轮换（λ下调15-25%）
  - 情景C：双方默契（双方λ各下调20%）
  - 最终概率 = 情景A概率 × (1-默契概率) + 情景B/C概率 × 默契概率

### ⑧ 📐 Edge与凯利仓位（v4.1新增 — 定量资金管理）
* **Edge计算：** `Edge = P_model - P_market`
  - P_model = 蒙特卡洛模拟概率
  - P_market = 市场隐含概率 = (1/赔率) / Σ(1/各赔率)
  - Edge阈值：
    - |Edge| < 3pp → 无价值，不投注
    - 3-5pp → 轻价值，小注
    - 5-10pp → 中价值，标准注
    - > 10pp → 强价值，重注
* **凯利仓位公式：**
  ```
  b = 赔率 - 1
  p = 模型概率
  q = 1 - p
  f* = (b × p - q) / b
  最终仓位 = f* × 0.5（半凯利防爆仓）
  ```
  - 当 f* < 0 → 凯利判定不下注（模型认为无正期望）
  - 当 f* > 0.25 → 钳制到0.25（单场不超过总资金25%）
  - 冷门方向额外 ×0.7 降权（赔率>5.0时）
* **输出格式：**
  ```
  Edge: +X.Xpp（[强/中/轻/无]价值信号）
  凯利仓位: X.X%（半凯利）
  推荐方向: [主胜/平/客胜/比分X-X]
  ```

## 七、 🕒 盘口时间序列行为解构（实操方法论）

> 本节补充v4.0框架中第三阶段"时间序列"的具体执行方法。基于竞彩网实际数据验证。

### 7.1 竞彩赔率数据提取

**数据来源：** 竞彩网 sporttery.cn → 竞彩足球 → 具体比赛页面 → "固定奖金"标签

**必须采集的时间序列字段：**
1. **胜平负（1X2）：** 从初盘到最新的全部时间点，观察方向趋势
2. **让球胜平负：** 让球数+赔率变化，关注让球平局（即全场平局）的资金信号
3. **比分盘：** 所有比分赔率的变化，重点关注：
   - 低比分（0-0/1-0/0-1/1-1）→默契/低进球信号
   - 高比分（3-1/2-3/3-2）→开放对攻信号
   - 某方向赔率下降=该比分被买入=市场预期该结果
4. **总进球盘：** 0-7+球的赔率变化，2球和3球是关键分割点
5. **半全场：** 负负(客半全场)和平平的赔率走势

### 7.2 品牌溢价计算公式

```
市场隐含概率 = (1/赔率) / (1/胜赔 + 1/平赔 + 1/负赔) × 100%
品牌溢价 = 模型概率 - 市场隐含概率
```

**溢价阈值判断：**
- |溢价| < 5pp → 市场定价合理，无价值信号
- |溢价| 5-10pp → 轻度偏差，可小注
- |溢价| 10-20pp → 显著偏差，标准仓位
- |溢价| > 20pp → **极端偏差，高价值信号**（如法国vs挪威29.8pp、佛得角vs沙特25pp）

**溢价来源分类：**
| 溢价类型 | 典型幅度 | 案例 |
|---------|---------|------|
| 强队品牌溢价 | +10~30pp | 法国/英格兰/德国已出线仍被高估 |
| 弱队品牌折价 | -5~15pp | 佛得角/冰岛等小国被低估 |
| 已出线轮换折扣未定价 | +5~15pp | 德国vs厄瓜多尔(市场71%→实际输了) |
| 默契球未定价 | +3~8pp | 英格兰vs加纳(让2球→实际0-0) |
| 战意差未定价 | +5~10pp | 背水一战vs已出线松懈 |

### 7.3 盘口轨迹解读四步法

**Step 1：看方向**
- 赔率↓ = 资金涌入该方向 = 市场看好
- 赔率↑ = 资金流出 = 市场看衰
- 不变 = 市场共识稳定

**Step 2：看幅度**
- 变化<3% → 正常波动
- 变化3-8% → 有意义的资金流动
- 变化>8% → **强烈信号，必须关注**

**Step 3：看时间节奏**
- 初盘→T-24h：机构定价期，反映基本面
- T-24h→T-6h：多方博弈期，聪明钱进场
- T-6h→T-0h：散户跟风期+首发名单确认→最终定价

**Step 4：看联动**
- 同组另一场比赛的赔率联动→默契球信号
- 让球盘与胜平负方向不一致→市场分歧→可能存在价值

## 八、 ⚠️ 世界杯48队赛制速查（实战验证版）

> 基于2026世界杯实测验证的赛制知识。

### 8.1 基本赛制
- 48队分12组×4队，单循环3轮
- **前2名(24队) + 8个最佳第3名(8队) = 32队**晋级淘汰赛
- 第3名排序：积分→净胜球→进球数→公平竞赛积分→FIFA排名

### 8.2 第3名晋级门槛经验值（2026实测）
- **4分第3名：99%晋级**（2026年4个4分第3名全部晋级）
- **3分第3名：30-55%晋级**（取决于有多少4分第3名+其他组结果）
- **2分第3名：<5%晋级**（理论上可能但极难）
- **0-1分第3名：0%晋级**

### 8.3 第3名分析核心工作
必须做的一件事：**穷举所有未结束组的第3名末轮结果**，列出：
1. 哪些第3名已经锁定（已赛完3场）
2. 哪些第3名还在踢（末轮结果影响排名）
3. 如果所有热门赢球，最终第3名排名是什么
4. 如果出现冷门，排名怎么变

### 8.4 已出线球队的模型校准（2026世界杯16场验证）

| 场次 | 市场预判 | 实际结果 | 教训 |
|------|---------|---------|------|
| 德国vs厄瓜多尔 | 德国让1球(71%) | 1-2负 | 已出线=大轮换=冷门 |
| 美国vs土耳其 | 美国让1球(65%) | 2-3负 | 东道主已出线=松懈 |
| 英格兰vs加纳 | 英格兰让2球 | 0-0平 | 双方已出线=默契 |
| 日本vs瑞典 | 日本让1球 | 1-1平 | 已出线=不拼命 |
| 葡萄牙vs乌兹别克 | 葡萄牙让2球 | 5-0胜 | ⚠️唯一没翻车的（但葡萄牙C罗因素） |

**核心规律：5场已出线强队比赛，4场翻车或平局。模型校准规则已验证有效。**
