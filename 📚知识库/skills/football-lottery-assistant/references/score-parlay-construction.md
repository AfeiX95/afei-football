# 比分串关构建方法论 — 职业版

> v2.0 | 基于2026世界杯1/8决赛四场实战验证
> 方法论来源：AFEI模型框架 + 职业交易员框架修正

---

## 核心原则（优先级排序）

```
1️⃣ EV筛选 > 概率排序 → 先砍负EV，再排正EV
2️⃣ 比赛分层 > 均等对待 → 主攻场/陷阱场/利润核心
3️⃣ 加权分配 > 等权均注 → 按EV和信心分配资金
4️⃣ 6注集中 > 16注分散 → 用最少子弹打最可能赚钱的路径
```

---

## 第一步：比赛分层

写串关前，先对每场比赛做三层定性，决定它在串关中的角色。

| 层 | 类型 | 特征 | 串关角色 |
|:--|:-----|:------|:---------|
| 🟢 **主攻场** | 模型胜率>60% + Edge>+5pp | 正EV明确，市场未充分定价 | **串关基石，重仓** |
| 🟡 **陷阱场** | 模型胜率高但Edge负 | 胜负确定但赔率已榨干 | **不碰胜负，只玩比分** |
| 🔵 **利润核心** | 模型胜率<40%但Edge>+8pp | 认知差盘口，市场低估 | **盈利发动机，中仓** |
| ⚪ **补充点缀** | 接近场次，无明显Edge | 结构凑合，增加赔率 | **轻仓或跳过** |

**实战判定示例（2026世界杯1/8决赛）：**
```
巴西vs挪威 → 🟢 主攻场 (模型64.6%, Edge+9.2pp)
法国vs巴拉圭 → 🟡 陷阱场 (模型74.9%, Edge-4.9pp, 不碰胜负)
墨西哥vs英格兰 → 🔵 利润核心 (模型35.8%, Edge+10.2pp)
加拿大vs摩洛哥 → ⚪ 补充点缀 (接近场次，无显著Edge)
```

---

## 第二步：EV筛选 — 砍掉负EV选项

**规则：** 每场列出所有可选项，计算单腿EV，只保留满足条件的。

```
单腿EV = 模型概率 × 竞彩赔率 - 1

保留标准:
  ✅ 单场胜平负: Edge > +3pp 或 EV > 0
  ✅ 单场比分: EV > -0.3（比分盘抽水高，适当放宽）
  ❌ 砍掉: Edge负且EV负的热门陷阱
  
典型陷阱:
  ❌ 法国胜 @1.19 → EV-0.108, Edge-4.9pp → 碰都不要碰
  ✅ 法国0-2 @29.00 → EV+3.756 → 值得玩
```

**EV过滤后的可选池示例：**
```
🇨🇦vs🇲🇦: 0-1摩(EV-0.22) / 1-1(EV-0.30) → 都不佳，仅结构点缀
🇵🇾vs🇫🇷: 0-2法(EV+3.76⭐) / 0-1法(EV+1.28⭐) / 0-3法(EV+6.98⭐) → 三个正EV！
🇧🇷vs🇳🇴: 2-0巴(EV-0.06) / 3-0巴(EV+0.28⭐) → 2-0是稳定器，3-0是放大器
🇲🇽vs🏴󠁧󠁢󠁥󠁮󠁧󠁿: 1-0墨(EV-0.35) / 2-1墨(EV-0.27) → 无正EV但Edge+10.2pp
```

## 第三步：结构分层 + 6注构建

### 标准6注分配

```
🥇 核心盈利路径 (2注) — 占60%资金
  选择标准：每场最合理比分串接，不求高赔求命中
  每注权重：30单位
  
🥈 放大路径 (2注) — 占24%资金
  选择标准：用高EV比分替换核心路径中的某1-2场
  每注权重：12单位

🥉 防守/对冲路径 (2注) — 占16%资金
  选择标准：用平局/冷门替换，覆盖核心路径不中的场景
  每注权重：8单位
```

### 实战示例（6注终极版）

**🥇 核心（2注 × 30单位 = 60单位）：**
```
1) 0-1摩 × 0-2法 × 2-0巴 × 1-0墨  ← 四场全零封，最可能路径
2) 0-1摩 × 0-2法 × 2-1巴 × 1-0墨  ← 巴西丢1球替代
```

**🥈 放大（2注 × 12单位 = 24单位）：**
```
3) 0-1摩 × 0-3法 × 2-0巴 × 2-1墨  ← 法国0-3(EV+6.98)替代0-2
4) 1-1  × 0-3法 × 2-1巴 × 2-1墨  ← 摩平+法大胜+墨进攻
```

**🥉 防守（2注 × 8单位 = 16单位）：**
```
5) 1-1  × 0-2法 × 2-0巴 × 1-0墨  ← 防摩洛哥打平
6) 0-1摩 × 0-1法 × 2-1巴 × 1-0墨  ← 防法国小胜替代大胜
```

## 第四步：资金分配（加权法，非凯利）

**为什么不用凯利？** 比分4串1的赔率通常在数千到数万倍，凯利公式分母(赔率-1)过大，算出的仓位<0.1%，实战意义为零。

改用**结构加权法**：

| 类型 | 注数 | 单注 | 占总资金 | 逻辑 |
|:----|:----:|:----:|:--------:|:------|
| 🥇 核心 | 2 | 30单位 | 60% | 最可能路径，重仓 |
| 🥈 放大 | 2 | 12单位 | 24% | 高EV路径，中仓 |
| 🥉 防守 | 2 | 8单位 | 16% | 结构对冲，轻仓 |

**总仓位：** 100单位（建议不超过总资金的10-15%）

## 第五步：临场动态修正（赛前6小时-30分钟）

**盯3个信号：**

### 🔴 信号1：利润核心场的赔率变化

```
赔率↓（市场认可）→ 加仓核心路径20%
赔率↑（庄家放冷）→ 转防守，替换为平局路径
```

实战示例（墨西哥@3.50基准）：
```
墨西哥 @3.50 → 维持
墨西哥 @3.30 → 核心+10%
墨西哥 @3.10 → 核心+20%  
墨西哥 @3.70 → 删除放大注，加防守注
墨西哥 @3.90+ → 全力转防守
```

### 🔴 信号2：陷阱场的赔率过热

```
强队赔率持续下压 → 减少该队大胜比分权重，替换为小胜
```

实战示例（法国@1.19基准）：
```
法国 @1.19 → 维持0-2/0-3
法国 @1.15 → 0-3替换为0-1（减小胜权重）
法国 @1.12以下 → 删除所有大胜选项
```

### 🔴 信号3：主攻场的让球变化

```
让球升盘（-1.25→-1.5）→ 加仓零封比分权重
让球降盘（-1.25→-1.0）→ 加仓丢球比分权重
```

## 第六步：完整工作流

```
T-6h:
  ① 比赛分层（看AFEI模型Edge数据）
  ② EV筛选（砍掉负EV选项）
  ③ 构建6注结构

T-2h:
  ④ 检查首发名单（影响λ和比分权重）

T-0.5h:
  ⑤ 临场盘口修正（3个信号）
  ⑥ 最终仓位确认
```

## ⚠️ 常见错误

1. **❌ 高赔率 = 高权重** — 法国0-3的EV+6.98远高于0-2的+3.76，但0-2的概率(16.4%)远高于0-3(11.4%)。实战中0-2才是主轴，0-3是放大器。**不是EV越高越要重仓。**
2. **❌ 等权均注** — 核心路径和爆发路径命中概率相差5-10倍，不应该投一样的钱。
3. **❌ 联合概率误解** — 16注4串1的"任何一注中奖概率"不是16注概率之和，而是每场覆盖率的乘积。这是因为同一场比赛的不同比分是互斥事件（不能同时打出2-0和1-1）。
4. **❌ 忽略临场信号** — 6注是赛前固定结构，但临场盘口变化决定加减仓。固定结构+临场修正才是完整体系。
