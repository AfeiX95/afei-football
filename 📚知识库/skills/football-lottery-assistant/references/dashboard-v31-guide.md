## 搜索格式
支持多种输入格式，会自动剥离元数据：
- 竞彩格式：`周日073 世界杯 06-29 03:00 [世界杯2]南非VS加拿大[世界杯2]`
- 简单格式：`南非VS加拿大` 或 `南非 vs 加拿大`
- 手动填表：点击"✏️ 手动"按钮

## 数据来源说明
- TEAM_DB 是**静态硬编码数据库**（48+队），不是实时搜索
- 用户提供的咪咕/竞彩数据 → 填入TEAM_DB后才能被仪表盘使用
- 数据不全时会fallback到Wikipedia API
- **仪表盘的模型输出和Python v4.1有差异**（仪表盘无状态修正/Form Index）

## JS语法陷阱
- `)*100.toFixed(1)` 会被解析为 `* (100.toFixed(1))` → 语法错误
- 正确写法：`)*100).toFixed(1)` — 需要额外的`(`包裹整个表达式
- 用 `node --check file.js` 验证语法
