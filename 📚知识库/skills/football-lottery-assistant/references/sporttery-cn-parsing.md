# 竞彩网 sporttery.cn HTML 数据提取指南

> 2026-06-27 实测验证。用于从用户保存的竞彩网比赛详情页HTML中提取赔率时间序列数据。

## 页面结构

URL格式: `https://www.sporttery.cn/jc/zqdz/index.html?showType=2&mid=XXXXXX`

每场比赛一个mid，页面包含：
- 对阵卡片（队名、排名、战绩）
- 固定奖金（胜平负、让球、比分、总进球、半全场的时间序列）

## 关键HTML标签

### 对阵信息
```html
<!-- 比赛编号+赛事 -->
<div class="u-top">周六069 <a ...>世界杯></a></div>

<!-- 主队名 -->
<div class="u-middleLf"><a ...>哥伦比亚</a></div>
<!-- 客队名 -->
<div class="u-middleRt"><a ...>葡萄牙</a></div>

<!-- 赛事信息 -->
<div class="u-btm">2026 小组赛 K组 第3轮 2026-06-28 07:30</div>

<!-- 左边=主队排名+战绩 -->
<p>排名: K组 第<span>1</span>名</p>
<p>赛季总成绩: <span>2</span>胜 <span>0</span>平 <span>0</span>负</p>

<!-- 右边=客队排名+战绩 -->
<p>排名: K组 第<span>2</span>名</p>
```

### 赔率数据
```html
<!-- 让球数 -->
<p class="u-num">+1</p>

<!-- 赔率数值（所有赔率都在u-batNum类中） -->
<span class="u-batNum">4.23</span>

<!-- 升降标记 -->
<img src="...icon_sjt.png">  <!-- ↑ 升 -->
<img src="...icon_xjt.png">  <!-- ↓ 降 -->
```

### 比分盘布局
比分盘按行排列，每行5个格子（共5行=25个比分）：
- 第1行: 主胜比分（1:0, 2:0, 2:1, 3:0, 3:1, 3:2, 4:0, 4:1, 4:2, 5:0, 5:1, 5:2, 胜其它）
- 第2行: 平局比分（0:0, 1:1, 2:2, 3:3, 平其它）
- 第3行: 客胜比分（0:1, 0:2, 1:2, 0:3, 1:3, 2:3, 0:4, 1:4, 2:4, 0:5, 1:5, 2:5, 负其它）

### 半全场布局
9个格子：胜胜, 胜平, 胜负, 平胜, 平平, 平负, 负胜, 负平, 负负

### 总进球布局
8个格子：0球, 1球, 2球, 3球, 4球, 5球, 6球, 7+球

## 数据提取方法

页面通常有2-3个时间点的赔率数据（初盘+1-2次更新）。

**快速提取法：** 用search_files搜索 `u-batNum` 关键词，所有赔率数值集中在一个长行中。按顺序排列即为：时间点1的所有赔率→时间点2的所有赔率→...

**验证方法：** 让球数在 `u-num` 标签中，比分盘第一个数值应该是"1:0"的赔率（通常是最低的主胜比分赔率）。

## 特征分析页（⚠️ 模型必须数据，不是可选）

竞彩网每场比赛有**两个独立数据页**，都必须提取：

| 页面 | 标签 | 数据内容 | 用途 |
|------|------|---------|------|
| 固定奖金 | `固定奖金` | 赔率时间序列 | 市场隐含概率、Edge检测 |
| **特征分析** | **`特征分析`** | 伤停·历史交锋·射手榜·积分榜·近况·未来赛事 | **lambda修正（伤停削弱）、战意判断** |

**缺少特征分析页数据的模型会严重失真。** 实战验证（巴西vs日本）：
- 仅用固定奖金页：模型巴西胜75.6%（严重高估）
- 加入特征分析页（拉菲尼亚OUT+日本近10场不败+日本7球小组赛）：修正至52-60%
- **偏差23pp，特征分析页数据不可跳过**

### 特征分析页数据结构

#### 伤停一览（最关键的修正因子）

每场必看，影响lambda值5-15%。

```
巴西
号码-球员(位置)  总出场  首发  替补  状态
11-拉菲尼亚(前锋)  2    2    0    伤     ← 关键球员OUT → lambda进攻-8~10%
```

**伤停对lambda的量化修正（经验值）：**
- 核心前锋/中场OUT → 进攻lambda -8~12%
- 主力中后卫OUT → 防守lambda +3~5%（失球概率上升）
- 替补球员OUT → -0~3%（影响可忽略）
- 多名主力同时缺阵 → 叠加但非简单相加（边际递减）

#### 历史交锋

```
近4场巴西3胜 (75%) | 0平 (0%) | 1负 (25%)
比赛日期  赛制  主队 VS 客队  总进球
2025-10-14 国际赛 日本 3:2 巴西  5   ← 去年日本赢过巴西
```

**价值：** 近期交锋结果比纯赔率更能反映比赛心理状态。特别注意最近一次交锋的赛果和总进球数。

#### 比赛近况（近10场）

```
巴西近10场6胜 (60%) | 2平 (20%) | 2负 (20%)  进24球，失11球
日本近10场7胜 (70%) | 3平 (30%) | 0负 (0%)  进20球，失7球  ← 10场不败！
```

**价值：** 近10场战绩比小组赛3场更有统计意义。特别注意：
- **不败纪录（如日本10场不败）** → 心理优势，模型要保守对待
- 场均进球（衡量进攻持续性）
- 场均失球（衡量防守稳定性）
- 近期强强对话的赛果（如日本2-2荷兰）

#### 射手信息（世界杯）

```
巴西 Vinicius Junior: 4球(57%) 1助攻   ← 核心依赖
日本 上田绮世: 2球(29%) 1助攻          ← 分散
```

**价值：** 进球集中度。某个球员承担球队大部分进球→该球员被锁死=球队进攻瘫痪。集中度越高，进攻被针对性防守影响越大。

#### 积分榜

确认小组排名和积分。注意：淘汰赛阶段的积分榜是**小组赛数据**，不代表当前状态。

## 常见陷阱

1. **两个HTML文件可能是同一场比赛的不同保存版本** — 检查mid参数是否相同
2. **让球数显示的是主队视角** — "+1"=主队受让1球（客队让1球），"-1"=主队让1球
3. **赔率变化箭头** — icon_sjt.png=↑（赔率上升=该方向被看衰），icon_xjt.png=↓（赔率下降=该方向被看好）
4. **比分盘中的"--"** — 表示该比分尚未开出赔率
5. **⚠️ 只提取固定奖金页不提取特征分析页 → 模型失真10-23pp** — 伤停数据直接改变lambda值，无法从赔率反推准确还原
6. **特征分析页的积分榜是静态数据** — 淘汰赛阶段积分榜已无意义，需结合淘汰赛阶段判断
