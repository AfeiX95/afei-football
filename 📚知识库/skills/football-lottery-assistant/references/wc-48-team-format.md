# 48队世界杯赛制速查

## 赛制要点（2026 FIFA世界杯）
- 48队分12组×4队，单循环3轮
- 每组前2名（24队）+ 8个最佳第3名 = 32队晋级淘汰赛
- 淘汰赛：1/16→1/8→1/4→半决赛→决赛，单场淘汰制，加时+点球

## 小组排名规则（同分）
1. 相互积分
2. 相互净胜球
3. 相互比赛进球数
4. 总净胜球
5. 总进球数
6. 公平竞赛积分（黄牌-1分，第二张黄牌红牌-3分，直红-4分，黄+红-5分）
7. 最新FIFA排名

## 第3名排名规则（决定8个晋级名额）
1. 积分
2. 净胜球
3. 进球数
4. 公平竞赛积分
5. 最新FIFA排名

## 第3名晋级经验规律
- **4分第3名：基本安全**（历史上4分晋级率>90%）
- **3分第3名：悬**（取决于其他组结果，通常需要至少2个组的第3名≤2分）
- **2分第3名：需赢球才有戏**（末轮赢球→5分晋级）
- **1分及以下：基本出局**

## 末轮战略博弈核心逻辑
- 已出线球队末轮→轮换+控分概率极高
- 背水一战球队→战意爆发但心态急躁
- "双方平局都受益"→默契球温床
- 第3名名额竞争→影响同组另一场比赛的战略判断
- 路径价值差→第1名vs第2名的淘汰赛对手差异驱动控分动机

## 数据来源优先级
1. 虎扑(hupu.com)——最全：场均进/失/净胜、第三名排名表、赛制规则
2. 竞彩网(sporttery.cn)——赛程+赔率+射手+伤停
3. ESPN/FIFA官网——赛果+首发+场地核实
