# 赛博风格终极预测输出规范

## When to Use
- 仪表盘"终极预测·全景综合研判"模块渲染
- 任何需要可视化展示模型结论的场景

## 赛博风格设计规范

### 色彩系统
- 金色(#ffd700)：标题、边框、高亮、终审判决
- 红色(#c60b1e)：主队/胜率
- 蓝色(#3884ff)：平局
- 绿色(#006c35)：客队/凯利
- 暗黑背景(#0a0e14 → #1a1d24 渐变)

### 终极预测模块结构
1. **标题栏**：`⚡ 终极预测 · 全景综合研判` + `v4.1 全维度融合`标签
2. **比分预测**：3rem金色大字+国旗+Top3比分
3. **四维核心指标**：红/绿/蓝/金四色卡片（主队胜率/客队胜率/平局/凯利仓位）
4. **概率分布条**：三色渐变条
5. **比分Top6表格**：迷你进度条+信号图标
6. **八维因子网格**：4列（FIFA/身价/进球/失球/状态/控球/模型/大2.5球）
7. **Edge信号列表**：进度条+信号徽章（强/中/轻/无）
8. **凯利仓位**：大字+渐变进度条+推荐方向
9. **终审判决**：金色边框渐变背景+综合文字结论
10. **底部签名**：`数据不会说谎，但人会。—— 阿飞·赛博聊球`

### 信号分级
- ≥10pp：🚨 强价值（绿色背景）
- ≥5pp：⚡ 中价值（金色背景）
- ≥3pp：💡 轻价值（蓝色背景）
- <3pp：⚪ 无价值（灰色背景）

### 终审判决文案结构
1. 比赛定性（谁占优/势均力敌）
2. 最可能比分+概率
3. 大小球概率
4. Edge信号（如有）
5. 球队备注（如有）
