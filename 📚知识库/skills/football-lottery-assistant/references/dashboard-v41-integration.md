# 仪表盘v4.1集成说明

## 概述
v4.1模型已整合进智能搜索版仪表盘（桌面/全维数据仪表盘_智能搜索版_v3.html，标题v4.1）。

## 已整合模块
1. **formIndex()** — 状态修正：W+0.08, D+0.02, L-0.05, max ±0.25
2. **estimateLambda()** — xG代理+状态修正+无主场优势（世界杯中立场）
3. **Edge计算** — 品牌溢价估算，阈值<3pp/3-5pp/5-10pp/>10pp
4. **凯利仓位** — 半凯利公式，冷门降权×0.7，上限25%
5. **10源AI对比** — ChatGPT/Gemini/Claude/豆包/DeepSeek/千问/Kimi/Copilot/Perplexity
6. **赛博模型复盘** — λ/概率/溢价/大小球/共识/关键矛盾/模型校准
7. **parseInput** — 支持"周日073 世界杯 06-29 03:00 [世界杯2]南非VS加拿大[世界杯2]"格式

## 与Python v4.1的差异
| 维度 | 仪表盘 | Python |
|------|--------|--------|
| xG代理 | 无（简化公式） | 0.92/1.08系数 |
| 主场优势 | 0（中立场） | 0（中立场） |
| MC模拟 | 50万次浏览器端 | 20万次Python |
| 数据源 | TEAM_DB静态 | 用户提供实时数据 |
| 结果 | 方向一致，绝对值有小幅差异 | 更精确 |

## 使用方式
1. 浏览器打开仪表盘
2. 搜索框输入竞彩格式或队名
3. 查看Edge信号+凯利仓位
4. 手动输入赔率可获得更精确的Edge计算
