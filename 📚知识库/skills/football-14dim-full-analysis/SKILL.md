## 第二阶段深层：内部参考技术方法

以下方法用于模型计算，不写入对外报告。

### 赔率趋势深度分析（内部参考用）

#### 数据源优先级

1. 竞彩官网固定奖金页——比分/总进球/半全场赔率以最新时间点为准
2. 竞彩API——快速获取胜平负让球赔率

#### 五步趋势解读法

| 步骤 | 分析内容 |
|:----|:---------|
| ① 方向 | 各选项升/降趋势（单调/震荡/反转） |
| ② 幅度 | 变动幅度%（绝对值+相对值） |
| ③ 时间 | 变动时段（与伤情披露吻合？） |
| ④ 晚盘信号 | 收盘前最后一个时段的方向 |
| ⑤ 一致性 | 胜平负与让球/半全场方向是否一致 |

#### 趋势模式识别

| 模式 | 识别 | 可靠性 |
|:-----|:------|:------:|
| 单调趋势 | 主胜一路降·平客一路升 | 🔴强信号 |
| 震荡趋势 | 先降后升或先升后降 | 🟡需警惕 |
| 平局趋势 | 平赔单边下降3%+ | 🔴强信号 |

#### 过热阈值修正（v3.0·联动排名差）

```python
# 当主队排名高于客队≥8位时，阈值从1.40放宽至1.50
rank_gap = away_rank - home_rank
overheat_threshold = 1.50 if rank_gap >= 8 else 1.40
```

### 数据拆解原则（跑模型前必做）

1. **H2H分主客场** — 查看同主客场交锋战绩
2. **伤停量化** — 谁/位置/出场占比/占队进球的%
3. **主客场胜率分离** — 主队主场胜率 vs 客队客场胜率
4. **停赛类型差异化** — 前锋(λ×0.85~0.88) > 中场(λ×0.93~0.95) > 后卫(λ×0.95)

### 数学模型（λ+MC模拟）

#### λ生成器

```python
λ_home = base(1.4) × (1 + strength_gap×0.35 + point_gap×0.15 + home_adv×0.20 + form_gap×0.20 + injury_away×(-0.30))
λ_away = base(1.4) × (1 - strength_gap×0.35 - point_gap×0.15 - home_adv×0.12 + form_away×0.20 + injury_home×(-0.30))
```

#### MC模拟代码

```python
import math, random
random.seed(42)
def psample(lmbda):
    L = math.exp(-lmbda)
    k, p = 0, 1.0
    while p > L:
        k += 1
        p *= random.random()
    return k - 1

def simulate(Lh, La, n=100000):
    results = {"1": 0, "X": 0, "2": 0}
    scores = {}
    for _ in range(n):
        h = psample(Lh); a = psample(La)
        if h > a: results["1"] += 1
        elif h == a: results["X"] += 1
        else: results["2"] += 1
        k = f"{h}-{a}"
        scores[k] = scores.get(k, 0) + 1
    for k in results: results[k] = round(results[k] / n * 100, 1)
    top = sorted(scores.items(), key=lambda x: -x[1])[:10]
    top = [(s, round(p / n * 100, 1)) for s, p in top]
    return results, top
```

#### H2H量化修正

| H2H表现(近7-10场) | 修正系数 |
|:-------------------|:--------:|
| 胜率<20%(被碾压) | ×0.85~0.88 |
| 胜率20~35%(明显劣势) | ×0.90~0.93 |
| 胜率55~65%(略优) | ×1.05~1.07 |
| 胜率>65%(克星) | ×1.10~1.15 |

**H2H权重应高于短期异常数据：** 主场0胜是短期极端数据，H2H长期权重更高。第8-12个主场回归均值概率上升。

### 赛事类型修正

| 场景 | 修正 |
|:-----|:------|
| 资格赛 | λ×0.95·置信度×0.70~0.85 |
| 休赛vs赛季中 | 休赛队λ×0.90·赛季中队λ×1.05 |
| 淘汰赛攻坚 | 强势方λ×0.90·弱势方λ×0.55 |
