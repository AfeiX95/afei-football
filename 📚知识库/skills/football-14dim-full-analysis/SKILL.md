# 14维全维度足球赛事分析管线


## 触发条件


当用户提供一场比赛的信息（联赛、对阵、编号、时间）时，按以下14维结构进行全维度分析。


## 第一阶段：数据采集（联网搜索）


**⚠️ 所有搜索在turn 1并行发起，不串行。**


### 1.1 竞彩网赔率数据（必搜）


```
搜索词: "{主队简称} vs {客队简称} 竞彩 赔率 {日期}"
目的: 获取胜平负、让球、比分、总进球赔率
```

#### λ估算


**方法1：市场反推法**
```python
λ主_mkt = 0.4 + P主 × 3.2
λ客_mkt = 0.2 + P客 × 3.2
```


**方法2：数据法**
```
xG_for = 场均进球 × 0.92
xG_against = 场均失球 × 1.08


# 淘汰赛L0.5修正：
# 强势方(目标90分钟解决): attack×0.90, defense×0.90
# 弱势方(目标不输拖加时): attack×0.55, defense×0.85
# 实力接近: 弱势xG×0.85 / 强势xG×0.95


λ主_data = (xG攻击调整 + 客队xG防守调整) / 2
λ客_data = (xG客攻调整 + 主队xG防守调整) / 2
```

**综合λ：** `λ = (λ_mkt + λ_data) / 2`（偏差>0.5时偏向数据法）

#### MC模拟（内含代码）


```python
import math, random
random.seed(42)


def psample(lmbda):
    """Poisson采样（Knuth乘法）"""
    L = math.exp(-lmbda)
    k, p = 0, 1.0
    while p > L:
        k += 1
        p *= random.random()
    return k - 1


def simulate(Lh, La, n=100000):
    results = {"1": 0, "X": 0, "2": 0}
    scores = {}
    goals_dist = {g: 0 for g in range(10)}
    for _ in range(n):
        h = psample(Lh)
        a = psample(La)
        if h > a: results["1"] += 1
        elif h == a: results["X"] += 1
        else: results["2"] += 1
        goals_dist[min(h + a, 9)] += 1
        k = f"{h}-{a}"
        scores[k] = scores.get(k, 0) + 1
    for k in results: results[k] = round(results[k] / n * 100, 1)
    for k in goals_dist: goals_dist[k] = round(goals_dist[k] / n * 100, 1)
    top = sorted(scores.items(), key=lambda x: -x[1])[:10]
    top = [(s, round(p / n * 100, 1)) for s, p in top]
    return results, goals_dist, top
```

#### 置信度与模型-市场分歧（2026-10-11 补）


| 检查 | 怎么看 | 动作 |
|:--|:--|:--|
| 模型 vs 市场概率差 | 三个方向逐个比，不是只看最大的那一头 | 分歧 ≤3pp：**听市场的**（本仓实测模型方向劣于市场） |

## 常见陷阱


1. **积分/小组排名未核实** — 必须从竞彩网特征分析页或FIFA官网核实，不能只靠记忆
2. **赔率数字泄露到正文** — 头条号文章发布前全文搜索"赔率""盘口""@"关键词
3. **淘汰赛路径错误** — 必须核实晋级后的对手
4. **H2H数据遗漏** — 特征分析页的历史交锋数据不可跳过
5. **把 Edge 当价值信号** — 45 场实测：模型方向 37.8% vs 市场 46.7%、Brier 0.695 vs 0.608，Edge 在 93% 的场次都报"有价值"却只兑现 19%（=噪声）。方向以**市场定价 + 盘口结构**为主锚；Edge 只是内部参考，不得当选场依据、更不得进正文
6. **忽略淘汰赛攻坚折扣** — 淘汰赛阶段强势方λ×0.90
7. **不确定的伤情用"确认缺阵"** — 应改为"有可能缺阵"或"大概率"
8. **数据源只写"竞彩网"** — 应注明"用户手动提取自竞彩网/中国体育彩票官方平台"
9. **同一影响重复计权** — 主力中卫缺阵已经压低了防守强度，就不得再在「定位球失球风险」里重复扣一次；一个事实只进一个 λ 修正项，进了两处必须写明理由（C16 / C24 的"按结构分摊"是同一个道理）
10. **数据时点混算** — 不同时间抓的数据不加标注就相乘 / 相加（见 1.5），本仓已经因此吃过两次亏
11. **只写支持证据** — 没有反证块的判断不许输出为结论（见十四节）
