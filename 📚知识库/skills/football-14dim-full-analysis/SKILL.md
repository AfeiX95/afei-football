### 十、数学模型（λ+MC模拟）


#### λ估算


**方法1：市场反推法**
```python
λ主_mkt = 0.4 + P主 × 3.2
λ客_mkt = 0.2 + P客 × 3.2
```


**方法2：数据法**
```
xG_for = 场均进球 × 0.92
xG_against = 场均失球 × 1.08


# 淘汰赛L0.5修正：
# 强势方(目标90分钟解决): attack×0.90, defense×0.90
# 弱势方(目标不输拖加时): attack×0.55, defense×0.85
# 实力接近: 弱势xG×0.85 / 强势xG×0.95


λ主_data = (xG攻击调整 + 客队xG防守调整) / 2
λ客_data = (xG客攻调整 + 主队xG防守调整) / 2
```


**综合λ：** `λ = (λ_mkt + λ_data) / 2`（偏差>0.5时偏向数据法）


**伤停修正：**
- 中场核心OUT → λ-10~15%
- 边锋OUT → λ-5~10%
- 后卫核心OUT → 对手λ+5~10%


**品牌溢价（世界杯）:**
```
brand_premium = min(20, rank_diff/10×2 + log10(身价比)×3)
if match_phase == "淘汰赛": brand_premium ×= 0.80
```


#### MC模拟（内含代码）


```python
import math, random
random.seed(42)


def psample(lmbda):
    """Poisson采样（Knuth乘法）"""
    L = math.exp(-lmbda)
    k, p = 0, 1.0
    while p > L:
        k += 1
        p *= random.random()
    return k - 1


def simulate(Lh, La, n=100000):
    results = {"1": 0, "X": 0, "2": 0}
    scores = {}
    goals_dist = {g: 0 for g in range(10)}
    for _ in range(n):
        h = psample(Lh)
        a = psample(La)
        if h > a: results["1"] += 1
        elif h == a: results["X"] += 1
        else: results["2"] += 1
        goals_dist[min(h + a, 9)] += 1
        k = f"{h}-{a}"
        scores[k] = scores.get(k, 0) + 1
    for k in results: results[k] = round(results[k] / n * 100, 1)
    for k in goals_dist: goals_dist[k] = round(goals_dist[k] / n * 100, 1)
    top = sorted(scores.items(), key=lambda x: -x[1])[:10]
    top = [(s, round(p / n * 100, 1)) for s, p in top]
    return results, goals_dist, top
```

## 常见陷阱


1. **积分/小组排名未核实** — 必须从竞彩网特征分析页或FIFA官网核实，不能只靠记忆
2. **赔率数字泄露到正文** — 头条号文章发布前全文搜索"赔率""盘口""@"关键词
3. **淘汰赛路径错误** — 必须核实晋级后的对手
4. **H2H数据遗漏** — 特征分析页的历史交锋数据不可跳过
5. **直接推方向不做EV分析** — 模型与市场Edge<3pp时不应推荐方向
6. **忽略淘汰赛攻坚折扣** — 淘汰赛阶段强势方λ×0.90
7. **不确定的伤情用"确认缺阵"** — 应改为"有可能缺阵"或"大概率"
8. **数据源只写"竞彩网"** — 应注明"用户手动提取自竞彩网/中国体育彩票官方平台"
