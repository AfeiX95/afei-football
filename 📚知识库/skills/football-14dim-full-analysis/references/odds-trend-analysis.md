# 赔率时间趋势分析方法论

## 为什么要分析赔率趋势

静态赔率只告诉市场价格在哪里。赔率时间趋势告诉**资金在哪里流动**——这才是更有价值的信号。

## 核心分析框架

### 1. 方向性判断

| 趋势 | 含义 | 可信度 |
|:-----|:------|:-------|
| 主胜持续↓(如1.58→1.49) | 资金在买入主胜 | 🟡中等——可能是跟风盘 |
| 主胜先↓后↑(如1.58→1.49→1.51) | 早盘买入→晚盘回吐/套现 | 🟡需看晚盘方向 |
| **晚盘强势买入**(1.83→1.69 in 2小时) | 信息披露后的聪明钱 | 🟢**可信度高** |
| 三向赔率几乎不动的 | 市场高度统一/无增量信息 | ⚪中性 |
| **平局赔率持续↑**(如3.25→3.50) | 市场抛弃平局选项 | 🟢强信号 |

### 2. 早盘vs晚盘博弈（最核心）

**实战案例：挪威vs英格兰(2026-07)**

```
早盘(07-09→10日): 挪威3.92→3.28(↓16%) → 有资金买入挪威
晚盘(07-11 15-18时): 挪威3.28→3.74(↑14%) → 大资金突然回流英格兰
                   英格兰1.83→1.69(↓8%) → 晚盘英格兰买盘强势
                    
解读: 早盘挪威资金vs晚盘英格兰资金激烈博弈
最终晚盘大资金碾压→英格兰方向是聪明钱的选择
结果: 1-1打平——晚盘英格兰资金翻车
教训: 晚盘方向≠必胜,但方向性信号最强
```

### 3. 比分赔率趋势

| 比分趋势 | 含义 | 例 |
|:---------|:------|:----|
| **唯一降赔的比分** | 市场最看好的具体比分 | 挪威vs英格兰: 1-2↓8% |
| ↑15-20%的比分 | 市场抛弃该选项 | 1-1↑18%, 0-1↑15% |
| 比分赔率大幅↓(如6.70→5.50) | 该比分成为市场焦点 | 阿根廷vs瑞士: 2-1↓18% |

### 4. 让球盘趋势

让球盘赔率变化往往比胜平负更敏感：

| 趋势 | 含义 |
|:-----|:------|
| 让球平赔率持续↓(如3.15→2.95) | 市场看好主队赢1球 |
| 让球负赔率↑(如2.07→2.20) | 市场不看好客队不败 |
| 让球线调整(如-1→-1.25) | 市场预期赢球幅度加大 |

## 输出格式

在14维分析的第二部分(赔率时间趋势)中，按以下格式输出：

```markdown
| 时间 | 主胜 | 平局 | 客胜 | {关键让球} | 解读 |
|:----|:----:|:----:|:------:|:--------:|:-----|
| M-DD HH:MM | X.XX | X.XX | X.XX | X.XX | 开盘/变动原因 |
| M-DD HH:MM | X.XX | X.XX | X.XX | X.XX | 趋势描述 |

**核心趋势：**
```
{主队} X.XX→X.XX(↓X%) = 资金方向描述
{客队} X.XX→X.XX(↑X%) = 资金方向描述
平局  X.XX→X.XX(↑X%) = 市场态度
```

**解读：** ⚡ 早盘/晚盘博弈结论 + 聪明钱方向
```

## 注意事项

1. 赔率变动的**百分比**(如↓8%)比绝对值(如-0.15)更有意义
2. 单一时点无趋势 → 标注\"单一时间点\"，不强行分析
3. 竞彩网和FanDuel等国际盘口放在一起对照——差异反映中国市场vs国际市场热度差
4. 晚盘(赛前3-6小时)资金比早盘(赛前48-72小时)资金更值得关注——信息披露更充分
5. 趋势分析不能替代EV计算——方向对≠有正EV
