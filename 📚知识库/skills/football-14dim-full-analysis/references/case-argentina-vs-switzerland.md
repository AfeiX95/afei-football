# 案例：阿根廷 vs 瑞士 (2026世界杯1/4决赛)

## 独特发现

### 1. 门将数据是重要的λ输入
马丁内斯(阿根廷)本届扑救率44.4%——赛事最差门将。
- 这意味着对手射正→进球的概率>55%
- 对瑞士这类定位球/反击型球队来说，这个数据是通关密码
- **教训：特征分析页的守门员数据必须提取进入模型**

### 2. 极端交锋间隔
瑞士上一次进入世界杯8强：1954年(72年前)。
- 这种极端历史间隔会影响球队心态——既有"零包袱"的利好，也有"大赛经验不足"的利空

### 3. 历史交锋的心理层面
2014年1/8决赛：阿根廷加时118分钟1-0绝杀瑞士。
- 两面性：瑞士"守住118分钟被绝杀"有心理阴影，但也有"我们差一点就赢了"的自信
- 扎卡参加了那场比赛，赛前发言体现老将的心理韧性

### 4. 热战影响
堪萨斯城7月晚间25-28℃，虽不如迈阿密极端，但对南美球队的高温适应性有加成。
