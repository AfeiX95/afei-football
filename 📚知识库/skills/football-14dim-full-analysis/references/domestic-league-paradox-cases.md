# 国内联赛主客场悖论案例集（2026-07-11→07-16）

## 模式说明

当球队排名高但客场胜率显著低于市场预期时 → 主队方向有认知差。

**检测公式：**
```
客场胜率 = 客场胜场/客场总场次
市场隐含胜率 = 1/客胜赔率/(去水因子)
偏差 = 市场隐含胜率 - 客场胜率
偏差>15pp时 → 客队被高估·倾向主队
```

## 案例1: 奥勒松(#13) vs 莫尔德(#5)

| 维度 | 奥勒松(#13) | 莫尔德(#5) |
|:-----|:------------|:-----------|
| 赛季总战绩 | 2胜5平4负 | 6胜1平4负 |
| 主场/客场 | 主场1胜3平2负 | **客场1胜1平3负(20%)** |
| 市场定价 | 3.20(27.7%) | 1.81(**49.0%**) |
| 模型定价 | 34.1% | **41.4%** |
| Edge | **+6.4pp 🟡** | -7.6pp |

**矛盾：** 莫尔德排名#5但**客场胜率仅20%**，市场却给49%隐含胜率——高估29pp。
**正确方向：** 奥勒松不败(胜+平) @1.68 → 2-2✅

## 案例2: TPS图尔(#7) vs AC奥卢(#4)

| 维度 | TPS图尔(#7) | AC奥卢(#4) |
|:-----|:------------|:-----------|
| 赛季总战绩 | 5胜4平5负 | 8胜2平4负 |
| **主场/客场** | **主场5胜1平1负(71%)🔥** | **客场3胜1平4负(38%)** |
| 市场定价 | 2.65(33.4%) | 2.46(36.0%) |
| 模型定价 | **43.3%** | 31.8% |
| Edge | **+9.9pp 🟡** | -4.2pp |

**矛盾：** 奥卢排名高(#4)但客场差(38%)。TPS排名低(#7)但**主场胜率71%**。市场被排名骗了。
**正确方向：** TPS图尔胜 @2.65 → 3-0✅

## 案例4: 博塔弗戈(#12) vs 桑托斯(#15)

| 维度 | 博塔弗戈(#12) | 桑托斯(#15) |
|:-----|:-------------|:------------|
| 主场/客场 | 主场3胜2平2负(43%) | **客场0胜4平4负(0%)** |
| 近10场 | 5胜2平3负(50%) | 4胜4平2负(40%) |
| 伤停 | Montoro(中场)停赛⚠️ | **加布里埃尔(7球·27%)停赛❌** |
| 市场定价 | 1.82(48.7%) | 3.45(25.7%) |
| 模型定价 | **64.7%** | 15.1% |
| Edge | **+15.7pp 🟡** | -10.6pp |

**矛盾：** 桑托斯客场0胜+头号射手停赛，但市场仅给博塔48.7%(Polymarket更只给49%)。
**正确方向：** 博塔弗戈不败(待赛)

## 案例5: 维多利亚(#13) vs 达伽马(#17)

| 维度 | 维多利亚(#13) | 达伽马(#17) |
|:-----|:-------------|:------------|
| **主场/客场** | **主场6胜1平1负(75%🔥)** | **客场0胜4平4负(0%)** |
| 近10场 | **7胜1平2负(70%🔥)** | 4胜2平4负(40%) |
| H2H近14场 | 6胜2平6负(势均力敌) | 6胜2平6负(势均力敌) |
| 伤停 | **凯克(中场·15场全首发)停赛⚠️** | 全员健康 |
| 市场定价 | 2.30(38.5%) | 2.74(32.3%) |
| 模型定价 | **52.4%** | 24.6% |
| Edge | **+13.9pp 🟡** | -7.7pp |

**矛盾：** 维多利亚主场75%+近10场70%，但市场仅给38.5%。原因：H2H势均力敌(6胜2平6负)+凯克停赛+达伽马豪门溢价(5-8pp)。
**偏差修正：** 39%-(5~8pp品牌溢价)=31~34%内在价值+主场75%=模型52.4%合理。

## 偏差分级表

| 偏差幅度 | 判定 | 应对 |
|:--------:|:----|:------|
| 10-15pp | ⚠️注意 | 市场可能合理(含品牌溢价) |
| 16-25pp | 🟡认知差 | 倾向主队方向 |
| >25pp | 🔴强信号 | 主队不败概率极高 |

**品牌溢价扣除：** 巴甲约5-8pp / 挪超约3-5pp / 瑞超约3-5pp / 芬超约2-3pp
