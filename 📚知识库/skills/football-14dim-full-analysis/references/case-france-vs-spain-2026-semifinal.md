# 实战案例：法国vs西班牙(2026世界杯半决赛) — H2H量化修正

## 场景

2026世界杯半决赛，法国vs西班牙。竞彩定价法国2.03(43.6%)，市场资金48小时持续买入法国(2.26→2.03↓10%)。

但H2H数据显示法国近7场1胜1平5负(14%)——西班牙是法国的克星。

## 处理流程

### Step 1: 提取H2H数据

从竞彩网特征分析页→历史交锋标签页→近7场：

| 日期 | 赛制 | 比分 | 胜者 |
|:----|:-----|:----:|:----:|
| 2025-06 | 欧国联 | 西班牙5-4法国 | 🇪🇸 |
| 2024-07 | 欧洲杯 | 西班牙2-1法国 | 🇪🇸 |
| 2021-10 | 欧国联 | 西班牙1-2法国 | 🇫🇷(唯一胜) |
| 2017-03 | 国际赛 | 法国0-2西班牙 | 🇪🇸 |
| 2013-03 | 世预赛 | 法国0-1西班牙 | 🇪🇸 |
| 2012-10 | 世预赛 | 西班牙1-1法国 | 🤝 |
| 2012-06 | 欧洲杯 | 西班牙2-0法国 | 🇪🇸 |

H2H结论：法国1胜1平5负，**胜率14%**

### Step 2: 应用H2H修正系数

```
lambda_modifier = 0.88  (因为 h2h_win_rate=14% < 25%)
```

### Step 3: 比较修正前后

| 指标 | 修正前(无H2H) | 修正后(λ×0.88) |
|:-----|:-------------:|:---------------:|
| 法国λ | 1.70 | 1.50(×0.88) |
| 西班牙λ | 1.12 | 1.27(÷0.88) |
| 法国胜 | ~48.0% | **44.2%** |
| 平局 | ~25.0% | 25.6% |
| 西班牙胜 | ~27.0% | **30.2%** |
| 法国Edge(vs市场43.6%) | **+4.4pp🟡** | **+0.6pp⚪** |

### Step 4: 结论

```
修正前: Edge+4.4pp → "法国方向有认知差"
修正后: Edge+0.6pp → "不推方向"
赔率趋势(法国2.26→2.03)显示资金买入法国
H2H数据(法国1胜5负)显示西班牙克制法国
两股力量完全对冲 → ⚪点缀场
```

## 教训

1. H2H数据不能只提不量化——必须进入λ计算
2. 赔率趋势反映的是"状态溢价"，H2H修正反映的是"历史债务"
3. 当状态数据和H2H数据打架时，半决赛/决赛级比赛更倾向于相信H2H(高压场合历史会重演)
4. 修正后Edge<3pp时，即使赔率趋势强烈，也不推荐方向
