## 五、核心工作流详解

### 5.1 数据采集顺序（效率最优）

```text
① 竞彩网API（一次性拉全量）
   curl -s 'https://webapi.sporttery.cn/gateway/uniform/football/getMatchCalculatorV1.qry?channel=c'

② 用户提供竞彩网HTML → 必须同时有：
   - 固定奖金页（赔率时间序列）
   - 特征分析页（伤停/历史交锋/射手/积分榜）

③ 特征分析页数据直接输入λ修正
   伤停：核心球员OUT → λ下调5-15%
   历史交锋：心理状态参考
   射手信息：进球集中度 → 被针对性防守风险

④ 雷速SWOT + 懂球帝阵容（补充叙事素材）
```

**⚠️ 铁律：** 只有固定奖金页而没有特征分析页时，必须要求用户补充。纯赔率反推λ偏差可达23pp（拉菲尼亚/穆西亚拉/凯塞多三案例验证）。

### 5.2 λ双方法（核心数学）

```python
# 方法1: 实际数据法（xG代理）
xg_for = 场均进球 × 0.92
xg_against = 场均失球 × 1.08
# 淘汰赛修正：强×0.9，弱大巴×0.5~0.6
# 伤停修正：-5~15%（中场核心 > 边锋）
lambda = (xg_for_adj + xg_against_opp_adj) / 2 + form_index

# 方法2: 市场反推法
fair = (1/odds) / sum(1/odds)
lambda_raw = 0.4 + fair * 3.2
# 修正：×KO_factor × injury_factor

# 综合λ = (方法1 + 方法2) / 2
```

### 5.3 淘汰赛战略目标（L0.5——最关键一步）

| 场景 | 强势方 | 弱势方 |
|:----|:-------|:-------|
| 强弱分明 | 目标"90分钟解决"×0.9 | 目标"不输拖加时"×0.5~0.6 |
| 实力接近 | 目标"全力争胜"×0.95 | 目标"全力争胜"×0.85 |
| 双方已出线 | 控分/轮换×0.7~0.8 | 控分/轮换×0.7~0.8 |

### 5.4 品牌溢价检测

```text
品牌溢价 = 市场隐含概率 - 模型概率
偏差 > 10pp = 存在价值信号
传统强队(法国/巴西/德国/英格兰)溢价+10~30pp
```

### 5.5 Edge公式（2026-07-02修正）

```text
Edge = P_model - P_market
Edge > +6%  → 强价值 ⭐
Edge > +3%  → 中价值 🟡
Edge < 0%   → 无价值 ✗
```

## 六、关键教训（新人必读）

### 伤停影响大于预期

| 球员 | 位置 | 场次 | λ修正 | 实际影响 |
|:----|:----|:----|:-----:|:---------|
| 拉菲尼亚 | 右边锋 | 巴西vs日本 | -8% | 上半场0-1落后 |
| **穆西亚拉** | **中场核心** | **德国vs巴拉圭** | **-10%** | **德国1-1平❌** |
| **凯塞多** | **中场核心** | **墨西哥vs厄瓜多尔** | **-12%** | **模型61%vs市场46%,偏差15pp** |

**中场核心OUT的修正幅度(10-15%)远大于边锋OUT(5-8%)。**

### 数据源不可跳过

- 特征分析页的伤停数据是必选项，不是可选项
- Wikipedia小组数据可能过时（注意"Updated to"日期）
- 所有积分/赛果必须联网核实

### 写文章不写什么

| ❌ 禁止 | ✅ 替换 |
|---------|---------|
| @1.52 @5.35 | 直接删除 |
| "赔率" | "数据"或省略 |
| EV / Edge | 全部删除 |
| 仓位/凯利 | 全部删除 |
| 竞彩网(数据来源) | 懂球帝、ESPN |
| 不构成投注建议 | 仅供参考 |
