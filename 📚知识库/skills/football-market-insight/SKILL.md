# Football Market Insight 指数与舆情风向标

> 定位：赔率走势分析 + 市场热度监控 + 冷门预警
> 适用场景：模型输出后的市场偏差校验
> 搭配使用：model-parameters.json overheat_rules + C06/C11低赔修正

---

## 一、数据源

| 数据源 | 内容 | 更新频率 | 获取方式 |
|:-------|:-----|:---------|:---------|
| 竞彩网 | 胜平负/让球/总进球定价 | 每日 | JSON API |
| 新球体育百家欧赔 | 10+家机构赔率对比 | 实时 | 爬虫 |
| Bet365/Pinnacle | 即时盘口/大小球 | 实时 | 爬虫 |
| 必发交易所 | 交易量/资金流向 | 实时 | API |

## 二、核心脚本

### 2.1 百家欧赔监控

脚本位置：`database/scripts/odds_monitor.py`

功能：
- 抓取新球体育百家欧赔数据
- 计算平均赔率、凯利指数、离散度
- 识别异常赔率（偏离均值>15%的机构）

```bash
python database/scripts/odds_monitor.py --match-id 2929675
```

### 2.2 赔率走势追踪

脚本位置：`database/scripts/odds_movement.py`

功能：
- 追踪赔率随时间的变化
- 识别「升水/降水」趋势
- 标记异常变动（短时间大幅波动）

```bash
python database/scripts/odds_movement.py --match-id 2929675 --interval 30
```

### 2.3 冷门预警系统

脚本位置：`database/scripts/upset_detector.py`

功能：
- 结合模型输出 + 市场定价 + 赔率走势
- 识别潜在冷门信号
- 输出预警等级（绿/黄/红）

```bash
python database/scripts/upset_detector.py --model-output model.json --market-odds odds.json
```

## 三、市场分析指标

### 3.1 凯利指数

```
凯利指数 = 机构赔率 / 平均赔率

凯利指数 > 1.10 → 该机构认为该结果概率偏低（高赔）
凯利指数 < 0.90 → 该机构认为该结果概率偏高（低赔）
凯利指数 ≈ 1.00 → 与市场一致
```

### 3.2 离散度（赔率分歧）

```
离散度 = 标准差 / 平均值 × 100%

离散度 < 5% → 机构高度一致（比赛结果较确定）
离散度 5-10% → 正常分歧
离散度 > 10% → 机构严重分歧（比赛结果不确定，可能有冷门）
```

### 3.3 资金流向指标

```
资金热度 = 大额投注占比 × 方向一致性

热度 > 70% → 市场过热（警惕反向）
热度 40-70% → 正常
热度 < 40% → 市场冷淡（可能有机会）
```

### 3.4 让球盘口强度

```
让球强度 = 让球方赔率 × 对手排名差修正

让球强度 > 1.50 → 过热（参考 C06/C11 修正）
让球强度 1.30-1.50 → 正常偏热
让球强度 < 1.30 → 合理定价
```

## 四、冷门预警模型

### 4.1 预警信号

| 信号 | 权重 | 说明 |
|:-----|:----:|:-----|
| 模型vs市场偏差 > 15pp | 30% | 模型与市场严重分歧 |
| 赔率离散度 > 10% | 20% | 机构之间分歧大 |
| 资金热度 > 70% | 20% | 市场过热，可能反向 |
| 让球强度 > 1.50 | 15% | 过热信号（C06触发） |
| 客队近期3连胜+ | 15% | 客队状态火热 |

### 4.2 预警等级

| 等级 | 综合得分 | 行动建议 |
|:----:|:--------:|:---------|
| 🟢 绿色 | < 30% | 正常分析，无特殊预警 |
| 🟡 黄色 | 30-60% | 关注偏差，考虑防冷 |
| 🔴 红色 | > 60% | 高度警惕，建议防冷/反买 |

## 六、与 model-parameters.json 对接

| 参数 | 对接方式 |
|:-----|:---------|
| overheat_rules.general | 让球强度 > 阈值 → 触发过热修正 |
| overheat_rules.k_league | K联赛专属阈值 |
| C06 低赔主胜下调 | 主队赔率 < 1.40 → 主胜-3-5pp |
| C11 低赔客胜对称修正 | 客队赔率 < 1.40 → 客胜-3-5pp |
| C15 大热主队让-1冷门陷阱 | 赔率<1.50让-1 → 主胜-20-25pp |

## 七、注意事项

1. **数据时效**：赔率实时变化，抓取时间点影响分析结果
2. **机构差异**：不同机构的赔率体系不同，不宜直接比较绝对值
3. **资金真实性**：公开的投注比例可能被操控，需结合多家数据
4. **时区问题**：欧洲机构与亚洲机构的开盘时间不同
5. **与模型互补**：市场分析是模型的校验层，不能替代模型本身
