# 📉 本地盘口库（盘口位移自动攒）

> 一句话：**双击仓库根的 `盘口采集器.cmd`**，选 1 抓一次、选 2 挂着自动抓、选 3 看位移表。
> 免费、不需要任何 API Key —— 数据来自中国竞彩官方 webapi（直连配方见 [`API接口.md`](API接口.md)）。

## 为什么需要它

竞彩官方 `getMatchCalculatorV1.qry` 每次只返回**当前一档**定价，`oddsHistory` 每档也只有 1 条记录
（见 [`API接口.md:65`](API接口.md#L65)），所以「盘口位移」过去只能靠人工在不同时点复制页面。
本库把这件事自动化：每抓一次落一条时间戳，位移表随时可出。

## 傻瓜操作

| 想做什么 | 怎么做 |
|:--|:--|
| 抓一次 | 双击 `盘口采集器.cmd` → 按 `1` |
| 挂着自动抓 | 双击 → 按 `2`（每 15 分钟一次，**窗口开着才抓**） |
| 看位移表 | 双击 → 按 `3`（直接回车=全部，或输入 `周二010` / `马竞` / `2041959`） |
| 看有哪些场次 | 双击 → 按 `4` |

命令行等价：

```bash
python scripts/odds_snapshot.py once                  # 抓一次并入库
python scripts/odds_snapshot.py loop --every 15       # 自动抓，Ctrl+C 停
python scripts/odds_snapshot.py move --days 3         # 位移表（首 → 末 + 每个变化点）
python scripts/odds_snapshot.py move --query 马竞 --min-pp 1.0
python scripts/odds_snapshot.py list --days 3         # 库里有哪些场次
```

## 采样纪律（怎么抓才有价值）

- **日常**：开赛前 3 小时起，每 15 分钟一次就够（一天 8~10 场 ≈ 20 行/次）。
- **关键窗口**：开赛前 1 小时改成 5 分钟一次（首发/伤停消息落地时位移最剧烈）：
  `python scripts/odds_snapshot.py loop --every 5`
- 官方源没有公布限额，但**别打太快**（<1 分钟一次毫无意义，还给 WAF 找麻烦）。
- 快照表带 `digest`：与上一快照完全相同会标 `changed=0`，「真有变化的时点」可直接筛。

## 库里长什么样

文件：`state/odds.sqlite`（SQLite，Python 标准库直接读；**不进 git**，属本机采集资产）

```
snap(taken_at, n_matches, digest, changed)                        -- 每次抓取一行
quote(taken_at, match_id, match_num, kickoff, league,
      home, away, market, line, h, d, a, status)                  -- 每场每盘口一行
```

- `market` = `胜平负` / `让球`；`line` = 让球数（如 `-1` / `+1` / `+2`）
- 显示的概率 = **去水**（复用 `scripts/devig.py` 的 `devig()`），与站内其它脚本同口径
- ⚠️ 让球盘三档顺序按竞彩原序（主让 `-N` 时依次是「打穿 / 走盘 / 让负」）→ 看位移前先确认 `line` 符号

## 和现有东西怎么配合

- **R35 位移表**：以前靠人工粘多时点，现在 `move` 直接出「首 → 末 + 变化点 + 净位移 pp」。
- **赛后校验**：位移 + 赛果（`python scripts/sporttery_fetch.py results …`）能回答
  「临场大位移的场次，结果站在哪边」——这是 `📚知识库/赛后校验/` 目前空白的一类样本
  （`prob_log.tsv` 只记模型与市场概率，没有位移维度）。
- **可以省掉的第三方 API**：本库 + 竞彩官方源已经覆盖「在售场次 + 定价 + 赛果 + 特征/伤停/射手」。
  真正还缺的只有 **≥6 场历史交锋**、**积分榜**、**xG 与事件流**（这三样免费源都拿不全）。

## 已知限制

1. 只覆盖**竞彩在售**场次（未开售/已下架的比赛没有数据）。
2. 比分盘（`crs`）、总进球（`ttg`）、半全场（`hafu`）暂**未入库**（只存胜平负与让球两档）—— 需要就说一声，加一张 `pool` 表。
3. 历史只在本机。换机器（公司 PC）不会自动带过去；要跨机保留，可加「每月导出 CSV 随 git 提交」。
4. 概率是**去水口径**，不含任何规则修正（修正按 `📚知识库/模型脚本/修正规则.md` 叠加）。
