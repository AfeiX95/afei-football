# AFEI 足球分析引擎 — 工作流与技能总结

> **版本：v2.1 | 最后更新：2026-06-28**
> **用途：给其他Agent读取使用的快速参考指南**

---

## 一、核心设计原则

1. **只用可观测变量** — 赔率、比分、xG、战绩、伤停。不用"资金流""庄家意图"等不可观测伪变量
2. **Edge>3%才出单** — 没有正期望不下注
3. **泊松是核心** — 所有概率推导必须经过泊松计算，禁止拍脑袋
4. **品牌溢价必须修正** — 传统强队系统性高估，弱队系统性低估
5. **轮换/默契必须量化** — 影响λ值15-30%
6. **输出固定结构** — 每场比赛完全相同的格式，即插即用
7. **⚠️ 竞彩是固定赔率市场** — 不是Betfair交易所，"资金流""Sharp Money""盘口操控"等概念不适用

---

## 二、引擎架构（单页六层）

```
L0: 数据输入（战力+赔率+盘口+战意）
L0.5: 战略目标判断（淘汰赛修正）
L1: xG模型（Poisson概率）
L2: 市场隐含概率（赔率→概率）
L3: Edge检测（模型 vs 市场）
L4: Kelly仓位 + 出单
```

## 三、完整工作流

### 步骤1：数据收集（L0）

**数据源：**
- 懂球帝API：`https://api.dongqiudi.com/data/tab/league/new/61`（世界杯比赛数据）
- 懂球帝新闻API：`https://api.dongqiudi.com/app/tabs/iphone/1.json`（最新新闻）
- 竞彩网截图：用vision工具分析赔率、盘口、伤停
- 咪咕视频：赛程、淘汰赛对阵

**必填数据：**
```
比赛：{主队 vs 客队}
赛事/阶段：{世界杯小组赛/淘汰赛/联赛等}
赔率：主胜___ / 平局___ / 客胜___
近10场：主队W-D-L / 客队W-D-L
场均进球：主队___ / 客队___
场均失球：主队___ / 客队___
伤停：主队缺阵人数___ / 客队缺阵人数___
```

### 步骤2：战略目标判断（L0.5）

**⚠️ 这是最关键的一步，不能跳过！**

```
比赛阶段判断 → 战略目标分析 → xG修正

淘汰赛首轮：
- 强势方（巴西/德国）：目标="90分钟解决"
- 弱势方（日本/巴拉圭）：目标="不输（拖入加时）"
- 弱势方xG修正：×0.5~0.6
- 强势方xG修正：×0.9

小组赛末轮：
- 双方均已出线：目标="控分/轮换"
- 双方xG修正：×0.7~0.8
- 平局概率大幅上升

实力接近的淘汰赛：
- 双方目标="全力争胜"
- 弱势方xG修正：×0.85
- 强势方xG修正：×0.95
```

**战略目标判定规则：**
```
弱势方目标判定：
- 淘汰赛首轮 + 实力差距大 → "不输（拖入加时）"
- 淘汰赛首轮 + 实力接近 → "全力争胜"
- 小组赛末轮 + 已出线 → "控分/轮换"
```

### 步骤3：xG计算（L1）

**xG代理公式：**
```
xG_for ≈ 场均进球 × 0.92
xG_against ≈ 场均失球 × 1.08
```

**淘汰赛修正：**
```
弱势方xG = 原始xG × 0.5~0.6（目标="不输"）
强势方xG = 原始xG × 0.9
弱势方xG = 原始xG × 0.85（目标="全力争胜"）
```

**状态修正：**
```
近5场：W+0.08 / D+0.02 / L-0.05
修正范围：±0.25
```

**身价修正：**
```
身价比>3:1 → +0.10（强势方）
身价比>2:1 → +0.05（强势方）
身价比<0.5:1 → -0.05（弱势方）
```

**λ计算：**
```
λ_home = (主队xG_for + 客队xG_against) / 2 + 主场修正(+0.15) + 状态修正 + 身价修正
λ_away = (客队xG_for + 主队xG_against) / 2 + 状态修正 + 身价修正
```

### 步骤4：泊松概率计算（L1）

**泊松公式：**
```
P(X=k) = (λ^k × e^(-λ)) / k!
```

**泊松概率速查表（常用λ值）：**

| λ | P(0) | P(1) | P(2) | P(3) | P(4) | P(5) |
|---|------|------|------|------|------|------|
| 0.5 | 60.7% | 30.3% | 7.6% | 1.3% | 0.2% | 0.0% |
| 0.8 | 44.9% | 35.9% | 14.4% | 3.8% | 0.8% | 0.1% |
| 1.0 | 36.8% | 36.8% | 18.4% | 6.1% | 1.5% | 0.3% |
| 1.2 | 30.1% | 36.1% | 21.7% | 8.7% | 2.6% | 0.6% |
| 1.5 | 22.3% | 33.5% | 25.1% | 12.6% | 4.7% | 1.4% |
| 1.8 | 16.5% | 29.8% | 26.8% | 16.1% | 7.2% | 2.6% |
| 2.0 | 13.5% | 27.1% | 27.1% | 18.0% | 9.0% | 3.6% |
| 2.5 | 8.2% | 20.5% | 25.7% | 21.4% | 13.4% | 6.7% |
| 3.0 | 5.0% | 14.9% | 22.4% | 22.4% | 16.8% | 10.1% |

**比分概率矩阵：**
```
P(比分 h-a) = P_home(h) × P_away(a)
```

**胜平负概率：**
```
P(主胜) = Σ P(h-a) 对所有 h > a
P(平局) = Σ P(h-a) 对所有 h = a
P(客胜) = Σ P(h-a) 对所有 h < a
```

### 步骤5：市场隐含概率（L2）

**欧赔→概率：**
```
P_raw = 1/odds
归一化（去除水钱）：
P_market(主胜) = (1/主胜赔) / Σ(1/odds)
P_market(平局) = (1/平局赔) / Σ(1/odds)
P_market(客胜) = (1/客胜赔) / Σ(1/odds)
```

### 步骤6：Edge检测（L3）

**Edge公式：**
```
Edge = P_model - P_market
```

**Edge分级：**
```
Edge > +6%  → 强价值（必出单）
+3% ~ +6%  → 中价值（可出单）
0% ~ +3%   → 弱价值（观察）
< 0%       → 无价值（放弃）
```

**品牌溢价修正：**
```
传统强队（荷兰/阿根廷/巴西/德国/法国/英格兰）→ 市场溢价 +3~8%
非传统强队（摩洛哥/克罗地亚/日本等）→ 市场折价 -3~6%
修正后Edge = Edge_raw + 品牌修正
```

**⚠️ 品牌折价适用边界：**
```
品牌折价在以下场景被抵消：
1. 淘汰赛弱势方（战术保守抵消品牌折价）
2. 弱势方目标是"不输"而非"赢球"
3. 盘口已充分反映品牌差异（赔率已调整）
```

**⚠️ 盘口折价识别规则：**
```
强队赔率 < 理论赔率 = 强队被折价保护（庄家看好强队）
弱队赔率 > 理论赔率 = 弱队被高估（利用不败题材分流资金）

❌ 错误解读：巴西赔率高=市场高估巴西
✅ 正确解读：巴西赔率高=庄家利用日本不败题材分流，保护巴西胜赔付
```

### 步骤7：比分EV计算（L3）

**EV公式：**
```
EV = 模型概率 × 赔率 - 1
EV > 0 → 正期望（可下注）
EV > 0.5 → 高价值
```

### 步骤8：Kelly仓位计算（L4）

**Kelly公式：**
```
b = odds - 1
p = model probability
q = 1 - p
f* = (b×p - q) / b
```

**实战修正：**
```
最终仓位 = f* × 保守系数(0.5) × 冷门修正(0.6-0.8)
```

**三单结构：**
```
🟢 主单（稳健）：最高Edge方向 × 50% Kelly
🟡 副单（价值）：第二Edge方向 × 30% Kelly
🔴 冷门单（搏杀）：最大赔率方向 × 10-20% Kelly
```

## 五、关键教训（从实战中总结）

### 1. 淘汰赛弱势方xG必须砍半
```
❌ 错误：直接用小组赛进攻数据计算xG
✅ 正确：淘汰赛弱势方xG × 0.5~0.6

原因：弱势方目标从"赢球"变为"不输（拖入加时）"
```

### 2. 盘口折价≠高估
```
❌ 错误：强队赔率高=市场高估强队
✅ 正确：强队赔率高=庄家利用弱队不败题材分流，保护强队赔付

识别方法：强队赔率 < 理论赔率 = 被保护
```

### 3. 品牌折价有边界
```
❌ 错误：品牌折价是万能修正因子
✅ 正确：淘汰赛弱势方的战术保守会抵消品牌折价

适用场景：小组赛、双方战意均衡的淘汰赛
不适用：淘汰赛弱势方（目标="不输"）
```

### 4. 分析顺序不可跳步
```
❌ 错误：比赛阶段 → 直接计算xG
✅ 正确：比赛阶段 → 战略目标 → xG修正 → 概率
```

### 5. 竞彩是固定赔率市场
```
❌ 错误：分析"资金流""庄家意图""Sharp Money"
✅ 正确：只分析赔率、比分、xG、战绩等可观测变量
```

| 比赛 | 最可能比分 | 概率 | 赔率 | EV | 置信等级 |
|------|-----------|------|------|-----|---------|
| 🇧🇷巴西 vs 🇯🇵日本 | 1-0 | 13.8% | @6.25 | -0.14 | A级 |

- 淘汰赛首轮低进球概率高
- EV最高比分往往是闷平或小胜
