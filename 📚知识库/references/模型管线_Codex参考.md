## λ值估算 — 双方法

⚠️ **推荐使用"双方法λ估算"，单一方法偏差可达23pp。**

### 方法1: 实际数据法（xG代理）

```python
# xG代理公式（基于近10场或小组赛数据）
xg_for = 场均进球 × 0.92
xg_against = 场均失球 × 1.08

# 淘汰赛修正（详见Step 0.5战略目标判断）
#   强势方(目标"90分钟解决"): 进攻×0.9, 防守×0.9
#   弱势方(目标"不输拖入加时"): 进攻×0.5~0.6, 防守×0.75~0.85

# 伤停修正: 核心球员OUT → λ下调5~15%
# 状态修正: W+0.08λ/场, D+0.02λ/场, L-0.05λ/场, 上限±0.25

# λ公式（中立场地, 主场修正=0）
lambda_home = (xg_for_home_adj + xg_against_away_adj) / 2 + form_home
lambda_away = (xg_for_away_adj + xg_against_home_adj) / 2 + form_away
```

### 方法2: 市场反推法（从赔率开始）

```python
fairH = (1/hOdds) / (1/hOdds + 1/dOdds + 1/aOdds)
fairA = (1/aOdds) / (1/hOdds + 1/dOdds + 1/aOdds)
lambda_home_raw = 0.4 + fairH * 3.2   # 钳制[0.3, 3.5]
lambda_away_raw = 0.2 + fairA * 3.2   # 钳制[0.1, 2.5]
```

### 综合λ（推荐）

```python
# 双方法平均，互相校验
LAMBDA_HOME = (lambda_home_method1 + lambda_home_method2) / 2
LAMBDA_AWAY = (lambda_away_method1 + lambda_away_method2) / 2

# 如果两法偏差>0.5，说明市场定价或数据存在显著问题，偏向xG法
if abs(lambda_home_method1 - lambda_home_method2) > 0.5:
    LAMBDA_HOME = lambda_home_method1  # 偏向xG实际数据法
```

### 战略目标判断（Step 0.5 — 不可跳过）

| 比赛阶段 | 强势方目标 | 进攻修正 | 防守修正 |
|:---------|:-----------|:--------:|:--------:|
| 淘汰赛首轮（强vs弱） | 90分钟解决 | ×0.90 | ×0.85~0.90 |
| 淘汰赛首轮（弱vs强） | 不输拖入加时 | ×0.50~0.60 | ×0.85（摆大巴） |
| 实力接近淘汰赛 | 全力争胜 | ×0.85~0.95 | — |
| 小组赛末轮（已出线双方） | 控分/轮换 | ×0.70~0.80 | ×0.70~0.80 |

## Edge公式与符号规定

```python
Edge = P_model - P_market
```

| Edge值 | 含义 | 信号 |
|:------|:-----|:----:|
| Edge > +6% | 强价值 | ⭐ 模型比市场高估=有价值方向 |
| Edge > +3% | 中价值 | 🟡 |
| Edge > 0% | 弱价值 | ⚪ |
| Edge < 0% | 无价值 | ✗ 市场定价已高于模型预期 |

> ⚠️ **错误写法（已犯过）：** Edge = P_market - P_model

### 比分EV计算

```python
ev_scores = []
for (h, a), prob in score_probs.items():
    odds = score_odds.get((h, a))
    if odds and prob > 0.005:
        ev = prob * odds - 1
        ev_scores.append((h, a, prob, odds, ev))

ev_scores.sort(key=lambda x: -x[4])  # 按EV降序
```

**EV阈值：**

| EV范围 | 含义 |
|:------|:-----|
| EV > +0.50 | 强价值（市场严重低估该比分） |
| EV > +0.10 | 中价值（可小注博冷） |
| EV > 0.00 | 弱价值（正期望但薄利） |
| EV < 0.00 | 无价值（市场定价过高） |

## 主客场分离λ校正

⚠️ **不可忽略：** 球队的排名≠主场战斗力。部分球队是"客场龙"（主场胜率远低于客场），市场容易按排名惯性高估其主场λ。

### 校正方法

```python
# ❌ 错误做法（世界杯思维）：
home_win_rate = season_win_rate  # 用总胜率代替主场胜率

# ✅ 正确做法（联赛思维）：
home_win_rate = home_data['wins'] / home_data['matches']
away_win_rate = away_data['wins'] / away_data['matches']

# 主场比赛的主队λ：
λ_home = (主场进攻xG + 客队客场防守xG) / 2 + 主队形式修正
# 客场比赛的客队λ：
λ_away = (客队客场进攻xG + 主队主场防守xG) / 2 + 客队形式修正
```

### 实战案例（2026-07-05 首尔FC vs 仁川联）

| 数据 | 首尔（排名#1） | 仁川（排名#6） |
|:----|:-------------:|:-------------:|
| 总胜率 | 高（排名第1） | 中（排名第6） |
| **主场胜率** | **50%**（3胜1平2负） | — |
| **客场不败率** | — | **85.7%**（3胜3平1负） |
| 市场误判 | 主场龙（❌） | — |
| 修正前λ | 1.95 | — |
| 修正后λ | 1.71 | — |
| 仁川Edge变化 | — | +1.8pp → **+6.6pp** |

> **方向判断完全反转！** 主客场分离是K联赛/国内联赛分析的最大价值来源。

### 使用原则

- 有主场/客场分离数据的，**必须**用分离计算
- 只有赛季总数据的，标注"⚠️ 缺乏主客场分离数据"
- 亚洲联赛（K联赛、J联赛等）主客场差异可能比欧洲联赛更显著

### 休赛期vs赛季中体能差

**何时触发：** 当一方联赛已休赛≥6周，另一方联赛赛季进行中时。

| 场景 | 修正 |
|:----|:----|
| 休赛队（≥6周无正式比赛） | λ×0.90（进攻端受休赛期影响更大） |
| 赛季中队 | λ×1.02 |

**实战案例（杰尔2-2雷克维京）：** 杰尔(匈甲休赛2个月·仅有2场热身赛)HT2-1领先→下半场体能崩盘→被雷克维京(冰超赛季中)2-2逼平。Model给杰尔73.3%/Edge+14.2pp，修正后可避免此类偏差。

### 休赛期伤病窗口警告

**⚠️ 不要将休赛期前的伤病名单当作临场数据使用。** 休赛期≥7周时，伤病名单可能已发生重大变化。

| 规则 | 说明 |
|:----|:------|
| 休赛期≥6周 | 伤病列表有效性降50% |
| 伤情含"恢复训练""接近复出" | 标记为可能出战 |
| 赔率趋势与伤病列表矛盾时 | **相信赔率趋势** |

### 天气/环境λ修正

| 天气条件 | λ修正系数 | 说明 |
|:---------|:---------:|:-----|
| **高温高湿（30°C+/体感40°C+）** | **×0.90** | 无空调顶棚球场，双方进球预期均降 |
| 中度高温（26-30°C） | ×0.95 | 轻度影响 |
| 暴雨/积水 | ×0.92 | 球速变慢，传递精度下降 |

| 高海拔（>2000m） | ×0.95（客队额外-0.05） | 客队适应力差 |
| 无异常 | ×1.00 | 不用修正 |

# 基础公式
品牌溢价 = min(20, (排名差÷10)×2 + log10(身价比)×3)

## 置信度三重检查

模型产出Edge和概率后，**必须过三重检查**，否则不输出推荐方向。

### 检查1: 叙事驱动风险

```python
if model_win_pct < 40 and edge > 8:
    warnings.append("🔴 叙事驱动风险")
    confidence *= 0.5  # 置信度减半
    # 释义：胜率<40%的弱队出现Edge>+8pp通常是模型被叙事说服而非数据驱动
```

### 检查2: 过热预警

```python
if home_odds < 1.40 or away_odds < 1.40:
    warnings.append("🔴 过热预警")
    hot_side_pct -= 2
    draw_pct += 1.5
    cold_side_pct += 0.5
```

> ⚠️ 联动规则：rank_gap≥8时阈值放宽至1.50（见[R4](#r4-超低赔例外)）

### 检查3: 淘汰赛攻坚折扣

```python
if match_type == "世界杯淘汰赛" and model_win_pct > 55:
    attack_lambda *= 0.90  # 淘汰赛防守强度→强队攻城效率打折扣
```

## MC模拟注意事项

### ⚠️ 泊松模拟陷阱

**错误示范（循环体永远不执行）：**
```python
t = 1.0              # ❌ 初始值=1, while t<1 直接跳过
while t < 1:
    t -= math.log(1 - random.random()) / lam
    if t < 1: gh += 1
```

**正确写法（从0开始累加间隔时间）：**
```python
t = 0.0              # ✅ 从0开始
while True:
    t += -math.log(1 - random.random()) / lam
    if t >= 1.0: break
    gh += 1
```

**原理：** 泊松过程的到达间隔时间服从指数分布。从比赛开始时刻t=0开始累加，每次跳跃一个指数间隔，直到超过比赛时长（90分钟=1.0单位）。

**验证方法：** λ=1.73时，10万次模拟应产出约60%主胜（不是100%的0-0）。

### 敏感性分析

| 测试 | 方法 | 通过标准 |
|:----|:----|:--------|
| λ敏感性 | λ±0.2，观察概率变化 | 波动<5pp=稳定 |
| 修正前后对比 | MC重跑前后比较 | 3-10pp变化=正常范围 |

### 极端比分剔除

```python
# 当球队有对阵鱼腩部队的暴力比分时，剔除后重算
# 处理原则：
# a) 对手是小组垫底/0分出局的鱼腩 → 强烈建议剔除
# b) 暴力比分（差值≥5球） → 建议剔除
# c) 仅一场暴力分、其余场均≤2球 → 强烈建议剔除
```

### K联赛特殊变量

| 变量 | 修正幅度 | 说明 |
|:----|:--------:|:------|
