## 二、统计汇总

| 指标 | 市场共识 | 后台模型 |
|:-----|:--------:|:--------:|
| 总场次 | 17 | 17 |
| 方向正确 | **10** | **7** |
| 方向准确率 | **58.8%** | **41.2%** |
| 让球方正确 | **8/11 = 72.7%** | **4/11 = 36.4%** |
| 平局识别正确 | **4/6 = 66.7%** | **4/6 = 66.7%** |

### 关键发现

1. **市场方向准确率58.8%，模型41.2%** — 市场比模型高17.6个百分点
2. **让球方判断：市场72.7% vs 模型36.4%** — 市场在让球判断上碾压模型
3. **平局识别：双方都是66.7%** — 平局判断是模型唯一不输的领域
4. **模型系统性低估主队** — 在17场中，模型有8场低估主队概率

## 四、关联规则

### 规则1：市场方向优先原则

```
IF 市场最低赔率方向 = 主胜 AND 模型最高概率方向 ≠ 主胜
THEN 检查模型是否过度修正（伤停/魔咒等）
建议：以市场方向为基准，模型做微调而非反转
```

### 规则2：让球盘信任原则

```
IF 竞彩开出让球-1 AND 市场让球方赔率 < 1.80
THEN 让球方赢盘概率 > 55%（市场共识）
建议：模型对让球方的修正幅度不超过-15pp
```

### 规则3：低赔保护原则

```
IF 市场最低赔率 < 1.60
THEN 该方向实际发生概率 > 60%
建议：模型对该方向的修正不超过-10pp
```

### 规则4：平局识别保留原则

```
IF 市场平局赔率在 2.80-3.50 之间
AND 模型平局概率 > 30%
THEN 平局概率保留模型值（模型在平局判断上不输市场）
```

## 五、模型迭代方向

### 5.1 短期修正（立即执行）

1. **降低伤停λ修正幅度** — C18已生效（×0.50）
2. **引入市场基准线** — 模型输出必须与市场方向对齐，偏差>20pp时自动修正
3. **让球方保护** — 模型对让球方的修正上限设为-15pp

### 5.2 中期优化（下批次执行）

1. **市场共识权重** — 在14维评分卡中新增「市场定价」维度，权重10-15%
2. **偏差回测机制** — 每次模型输出后，与市场对比，偏差>15pp时触发人工审核
3. **让球盘数据训练** — 用历史让球盘数据训练模型，提高让球判断准确率

### 5.3 长期架构（模型升级）

```
V1: 纯泊松模型（λ+14维修正）
V2: 泊松+修正规则（C01-C20）← 当前
V3: 泊松+修正规则+市场共识校准 ← 下一步
V4: 机器学习融合（泊松+市场+舆情+伤停）
```

## 六、核心结论

> **市场共识是「集体智慧」，模型是「个人判断」。**
> 
> 在17场对比中，市场方向准确率58.8%，模型41.2%。
> 市场在让球判断上碾压模型（72.7% vs 36.4%）。
> 模型唯一不输的领域是平局识别（双方都是66.7%）。
> 
> **最佳策略：以市场方向为基准，模型做微调。**
> 当模型与市场方向一致时，信心最高；
> 当模型与市场方向相反时，需要额外验证（可能是模型过度修正）。
