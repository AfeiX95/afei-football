# 14维评分卡框架 v1.0

> 核心逻辑：基础λ值（泊松） + 14维修正 = 最终λ值 → 概率矩阵
> 评分范围：-2 到 +2（每维±0.05~0.15 λ修正量）
> 总修正量控制在 ±0.4 以内，防止过度拟合

## 评分汇总规则

### 步骤1：基础λ值（泊松）
```
λ₁_base = 主队主场场均进球 × 客队客场场均失球 ÷ 联赛场均
λ₂_base = 客队客场场均进球 × 主队主场场均失球 ÷ 联赛场均
```

### 步骤2：14维逐项评分
每维评分 ∈ {-2, -1, 0, +1, +2}，对应λ修正量见上表。

### 步骤3：加权汇总
```
Δλ₁ = Σ(维度评分 × 修正量 × 模块权重)
Δλ₂ = -Δλ₁ × 0.6  (客队修正取反向60%)
```

### 步骤4：约束与输出
```
λ₁_final = clip(λ₁_base + Δλ₁, 0.3, 3.5)
λ₂_final = clip(λ₂_base + Δλ₂, 0.1, 2.5)
```
总修正量 |Δλ₁| ≤ 0.4，超出部分按比例缩放。

### 步骤5：泊松概率矩阵
```
P(主胜) = Σ P(i>j) × 100%
P(平局) = Σ P(i=j) × 100%
P(客胜) = Σ P(i<j) × 100%
```

## 文章/报告选用规则

### 分析报告（全量14维）
- 完整输出所有14维评分明细
- 每维度给出评分理由
- 汇总表 + 最终λ值 + 概率矩阵

### 头条文章（精选5-6维）
- ⚔️ 战意（模块三·维度9）
- 📊 基础数据（模块一·维度1+2）
- 🤕 伤停（模块一·维度3）
- ⚔️ 关键对位（模块二·维度5+6）
- 💰 信号（市场对比）
- 📅 赛程（模块三·维度10）

- 概率矩阵 + 比分表
