## 二、规则详解

### C01 五五开平局上浮
- **触发条件**：两队实力评分差<0.5，赔率差<0.3
- **修正量**：平局概率+5-8pp
- **逻辑**：实力接近的比赛平局概率被系统性低估

### C02 欧战主队λ下调
- **触发条件**：欧冠/欧联资格赛阶段
- **修正量**：主队λ×0.85，叠加联赛级别惩罚（非五大联赛再×0.90）
- **逻辑**：欧战资格赛主队优势比联赛弱，客场球队备战更充分

### C03 赛季过渡期修正
- **触发条件**：联赛新赛季前3轮 / 休赛期后首场
- **修正量**：近期数据权重降低30%，上赛季数据权重提升
- **逻辑**：新赛季初期球队状态不稳定

### C04 巴甲平局系数
- **触发条件**：巴甲赛事
- **修正量**：平局系数提至0.30（常规0.25）
- **逻辑**：巴甲平局率系统性偏高

### C05 升班马客场惩罚
- **触发条件**：升班马客场作战
- **修正量**：客队λ×0.80
- **逻辑**：升班马客场适应能力差

### C06 低赔主胜下调
- **触发条件**：主队赔率<1.40
- **修正量**：主胜概率-3-5pp
- **逻辑**：低赔主胜被市场过度乐观

### C07 欧冠资格赛小联赛λ修正
- **触发条件**：欧冠资格赛 + 球队来自非五大联赛
- **修正量**：λ×0.70
- **逻辑**：小联赛数据在欧战场完全失效

### C08 平局概率全局上浮
- **触发条件**：全赛事通用
- **修正量**：平局概率+15-18pp
- **逻辑**：模型系统性低估平局

### C09 让球-1赢盘修正
- **触发条件**：竞彩开出让球-1
- **修正量**：让球-1方概率-12-15pp
- **例外（v1.3 新增）**：让-1方为「状态正常强队（近3场≥2胜 + 无欧战周中分心）+ 主场 + 对手实力差真实（升班马/伤停≥5人/排名明显下风）」→ **不默认下调**
- **逻辑**：让球-1方赢盘率持续低于预期；但 Batch #23/#24 连续两批赢盘率 67%/50%（合计 11/20=55%），赢盘集中强队主场，输盘集中中游/状态差/杯赛首回合——需按实力分档

### C10 半场0:0平局上浮
- **触发条件**：半场比分为0:0
- **修正量**：下半场平局概率+10pp
- **逻辑**：半场0:0后双方趋于保守

### C11 低赔客胜对称修正
- **触发条件**：客队赔率<1.40
- **修正量**：客胜概率-3-5pp
- **逻辑**：低赔客胜同样被市场高估

### C12 让球-1方全面溃败
- **触发条件**：所有让球-1方
- **修正量**：概率下调12-15pp（强队主场例外同 C09：不默认下调）
- **逻辑**：Batch #14验证让球-1赢盘率仅14.3%；后续批次累计约32-34%仍成立，但强队主场场景赢盘率显著更高（见 C09 例外）

### C13 欧冠资格赛让球方零胜
- **触发条件**：欧冠资格赛让球方，且主队定价≥1.40（小联赛让球方为主）
- **修正量**：概率下调20-25pp
- **逻辑**：Batch #14验证4场0%赢盘率；Batch #17起限定适用：费内巴切1.24让-1打出2-0，主队定价<1.30的传统强队大热由C21接管，不再下调

### C14 平局基础上浮
- **触发条件**：全赛事
- **修正量**：平局基础概率提至38-40%
- **逻辑**：Batch #14验证平局率50%

### C15 大热主队让-1冷门陷阱（分两档+实力分档，v1.3）
- **触发条件（C15a）**：主队赔率<1.50 + 让球-1（无条件）
- **触发条件（C15b）**：主队赔率1.50-2.00 + 让球-1 + 客队近3场不败（或主队近3场<2胜）
- **修正量（C15a 默认档）**：主胜概率-20-25pp，客胜概率+15-20pp
- **修正量（C15a 强队主场例外，v1.3 新增）**：让-1方为「上季联赛前6 / 身价排名明显占优 + 主场 + 对手为升班马或伤停≥5人」→ 下调减半（-10-12pp）
- **修正量（C15a 亚洲联赛例外，v1.3 新增）**：日职/韩职主队让-1 → **不默认下调**（仅基础 -3-5pp）
- **修正量（C15b）**：主胜概率-10-15pp
- **逻辑（v1.3 更新）**：08-15~17 全量69场验证 C15a 翻车 62.5%——但 Batch #20-24 连续5批翻车率下行至约 41%（7/17），未翻车案例全部是**强队主场+实力差真实**（埃因霍温1.20/朗斯1.35/温哥华1.39/马竞1.20/东京1.42/柏1.34/赫根1.22），翻车案例是**状态平庸中游**（赫尔辛基1.47/巴西国际1.41/佐加顿斯1.31/阿贾克斯1.33）——**判定变量是让-1方实力，不是价格档位**
- **验证**：Batch #15: 江原/瓦勒伦加；08-17全量: 费耶诺德1.15/佐加顿斯1.31/阿贾克斯1.33/吉达联合1.36/伍尔弗1.38 全翻车；Batch #20-24: 累计7/17≈41%

### C16 强强对话平局上浮（降级参考信号，v1.2）
- **触发条件**：双方排名差<5 + 赔率差<0.5 + **双方近3场均≤1胜**（新增硬条件）
- **修正量**：平局概率+8-12pp（仅作参考，不再默认触发）
- **逻辑**：08-17全量验证 C16 命中率仅 3/10=30%，纯赔率差<0.5 触发过宽（纽约城/葡国民/阿森纳/海牙/弗鲁米嫩等7场未平）。降级为参考信号，不再自动叠加
- **验证**：Batch #15: 全北0-0首尔；08-17全量: 奥勒松5:5/德岛0:0/基尔2:2 仅3/10

### C17 客场胜率回归均值
- **触发条件**：客队赛季客场胜率>70% + 近3场不胜
- **修正量**：客胜概率-10-15pp，平局+8-10pp
- **逻辑**：首尔客场80%胜率但近期3连不胜（杯赛0-2+联赛1-3+0-0），赛季早期数据在样本回归后失效
- **验证**：Batch #15: 首尔0-0全北

### C24 H2H克星升级为胜信号
- **触发条件**：主队H2H不败率≥75%（近4场2胜2平0负）+ 客队近10场胜率<35%
- **修正量**：主队胜率+8-12pp（而非只给平局上浮）
- **逻辑**：Batch #18 富川3-2全北——富川H2H近4场2胜2平0负（不败率100%），模型只把H2H量化为平局倾向（平局36.8%第一），实际富川直接赢球。H2H克星在"主队实力不弱太多+客队状态差"时是胜信号而非平信号
- **验证**：Batch #18: 富川3-2全北

### C25 赛季初韩职大球上浮
- **触发条件**：韩职赛季前5轮
- **修正量**：大2.5概率+10-15pp
- **逻辑**：2026-08批信号92%大球率（23/25场≥3球）+ Batch #18富川场5球。赛季初韩职进球爆炸，小球倾向系统性错误
- **验证**：Batch #18: 富川3-2（5球）

### C26 让球-1打穿难加严
- **触发条件**：K联赛让球-1方定价≥1.70
- **修正量**：打穿概率再-5pp（叠加C09/C12之上）
- **逻辑**：Batch #15-18连续4批次验证让球-1打穿难（仁川-1让球负、蔚山-1等）。K联赛让球-1方赢盘率仅约33%
- **验证**：Batch #18: 仁川1-1金泉（仁川-1让球负）

### C27 赛季初大球上浮（降级参考信号，v1.3）
- **触发条件**：新赛季前2轮（五大联赛+主流联赛），或双方场均进球合计≥4.5
- **修正量**：大2.5概率+5-8pp（v1.2 为 +10-15pp，幅度减半）
- **状态**：参考信号（v1.2 中置信 → v1.3 低）
- **逻辑**：08-15~17全量69场大球率 78.3% 是特定窗口现象；Batch #21/#22/#24 大球率 20%/37.5%/62.5%（近三批均值约40%）——**「赛季初全联赛默认上浮」不成立**，仅强队主场碾压局贡献大球（埃因霍温/朗斯/温哥华等），意甲西甲中游互搏大量小球（尼斯0:0/巴伦西亚0:0/斯旺西0:0）
- **验证**：08-17全量: 54/69=78.3%（依据批）；Batch #21-24: 连续挑战，v1.3 降级

### C34b 决胜场大球（v1.4 转正，Batch#26/28/33 累计 10/11≈91%）
- **触发条件**：杯赛/附加赛首回合战平（0:0 或 1:1 等）→ 次回合为无退路决胜场
- **修正量**：大2.5概率+5-8pp
- **逻辑**：首回合战平 → 次回合双方都必须赢或至少净胜晋级 → 战术开放，进球数上浮
- **样本**：欧冠附加赛次回合 3/4（首回合1:1/2:2/0:0/1:1 四场均平，采列1:1唯一小球）+ 欧罗巴附加赛次回合 6/6 全大（batch28）+ 巴西杯八强次回合 1/1（格雷米奥3:1，batch33 周四007）= **10/11≈91%**
- **区分**：与 C34（首回合领先方次回合大球）互为两个机制——C34=领先方确立优势，C34b=首回合战平决胜场
- **验证**：Batch #26 两场 + Batch #28 6场全大 + Batch #33 巴西杯

### C36 客热翻车分档（v1.5 转正，Batch#30-35 累计）
- **触发条件**：
  - **中热档**：客队为热门且定价 **1.70-2.45**（客队排名不占优 / 主队主场防守尚可时优先触发）
  - **超热档**：客队为热门且定价 **≤1.50**（强队客让）
- **修正量**：
  - 中热档：**客胜 -8~12pp**，平局与主胜按比例上浮
  - 超热档：**不调整**（照常兑现，勿被"客场"标签拖累）
- **逻辑**：中热档客队多是"品牌大于实力"或"状态虚高"——市场按名气定价，主队主场抵抗力被低估；超热档客队是真实力碾压（阿森纳/阿贾克斯/波尔图/利雅新月级），客场照样兑现
- **样本**：
  - 中热档翻车 **约 6/8**：诺维奇1.83(batch32) / 柏太阳神1.95(batch32) / 勒沃库森1.73 / AC米兰1.95 / 摩纳哥2.01 / 里昂2.42 / 巴竞技2.17（batch35）
