## 一、朱雀 AIGC 检测原理（了解一下）

**朱雀（Zhuque）AI 检测助手**是腾讯的 AI 生成内容检测工具（文本+图像），入口：
- 网页版：https://matrix.tencent.com/ai-detect/ai_gen（"AI 检测助手"）
- API 版：https://matrix.tencent.com/ai-detect/ai-or-not（"supports API access"）
- 腾讯云 EdgeOne（边缘安全加速平台）接入文档：https://cloud.tencent.com/document/product/1552/135974

> ⚠️ 本机沙箱网络受限无法直连抓取文档全文，以下原理基于 AIGC 检测通用技术栈 + 公开信息整理；**接口参数/返回字段以腾讯云官方文档为准**（文末链接）。

**检测原理（四层技术栈，业界通用，朱雀同类）：**

1. **困惑度（Perplexity, PPL）**——核心指标
   - 用一个语言模型逐词计算文本的"惊讶度"：AI 生成的文本高度可预测 → 困惑度低；人类文本跳跃大 → 困惑度高。
   - 检测器判断：整篇困惑度异常低 → 像 AI。

2. **突现性（Burstiness）**——困惑度的方差
   - 人类写作"忽难忽易"：有的句子像顺口溜（低困惑），有的句子像天书（高困惑）——方差大；
   - AI 写作全程平稳：困惑度方差小——这是比平均困惑度更强的信号。

3. **多维统计特征 + 判别分类器**
   - 句长分布、词汇多样性、n-gram 统计、标点习惯、连接词密度、排比结构、书面语比例等；
   - 用标注好的「人写 vs AI写」语料微调分类器（如 RoBERTa/DeBERTa 类），或直接用大模型做判别打分。

4. **水印/溯源（部分模型支持）**
   - 若生成方模型内置水印（token 级统计签名），检测器可直接溯源到具体模型；无水印则靠前三种。

**朱雀落地形态**：云端 API（EdgeOne 接入）——传文本，返回 AI 生成概率/判定 + 置信度；批量、低延迟，适合内容平台做发布前审查。**对公众号文章是权威判定源，但需要腾讯云密钥（按量付费）。**

## 二、本地检测工具（免费、零依赖、离线）

```bash
python 📚知识库/模型脚本/ai_detect.py 文章.md          # 报告 + 可疑句TOP
python 📚知识库/模型脚本/ai_detect.py 文章.md --json     # JSON 输出供脚本集成
```

**七维特征**（0-1 加权合成 0-100 分）：

| 特征 | 权重 | AI 信号 | 本批实测（我们的文章） |
|:---|:---:|:---|:---|
| 句长均匀性（变异系数CV） | 0.25 | CV<0.35 均匀 | 0.61-0.75（我们变化大 → 0 分 ✅） |
| 书面连接词密度 | 0.15 | 然而/因此/此外 密集 | 0.03-0.05（干净 ✅） |
| AI 套话短语命中 | 0.20 | 值得注意的是/综上所述… | 0（无 ✅） |
| 语气词/口语密度 | 0.15 | 人类更多（反向） | 我们偏少（该维拉满 ⚠️ 校准点） |
| 破折号/冒号密度 | 0.10 | AI 爱用 —— ： | 1.5-1.6/100字（我们确实爱用 ⚠️） |
| 排比结构 | 0.10 | 相邻短句同开头 | 0.06（低 ✅） |
| 节奏平缓度（相邻句长变化） | 0.05 | 人类起伏大（反向） | 0.61-0.73（起伏大 ✅） |

**判定阈值**：<30 低（像人写）/ 30-55 中（有痕迹）/ >55 高（必须降）。

**实测结果（2026-08-29）**：
- 利物浦vs诺丁汉 头条深度版：**22.1 低** ✅
- 三场豪门热度扫描：**22.2 低** ✅（可疑句仅剩配图关键词超长句，属正常）
- 全维度分析文件（未降AI）：21.4 低——**启发式在我们自家文风内不分层**（我们本就句长多变、无套话），它真正防的是典型 AI 文本（句长均匀+连接词+套话密集）

**局限性（诚实说明）**：启发式 ≠ 权威；对不同文体需要重新校准阈值；对"已伪装成人类"的高质量 AI 文本可能漏检。**定位=发布前第一道快速筛，权威判定用朱雀云端 API 交叉。**

## 三、降 AI 闭环流程（接入写作管线）

```
写稿 → humanizer-zh 降AI（R10 手法）
     → python ai_detect.py 文章.md          # 本地快速筛
     → 分数 <30 → 发布；≥30 → 定位可疑句再降AI → 复测
     → （可选，重要文章）朱雀云端 API 交叉验证
```

**降 AI 重点（检测器定位的可疑句处理）**：
1. 套话短语（值得注意的是/综上所述/不难发现）→ 直接删或换口语（"说白了"）
2. 连接词密集句 → 拆短句，去掉 然而/因此/此外，改用破折号或直接并列
3. 句长均匀区（CV 低）→ 手动制造长短交替：插短句/断句（R10 断句法）
4. 超长句 → 按意群切开；破折号/冒号过量 → 保留 1-2 处即可

## 四、朱雀云端 API 接入（占位，需腾讯云密钥）

1. 开通：腾讯云控制台 → 边缘安全加速平台（EdgeOne）→ AIGC 检测（文档：`https://cloud.tencent.com/document/product/1552/135974`）
2. 密钥：SecretId / SecretKey（或子账号最小权限），按文档构造请求
3. 请求：POST 文本检测接口，body 带 content；返回 AI 概率/判定
4. 本地集成：在 `ai_detect.py` 加 `--api` 模式（requests 已可用），配置项：

```python
# ai_detect.py --api 模式占位（填密钥后启用）
TENCENT_SECRET_ID = ""       # 腾讯云 SecretId
TENCENT_SECRET_KEY = ""      # 腾讯云 SecretKey
ZHUQUE_API_URL = ""          # 按官方文档填写
```

> 接口细节未验证（沙箱网络受限），密钥和 URL 按官方文档填好后，把 `--api` 分支实现补全即可（签名用腾讯云 TC3-HMAC-SHA256）。
