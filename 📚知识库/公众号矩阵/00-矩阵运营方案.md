## 二、内容差异化矩阵

### 同一场比赛，三个号的不同写法

**以「罗森博格 vs 腓特烈」为例：**

| 要素 | 主号（深度分析） | 子号A（速读） | 子号B（数据） |
|:-----|:----------------|:-------------|:-------------|
| **标题** | 泊松分布下的主场优势量化与市场溢价校验 | 罗森博格主场龙？腓特烈客场虫！这场怎么看 | 罗森博格vs腓特烈·14维数据面板 |
| **篇幅** | 1500-2000字 | 500-800字 | 300字+3张图 |
| **核心内容** | λ值计算、概率矩阵、14维评分卡 | 一句话结论+核心逻辑+推荐比分 | 数据表格+概率饼图+关键指标 |
| **叙事风格** | 学术论文式，数据先行 | 老哥唠嗑式，结论先行 | 工具书式，图表先行 |
| **互动设计** | "你觉得模型准吗？" | "评论区猜比分，猜对请喝酒" | "截图保存，赛后来对" |

### 内容复用规则

```
主号深度分析 → 拆解为：
  ├── 子号A：提取核心结论+态度，500字速读版
  └── 子号B：提取数据表格+概率，图表版

子号A爆冷复盘 → 升级为：
  └── 主号：深度复盘+模型校验+偏差分析

子号B数据面板 → 补充为：
  └── 主号：数据来源+分析解读
```

## 三、每日生产流程

### 时间线（以工作日为例）

```
08:00  数据采集
       ├── 竞彩网API拉取赛程
       ├── 懂球帝/新球体育抓取伤停、阵容
       └── 联网核实积分榜、近期战绩

10:00  模型运算
       ├── 14维评分卡逐项打分
       ├── 泊松+蒙特卡洛跑概率
       └── 输出：概率矩阵、高概率比分、大小球

11:00  主号写作
       ├── 加载叙事池，选2-3个维度
       ├── 按「八层铁律」写作
       ├── 降AI处理
       └── 输出：头条版HTML + 公众号版MD

12:00  子号B出图
       ├── 从主号数据提取关键表格
       ├── 生成数据面板图片
       └── 输出：3张图+300字说明

12:30  主号发布 ← ⭐主力窗口

16:00  子号A写作
       ├── 从主号文章提取核心结论
       ├── 改写为老哥唠嗑风格
       └── 输出：500字速读版

17:00  子号A发布 ← 大众向窗口

20:00  子号B发布 ← 赛前数据窗口

20:30  主号复盘（如有完场比赛）
       └── 赛后复盘+模型校验

21:00  今日结束，素材归档
```

### 周末/大赛日加急流程

```
如有凌晨场（00:00-06:00开赛）：
  16:30  主号凌晨场前瞻发布
  17:00  子号A凌晨场速读发布
  次日08:00  主号赛后复盘
```

## 七、风险控制

| 风险 | 应对 |
|:-----|:-----|
| 账号关联被识别 | 三号使用不同手机、不同WiFi、不同注册信息 |
| 内容重复被限流 | 严格差异化：主号学术、子号A口语、子号B图表 |
| 模型预测翻车 | 主号定期发布「模型校验」展示客观性 |
| 合规风险 | 全文禁用博彩术语，数据来源仅标1处 |
| 过度依赖单号 | 矩阵互导流量，主号→子号A引流速读版 |
