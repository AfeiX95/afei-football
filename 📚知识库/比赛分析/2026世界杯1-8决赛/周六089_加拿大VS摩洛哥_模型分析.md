## 一、修正历程

### v1.0（原始版）
- λ: 加拿大1.063 / 摩洛哥1.490
- 结论: 加拿大27.0% / 平26.1% / 摩洛哥46.8%
- **问题：** 卡塔尔6-0极端值拉高加拿大数据，摩洛哥被低估

### v2.0（六场校验修正）
- 修正项：剔除极端值、Davies缺阵、强弱场次偏保守修正
- λ: 加拿大0.786 / 摩洛哥1.544
- 结论: 加拿大18.9% / 平25.7% / 摩洛哥55.5%
- **问题：** 未纳入更衣室变量

### v2.1（更衣室λ修正）
- 新增：摩洛哥赛前3个月换帅（Regragui→Ouahbi U20直升）
- 修正：摩洛哥λ -3~5%（压力影响创造力），加拿大λ +3%（轻松心态）
- λ: 加拿大0.800 / 摩洛哥1.500
- 结论: 加拿大20.5% / 平26.5% / 摩洛哥53.0%

### v3.0（最终版 — 加入阿根廷冷门启示）
- 新增：阿根廷1-1佛得角冷门（-2深盘品牌溢价极限）
- 启示：已出线球队轮换折扣可能需从×0.70~0.80下调至×0.50~0.60
- 摩洛哥C组第2已出线→同样适用轮换折扣逻辑
- **λ: 加拿大0.800 / 摩洛哥1.500（维持，更衣室变量已吸收折扣逻辑）**
