## 写作铁律 R1-R40（累计修正，覆盖层）
真源：`📚知识库/skills/afei-writing-standards/SKILL.md`

高频重点（完整版技能内）：
- **R19 交付只出 md**（v1.6 改写：不出 docx、不出 PDF、不出图片；保留文末 `<details>` 配图关键词块）
- R20 标题 ≤30字；R20b 数字转百分比（禁具体赔率小数）
- R23 金字塔骨架：结论前置 + 单点打透
- R25 互动钩子强制植入
- R27 合集优先格式（多场合集优于单篇）
- R28 SCA 开篇三选一（反差/数据锚/故事）
- **R29 v2 流量分层选场 + 标题公式**（2026-10-07 按 277 篇全量数据重写）：王牌=日职/日乙、韩职/韩K｜中腰=瑞超/挪超/芬超、国际赛焦点｜**降级=五大联赛**、冷门杯赛、深夜场；标题**必带让球/让步字样**，⛔ 标题结尾慎用问号
- R30 三档比分（首选/次选/防范）；R31 结构轮换；R32 字数 1200（单场 1100-1300 / 双场 1200-1600 / 多场 1200-1800）；R33 手机端排版；R34 排版表层与写法双维度轮换；R35 爆款四件套（位移表/基准线/金句缝/敢不挑边）
- **R36 标题钩子实测表 + 运营指标纪律**（2026-10-07 新增）：让球钩子 2.3–4.4× ✅必用；打包 ✅必用；**问号 ⛔**（9 月起 180 vs 696）；**平均阅读完成率不进 KPI**（与展现 Spearman −0.684）
- **R37 不向读者暴露规则内部机制**（2026-10-07 新增，用户："这些不用写到文内没啥价值"）：规则名/触发条件/修正量公式/口径分歧/豁免条款/样本批次/规则修订史**一律不写进正文**；只写「结论 + 自算基准 + 偏离」；例外仅 `⚔️战意` `💰定价信号` 元标签。⚠️ **门禁不查此项，只能自查**
- **R38 标题必含「主队vs客队」队名对位**（2026-10-11 新增）：公式 `[焦点队/对阵]+[反常数据事实]+[矛盾结论]`；反差点 ≤12 字（超长先砍反差点不砍队名）；日期短格式 `10/8`；**字数仍 ≤30 字（R20）**
- **R39 发布窗口**（2026-10-11 新增）：主档 **10:30–13:00**（75% 高 / CTR 9.0% / 中位 12,947）；**避开 16:00–19:00**（CTR 5.4% 最低）；10-12 点 vs 16-19 点 +3.16pp p<0.001；与 R36 §四互证
- **R40 运营指标台账纪律**（2026-10-11 新增，承接 R36 §五）：CTR 三档（<5% 停推 3k–6k / ≈10% 1.5-2.5 万 / 7%+大赛题材+长阅读 10 万+，峰值 229,668·21.75 元）；台账必记 **平均阅读时长 + 单篇收益(元)**（eCPM≈1.30）；🔴 **CTR 决定能否进池，题材+完读+互动决定池子多大**

## 合规替换表（写文章前必查）
| 禁用 | 替换 |
|:-----|:-----|
| 赔率 | 定价 |
| 盘口/赢盘率 | 设置/门槛/赢指率 |
| 庄家 | 机构 |
| 泊松/蒙特卡洛 | 后台模型 |
| EV | 溢价 |
| 仓位 | 配比 |
| **打穿/穿盘** | 净胜两球 / 大胜 |
| **水位** | 虚高（讨论"这块便宜是假的"时最易顺手写出） |
| **时间锚点**（今天/明天/昨天/刚刚/今晚/昨晚/本月/北京时间） | 写比赛日日期 |

⚠️ **免责豁免短语**：`远离赌博 / 远离赌球 / 理性购彩 / 理性投注` 从红线词「赌」的检测中豁免（check_article.py v1.1 起）；但 `彩票 / 博彩 / 荐彩 / 投注 / 下注 / 串关 / 稳胆 / 让球盘` 仍计入 FAIL。
⚠️ **门禁 v1.2**：第 2/3/6 项跑 `full_body()`（**含表格行与标题行**）——表格里也不能写硬禁用词、红线词、裸两位小数。
