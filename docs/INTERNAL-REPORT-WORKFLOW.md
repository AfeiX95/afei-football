## 二、A 层内部分析报告全流程（竞彩主线 · 采→补→算→报→验）

### 第 1 步：数据采集与缺失盘面补齐
```bash
python -X utf8 scripts/prematch_intel.py --date YYYYMMDD --leagues --media  # 1. 竞彩五套盘 + 积分榜 + 比赛时刻天气 + 外媒
python -X utf8 scripts/books_500.py --date YYYYMMDD                         # 2. 500.com 百家亚盘/欧赔/大小（初盘→即时）
python -X utf8 scripts/market_from_intel.py YYYYMMDD                        # 3. 聚合市场结构
python -X utf8 scripts/audit_data.py YYYYMMDD                               # 4. 入模前数据质检（阻断主客颠倒/跨季污染/重复场次）
python -X utf8 scripts/model_v3.py YYYYMMDD                                 # 5. 跑 v3.1 模型（λ_A/λ_B/λ_C + 10万次MC + 五状态EV + 台账登记）
```
**硬性补齐纪律（整合《传统足彩》模块一/二 +《足球情报》第一步）**：
1. **缺失赔率主动补齐**：若竞彩官方显示 `--` / 未开售，或 500 被 EdgeOne 拦截，**严禁跳过或凭记忆估算**——先走 `python -X utf8 scripts/_x500.py gate` 过验证，或通过联网检索补齐主流外盘欧赔（Bet365 / 澳彩 / 威廉 / 立博）与亚盘线并注明替代源。
2. **四项赛前硬核情报必查**（落入 `state/intel/<date>/_ext_<date>.json`）：
   - **关键伤停与停赛**：尤其前场支点、做墙中场、主力中卫防线缺阵（以官方/随队记者为准，无源标缺源不编）。
   - **近况与主客场反差**：全季 vs 同主客 vs 近 5 场（先去重再算），把**创造机会能力**与**临门一脚转化率**分开看。
   - **赛程密度与体能消耗**：国际比赛日后加赛、周中欧战/亚冠、长途飞行、双线/三线轮换深度。
   - **历史交锋心理与风格克制**：识别排名悬殊背后容易被忽视的反常交锋记录。
3. **全球主流媒体、预测市场与 AI/算法模型**：除 `prematch_intel --media`（DeepSeek）与 `ext_predict.py`（Sports Mole / API-Football）外，重点场次补充核查 Goal、SportsGambler、Forebet、BetBuilders xG、Polymarket 等观点，**只采信可核对口径，标明来源与日期**。

### 第 2 步：A 层内部分析报告标准结构（v3.2 · 覆盖全部 17 项维度）

由 `scripts/build_internal_report.py YYYYMMDD 周N<k>场` 生成，每场固定 **七块**，全批末尾固定 **两块**（**严禁把总结提到报告开头**）：

#### 单场七块结构（每场均齐备 17 项要素）

| 块 | 对应用户要求维度 | 核心内容与数据来源 |
|:--|:--|:--|
| **一、情报收集与利弊拆解（含天气）** | 情报收集、有利情报、不利情报、天气 | 四项硬核情报（伤停/停赛、赛程体能、临场新闻）＋ **比赛时刻天气**（自动读 `_leagues_<date>.json` 温度/降水/风速）＋ **主客有利/不利情报对照** ＋ 情报冲突提醒 |
| **二、百家欧赔、盘口变化与凯利指数** | 百家欧赔对比、盘口变化、凯利指数 | 百家代表公司 亚盘/欧赔/大小 初盘→即时对比表 ＋ 去水三向概率 ＋ 位移轨迹 ＋ **凯利指数（均值/返还率/主平客凯利方差/超标警报）** ＋ 跨盘自洽检验 |
| **三、积分形势、近期状态与战意** | 积分形势、近期状态、战意 | 积分榜排名/分差/争冠保级欧战处境（合并 `_data_` + `_leagues_` + `head.json`）＋ 真实战意定位 ＋ 同主客/近 5 场重算进失/逐场战绩（区分创造机会与转化效率）＋ 历史交锋（心理与风格克制） |
| **四、全球主流媒体及 AI 预测分析** | 全球主流媒体及 AI 预测分析 | 海外/国内主流媒体观点 ＋ 预测市场倾向 ＋ 第三方 AI/算法模型读数 ＋ 媒体与数据冲突标注（缺源明标不编） |
| **五、数学模型模拟分析预测（v3.1）** | 数学模型模拟分析预测 | A 独立模型 λ_A / B 市场联合拟合 λ_B / C 融合 λ_C（权重、数据/模型/证据三级）＋ 三向概率与 Edge(A−B) ＋ Gamma 参数区间 ＋ 亚盘/大小五状态分布与 EV（含 C50 拦截）＋ 10 万次蒙特卡洛复核与进球分布 ＋ λ±0.20 敏感性 ＋ 比分前六 |
| **六、核心矛盾、胜负手与看点** | 核心矛盾、胜负手、看点 | **核心矛盾**（拆解「该赢」与「真赢得」的落差，说明账面占优为何未必赢得痛快）＋ **胜负手**（R63 单场关键变量：赛程/战意/伤停/战术克制/应激拐点）＋ **看点** ＋ 技术面综合研判 |
| **七、单场综合分析与打破条件** | 综合分析 | **赢球概率 vs 赢球可信度分级**（`S 最敢碰` / `A 顺势可跟` / `B 赢面在但易卡壳` / `C 防平博冷` / `D 证据不足跳过`）＋ 方向站位（严守 R60/R61）＋ 剧本比分三档（首选/次选/防范，跟结论走）＋ 概率口径与足彩单/双选 ＋ **打破条件** |

#### 全批末尾两块结构（汇总排序 + ≤50 元方案）

- **八、全批多维共振总表与把握分层排序**
  1. **多维共振总表**：`场次 | 数据/证据 | 欧赔去水与凯利方差 | 融合三向 | 共振/背离定性 | 把握分级 | 站位与市场动作 | 足彩`。
  2. **多维共振 vs 背离冲突拆解**：明确列出「多维共振场（赔率/情报/媒体/模型同向，优先核心胆材）」与「背离冲突场（盘模反向/情报冲突/大热陷阱，列为防冷或剔除候选）」。
  3. **把握层次排序**：明确排出 **最敢碰 → 顺势可跟 → 赢面在但易卡壳 → 最值得防平/博冷 → 跳过不碰**，杜绝多场同向写出平行同构结论。
  4. **溢价与基线自检**：亚盘/大小 EV≥+3% 列表 ＋ 跨盘一致性基线自检 ＋ 不站方向场次统计（R49）。

- **九、50 元以内投注与比分方案（严格 A 层内部参考 · 永不上公开平台）**
  - 按竞彩单注 **2 元** 精确核算，总金额强制 **≤ 50 元**，标配两套组合：
    1. **方案 A · 稳健方向过关（建议 16–24 元）**：只选 `S/A` 级多维共振场做 2 串 1 或 3 串 1（主选单挑 + 隐患局双选防平），严禁纳入 `D` 级单腿缺数据场。
    2. **方案 B · 比分博弈 / 防冷组合（建议 20–26 元）**：用单关或小额 2 串 1 覆盖核心剧本比分（首选/次选/防冷平局），与方案 A 合计严格 **≤ 50 元**。
    3. **剔除清单与临场熔断**：写明不碰场次理由；临场首发公布若出现核心支点/中卫临时缺阵，对应场次自动熔断不跟。
  - *(注：90 分钟常规时间口径；仅作内部数据观察与思路参考，控制仓位与过关风险。)*

## 三、A 层 → B 层（头条公开稿）转化红线

从内部分析报告提炼头条公开稿时，必须执行严格的**信息脱敏与叙事重构**：

| 维度 | A 层（内部分析报告 · 留本地） | B 层（头条公开稿 · 上平台） |
|:--|:--|:--|
| **赔率 / 盘口 / 凯利** | 全量呈现百家欧赔、亚盘、大小、凯利指数与方差、EV | **零赔率、零让球行话、零机构态度解读（R41）**：不写具体小数赔率、不写「受让/平手/球半/上盘/走盘」、不编资金流向、不写凯利/EV |
| **50 元投注方案** | 完整列出注数、金额、串关、比分组合 | **严禁出现任何金额、注数、串关、押注黑话**（`押/下注/重仓/稳胆/跟单/买/投注` 全拦，免责声明同样禁含「投注」） |
| **模型与算法术语** | λ_A/λ_B/λ_C、泊松、10 万次 MC、Gamma 区间、权重 | **全面读者化（R55）**：不出现 `后台模型/泊松/蒙特卡洛/点估计/置信区间/样本量/融合权重`，转译为老球迷「阿飞」第一人称判断语言 |
| **核心矛盾与层次** | 表格 + 分级标签（S/A/B/C/D） | **反工整去 AI 味（R56/R62/R63）**：取消 `⚔️战意/💰信号` 模板行；每场围绕 R63 单场关键变量与「该赢 vs 真赢得」落差展开；避免平行排比与同构结尾；用口语化层次收尾点出最稳、最卡壳与最易出平的场次 |
| **判断与叙事纪律** | 融合概率 + Edge + 证据等级 | **严守 R60/R61**：数据权重 <0.25 只写弱倾向/观察；分歧 <5pp 不用强词；先定单场独立判断再定标题与开场；**少场精选篇（2–3 场）目标 1100–1450 字写透深度战术/核心矛盾/多维看点，多场合一篇（8–9+ 场）可放宽至 1700–1900 字**（仍须过 8/8 门禁）；破折号 ≤3、无时间锚点；比分行写 `比分推演：X比Y／X比Y／X比Y`（不写 `首选/次选/防范`，同文撞比分时第二场加尾注防 `check_dup`）；避开高频门禁误触词（`样本`→`底数/场次`、`打穿`→`突破`、`刚刚/本月`→`刚/此前`、人名含 `凯利` 改称主帅） |

**B 层出稿与审核门禁（全绿才交付）**：
```bash
python -X utf8 scripts/writing_engine.py --pick --matches N               # 1. R62 风格×结构轮换选型
python -X utf8 scripts/preflight.py "📝文章/YYYYMMDD/<文章>.md"            # 2. 字数(800-1500)+8项合规+R55视角+句长sd
python -X utf8 scripts/check_dup.py YYYYMMDD                              # 3. 同批多篇去重（0 命中）
python -X utf8 scripts/check_pub_safety.py YYYYMMDD                       # 4. A/B 分层安全闸（A层拦截+红词/表格残留扫描）
python -X utf8 scripts/check_report_consistency.py YYYYMMDD               # 5. A/B 字段级溯源复核
```
> 若属于**审核改稿场景**，交付时额外附上三段摘要：① **采纳修改项**；② **因合规红线未采纳项（附理由）**；③ **终态校验指标**（字数、破折号数、长句/句长 sd、门禁与安全闸结果）。

## 四、传统足彩（14 场 / 任九）专项模块（按需触发）

当用户浏览传足页面或指定期号分析 14 场 / 任选 9 场时，在 A 层管线上叠加以下专项模块：

1. **模块一 · 14 场盘型归类与缺失盘面补齐**：
   - 识别本期盘型：`纯五大联赛周末期` / `次级混杂大奖滚存期`（德乙/法乙/荷乙/英冠占比高）/ `周中欧战杯赛期` / `国家队比赛日期`。
   - 凡官方显示 `--` 缺失赔率的场次，**必须联网补齐主流外盘欧赔**，不得跳过。
2. **模块二 · 14 场多维共振总表**：
   - 按「场次 | 联赛 | 对阵 | 官方/外盘欧赔与凯利 | 全球媒体与市场观点 | AI/数学模型概率 | 共振/背离定性」统一建表，标出 **多维共振稳胆** 与 **背离陷阱（任九优先剔除）**。
3. **模块三 · 历史开奖宏观统计与节奏校准**（打开历史开奖页或做周期复盘时触发，一键脚本：`python -X utf8 scripts/results_review.py --end YYYY-MM-DD --days 30 --issues 30 --base 100`）：
   - 统计近 30 期与近 100 期 `3/1/0/*` 占比与场均个数，识别平局/客胜回补窗口。
   - 按「滚存 / 500 万封顶 / 100–500 万 / 5–100 万 / 5 万以下火锅奖」五档统计奖金成色，结合近 3–5 期冷热节奏判定当前处于「火锅反弹窗」还是「大奖回调期」。
4. **模块四 · 赛后单期复盘与数据沉淀**（打开赛果开奖页时触发）：
   - 奖期概览（期号、联赛结构、3/1/0 分布、一二等奖注数与奖金）→ 14 场逐场冷热归类（绝对稳胆 / 预期平局 / 心理小冷 / 核心大冷）→ 奖金成因诊断 → 跨期重合球队走势预警反哺在售期。
5. **模块五 · 分预算选场与结构校验**：
   - 任选 9 场：果断剔除 5 场最混乱/背离场 → 锚定多维共振稳胆 → 双选精准投向强队体能伤停隐患局与次级联赛平局回补局。
   - 严格校验方案 `3/1/0` 配比与精确金额（单注 2 元，任九默认 ≤32 元或按用户指定 ≤50 元封顶）。
