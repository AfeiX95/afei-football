# 写作管线速查（10步）

> 完整版在技能 `football-match-preview-pipeline` v3.0。此处为速查卡片，任何 agent 都能照着走。

## 依赖技能加载顺序（写文章前）
1. `match-model-pipeline` — 跑 λ/MC/Edge
2. `football-match-preview-article` — 写作工作流
3. `afei-writing-standards` — R1-R27 偏好覆盖
4. `humanizer-zh` — 降AI
5. `📚知识库/写作指南/叙事池.md` — 选 2-3 维度，选型记录落盘 R11

## 主流程
1. 数据采集（竞彩网官方 HTML 用户粘贴）→ 提取胜平负/让球/比分/总进球/近况/H2H/伤停
2. 14维评分卡 + 模型推演 → 落盘 `📚知识库/比赛分析/{联赛}/`
3. 提炼单场核心矛盾（单点打透 R23）
4. 叙事池选型 + 素材库拼积木
5. 文章写作（R23 金字塔骨架 / R19 白底图 docx）
6. 合规体检脚本（禁用词0/锚点0/破折号≤3/标题≤30/数字转百分比）
7. 朱雀降AI（humanizer-zh）
8. 白底图 + docx 生成（R19，背景 `#ffffff`）
9. 归档 git（分析报告 + 文章 + 选型记录 + 记忆）
10. 赛后校验闭环（football-calibration-batch）

## 铁律（写进文章前必查）
- 竞彩数据只统计 90 分钟常规时间（加时/点球不计）
- 标题 ≤30字，冲突+数字+悬念，禁堆砌队名
- 禁用词：赔率→定价 / 盘口→设置或门槛 / 庄家→机构 / 泊松·蒙特卡洛→后台模型 / EV→溢价
- 无时间锚点（今天/明天/昨天/今晚/北京时间）
- 每场必含：⚔️战意 + 💰信号 + 🌍外媒 + 推荐比分（首选-次选-防范）
- 数据来源标注仅 1 处；文末免责声明「纯属个人瞎琢磨，理性看球，远离赌博」
- 文章必须 20:00 前完成（体彩店 22 点停售）
- 模型数据文中称「后台模型」，不暴露具体算法名

## 发布窗口
- 赛前 5-8 小时发布；发文后首评置顶（带具体预测方向）
- 发文前检查图表：背景白 `#ffffff`，主队蓝 `#4fc3f7`、平局黄 `#ffd93d`、客队红 `#ff6b6b`
