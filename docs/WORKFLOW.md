## 主流程

### 1. 数据采集
- **投注页**（SPF/让球/比分/总进球/半全场）→ 市场解析先行版
- **特征分析页**（近况/H2H/积分榜/射手/伤停）→ 深度版前提
- 🔴 **页面去重惯例**：赛果页粘贴后，先 grep `📚知识库/赛后校验/` 查旧批次是否已覆盖同窗口（跨天编号如 周三/周四/周五 可能已并入早批）——只统计真正的新数据，绝不重复计 batch/totals

### 2. 市场解析（先行版）
- 全表去水：隐含概率 = (1/odds) / Σ(1/odds)；让球三向同法
- 规则标记：C15a/C15b/C35/深盘±2/客热档/平局池/C09 溃败区
- 档级推荐：深做 3 场（R27 合集优先）+ 备选 2-3 场

### 3. 模型推演（V2 引擎）
- `database/model_engine_v2.py`：`EngineV2().full_analysis(home_stats, away_stats, home_team, away_team, handicap=±1.0, odds_hk=...)`
- `home_stats = {scored, conceded, played, weight}`；纸面 = `{attack, midfield, defense, worthScore, morale}`
- 🔴 **样本质量权重惯例**：热身 2/10→0.90、4/10→0.85、5-6/10→0.75-0.80；**升班马/次级联赛+热身灌水样本→0.45-0.60**（失真悬崖，权重选择须在分析文件写明并解释）；对手质量高（vs 强队热身）可不下调
- 🔴 **临时 runner 惯例**：写 ASCII 路径（`database/`）输出 JSON，跑完即删；**emoji 路径（📝文章/📚知识库）python 子进程写入被沙箱拒**（WinError 5）
- 🔴 **引擎局限背书（必做）**：引擎无 H2H/伤停/战意输入 → 深度版必须人工补「H2H 克星 / 伤停折损 / 战意」背书，模型数字只作参照；无外媒源不编造，标"待补"
- 🔴 **模型翻转信号降权**：连续多批看空豪门时全体打折——强队让-1 打穿下修三连证伪（皇马42.6%/巴萨40.1%/米兰12.7%→全打穿）→ **强队让-1 打穿不下修**；LASK/里尔式翻转用「保护层」（受让+1）表达，不直取方向

### 4. 全维度分析落盘（14 维评分卡）
- 固定骨架：市场定价解析 → 基本面（近况/H2H/积分榜/伤停射手）→ λ三层拆解 → 赛果vs市场 Edge → 让球门槛 → 大小球 → 比分Top8 → 修正规则适用 → 外媒 → 核心结论+一句话定位+风险提示
- 落盘 `📚知识库/比赛分析/{联赛}/YYYYMMDD_编号_队名_全维度分析.md`

### 5. 提炼核心矛盾 + 叙事池选型
- 单点打透（R23）；SCA 开篇（R28，反差/数据锚/故事三选一）
- 一句话定位必须可被读者一句话复述

### 6. 文章写作（R27 合集优先）
- 合规词表；标题≤30字；数字转百分比（R20b，禁具体赔率小数）
- 每场必含 ⚔️战意 + 💰信号 + 🌍外媒 + 高概率比分（R5）
- 三场矩阵表收尾 + 互动钩子 + 数据来源(全文1处) + 免责声明

### 7. 合规体检（写完后 grep）
- 禁用词：`赔率|盘口|庄家|泊松|蒙特卡洛|EV|打穿|赢盘|北京时间|今天|明天|昨晚|今晚`
- ⚠️ 「打穿」双重含义：让球术语禁用；足球描述（"防线被打穿"）也易误读 → 统一改「空当被反击撕开」

### 8. 降AI（humanizer-zh + R10）+ AI 痕迹检测
- 口语/断句/反问/视角滑动 3-5 处不均匀分布；「难说。真说不好。」全文仅 1 次
- 🔴 **检测闭环（2026-08-29 新增）**：降AI 后跑 `python 📚知识库/模型脚本/ai_detect.py 文章.md`——分数 <30 判「低」才发布；≥30 定位可疑句（套话/连接词/句长均匀/超长句）再降再测；重要文章叠加朱雀云端 API 交叉（详见 `📚知识库/模型脚本/AI检测与降AI指南.md`）

### 9. docx 生成（R19 白底图）
- `gen_docx_*.py` 惯例：白底 `#ffffff`、主队蓝 `#4fc3f7`/平局黄 `#ffd93d`/客队红 `#ff6b6b`；matplotlib 颜色需 `#` 前缀（docx 填充不需要）
- 🔴 **沙箱惯例**：脚本输出到 ASCII 临时目录（`I:\阿飞说球\_tmp_docx_out`）→ `Copy-Item` 进 `📝文章/YYYYMMDD/`（emoji 路径写操作需一次性 `danger-full-access` 升级）；生成脚本保留在文章目录便于再生成

### 10. 赛后校验闭环（三轨）
- **轨1 窗口方向统计**：去水最大概率方 vs 实际（90分钟口径）；大球率/平局率
- **轨2 主打场次模型校验**：对照分析文件逐维度（方向/打穿/大小球/比分/平局/半场剧本）
- **轨3 文章主张校验**：md 直接读；docx 解压（Copy 成 .zip → Expand-Archive → 剥 XML）
- 产出 `📚知识库/赛后校验/batchNN_calibration.md`（总览表+主打校验+规则更新+下批清单）
- state/model-state.json 同步（batch/total_matches/direction_correct/rate/candidate_rules/active_tasks/published_articles_pending_check）
- 🔴 **候选规则回写阈值**：累计样本达标（如 C34b 决胜场大球 9/10≈90%、C35 三连证伪、C15 系列细分）→ 统一回写 `📚知识库/模型脚本/修正规则.md` + `docs/RULES.md`

## 铁律（写进任何文章前必查）
- 竞彩数据只统计 90 分钟常规时间（加时/点球不计）
- 标题 ≤30字，冲突+数字+悬念，禁堆砌队名
- 禁用词：赔率→定价 / 盘口→设置或门槛 / 庄家→机构 / 泊松·蒙特卡洛→后台模型 / EV→溢价
- 无时间锚点（今天/明天/昨天/今晚/北京时间）
- 每场必含：⚔️战意 + 💰信号 + 🌍外媒 + 高概率比分（首选-次选-防范）
- 数据来源标注仅 1 处；文末免责声明「纯属个人瞎琢磨，理性看球，远离赌博」
- 文章必须 20:00 前完成（体彩店 22 点停售）
- 模型数据文中称「后台模型」，不暴露具体算法名
