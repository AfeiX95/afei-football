## 主流程

### 1. 数据采集
- **投注页**（SPF/让球/比分/总进球/半全场）→ 市场解析先行版
- **特征分析页**（近况/H2H/积分榜/射手/伤停）→ 深度版前提
- 🔴 **页面去重惯例**：赛果页粘贴后，先 grep `📚知识库/赛后校验/` 查旧批次是否已覆盖同窗口（跨天编号如 周三/周四/周五 可能已并入早批）——只统计真正的新数据，绝不重复计 batch/totals

### 2. 市场解析（先行版）
- 全表去水：隐含概率 = (1/odds) / Σ(1/odds)；让球三向同法
- 规则标记：C15a/C15b/C35/深盘±2/客热档/**C36 客热分档**/**C37 主让-1**/平局池/C09 溃败区/**双口径失真场（放弃入文）**
- 🔴 **双口径全失真场 = 放弃入文（batch33 补录教训）**：联赛样本<2场 且 近10场热身/杯赛灌水（11:0/7:0级）时，「市场反推兜底」同样不可靠（法兰克福1.63主热→1:4惨败，市场也错）→ **排除出选题，不写进合集**；合集选场不为凑数量纳入无 Edge 失真场
- 🔴 **选场策略（R29 v2，2026-10-07 按 277 篇全量数据重写）**：**王牌**=日职/日乙、韩职/韩K 早场（标题必带竞彩编号 + 让球/让步字样）；**中腰**=瑞超/挪超/芬超、国际赛焦点；**降级**=**五大联赛**、冷门杯赛、深夜场。依据：五大联赛三个分期全部垫底（阅读中位 150/259/310，全期 96 篇占 35% 篇数、中位 192），**日职/日乙是唯一越做越强的品类**（1,076→1,022→2,055）→ 五大联赛降为「有明确结构性机会才做」（观察项 C42）。**双场打包 > 单场**（双场 1,292 > 三场+ 776 > 单场 286）。详见 `📚知识库/写作指南/头条流量分层与选题策略.md` v2.0

### 3. 模型推演（V2 引擎）
- `database/model_engine_v2.py`：`EngineV2().full_analysis(home_stats, away_stats, home_team, away_team, handicap=±1.0, odds_hk=...)`
- `home_stats = {scored, conceded, played, weight}`；纸面 = `{attack, midfield, defense, worthScore, morale}`
- 🔴 **样本质量权重惯例**：热身 2/10→0.90、4/10→0.85、5-6/10→0.75-0.80；**升班马/次级联赛+热身灌水样本→0.45-0.60**（失真悬崖，权重选择须在分析文件写明并解释）；对手质量高（vs 强队热身）可不下调
- 🔴 **临时 runner 惯例**：写 ASCII 路径（`database/`）输出 JSON，跑完即删；**emoji 路径（📝文章/📚知识库）python 子进程写入被沙箱拒**（WinError 5）
- 🔴 **引擎局限背书（必做）**：引擎无 H2H/伤停/战意输入 → 深度版必须人工补「H2H 克星 / 伤停折损 / 战意」背书，模型数字只作参照；无外媒源不编造，**直接省略该段**（不写"待补"占位）
- 🔴 **模型翻转信号降权**：连续多批看空豪门时全体打折——强队让-1 打穿下修三连证伪（皇马42.6%/巴萨40.1%/米兰12.7%→全打穿）→ **强队让-1 打穿不下修**；LASK/里尔式翻转用「保护层」（受让+1）表达，不直取方向

### 4. 全维度分析落盘（14 维评分卡）
- 固定骨架：市场定价解析 → 基本面（近况/H2H/积分榜/伤停射手）→ λ三层拆解 → 赛果vs市场 Edge → 让球门槛 → 大小球 → 比分Top8 → 修正规则适用 → 外媒 → 核心结论+一句话定位+风险提示
- 落盘 `📚知识库/比赛分析/{联赛}/YYYYMMDD_编号_队名_全维度分析.md`

### 5. 提炼核心矛盾 + 叙事池选型
- 单点打透（R23）；SCA 开篇（R28，反差/数据锚/故事三选一）
- 一句话定位必须可被读者一句话复述

### 6. 文章写作（R27 合集优先）
- 合规词表；标题≤30字；数字转百分比（R20b，禁具体赔率小数）
- 🔴 **标题公式（R29 v2 + R36）**：`[日期] + [竞彩编号] + [对阵] + 【让球/让步字样 —— 必带】 + [具象化对立]`。✅ 必带「让球/让步/让一球/让两球」（本号唯一经三时间窗验证的强钩子 2.3–4.4×）；✅ 具象化对立（克星/魔咒/平局大师/翻车隐患）；⛔ **标题结尾慎用问号**（v1 的「悬念反问」已被 277 篇数据推翻：9 月起 180 vs 696、点击率 3.0% vs 7.0%）；❌ 禁纯数字差陈述（"市场高估N个点"）。钩子实测排序见 **R36**
- 🔴 **结构轮换（R31）**：连续文章禁同款结构，可选「逐场分节 / **按判据横切** / 悬念三连问 / 双面矛盾 / 速览式」；写法也换（逐场通报 vs 对比分析 vs 判定前置）
- 🔴 **字数基准 1200（R32）**：单场 1100-1300 / 双场合集 1200-1600 / 多场合集 1200-1800；写完必跑 `python scripts/wordcount.py <文章.md>` 核对（超上限删重复铺垫与形容词，不足补战意/定价对比/风险提示）
- 🔴 **阅读排版（R33，手机端优先）**：一屏一视觉块；每段 2-4 行、每节 ≤400 字；关键结论独立成行加粗；金句用 `>` 引用块（每篇 1-2 处）；表格列数 ≤5；`---` 只切大节；结尾三件套（互动钩子→难说。真说不好。→数据来源+免责）；标准骨架见 R33
- 🔴 **每场三个比分（R30）**：首选/次选/防范 三档必给，独立成行；合集每场各自给 + 矩阵表含"高概率比分"列
- 每场必含 ⚔️战意 + 💰信号 + 高概率比分（R5）；🌍外媒**有源必写、无源省略**（R12 修订）
- 三场矩阵表收尾 + 互动钩子 + 数据来源(全文1处) + 免责声明

### 7+8. 发布门禁（合规体检 + 降AI检测 一条命令）🔴
- 写完后跑 `python 📚知识库/模型脚本/check_article.py 文章.md`（退出码 0=PASS）
- 7 项检查：标题≤30 / 硬禁用词=0（赔率、盘口、庄家、泊松、蒙特卡洛、EV、打穿、时间锚点等）/ 红线词语境确认（投注、稳赢、彩票等，免责模板"合法体育彩票"已豁免）/ 破折号≤3 / 必备要素（战意+信号+高概率比分+数据来源+免责+互动；**外媒为可选**，无源即略，门禁 v1.1 起不再判 FAIL）/ 裸赔率小数=0 / **AI 评分 <30**（内部复用 `ai_detect.py`）
- ⚠️ **乱码星号误报（2026-09-13 实测）**：第8项正则 `\*\s+\*` 会把「行尾 `**` + 空行 + 下一行行首 `**加粗**`」误判为乱码 → **写作时避免"加粗句结尾紧接空行再接加粗开头"**，改为删掉前句加粗或调整顺序
- FAIL → 修完再跑；⚠️ 红线词与 ⚠️ 段（`ai_detect.py --section`）是降AI 精确瞄准镜
- 全部 PASS 即完成交付（纯本地，不接云端 API）

### 9. 交付格式：**只出 md** 🔴（2026-09-19 用户决定）
- **所有文章交付一律只出 `.md`**，写入 `📝文章/YYYYMMDD/` → **不生成 docx、不出 PDF、不做图片文件**
- 门禁通过（8/8 PASS）即视为可发布；配图交由人工按文末 `<details>` 关键词自行搜图
- 图表需求用 **md 表格/文字**表达（不再用 matplotlib 出图）
- 原 docx 产物线（`gen_docx_*.py`、白底图、emoji 路径沙箱经验）**已停用**，保留于 `afei-writing-standards/SKILL.md` 的历史记录中备查

### 10. 赛后校验闭环（三轨）
- **轨1 窗口方向统计**：去水最大概率方 vs 实际（90分钟口径）；大球率/平局率
- **轨2 主打场次模型校验**：对照分析文件逐维度（方向/打穿/大小球/比分/平局/半场剧本）
- **轨3 文章主张校验**：md 直接读；docx 解压（Copy 成 .zip → Expand-Archive → 剥 XML）
- 产出 `📚知识库/赛后校验/batchNN_calibration.md`（总览表+主打校验+规则更新+下批清单）
- 🔴 **轨4 市场全量复盘（2026-09-13 新增，用户要求"不光模型跑过的，市场定价和赛果全部复盘"）**：每批单独产出一份 `batchNN_market_review.md`——**不看模型只看市场**，用脚本按维度统计：①热门档位分层兑现率（超超热≤1.20 / 超热1.21-1.50 / 中热1.51-2.00 / 微热2.01-2.50）②让球线类型打穿率（主让-1 / 客让-1 / 深盘-2、-3）③联赛维度（五大联赛 vs 亚洲/非主流）④冷门清单全列 ⑤附全量明细表；脚本惯例：ASCII 路径输出 txt → read 后整理进 md，脚本用完即删
- state/model-state.json 同步（batch/total_matches/direction_correct/rate/candidate_rules/active_tasks/published_articles_pending_check）
- 🔴 **候选规则回写阈值**：累计样本达标（C34b 10/11≈91%、C36 客热分档、C37 主让-1 打穿率、C15b 陷阱档）→ 统一回写 `📚知识库/模型脚本/修正规则.md`（总表+详解+叠加顺序）+ `docs/RULES.md` 索引 + state 标记"✅已转正"；**回写后须跑 JSON 校验**（尾随逗号/重复键是高频事故）

## 铁律（写进任何文章前必查）
- 竞彩数据只统计 90 分钟常规时间（加时/点球不计）
- 标题 ≤30字，冲突+数字+悬念，禁堆砌队名
- 禁用词：赔率→定价 / 盘口→设置或门槛 / 庄家→机构 / 泊松·蒙特卡洛→后台模型 / EV→溢价
- 无时间锚点（今天/明天/昨天/今晚/北京时间）
- 每场必含：⚔️战意 + 💰信号 + 高概率比分（首选-次选-防范）；🌍外媒有源必写、无源省略
- 数据来源标注仅 1 处；文末免责声明「纯属个人瞎琢磨，理性看球，远离赌博」
- 文章必须 20:00 前完成（体彩店 22 点停售）
- 模型数据文中称「后台模型」，不暴露具体算法名

## 发布窗口（2026-08-30 按流量数据修正）
- 🔴 **早场（18:00-20:30 开球）**：前日晚间 或 比赛日 **11:30 前**发出——留足 6-8 小时算法冷启动发酵期
- 🔴 **晚场（23:00+ 开球）**：比赛日 **15:00 前**发出
- 🔴 **判断窗口前必须先核实系统时间**：跑 `Get-Date -Format 'yyyy-MM-dd HH:mm:ss dddd'` 拿到当前时间与时区，再与开球时间比对——**严禁凭"用户贴的是今日赛程"就猜窗口已过/还有时间**（2026-09-19 教训：未核实时间即误报"11:30 窗口已过"，实际当时 09:48，窗口还剩 1 小时 42 分）
- 深做/文章排期按开球时间倒排；发文后首评置顶（带具体预测方向）
- 发文前检查：无「图N ×××」占位符、标签无乱码（门禁第8项）；**交付只出 md**（图表用 md 表格/文字，无图片文件）
